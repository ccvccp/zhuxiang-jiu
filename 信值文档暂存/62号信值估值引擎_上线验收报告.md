## 二、设计依据与升级定位

### 2.1 设计文档核心(用户核定)

估值逻辑从"交易定价"转向**"风险与偿债能力评估"**——AI 模型不仅
要算出资产"值多少钱", 更要回答"违约或清算时能变现多少"及"价值
波动对主体信用的影响程度":

    V_credit = V_fair × α_liquidity × β_legal × γ_stability

- α 流动性折扣: 无法快速变现的资产大幅折减;
- β 权属确定性: 质押/诉讼/争议资产信值权重降低;
- γ 价值稳定性: 高波动资产保守处理;
- 三主体差异化(事业单位合规优先/企业偿债覆盖/个人可执行性);
- 估值与信值解耦: 信值分支只算调整因子, 不参与公允价值计算;
- 报告双模板: 信值评估报告强制三章节+免责标注;
- 守护强化: 信值调整因子计算依据可追溯。

### 2.2 本站落地映射

| 设计要求 | 本站实现 |
|---|---|
| 经线"信值调整分支" | av62_credit_service.py(独立分支, 与 assess 公允引擎解耦) |
| V_fair 来源 | assess 最新记录 netContribution 绝对值(锚定评估 ID) |
| α 系数 | 复用既有 DOMAIN_LIQUIDITY 域档映射 + 角色差异化 alphaCap |
| β 系数 | 新增 legalStatus 权属封闭域(登记端点接入) |

| 中枢"双报告模板" | templateType=credit 三章节 + 免责标注 |
| 守护"审计留痕" | 审计因子链(三系数依据+数据来源)+ 事件追踪 |

## 三、功能验收清单

### 3.1 三系数与公式

| 验收项 | 验收标准 | 结果 |
|---|---|---|
| **公式合成** | V_credit = V_fair × α × β × γ(四舍五入一致性) | ✅ |
| α 流动性 | 域档映射 high 0.95 / medium 0.85 / low 0.60 / none 0.00 | ✅ |
| β 权属封闭域 | clean 1.00 / pledged 0.70 / litigated 0.40 / disputed 0.30 / **unverified 0.80(登记缺省保守)** | ✅ |
| γ 价值稳定性 | 置信档 high 0.95 / medium 0.85 / low 0.60 | ✅ |
| V_fair 锚定 | 须先完成公允估值(assess)——无评估记录 409 拒绝 | ✅ |
| 估值信值解耦 | 信值分支不修改公允评估记录; 只读取最新锚定 | ✅ |

### 3.2 三主体差异化(CREDIT_ROLE_RULES 封闭注册 6 条)

| 主体 | 域 | 规则 | 设计依据 |
|---|---|---|---|
| organization | compliance | α≤0.60 | 特许经营公共属性剥离, 仅计市场化增值 |
| enterprise | knowledge | α≤0.85 | 技术类人员流失风险折扣 |
| enterprise | behavior | V_credit≤公允×50% | 客户关系单一客户占比>30% 权重减半 |
| personal | capability | α≤0.30 | 不可转让资质原则上不计入 |
| personal | knowledge | α≤0.20 | 自媒体未实名不可转让折扣≥80% |
| personal | reputation | α≤0.20 | 个人IP未绑定MCN折扣≥80%, 负面舆情归零 |

铁律: **规则键须锚定已注册要素 (role, domain)**——启动自检强制
(RuntimeError 宪法级)。

### 3.3 信值有效性判定

## 六、工程沉淀

| 主题 | 记录 |
|---|---|
| 估值信值解耦范式 | 信值分支只算调整因子(α/β/γ), V_fair 锚定公允评估记录——二者不可混合, 信值保守性不污染公允中性(设计文档"模型分层验证"落地) |
| 规则锚定自检 | 主体差异化规则表键必须锚定封闭注册表已注册要素——启动自检强制(域外规则启动即 RuntimeError), 避免死规则 |
| 缺省保守原则 | legalStatus 缺省 unverified(β 0.80)而非 clean——权属不明按折减处理 |
| 三系数留痕 | 每系数带 basis(档位来源/权属态/置信档)+ V_fair 锚定评估 ID——金融监管可追溯性 |
| 信值数据清理 | DEL av62_credits:{id} + LREM credit_all(62号新增 credit 表) |
