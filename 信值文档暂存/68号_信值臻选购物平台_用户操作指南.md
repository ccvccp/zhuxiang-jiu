# 信值·臻选购物平台 · 用户操作指南

> 在这里, 您的诚信不是口号, 而是**看得见的资产**——它决定您看到什么好物、
> 享受多少抵扣、被邻里如何信任。我们承诺:**价格构成全透明, 永不大数据杀熟**。

---

## 一、这是什么?

信值·臻选是建立在您**真实信用**之上的购物平台:

| 概念 | 说明 |
|---|---|
| **信值雷达** | 您的五维信用画像(诚信/互助/专业/活跃/成长), 0-100 分 |
| **信值等级** | S(≥90)/A(80-89)/B(70-79)/C(60-69)/D(<60) 五档 |
| **臻选货架** | 只展示通过安全硬闸的好物, 高契合商品优先 |
| **信值抵扣** | 等级越高, 购物抵扣越多(S 级享基准价 15% 信值抵扣) |
| **邻里臻选** | 看看同城市民在买什么(仅聚合数据, 无人可见您的购买) |

**核心承诺(红线公示)**:
- 价格构成强制公示: 原价 − 信值抵扣 − 平台折扣 = 实付, 每一项可追溯;
- 同一商品对不同信值用户的价差不超过 20%, 超线自动进入审计通道;
- 您的信值抵扣永远受地板保护, 但单笔抵扣不超过商品价的 30%;
- 观测与反馈通道**永不关停**——您的意见随时可提。

## 二、信值雷达:您的信用画像

### 2.1 五个维度怎么来?

| 维度 | 权重 | 数据来源(零手工申报, 全部真实行为) |
|---|---|---|
| 诚信度 | 30% | 风险档案(违规记录按 90 天半衰期衰减) |
| 互助值 | 25% | 67号叫帮互助信值 + 帮助质量评价 |
| 专业度 | 20% | 44号评分体系(您贡献的评分质量) |
| 活跃度 | 15% | 登录与订单流水(自然使用) |
| 成长力 | 10% | 资产估值斜率(62号) |

### 2.2 看懂您的雷达

- **总分 0-100**: 分段曲线计分(及格线 50, 卓越线趋近 100);
- **硬熔断**: 任一维 < 40 → 总分封顶 59(单维短板会拖累整体);
- **软奖励**: 连续 6 个月无违规 + 互助活跃前 10% → 总分 +5;
- **新用户保护**: 注册 30 天内冷启动权重(活跃度权重上调, 诚信度下调)——
  新人不因"没记录"被低估。

### 2.3 每维"影响因素 TOP3"

雷达页每一维都展示最具体的影响因素, 例如:
> 诚信度 ↓: 因上周 1 笔订单超时 / 风险信号命中 2 次

**如何提分(确定性路径, 无捷径)**: 守约(诚信)/参与邻里互助(互助提升最快)/
发布高质量评价(专业)/自然活跃(活跃)/持续使用(成长)。

## 三、臻选货架:选好物

### 3.1 商品为什么排前面?

每个商品经过三维评估, **总分公示**:

| 维度 | 说明 |
|---|---|
| 契合度 | 商品特征×您的画像(您常参与互助→宴请/礼品类更契合) |
| 安全系数 | 硬闸检查(在售状态/违禁词/差评观察)——低于 0.6 直接拦截 |
| 转化潜力 | 同类商品的历史成交表现 |

分级: **L1 臻选位**(≥75, 货架前排) / L2 优选(≥50) / L3 普通 / L4 风险
(拦截留痕, 详情页如实告知拦截原因——**永不静默丢弃**)。

### 3.2 商品详情页看什么?

- **三维分明细**: 契合 X × 安全 X × 转化 X = 价值分 X(等级)+解释文本;
- **信值加权排序分**: 高信值用户看到的排序更贴合自身画像。

## 四、透明定价:看清每一分钱

### 4.1 价格构成卡(每个商品详情页强制公示)

```
原价 ¥268
- 信值抵扣 ¥38.19(等级S α=0.15)
- 三因子折扣 ¥13.40(信任×贡献×活动)
─────────────────
= 实付 ¥216.41
```

**您的等级越高, 信值抵扣越多**:

| 等级 | 抵扣系数 α | 例(¥268 基准价) |
|---|---|---|
| S | 15% | 约抵 ¥38 |
| A | 12% | 约抵 ¥30 |
| B | 8% | 约抵 ¥20 |
| C/D | 0 | 无抵扣 |

### 4.2 三重保护(平台红线)

1. **抵扣上限**: 单笔信值抵扣 ≤ 商品价 30%(防恶意套现);
2. **地板保护**: 折上折再深, 实付也不低于基准价 7 折(68号 α 不可
   击穿 60号三因子地板);
3. **杀熟审计**: 同商品跨用户价差 >20% 自动留痕进入审计通道
   (大数据杀熟零容忍)。

## 五、小竹导购:问不踩坑

在商品页向小竹提问, 她按 **SOP 五步法**回答:

1. **意图锚定**——听懂您问价格/求推荐/还是有疑问;
2. **信值佐证**——"您当前信值等级 S(雷达总分 95), 等级决定臻选抵扣权益";
3. **透明解释**——逐项拆解价格构成, 数字全部实时查询(无预测性数字);
4. **履约跟进**——商品口碑(月销/评分)如实展示, 风险商品直接告知;
5. **价值沉淀**——指出您最弱维度, 给出确定性成长建议。

**边界公示**(导购人格卡片 `GET /api/xinzhi/guide/personas`):
小竹是**解释者而非推销者**——不承诺降价、不诱导消费;
一切数字来自实时查询层。

## 六、邻里臻选与求购:社区一起买

### 6.1 邻里臻选频道

展示**同城市民在买的品类聚合**(多少人买过/多少单):
- **隐私红线**: 仅平台×品类聚合, 单品类不足 5 人不展示
  (您的个人购买**任何人**不可见)。

### 6.2 邻里求购(三步)

1. **发布**: 说明想买什么(可指定商品/数量/紧急度/位置);
   - 限 3 单在途(等邻里响应后再发);
   - 违禁内容(刷单/办证等)直接拒绝;
2. **响应**: 看到邻居的求购可以搭把手(您的响应仅显示脱敏昵称,
   **不留任何联系方式**——安全靠平台撮合, 不靠交换隐私);
3. **关闭**: 发起人确认解决后关闭, 记录邻里拼单碳减排
   (500g×参与人数, 并入您的碳档案)。

### 6.3 碳积分档案

您的碳积分 = 67号互助碳(公益 100%/有偿 50%/接力均摊)
+ 求购拼单碳。**只读观测, 不可交易**——它是对您环保行为的
荣誉记录, 不是货币。

## 七、商家入驻:信值认证

### 7.1 4+2 认证

| 项目 | 性质 | 说明 |
|---|---|---|
| 主体资质 | **必查** | 营业执照/许可证 |
| 履约能力 | **必查** | 仓储/物流/供货证明 |
| 服务保障 | **必查** | 售后/客服体系 |
| 后台系统 | **必查** | 库存/订单系统对接 |
| 生态贡献 | 加分(+8) | 平台生态共建 |
| 外部背书 | 加分(+6) | 第三方权威认证 |

**四必查缺一即拒**(确定性规则, 提前补齐再申请, 省时间)。

### 7.2 预演沙盘(入驻前先"试运营")

申报预期指标(日均单量/履约率/客诉率/时效达标率)→ 系统模拟
1000 单履约 → 生成**《启航报告》**:
- **信值轨迹预测**(10 段爬坡至稳态);
- **TOP3 风险**(按模拟绝对量排序: 违约/客诉/迟发);
- **成长路线图**(每项提升的分数弹性)。

> 沙盘为确定性推演(非承诺); 建议履约率 98%/客诉 ≤1%/时效 95%
> 即可稳定进入 A-S 档。

### 7.3 商家评级 S-A-B-C-D

评级分 = 认证分 + 履约分(订单结算率×28 + 好评率×18, 全平台只读
聚合——刷不出来):
- **升级**: 履约表现提升自动生效(历史留痕);
- **降级**: **永不自动**——仅生成平台内部建议书, 经人工审批总线
  裁决(给商家申诉与改进窗口, 处罚透明)。

## 八、反馈通道:意见直达(永不关停)

遇到问题随手反馈, 平台按标签**自动分流**:

| 级别 | 触发 | 响应承诺 |
|---|---|---|
| **L3 紧急** | 涉及诈骗/隐私泄露/人身安全等关键词 | **15 分钟**专人响应 |
| **L2 工单** | 物流/分数/客服/价格/商品/互助类明确问题 | 24 小时内 |
| **L1 安抚** | 情绪/无效表达 | 即时自动回复(已记录) |

提交后可随时查询进度(`GET /api/xinzhi/feedback/{id}`, 仅本人可见)。

## 九、灰度说明(为什么有的功能暂不可用?)

平台新功能按**三态灰度**渐进开放: 观察(shadow)→ 辅助(assist)。

- 若提示"决策面关闭"(409): 功能处于灰度观察期, 数据在积累,
  观察达标后开放;
- **观测面永不关停**: 您的雷达/评分/价格构成/反馈/碳档案/白皮书
  在任何阶段都可正常查看——信用透明是宪法, 不是功能。

## 十、常见问题

**Q: 我的信值分为什么比朋友低?**
A: 五维来源不同(互助活跃度/评价质量/守约记录), 雷达页每维
TOP3 影响因素写得清清楚楚——全部可解释, 无黑箱。

**Q: 同一商品我和朋友价格不一样, 是杀熟吗?**
A: 信值抵扣因等级而异(这是透明激励, 构成卡公示每一项); 但价差
超过 20% 会自动触发审计——**平台对大数据杀熟零容忍**, 超线
记录会被核查。

**Q: 信值能买卖吗?**
A: 不能。信值与碳积分均为**只读信用资产**, 不可交易不可转让
(防金融化红线)。

**Q: 商家被降级有救济吗?**
A: 有。降级永不自动执行——必须经人工审批, 且全程留痕可申诉。

**Q: 邻里能看到我买了什么吗?**
A: 永远不能。邻里频道仅展示品类聚合(<5 人品类不展示),
个体购买数据对任何人不可见。
