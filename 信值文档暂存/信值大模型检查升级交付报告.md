## 二、升级内容

### 2.1 ② 每日扫描调度器（trust45_scan_scheduler 新建）

- 扫描四件：
  1. **申诉反馈批量回流**（collect_appeal_feedback——appealFed 幂等标记，真值口径 upheld/overturned ±0.5）
  2. **学习批处理**（run_learning——产出**建议 patch 永不自动 apply**；样本不足 min_feedback 时诚实跳过，预期态非错误）
  3. 学习状态快照（learning_status）
  4. 信值主体分布快照（person/org 统计）
- 留痕三层：调度日志（docker logs）+ learning 侧建议 patch + **快照键 `trust45:daily_scan:last`**（看板/验证可查）
- 双闸 `TRUST45_SCAN_AUTO × TRUST45_MODE != off`，间隔 86400s 启动即首轮；main.py 已注册

### 2.2 ③ 看板断链修复（不新建，修通既有）

- 双 js（[trust-dashboard.js](file:///d:/网站架构设计/zhuxiang-jiu/js/trust-dashboard.js) / trust-risk-dashboard.js）apiBase 改**同源默认**（与其余七看板对齐；本地调试可手填）
- 双看板（html×2 + js×2）**首次部署生产**：404 → **200×4**

### 2.3 既有强项锁定（不重复建设）

灰度五端点（/mode /mode/override /mode/guard /mode/resume + status）与业务挂接保持零改动——升级测试专门断言其不回归。
