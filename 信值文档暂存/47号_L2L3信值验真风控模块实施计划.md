# 47号·L2/L3 信值验真风控模块实施计划 v1.0
## ——角色级风险画像 · 语义指纹 · 价值分布 · 轻量协同 · 验真回流

> 状态: 规划设计稿 · 2026-09-04
> 定位: **45号 P6(守门层)/P7(验真 v2)的"角色级纵深"**——
> 把单事件粒度的真伪鉴别升级为持续累积的风险画像, 让
> **"伪善"与"刷分"在时间维度和协同维度上无处遁形**
> 前序: P6/P7 完成了"一次提交验得准", 47号完成"一百次
> 提交看得穿"

## 一、设计理念与核心命题

### 1.1 一个核心命题

> P6 四守门与 P7 验真引擎都是**单事件/单次提交**粒度:
> 每次存证独立验真, 每次修复独立判分。但伪善与刷分的
> 本质是**行为模式**而非**单个行为**——
>
> - 单次 0.75 置信度的存证, 十连发就是刷分
> - 单看合规的每次申报, 价值分布全是小额高频就是脚本
> - 单角色干净的证据, 跨角色共享同一指纹就是团伙
>
> **47号的答案: 三层防线(入口守门→单次验真→角色画像)
> + 一张画像(累积风险视图), 并让画像回流为验真先验——
> 风险角色越提交, 通道越窄; 诚信角色越提交, 通道越宽。**

### 1.2 与既有能力的边界(不重复建设)

| 既有能力(45号 P6/P7) | 粒度 | 47号补什么 |
|---------------------|------|-----------|
| P6 consistency/selfPromotion 守门 | 单事件 delta 乘性修正 | **命中沉淀为角色画像**(累积视图) |
| P6 recurrence risk | 同因子违规计数 | 扩展为**全维度风险累积**(不只违规) |
| P7 四组件融合验真 | 单次提交置信度 | 验真结果**回流画像** + 画像作下次**先验** |
| P7 burst_ratio | 时序密度 | 补**价值分布**维度(小额高频/价值错配) |
| P7/v1 指纹 | SHA-256 精确去重 | 补**语义近似指纹**(改字重放识别) |
| (无) | — | **轻量协同分析**(团伙互证/指纹共享) |
| (无) | — | **人工复核闭环**(假阳性出口) |

### 1.3 三大理念落法(本仓惯例)

| 理念 | 落法 |
|------|------|
| 遵循规则 | 风险画像只**收窄通道**(验真起点折扣/入分折损), 不直接扣信值分; 团伙嫌疑**仅标记走人工复核**(46号审批总线范式), 不自动处罚; 全链留痕可申诉 |
| 方便快捷 | 画像自动累积(零操作); 诚信角色通道自动变宽(信任加速); 风险查询一键 |
| 智能自主 | 三检测器自动升级(单事件→角色级); 桥接 46号公平性采样(风险维度成为公平性审计的群体切面) |

### 1.4 设计红线(继承 45号宪法)

- **不新增评分档案**: 风险画像是**验真层的确定性聚合**,
  不入 28 档案结构, 不动宪法 50/30/20
- **修正只作用于 L2/L3**: L1 法治数据(司法/监管)有官方
  背书, 不走风险折损——风控对象是"自愿申报的行为资产"
- **负向不折损**: 继承 P6 铁律——风险画像只影响正向
  入分通道, 扣分/违规不折扣
- **宁可标记不可误罚**: 团伙/复用等协同信号只产生
  `suspect` 标记与通道收窄, 处罚必须走人工复核

## 三、P0:角色风险画像

### 3.1 差距

P6 守门命中与 P7 验真结果**用完即弃**——每次提交的
riskTags/组件分没有沉淀, 同一角色 20 次中等风险提交与
零风险提交在系统眼里无差别。

### 3.2 方案

**① 画像仓库**(trust_risk_profile, 双模式):

```
{trustId, riskEMA(0-1 风险指数, α=0.2 平滑),
 hitCounts{hypocrisy/self_promotion/recurrence/
           behavior_burst/semantic_reuse/value_anomaly/
           collusive_suspect},
 eventCount(参与画像的事件数), trustLevel(0-1 信任度=
   1−riskEMA 的分段映射), evidenceFingerprints{近 N 条
   指纹的桶索引(P1 消费)}, lastUpdated}
```

**② 事件回流管道**(零侵入挂钩):

- `record_event`(P6 守门命中) → 画像 hitCounts+1, riskEMA 更新
- `submit_deposit`/`submit_repair`(P7 验真完成) → 组件分
  低于阈值时沉淀对应命中; **verified 通过不加分**——画像
  只记风险不记功劳(功劳由信值分本身承载, 职责分离)
- fail-soft: 画像沉淀异常不阻断主流程(存证/修复照常)

**③ 风险指数数学**:

```
riskEMA' = riskEMA×(1−α) + risk_event×α    (α=0.2)
risk_event = 单事件风险分(0-1): 守门命中 1.0×命中数封顶 /
             P7 组件最低分 < 0.5 的维度数×0.25
trustLevel: ≥0.8 trusted / ≥0.5 standard / <0.5 watched
            / <0.3 restricted(仅标签, 不直接处罚)
```

**④ 端点(2)**: `GET /risk/{trustId}`(画像视图+命中明细+
风险历史)、`GET /risk`(全档案风险排行, 管理端)。

**测试与验收**: 专项预计 24 项(EMA 数学/回流管道零侵入/
fail-soft/信任分层) + 实机 6 项(灌事件→画像→排行 E2E)。

## 四、P1:语义指纹与价值分布

### 4.1 差距

- SHA-256 指纹只防**同文重放**——"志愿服务 200 小时
  (编号 ZY2026-088)" 改成 "志愿服务 201 小时(编号
  ZY2026-089)" 即绕过
- P7 burst_ratio 只看**频次密度**——每 3 天一次、每次
  +1.5 分的小额高频刷分, 时序完全正常

### 4.2 方案

**① 语义近似指纹**(3-gram + Jaccard, 纯标准库):

```
simhash_bag(evidence) → 字符 3-gram 集合桶(画像携带近
  100 条; 查询时与桶内逐一 Jaccard)
相似度 > 0.8 → semantic_reuse 命中(证据复用嫌疑)
  → 事件置信度 ×0.3 + 画像沉淀
```

- mock 确定性(无模型依赖); 指纹桶随画像滚动更新
- **同角色**复用是主要目标; 跨角色共享留给 P2 协同分析

**② 价值分布检测器**(角色级, 与 P7 单事件互补):

- **小额高频**: 近 30 日正向存证 ≥N 次(默认 6)且单次
  净贡献全部 < 单次中位数×0.5 → value_anomaly 命中
- **价值-证据错配**: 申报值(observed) > 同群体 P90 且
  验真组件分 < 0.7 → 同命中(高申报低证据)
- 命中 → 该次 delta ×0.5 + 画像沉淀(P6 守门同款乘性)

**③ 端点(1)**: `POST /risk/scan/{trustId}`(触发一轮
角色级检测: 语义复用+价值分布 → 命中沉淀, 幂等)。

**测试与验收**: 专项预计 26 项(3-gram 数学/改字重放
识别/小额高频构造/价值错配/阈值边界) + 实机 8 项
(灌"改字重放"序列→命中→通道收窄 E2E)。

## 五、P2:轻量协同分析

### 5.1 差距

无团伙视角——水军式刷分天然是**多角色协同**: A/B/C
三个档案互相为对方存证作证源, 或共享同一份证据文本。

### 5.2 方案(GNN 明确不落地的轻量替代)

**① 互证对分析**(基于 trust45_events 存证留痕):

```
扫描近 90 日存证事件 source=deposit 的 sources 数组:
  A 的存证 sources 含 B、B 的存证 sources 含 A → 互证对(A,B)
互证对数 ≥3 → collusive_suspect(双向画像标记)
  —— 仅 suspect 标记 + 通道收窄, 不处罚(红线④)
```

**② 跨角色指纹共享**:

```
同一 evidence 指纹/语义近似指纹出现在 ≥2 个角色 →
  共享标记; 单角色命中 ≥2 次共享 → collusive_suspect
```

**③ 团伙视图**: `GET /risk/collusion`(管理端: 嫌疑对
列表 + 证据链明细——互证时间线/共享指纹, 供人工复核)。

**测试与验收**: 专项预计 20 项(互证对计数/共享指纹/
阈值边界/suspect 不自动处罚断言) + 实机 6 项(三角色
灌互证序列→嫌疑标记→人工复核入口 E2E)。

## 六、P3:先验回流与复核通道

### 6.1 差距

画像目前只"看"不"用"——风险角色下次提交与首次提交
通道完全相同; 诚信角色也无加速激励; 假阳性无出口。

### 6.2 方案(本模块唯一的干预期, 显式开关)

**① 验真起点折扣**(画像 → P7 融合先验):

```
preliminary_score 初始 = trustLevel(画像信任度)
  (trusted 0.9 起步 / watched 0.5 / restricted 0.3)
  再走 P7 四组件融合——风险角色要靠证据质量爬回来,
  诚信角色天然高起点(信任加速)
```

- 挂钩点: `verify_pipeline_v2` 增加 `trust_prior` 参数
  (默认 None = 不启用, **显式激活零影响**——P7 既有
  调用与 343 项断言零改动)

**② L2/L3 入分守门**(画像 → delta 乘性修正):

```
restricted 档: 正向 delta ×0.5(通道收窄)
watched 档: 正向 delta ×0.8
trusted 档: 正向 delta ×1.1(信任加速, 与 P6 voluntary
  激励可叠乘封顶 ×1.15)
——同样显式参数激活; 负向永不折损(红线③)
```

**③ 复核通道**(45号申诉流 + 46号审批总线范式):

- `POST /risk/{trustId}/review-request`(角色申诉画像
  误判: 管理端复核 → 画像信任度人工校准 + 复核留痕)
- `POST /risk/{trustId}/calibrate`(管理端: 人工设定
  trustLevel 覆盖值 + 理由留痕——零不可逆, 可再校准)

**④ 端点(3)**: 回流开关走环境变量
`RISK_PRIOR_MODE=off|on`(默认 off——与 46号 P6 调度器
同款零影响铁律)。

**测试与验收**: 专项预计 28 项(起点折扣数学/守门乘性/
负向不折损/人工校准覆盖/开关默认 off 零影响) + 实机
8 项(风险角色提交→通道收窄 E2E→申诉→校准→恢复)。

## 八、合规与红线(宪法层)

| # | 红线 | 工程落法 |
|---|------|---------|
| 1 | **画像不处罚** | 风险画像只收窄通道/标记嫌疑; 任何信值扣减仍走既有事件流; 团伙嫌疑必须人工复核 |
| 2 | **L1 不折损** | 风控对象仅 L2/L3 自愿申报资产; 法治数据官方背书不适用 |
| 3 | **负向不折损** | 画像修正只作用于正向 delta(继承 P6 铁律) |
| 4 | **可申诉可校准** | 画像全链留痕 + 复核通道 + 人工校准覆盖(零不可逆) |
| 5 | **默认零影响** | P0-P2 纯沉淀观察; P3 回流显式开关(RISK_PRIOR_MODE=off 默认); 既有 343 项断言零改动 |

## 九、与既有模块的一致性声明

- **零不可逆**: 既有路由零改动; P7 仅加可选参数(
  trust_prior 默认 None); 画像校准可反复修正
- **不新增评分档案**: 风险画像属验真层, 不入 28 档案,
  不动宪法权重/αβγ 修复数学
- **范式复用**: fail-soft(P6/P7)/显式参数激活(P6/P7)/
  调度器开关(46号 P6)/申诉流(45号 P4)/审批留痕(46号 P0)/
  看板区块化(43-46号)/公平性采样维度(46号 P2)
- **编号衔接**: 45号子域增强模块(47号), 数据挂在
  trust45 命名空间下(trust_risk_profile 表)

## 十一、关键风险

| 风险 | 对策 |
|------|------|
| 画像误伤诚信角色 | 阈值保守(七类命中才降档)+ 复核通道 + 人工校准; EMA 平滑天然抗单次噪声 |
| 协同误报(正常互助被标记) | suspect 仅标记不处罚; 互证对阈值 ≥3; 复核看证据链 |
| 语义指纹误判(格式化证据天然相似) | 3-gram Jaccard 阈值 0.8 保守 + 只对**同角色**生效; 跨角色走人工复核 |
| 回流造成通道死锁 | 折扣是乘性不是禁入(restricted 仍可提交); 证据质量高可爬回; 信任加速对称存在 |
| 与 P6/P7 双重折损 | 入口守门与画像守门**叠乘封顶 ×0.4**(总折损不超过 60%), 防过度惩罚 |

*47号计划(2026-09-04): P6/P7 让一次提交验得准, 47号让
一百次提交看得穿——伪善是行为模式, 不是单个行为; 刷分
是时间序列, 不是单笔交易。风险画像的终点不是惩罚, 而
是通道: 让诚信者的路越走越宽, 让投机者的路越走越窄,
且永远留一条人工复核的正门。*
