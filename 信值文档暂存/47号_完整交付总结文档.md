## 一、模块概览

### 1.1 定位与核心命题

45号信值体系的验真能力(P6 守门/P7 验真引擎 v2)都是
**单事件/单次提交**粒度: 每次存证独立验真, 每次修复独立
判分。但伪善与刷分的本质是**行为模式**而非**单个行为**——

- 单次 0.75 置信度的存证, 十连发就是刷分
- 单看合规的每次申报, 价值分布全是小额高频就是脚本
- 单角色干净的证据, 跨角色共享同一指纹就是团伙

47号的答案: **三层防线(入口守门→单次验真→角色画像)
+ 一张画像(累积风险视图), 并让画像回流为验真先验——
风险角色越提交, 通道越窄; 诚信角色越提交, 通道越宽。**

### 1.2 三大理念落法

| 理念 | 落法 |
|------|------|
| 遵循规则 | 风险画像只**收窄通道**(验真起点折扣/入分折损), 不直接扣信值分; 团伙嫌疑**仅标记走人工复核**; 全链留痕可申诉 |
| 方便快捷 | 画像自动累积(零操作); 诚信角色通道自动变宽(信任加速 ×1.1); 风控查询一键 |
| 智能自主 | 三层检测器自动升级(单事件→角色级); 画像回流验真先验; 桥接 46号公平性(风控自身的公平性审计) |

### 1.3 平台参照与本仓创新

| 参照 | 借鉴点 |
|------|--------|
| 45号 P6 UEBA 守门 | 命中沉淀画像范式、乘性修正范式 |
| 45号 P7 验真引擎 v2 | 组件分/风险标签、显式参数激活零影响 |
| 45号 P4 申诉流 | 复核通道范式(单待复核/审批留痕) |
| 46号 P2 公平性 | tier 维度采样桥接 |
| UEBA(用户与实体行为分析) | 反事实基线、角色级累积画像 |
| **本仓创新** | **语义近似指纹**(3-gram 改字重放识别, SHA-256 只防同文不防改字) + **窗口外基线小额高频检测** + **互证对团伙识别**(GNN 明确不落地的轻量替代) + **画像先验回流**(风险角色通道收窄/诚信角色信任加速) |

### 1.4 一句话内核

> **画像的终点不是惩罚, 而是通道: 让诚信者的路越走越宽,
> 让投机者的路越走越窄, 且永远留一条人工复核的正门。**

## 三、各期交付明细

### P0 · 角色风险画像(★★★ 累积地基)

- **画像仓库**(trust47_risk_profiles, 双模式):
  `{trustId, riskEMA(0-1 风险指数, α=0.2 平滑), hitCounts
  (七类命中), eventCount, calibrateOverride/Note/At,
  evidenceFingerprints(P1), reviewRequests(P3), riskHistory
  (滚动 20 条)}`。
- **事件回流管道**(零侵入挂钩, fail-soft——画像沉淀异常
  永不阻断主流程):
  - P6 守门命中(hypocrisy/self_promotion/recurrence) →
    tag 归一化沉淀
  - P7 验真完成(v2) → 组件最低分 <0.5 的维度数沉淀
  - **verified 通过不加分**(职责分离铁律——画像只记风险
    不记功劳, 功劳由信值分本身承载)
- **风险指数数学**:
  ```
  riskEMA' = riskEMA×(1−α) + risk_event×α    (α=0.2)
  risk_event = max(信号计数封顶 1.0,
                   组件低维数×0.25 封顶 1.0)
  trustLevel = 1 − riskEMA(带人工校准覆盖)
  分层: ≥0.8 trusted / ≥0.5 standard /
        <0.5 watched / <0.3 restricted(仅标签不处罚)
  ```
- **人工校准**: trustLevel 覆盖值 + 理由留痕, 零不可逆可
  反复修正; 重放回流不冲掉校准覆盖。

### P1 · 语义指纹与价值分布(★★★ 反刷分核心)

- **语义近似指纹**(3-gram + Jaccard, 纯标准库):
  - SHA-256 精确指纹只防**同文重放**——"编号 ZY2026-088"
    改成 "ZY2026-089" 即绕过; 3-gram 捕捉**改字重放**
  - 相似度 >0.8 → semantic_reuse 命中 → 该次存证
    delta ×0.3 + 画像沉淀
  - 指纹桶随画像滚动(100 条), grams 截断 60 防膨胀
- **价值分布检测器**(角色级, 与 P7 单事件互补):
  - **小额高频**: 近 30 日正向存证 ≥6 次且单次全部 <
    **窗口外基线中位数×0.5**(基线=30 日前正向存证;
    无基线不判——防新角色误伤; 注: 计划原文"自有中位数"
    口径数学恒假, 实现时修正为窗口外基线, 见 §九)
  - **价值-证据错配**: 申报值 > 群体 P90 且验真组件
    分 <0.7 → 命中 → delta ×0.5 + 画像沉淀
- **扫描入口**: POST /risk/{trustId}/scan 触发角色级检测,
  幂等(与最近一次 scan 留痕一致时跳过沉淀, 新存证进入
  则增量重判)。

### P2 · 轻量协同分析(★★ 团伙识别)

- **互证对分析**(基于存证 sources 留痕):
  - sources 中的角色互证引用约定 `"trust:{trustId}"`
    (B 出现在 A 的存证 sources → B 为 A 作证)
  - 双向作证 → 互证对; 互证对数 = min(双向计数)——
    完整互证回合数, ≥3 → 双方 collusive_suspect
  - 自证引用剔除(自己给自己作证不计独立源)
- **跨角色指纹共享**:
  - 精确: 同一 evSha 出现于 ≥2 角色画像指纹桶
  - 语义近似: 跨角色桶内 Jaccard >0.8(倒排索引预筛
    数学等价条件 c > (4/9)×(|A|+|B|), 免全对比较;
    条目 >5000 自动降级精确-only——MinHash LSH 外部待办)
  - 单角色共享次数 ≥2 → collusive_suspect
- **团伙视图**: GET /risk/collusion(嫌疑对列表+证据链
  明细——互证时间线/共享指纹, 供人工复核; 纯读零写入)。
- **红线④**: suspect 仅标记 + 通道收窄(P3), 零自动处罚。

### P3 · 先验回流与复核通道(★★★ 唯一干预期)

- **验真起点折扣**(画像 → P7 融合先验):
  ```
  preliminary = trustLevel×0.3 + 组件融合分×0.7
  ```
  - verify_pipeline_v2 新增 trust_prior 参数(默认 None
    **零影响**——P7 既有断言零改动)
  - 折扣是乘性不是禁入: restricted(0.3)+满分证据 →
    0.79 仍可过(风险角色靠证据质量爬回来); trusted
    天然高起点(信任加速)
- **L2/L3 入分守门**(画像 → delta 层级乘性):
  ```
  restricted ×0.5 / watched ×0.8 / standard ×1.0 /
  trusted ×1.1
  入口守门(P1)×画像守门叠乘封底 ×0.4(总折损≤60%)
  命中入口守门时信任加速失效(不叠乘)
  trusted × voluntary 加速封顶 ×1.15
  ```
  - 红线②: 仅 L2/L3 自愿申报(L1 法治数据官方背书
    不折损); 红线③: 负向/零 delta 永不折损
- **显式开关**: `RISK_PRIOR_MODE=on` 激活(默认 off——
  与 46号 P6 调度器同款零影响铁律, 运行时动态读取)。
- **复核通道**(45号申诉流范式):
  - POST /risk/{id}/review-request(角色申诉, 开放端点,
    单待复核防刷, 留痕含 tierAtRequest/riskEmaAtRequest
    风险快照)
  - POST /risk/{id}/reviews/{reviewId}/decide(管理端:
    误判确认→复核即校准留痕 / 维持原判画像不动)

### P4 · 风控看板与桥接(★★ 收官)

- **五区块聚合看板**(GET /risk/dashboard, fail-soft
  分区——单区块异常 error 留痕不阻断看板):
  - ① 风险排行(分层分布 + watched/restricted watchlist
    按风险降序)
  - ② 命中统计(七类命中汇总 + 波及档案数)
  - ③ 嫌疑视图(复用 P2 view 纯读: 嫌疑对/互证对/
    共享指纹/标记态)
  - ④ 复核队列(pending 待决 + recent 近期已决分流)
  - ⑤ 回流状态(开关态 + 四档乘数表 + 封底封顶口径)
- **46号公平性桥接**(POST /dashboard/fairness-bridge):
  画像 tier → `risk_{tier}` 分组按信值分均值上报 46号
  公平性采样(无个人标识字段, n≥5 对齐 MIN_GROUP_SAMPLES)
  ——**风控自身的公平性审计**(验证通道收窄是否在群体间
  造成系统性偏差, 防守门误伤)。
- **前端面板**: trust-risk-dashboard.html +
  js/trust-risk-dashboard.js(45号 trust-dashboard 范式
  平移: ES5/localStorage 连接/手动刷新/X-Role: admin) +
  公平性桥接按钮 + 画像追溯查询。

## 九、执行中发现并修复的缺陷(3 项)

1. **P1 小额高频检测器数学死代码**(P1-3 专项测试发现)
   ——计划原文口径"单次全部 < 单次中位数×0.5"若中位数
   取自同一窗口则恒假(至少半数样本 ≥ 中位数), 检测器
   永不命中。修正: **窗口外基线参照**(基线=30 日前正向
   存证中位数, 无基线不判——与 P7 burst_ratio"观察窗
   不足不判"同范式)。
2. **P1 scan 幂等缺失**(P1-3 发现)——重复扫描会重复
   累积 value_anomaly 计数。修正: 与最近一次 scan 留痕
   (信号+判定说明)一致时跳过沉淀, 新存证进入则增量重判。
3. **P2 实机跨轮残留**(P2-4 实机发现)——互证对分析读取
   近 90 日全量存证事件, 只清 trust47 画像键不够, 上轮
   灌入的互证环事件污染本轮嫌疑判定。修正: 验收脚本
   同时清理 zhuxiang:trust45:trust45_events:* 与
