## 二、对接背景与数据用途

- 我方为**短剧题材/热度数据消费方**：将剧集元数据与聚合指标用于站内短剧改编决策（题材研判→改编→站内引流），不做数据的二次分发或转售。
- 数据消费范围仅限：**公开元数据、聚合播放指标、公开评论摘要、剧情简介**——不涉及任何个人隐私信息。
- 我方立场：不做平台爬虫（不绕登录、不破解接口），数据一律由合规供给方（贵方）提供。

## 四、接口契约（模式 A）

### 4.1 请求

```
GET {DRAMA85_SOURCE_URL}?offset={offset}&n={n}
```

| 参数 | 类型 | 说明 |
|---|---|---|
| offset | int | 偏移量，从 0 起 |
| n | int | 单页条数（我方默认请求 50） |

> 若 `DRAMA85_SOURCE_URL` 自身已带 query（如 `?app=xxx`），我方自动以 `&` 追加上述两参数，供给方无需处理。

### 4.2 鉴权（Header）

| Header | 必需 | 说明 |
|---|---|---|
| `X-Api-Key` | 是 | 供给方签发的访问密钥 |
| `X-Timestamp` | 是 | Unix 秒级时间戳（我方每次请求实时生成） |
| `X-Source-Signature` | 可选 | 仅当双方约定启用 HMAC 签名时校验 |

**签名算法**（启用时）：

```
signature = hex( HMAC-SHA256(
    key    = secret,                       # 双方约定同值
    msg    = apiKey + timestamp + path     # 三段字符串拼接
) )
```

- `path` 为 URL 的 **path 部分（不含 query string）**，如端点为 `https://api.provider.com/openapi/dramas` 时 path = `/openapi/dramas`。
- 签名计算/复算示例见 **附录 B**。
- 双方约定时间戳容差窗口：{ ±300 秒 / 供给方默认值 }。

### 4.3 响应结构

```json
{
  "dramas": [
    {
      "title": "龙王归来第一季",
      "platforms": ["douyin", "kuaishou"],
      "episodes": 80,
      "durationSec": 95,
      "tags": ["战神归来", "逆袭"],
      "metrics": {
        "plays": 2345678,
        "likes": 156000,
        "comments": 21000,
        "shares": 33000,
        "completionRate": 0.62
      },
      "commentsData": [
        {"platform": "douyin", "text": "反转太绝了"}
      ],
      "subtitleText": "[开场钩子]战神归来家产被夺。[核心冲突]全家逼迫放弃继承权。[中段反转]原来他才是真正的继承人。[结尾悬念]门后传来陌生的脚步声。",
      "structure": {
        "hook": "战神归来家产被夺",
        "conflict": "全家逼迫放弃继承权",
        "twist": "原来他才是真正的继承人",
        "suspense": "门后传来陌生的脚步声"
      }
    }
  ],
  "hasMore": true
}
```

### 4.4 条目字段明细

| 字段 | 类型 | 必需 | 约束与说明（含我方容错规则） |
|---|---|---|---|
| `title` | str | **是** | 剧名。缺失则**整条丢弃**；超 60 字我方截断 |
| `platforms` | list[str] | 否 | 上线平台（如 douyin/kuaishou/bili/wechat）。缺省 `["unknown"]`；最多取 5 个 |
| `episodes` | int | 否 | 总集数。缺省 0 |
| `durationSec` | int | 否 | 单集时长（秒）。缺省 0 |
| `tags` | list[str] | 否 | 题材标签。最多取 8 个 |
| `metrics.plays` | int | 否 | 累计播放。缺省 0 |
| `metrics.likes` | int | 否 | 累计点赞。缺省 0 |
| `metrics.comments` | int | 否 | 累计评论数。缺省 0 |
| `metrics.shares` | int | 否 | 累计分享。缺省 0 |
| `metrics.completionRate` | float | 否 | 完播率，**0–1 小数**（0.62 即 62%）。越界我方自动 clamp 到 [0,1] |
| `commentsData` | list[{platform,text}] | 否 | 热评摘要，每条 `{platform, text}`。最多取 20 条，text 超 200 字截断 |
| `subtitleText` | str | 否 | 剧情简介，含四段标注（见 4.5）。超 2000 字截断；无能力可置空（我方退化为仅元数据研判） |
| `structure` | dict | 否 | 四段结构直传 `{hook, conflict, twist, suspense}`。**优先于 subtitleText 标注解析**；供给方无此能力可省略 |
| `hasMore` | bool | 否 | 是否还有下一页。我方按 offset 递增遍历，直至返回条数 < n 或 hasMore=false |

> 除 `title` 外字段全部可选——供给方按能力提供即可，缺失不报错（我方按默认值容错）。

### 4.5 subtitleText 四段标注格式（可选能力）

```
[开场钩子]……。[核心冲突]……。[中段反转]……。[结尾悬念]……。
```

四段顺序固定、方括号标记；供给方不具备剧情结构化能力时整字段留空即可，不影响对接。

### 4.6 错误响应约定

| 场景 | 建议状态码 | 我方行为 |
|---|---|---|
| 鉴权失败 | 401 | 记日志；重试 3 次（退避）后按降级策略处理 |
| 限流 | 429 | 同上 |
| 服务异常 | 5xx | 同上 |
| 成功但数据为空 | 200 + `{"dramas": [], "hasMore": false}` | 正常结束遍历 |

## 五、模式 B：自有格式 + 字段映射

### 5.1 需供给方提供（三项）

1. **分页响应真实样例**：一份完整分页响应 JSON（含各字段的真实形态——字符串/数字/数字串/嵌套结构都要体现）；
2. **字段字典**：字段名 / 类型 / 含义 对照表；
3. **剧集数组所在层级**：如 `data.rows` / `data.list` / 顶层数组。

### 5.2 我方映射配置（供给方无需开发）

我方按样例配置 `DRAMA85_SOURCE_FIELD_MAP`（JSON，单向映射到我方契约字段），主流三风格预置模板：

| 模板 | 数组路径 | 字段风格 | 适用形态 |
|---|---|---|---|
| A | `$.data.rows` | 驼峰（dramaName/playCnt/finishRate） | 电商化数据服务 |
| B | `$.data.list` | 下划线（drama_name/play_count） | 国内开放平台/Python 系 |
| C | `$.list` | 短别名（name/pv/cmt_num） | 轻量聚合接口 |

三模板全文见 **附录 C**。

### 5.3 我方适配容错（供给方格式放宽项）

- **数字串自动转 int**：`"980000"` / `1234567.8` → int；
- **评论三形态兼容**：字符串列表 `["评论A"]` / `[{content:"评论A"}]` / 标准对象 `[{platform,text}]` 均可；
- **字段名支持点路径**：嵌套字段如 `stats.play_count` 可直接写路径；
- **缺失字段**：直接省略对应映射键，我方取默认值；
- **缺 title 条目**：自动丢弃（与契约模式一致）。

## 六、非功能要求

| 项 | 要求 |
|---|---|
| 限流阈值 | ≥ 1 QPS 即可（我方默认按 1 QPS 频控访问，可按供给方限额下调） |
| 响应超时 | ≤ 10 秒（超时我方按失败重试，共 3 次退避） |
| 数据时效 | T+1 可接受（研判场景非实时） |
| 可用性 | 建议 99%+；我方配有降级机制（`mock_fallback`），短时不可用不阻断我方业务 |
| 数据量级 | 每日增量即可，我方以 offset/n 分页遍历拉取 |

## 七、合规要求（双方红线）

1. 供给方需声明数据来源合法（自有授权采集 / 平台官方合作 / 公开数据聚合），并提供{数据来源合法性说明/授权材料}；
2. 数据不得包含个人隐私（评论需脱敏，不含用户 ID/昵称/头像等可识别信息；`commentsData.platform` 为平台名，非用户标识）；
3. 我方承诺数据仅用于站内研判决策，不二次分发、不转售；
4. 我方红线（不接受的数据获取方式）：绕登录、破解接口、采集隐私——此类数据即使提供我方也不接入。

## 八、联调与验收流程

| 步骤 | 内容 | 责任方 |
|---|---|---|
| 1 | 提供测试环境地址 + 测试凭证 + 响应样例 | 供给方 |
| 2 | 我方配置 `mock_fallback` 灰度接入（真实源失败自动降级留痕，不阻断） | 我方 |
| 3 | real 冒烟：我方触发采集（`POST /api/drama85/collect`），核对采集报告 `sourceChannel=real`、池内记录 `sourceMode=real` | 双方 |
| 4 | 试运行验收（见下方标准） | 双方 |
| 5 | 切生产（`DRAMA85_SOURCE_MODE=real`） | 我方 |

**验收标准**：

- 连续 3 天采集成功率 ≥ 95%；
- 字段完整率：title 100%，指标类（plays/completionRate）≥ 90%；
- 模式 B 需确认映射后日志 `drama85_field_map_applied rows=N` 与供给方样例条数一致。

## 附录 B：签名计算示例（Python，双方可复算比对）

```python
import hashlib, hmac

api_key = "your-api-key"
secret  = "shared-secret"          # 与供给方同值
ts      = "1760323200"             # X-Timestamp 同值
path    = "/openapi/dramas"        # URL path, 不含 query

msg = f"{api_key}{ts}{path}"
sig = hmac.new(secret.encode(), msg.encode(), hashlib.sha256).hexdigest()
# 供给方按同算法复算, 与 Header X-Source-Signature 比对
```

## 附录 C：三风格映射预置模板（模式 B）

```ini
# 模板A 嵌套data.rows+驼峰: {"data":{"rows":[{dramaName,playCnt,finishRate,hotComments,...}]}}
DRAMA85_SOURCE_FIELD_MAP={"list":"$.data.rows","title":"dramaName","platforms":"platform","episodes":"episodeCount","durationSec":"duration","plays":"playCnt","likes":"likeCnt","comments":"commentCnt","shares":"shareCnt","completionRate":"finishRate","commentsData":"hotComments","subtitleText":"synopsis"}

# 模板B 嵌套data.list+下划线: {"data":{"list":[{drama_name,play_count,completion_rate,hot_comments,...}]}}
DRAMA85_SOURCE_FIELD_MAP={"list":"$.data.list","title":"drama_name","platforms":"platform","episodes":"total_episodes","durationSec":"duration_seconds","plays":"play_count","likes":"like_count","comments":"comment_count","shares":"share_count","completionRate":"completion_rate","commentsData":"hot_comments","subtitleText":"subtitle"}

# 模板C 顶层数组+短别名: {"list":[{name,pv,finish_rate,top_comments,...}]}
DRAMA85_SOURCE_FIELD_MAP={"list":"$.list","title":"name","platforms":"platform","episodes":"ep","durationSec":"total_sec","plays":"pv","likes":"like_num","comments":"cmt_num","shares":"share_num","completionRate":"finish_rate","commentsData":"top_comments","subtitleText":"synopsis"}
```

> 契约字段 → 第三方字段；`list` 为剧集数组点路径（必需）；映射值支持字段名或点路径（如 `stats.play_count`）；缺失字段删键即可。
