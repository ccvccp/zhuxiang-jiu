## 二、公众号备案

- **入口**：微信公众平台 → 设置 → 备案（需先完成微信认证或主体验证）
- **材料**：与 ICP 备案同源（营业执照+法人/负责人证件+人脸核验+域名备案号）
- **依赖图**：ICP 备案号 → 公众号备案 →（服务号）微信认证 → 支付渠道
