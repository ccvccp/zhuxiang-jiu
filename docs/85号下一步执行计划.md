## 总路线（数据驱动，样本先行）

```
P0 周期验证(即刻) → P1 样本累积(2-4 周) → P2 建模评估(样本达标) → P3 生产层(独立产品决策)
```

**核心原则**：爆款预测是蓝图"大脑"，但 327 部/单期多源快照的量级**不足以训练稳定模型**——先用已就绪的调度链零成本累积样本，期间做趋势洞察雏形（不训练也能产出），样本达标后再评估建模。不为建模而建模。

## P2 · 爆款预测 MVP 评估与实施（样本达标后）

**85号特色约束**：播放量/完播率细粒度拿不到（登录态合规红线）→ 目标变量用**榜单观测代理**而非绝对播放量：

1. **目标变量**（三级代理，按可得性选）：①多源在榜时长（快照期数）②名次上升斜率 ③dataeye 月榜上榜与否（二分类，月度新标签）；
2. **特征表**（已就位可直接建模）：多源首曝名次/热度峰值/集数/题材标签集/contentType/is_ai_drama/入池来源数/推荐位发现标记；
3. **两步走**：无监督起步（题材带聚类 + 热度斜率分段，出《题材带×热度模式图谱》）→ 有标签评估（dataeye 上榜二分类的 AUC 基线，XGBoost/LightGBM）；
4. **产出形态**：新入池剧"多源在榜潜力分"——反哺投喂优先级（先喂哪类链）与观察赛道加权。

**验收**：二分类 AUC ≥0.68 且特征重要性可解释（题材/多源首曝名次应居前）→ MVP 成立；否则回 P1 补特征（灰豚激活可补互动指标）。
