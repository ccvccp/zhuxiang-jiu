# 短剧平台数据采集字段表（85号数据源规划）

> **定位**：基于平台梯队梳理（用户提供，2026-10 口径）+ 85号契约字段（`drama85_source_gateway`），给出每平台「可采字段 × 合规通道 × 更新频率 × 契约映射」的落地字段表。
> **数据口径说明**：文中日活/占比等数字为业务侧提供口径，选型与商务谈判时以供给方官方核实为准。

---

## 一、采集通道与合规框架（先读）

全部数据经三条**合规通道**之一进入，最终统一输出 85号标准 JSON 契约（零平台直爬）：

| 通道 | 方式 | 适用 | 红线 |
|---|---|---|---|
| **① 第三方数据服务 API**（推荐先行） | 商务采购 DataEye / 新榜 / 灰豚等，按其开放接口拉取（蝉妈妈不可用，2026-10-13 实测剔除） | 头部平台热度榜/播放/投流汇总数据 | 签数据使用协议；不转售 |
| **② 自建合规采集 worker** | 只采**公开榜单页/公开详情页**（不登录、不破接口、尊重 robots、限速 ≤1QPS、T+1 批跑） | 平台公开可见的元数据/榜单排名 | 不绕登录、不采用户隐私、不采评论者身份 |
| **③ 平台官方开放能力** | 微信小程序公开页 / B站开放接口等官方途径 | 补充性元数据 | 遵平台条款 |

**接入统一走既有底座**：任意通道产出 → 85号契约（或 `DRAMA85_SOURCE_FIELD_MAP` 映射）→ `DRAMA85_SOURCE_MODE=mock_fallback` 灰度 → real。供给方对接材料用《第三方短剧数据接口对接文档模板.md》。

>
> **分享链接结构实测（2026-10-13，样例《父亲的礼物》）**：
> - 链路：`m.wkbrowser.com/is/{分享码}/` → 302 → `m.wkbrowser.com/short_play/{itemId}/?series_rank=2&series_gid=...&app=gold_browser`（移动 UA 免登录 200）；

> - **RENDER_DATA SSR 深挖（10-13 深夜，推翻局部结论）**：`articleInfo` 结构化字段——`tomatoPlayetInfo.serialCount` 总集数（替代正文正则）、`videoDuration` **单集时长**（→durationSec，share 形态此前恒 0）、`content` **剧情简介**（→subtitleText，激活 85号四段结构化）、`videoPlayCount`/`diggCount` **当前集指标**（集级口径与红果全剧级不可比，仅探针预览不入契约 metrics）、`source`/`mediaUser.screenName` 出品方；`seoTDK.title` 剧名（剥「- 悟空浏览器」后缀）；`relatedInfo`/`commentList` 恒 null——**无推荐位**（运行时签名 API 拉取，不可采维持）；解析器三级结构：SSR 优先→正文正则回退→红果形态（专项 62/62）；
> - **不可采**：全剧级播放量/完播率/评论/推荐位（页面无或运行时签名 API）；`toutiao.com/short_play/{id}` 桌面 UA 404（og:url 为装饰性）；数据服务 `api.toutiaoapi.com` 带设备签名（按红线不逆向）；

> - **定位修正**：悟空分享链 = **单剧元数据/新剧发现通道**（一链接一剧），非批量榜单源——批量数据仍走通道①；系列榜单列表页待后续分享样例再探。
