## 二、R3+R4 复购预测精度（4 新增用例）

被测：[repurchase_predict_service.py](file:///d:/网站架构设计/zhuxiang-jiu/backend/services/repurchase_predict_service.py) 的 `predict_member` 周期计算增强（归一化 → 剔除 → 中位数/CV/qFactor 流水）。

| 用例 | 断言要点 |
|---|---|
| T14 归一化生效 | 订单 A(2 件)→40 天→B(1 件)→20 天→C(1 件)：归一化间隔 [20,20] → 周期 **20**（原始口径为 median(40,20)=30——囤货量干扰被消除的直接证据） |
| T15 数量缺失回退 | 同构造数但订单无数量字段 → 周期=30 与 T1 旧行为**逐值一致**（向后兼容锚点：本批前全部既有留痕口径不受影响） |
| T16 送礼剔除 | 归一化间隔 [20,20,100]（100 > 2×20）→ 周期 20、`giftOutliers=[100]`、CV 基于剩余两样本——**qFactor 档位不被送礼尖峰拉降** |
| T17 保护兜底 | **数学证明自然数据不可触发**（超限样本至多 ⌊n/2⌋、剔后恒 ≥⌈n/2⌉≥2，推导全文注释于用例与函数 docstring）——以脏数据（median0<0）直测 `_drop_gift_outliers` 原样回退分支，并以 [10,10,300] 纯函数+全链双对照验证正常剔除不被保护误伤 |

> 口径说明：数量字段 items[].quantity 优先 / qty 兼容、行级容错（单行非法只跳该行），与 finance_service 从量计征读取口径同源；结果留痕增 `normalized / normalizedIntervals / giftOutliers` 三字段，formula 动态标注。

## 六、结论与观察点

1. **22 项新用例 + 396 项回归全绿**，两批默认零行为变化承诺均有行为级证据锚定：R3 的 T15（旧行为逐值一致）、L3 的 None 兼容用例、Persona 的 LLM-off 论证、音色的 observe 打桩对比。
2. **本轮的方法论增量**：R4 保护分支经数学证明不可达后，测试转为「脏数据直测兜底分支 + 正常路径双对照」——将证明固化进 docstring，未来阈值收紧时证明前提变化会被 code review 捕获。
3. **观察点（后续决策输入）**：
   - R3 归一化生效后，observe 留痕的 `normalized` 占比与 `giftOutliers` 频率——若大量订单缺数量字段，推动下单链补齐 quantity 落库；
   - wouldVoice 分布（care/steady/cheerful 三档占比）积累后决策 `XIAOZHU_JOYVOICE_VOICE_MODE` 是否 enforce；
   - live 语料录入进度——运营按 category=live 录入后，L3 的 T17 场景（live 优先命中）将在生产显效，stats 的 unsolved 率应随之下降（L1 告警闭环联动）；
   - personaLine 留痕分布——LLM 轨未来开闸时 persona 行即刻生效，无第二次改造。
4. **测试形态说明**：本批新增三文件均为 pytest 形态（与 live_qa/repurchase 批对齐）；回归面 7 个脚本形态文件直跑计数，两形态并存口径沿袭上份报告标注法。
