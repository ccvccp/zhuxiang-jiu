## 七、结论与观察点

1. **四模块 62 项新用例 + 163 项回归全绿**，主链零行为变化：新能力全部 observe/on 默认（REPURCHASE_PUSH_MODE=observe / LIVE_QA_MODE=on 且只读），无任何自动触达路径。
2. **口径与安全锚点均已测试固化**：①的 `_calc_price` 逐字段对齐用例保证未来 order 价格引擎变更时测算引擎同步暴露漂移；F 组三层对齐用例使后续新增指令若漏注册任一层即红。
3. **观察点（后续决策输入）**：②observe 积累建议书分布（upcoming/overdue 占比、qFactor 分布）后决策是否 enforce；④stats 的 unsolved 率若持续高企，说明知识库直播场景覆盖不足，优先补 knowledge 条目而非调参；③feed 上线后需运营侧执行 bind-product 挂载与 UGC 审核（先审后显闸在 T5-T7 已验证）。
4. **测试形态说明**：coupon 与 xiaozhu 族为项目既有自断言脚本形态（pytest 收集为 0 属预期，直跑计数为准）；live_qa/repurchase/community/growth80 为 pytest 形态——两形态并存是项目现状，报告计数口径已分别标注。
