# 百度 AI 摘要与推荐链接质量割裂分析

> 生成：85号短剧智能研判引擎 · 2026-10-15
> 触发：百度 AI 投喂九链事件——检索正文引用真实榜单口径，推荐链接 5/5 全为内容农场
> 证据：池内 703 快照 13 源 + 主表 297 部对照实测

---

## 一、现象（实证）

| 维度 | 检索正文（百度 AI 摘要） | 推荐链接（5 链） |
|---|---|---|
| 剧名 | 万妖图录传第十三季 / 二嫁有喜 / 岁岁年年 | 闪婚老公竟是首富 / 重生之我在豪门当团宠 / 我在古代开外卖 |
| 池内对照 | **命中**（万妖图录传第十三季=sdc_ai 榜二 L2 互链剧，9487 万口径与红果榜首一致；二嫁有喜=池内四源剧，6130 万/9.6 分一致） | **0/297 命中**（30 个《》剧名全部编造） |
| 数据口径 | 可溯（红果/DataEye/媒体通稿级） | 编造（「上线 72 小时播放破 3.2 亿」配编造剧名） |
| 合规特征 | — | 5/5 无 ICP 备案、模板同族、假 UGC、静态旧日期 |

**同一轮 AI 回答里，正文与推荐链接的可信度完全割裂。**

## 二、四层原因

### 1. 机制层：正文 RAG 与推荐链接是两条独立管线（割裂的直接原因）

- AI 搜索正文生成走 RAG：query「短剧热播榜」检索→命中高权重真实源（红果官方动态、DataEye 通稿、权威媒体报道）→生成时有**内容一致性约束**，数据能对上真实口径；
- 「推荐链接」模块大概率不是正文的引用源清单，而是**独立的相关性召回排序**（或商业推荐位）——只回答「哪些页面与 query 相关」，**不回答「哪些页面是真的」**；
- 割裂本质：**引用链路有真实性压力（错了正文会露馅），推荐链路没有真实性验证环节**。

### 2. 供给侧：内容农场精准针对搜索/AI 搜索做 SEO（为什么推荐位被它们占领）

- title 全部是「短剧推荐_2026热播短剧排行榜_免费短剧推荐」式关键词堆叠——精确瞄准「短剧榜」类 query 的分词命中；
- 页面 SSR 全量输出、robots 放行、sitemap 齐备（aayow.cn 带 sitemap.xml）——**机器可读性故意做到最优**，比真实媒体站更「懂」爬虫；
- 模板批量生成 + 多域分发（本批五域同族），单站成本极低，赌搜索流量分发——被拉黑一个域再换一个；
- 剧名+「热度/播放量」字样密度极高（bkdjtj 96 处 rank/热度词），传统关键词相关性排序下得分不低。

### 3. 对抗层：链接质量过滤滞后于内容农场生产（为什么过滤没拦住）

- 搜索引擎的可信度信号（备案、域名年龄、外链图）更新有时滞；无备案+新域在人工标准里一票否决，在自动相关性排序里**不扣分或扣分不足**；
- 「短剧榜单」恰是时效性高频 query，新内容农场站点持续产出，过滤模型来不及标记；
- .com.cn 域注册需实名且成本更高，反而在中文搜索场景可能获得**信任加权**——被内容农场当作规避 .com 域连坐的手段（本批 5 站 3 个 .com.cn）。

### 4. 需求侧：真实榜单源在公开 web 上「可抓性差」，供给真空被农场填补（为什么真空存在）

这是 85号采集实践的直接印证——真实权威源的公开 web 形态普遍不友好：

| 真实源 | 公开 web 可抓性（85号实测） |
|---|---|
| 抖音搜索页 | JS 壳 72KB，数据全客户端渲染+风控（技术不可采） |
| 快手分享链 | 302 落地域 robots 全站禁采（终局不可采） |
| 猫眼短剧榜 | robots `Disallow:/`（终局不可采） |
| 红果官方数据 | 分享落地页 SSR 可采，但入口靠分享链逐剧发现（我们用 8511 worker 53 链解决） |
| DataEye/新榜 | 公开图文榜可采（85号已接 4 榜），但更新周期日/周/月不等 |

→ **搜索引擎索引里「看起来像榜单且可抓的页面」供给稀缺**，内容农场恰好是少数满足该形态的供给方——推荐位召回时它们天然占优。

## 三、因果链总结

```
真实榜单源 web 可抓性差(供给真空)
        ↓
内容农场模板化填补(多域分发+SEO堆叠+SSR最优化)
        ↓
自动相关性排序吃这套(可信度信号更新滞后)
        ↓
推荐位被农场占领 → 推荐链接 5/5 假
        ≠
正文 RAG 引真实源(有一致性约束) → 正文真
        ↓
同一回答内质量割裂
```

## 四、对 85号引擎的启示

1. **投喂链逐链独立判定不可省**（已固化为流程）：来源背书（百度推荐/人工粘贴）不构成可信度——本轮 5/5 全灭即为实证；
2. **池命中率判别法可自动化**：新源《》剧名 vs 主表剧名命中率 + 站间剧名交叉复用检测，可作为未来投喂的**自动预检层**（人工只复核边缘 case）——本判别法已在 probe_baiduai5b.py 落地；**✅ 当日落地（2026-10-15）：`drama85_preflight.py` 预检层上线**——五层检测（robots 根级禁/农场指纹库/ICP/剧名池命中率/SEO 堆叠）+ 三态判定（REJECT/PASS/REVIEW），指纹库 drama85_farm_fp.json seeding 6 域 32 名，四路径验证全过（含空指纹库模拟新农场的启发式 REJECT），判农场成本降为一条命令；
3. **「不采」分类第六型（内容农场）判别三步法**沉淀：ICP 备案查 → 剧名池命中率 → 同族交叉复用；与 robots 终局判定的「一票否决」同权重；
4. **真实源 web 可抓性差是行业性现象**——85号「分享链 worker + API 契约 + 图文榜解析」三通道并进的架构恰是对该真空的正确应对，也是本引擎数据壁垒所在。
