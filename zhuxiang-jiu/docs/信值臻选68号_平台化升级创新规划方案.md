# 信值·臻选大模型 平台化升级 创新规划方案 v2.0

> 定位: 68号从「频道(展示+试算)」升级为「平台(店铺×铺货×购物×结算)」——对齐天猫精选的平台化范式, 叠加本站信值特色。
> 参照: 37号同盟商城(一人一铺/状态机/三道门禁/五方分账) + 主站 order/checkout/wallet 既有链。
> 铁律: 沿用 68号宪法——LLM 禁入定价判定链; 杀熟审计留痕; 建议书模式(评级降级/铺货审核永不自动执行资金给付); α 信值抵扣资金源可审计。
> 基线: 既有 25 端点(P0-P5)零改动, 平台化叠加 P6-P9 四期。

---

## 一、基线盘点(现状 × 目标差距)

| 域 | 现状(P0-P5) | 平台化目标(P6-P9) | 差距 |
|----|------------|------------------|------|
| 角色店铺 | xinzhi_merchants 纯评级档案(S-A-B-C-D) | 店铺实体: 入驻申请/状态机/店铺主页/等级映射 | 无店铺实体 |
| 铺货 | 只读消费主站自营商品 | 商家发布+四道门禁(资质/溯源/合规/**信值分**)+上下架 | 全缺 |
| 购物 | 无购物车无下单(price 纯试算) | 购物车+下单: 三因子×α信值抵扣真实计价+年龄门+库存预扣 | 全缺 |
| 结算 | groupbuy 仅意向计数 | 订单结算: 商家货款+平台抽佣+信值抵扣资金源+T+1 分账+冲正 | 全缺 |

**可复用资产**(调研实证):
- 37号: 入驻状态机(pending→reviewing→signed→probation→active, L77-101)/一人一铺/商品三道门禁/`settle_order` 幂等分账+冲正(L639-651)
- 主站: `order_service.create`(库存预扣+年龄门)/`_calc_price` 计价骨架/wallet 三支付法
- 68号既有: pay60 `compute_price` 三因子(α 抵扣上限30%)/商家四必查评级/杀熟审计/信值雷达

## 二、平台化四期架构

```
P6 角色店铺:  xinzhi_shop_service
    入驻申请(信值门槛: 雷达总分≥60+等级) → 状态机(对齐37号九态) 
    → 店铺等级=商家评级映射(S旗舰店/A优选/B标准/C新锐) → 店铺主页
P7 铺货:      xinzhi_listing_service
    商品发布(商家) → 四道门禁(资质/溯源/合规/信值分≥40) 
    → 上下架状态机 → 货架(品类聚合+店铺维度)
P8 购物:      xinzhi_cart_service
    加购(信值价实时试算展示) → 下单(三因子×α抵扣+年龄门+库存预扣)
    → 九态状态机(复用主站订单语义)
P9 结算:      xinzhi_settle_service
    订单支付(信值抵扣资金源: TV redeem + wallet 组合) 
    → 分账(商家货款+平台抽佣12%[低于37号15%, 臻选让利]) 
    → T+1 结算+冲正+信值回流(购物加分)
```

**铁律调和**(天猫范式 → 本站口径):

| 天猫机制 | 臻选落地 | 依据 |
|---------|---------|------|
| 保证金/年费 | 信值质押观测(雷达分<40 预警, 建议书制) | 宪法: 惩罚永不自动 |
| 商家自主定价 | 三因子定价引擎保留(平台管价, 杀熟审计) | 68号既有铁律 |
| 直通车/推广 | 不引入(信值排名即流量, finalRank 既有) | 反竞价腐蚀信值语义 |
| 自动扣款 | 全部人工确认/建议书 | 宪法: 给付永不自动 |
| 售后仲裁 | 复用 L1/L2/L3 反馈分流+46号审批轨 | 68号既有 |

## 三、数据与端点规划

**新增服务**: `xinzhi_shop_service.py`(P6) / `xinzhi_listing_service.py`(P7) / `xinzhi_cart_service.py`(P8) / `xinzhi_settle_service.py`(P9)
**路由**: 扩展 `xinzhi_routes.py` 新增约 24 端点(前缀 /api/xinzhi/, 商家侧 X-Member-Id+店铺归属校验, 管理侧 X-Role: admin)

**Redis Key(zhuxiang:xinzhi:* 新表)**:

| Key | 说明 |
|-----|------|
| xz:shops:{shopId} | 店铺(等级/状态/信值快照) |
| xz:listings:{listingId} | 铺货商品(四门禁状态/归属店铺/信值价) |
| xz:cart:{memberId} | 购物车(member 级) |
| xz:orders:{orderId} | 臻选订单(XZ 前缀/九态/抵扣明细) |
| xz:settlements:{settleId} | 结算单(分账明细/冲正) |

**核心模型**:
- 店铺: shopId/memberId/shopName/status(pending→reviewing→signed→probation(30天)→active⇄suspended→terminated)/grade(S/A/B/C)/radarSnapshot
- 铺货: listingId/shopId/productId/sourcePrice/xinzhiPrice(三因子×α试算缓存)/gates{qualification,trace,compliance,primeScore}/status(draft→reviewing→listed⇄delisted→removed)
- 购物车: memberId/items[{listingId,quantity,priceSnapshot(含抵扣明细)}]
- 订单: orderId(XZ+)/memberId/items/priceDetail(复用三因子+α字段)/status 九态
- 结算: settleId/orderId/merchantProceeds(货款)/platformFee(12%)/funding{wallet,trustValue}/status(pending→settled/reversed)

## 四、实施节奏

| 期 | 内容 | 验收口径 |
|----|------|---------|
| P6 | 店铺实体+状态机+等级映射+主页 | 状态机转移合法/信值门槛拦截/建议书降级 |

## 六、边界声明

- 68号平台与 37号同盟**并行不悖**: 37号面向"酒水不分家"外部商户同盟; 68号臻选面向**信值体系内商家**(雷达分/评级准入), 客群与门槛不同
- 主站 order 与臻选订单**分表并存**: 臻选订单带 XZ 前缀+抵扣明细, 不污染主站九态语义
- α 抵扣资金源走 45号 TV redeem(1TV=1元)与 wallet, 全程留痕可审计
