# 40号·AI智能音视频播主大模型——P6 期升级方案(音视频自主学习+自主发布)

> 依据:用户提供的《Value-UEBA 音视频自主化架构》与《自主合规转发引擎》两份优化参考
> 定位:P0-P3d 已交付"跟随模式"(图文侦测→合规转发),P5 已交付"自主模式"(图文四引擎:
> 学习/创作/发布/自治理);**P6 升级为"音视频自主模式"**——从"图文信息流"向"多模态情感流"
> 跨越,并新增"自主合规转发引擎"(跟随模式授权化升级:双重确权→深审→二创→分润)
> 架构原则:**"大模型"仍不是训练 LLM**——视听语义=确定性特征提取(字幕词表/元数据/
> 授权库匹配),情感=确定性词表密度+行为率聚合,脚本=模板引擎,判定链 LLM 禁入铁律不变
> 核心命题:**音视频的"自主"必须以"人格可信+内容合规+情感真实"为前提**——AI 生成的
> 虚拟主播/播客声音必须为平台原创 IP 或已授权声纹;学习目标函数中**情感共鸣度权重 γ
> 永不低于转化效率权重 α**;一切分润/质押经 46号审批;人工暂停优先级高于一切自主行为

## 二、四维+1 音视频自主化架构

```
【信号层】视听信号实时采集(正向/负向/合规三通道, 新增完播/分享/收藏/弹幕情感)
    │
    ▼ ①多模态自主学习引擎(P6a)
    情感对齐复合奖励: reward = α×转化 + β×合规 + γ×共鸣 − δ×风险(γ≥α 铁律)
    → 44号 Hedge 更新 → 跨平台调性迁移(确定性映射表) → 微调研复用
    │
    ▼ ②音视频自主创作工坊(P6b)
    形式决策(短视频/中视频/播客/切片) → 人设匹配(原创IP/授权声纹)
    → 确定性脚本生成(钩子×结构×节奏标记=分镜列表)
    → 合规内生(字幕违禁置零+BGM授权库+声纹授权校验+AI标识+不可见水印)
    → 渲染(mock 轨) → A/B 复用 → 胜出固化策略库
    │
    ▼ ③音视频自主发布调度器(P6c)
    跨平台自适应渲染(参数表: 分辨率/码率/时长/字幕样式)
    + 黄金时段(EMA×完播率加权) + 账号协同复用
    → 发布 → 1h 互动自愈(追加推广分轨/置顶回复/负面仅建议)
    │
    ▼ ④自治理与进化层(P6d)
    六层归因漏斗 + 音视频专项自愈(转码/音画同步/上传分类)
    + 透明度看板扩展 + pause 仲裁覆盖全部音视频自主行为
    │
    ▼ ⑤自主合规转发引擎(P6e——跟随模式授权化升级)
    双重授权确权(平台+原作者) → 多模态深审(≥90自动/70-89人工/<70拒绝)
    → 二创增值(策展说明+信值钩子+来源标注强制) → 智能分润(建议书→46号)
    → 应急响应(撤回秒级下架/投诉15分钟处置)
    │
    ▼ 治理红线(全层贯穿, 宪法域)
    γ≥α | β 拒改 | 声纹/肖像授权前置 | AI 标识+不可见水印强制 |
    分润/质押永不自动(46号) | 授权缺失绝不转发 | pause 最高优先级
```

## 三、引擎一:多模态自主学习引擎(P6a)

### 3.1 视听信号三通道扩展(继承 P5a 信号流)

| 通道 | 新增 signal kind | 采集方式 |
|------|-----------------|---------|
| 正向 | completion_rate(完播率)/ share_rate(分享率)/ favorite_rate(收藏率) | 平台回执聚合(发布后 1h/6h/24h 三采样点, 滚动更新) |
| 负向 | danmaku_negative(弹幕负面密度) | **确定性情感词表**(P5a NEGATIVE_SENTIMENT_WORDS 扩展弹幕场景: "无聊/划走/尬/广告狗"等), 命中密度 > 0.3 生成信号 |
| 合规 | 版权投诉计数/账号健康度降幅 | 三审留痕+账号矩阵 receipt 交叉(既有) |

- **"视听语义理解"的确定性实现**:字幕文本词表命中 + BGM 授权库匹配 + 元数据规则
  (时长/分辨率/完播曲线分段)——**无任何 LLM 推理**(宪法铁律)
- 信号与反馈分离原则继承:原始流可重复采样, 学习轮按 consumed 幂等

### 3.2 情感对齐复合奖励函数(宪法域核心)

```
reward = α × 信值转化效率 + β × 合规得分 + γ × 情感共鸣度 − δ × 风险损失
                                                          clamp [-1, 1]

α = 0.3(转化)   β = 0.3(合规, 宪法域继承)   γ = 0.3(情感共鸣)   δ = 0.1(风险)
```

| 分量 | 公式 | 基准 |
|------|------|------|
| 信值转化效率 | 继承 P5a(注册×0.4+下单×0.6)/点击, 5% 归一 | CONVERSION_REF |
| 合规得分 | 三审 compliance_score/100 | 既有 |
| **情感共鸣度** | `0.4×完播率归一 + 0.3×分享率归一 + 0.2×收藏率归一 + 0.1×评论正面密度(词表)` | 完播 60%/分享 5%/收藏 8% 视为满分 |
| 风险损失 | 继承 P5a(举报×0.5+限流×0.3+投诉×0.2) | 既有 |

**新增宪法铁律**:
- **γ ≥ α 永不小于**——"情感真实性权重不得低于转化效率"的工程化:参数写入
  校验 `γ < α` 直接 ValueError 拒绝;γ 与 β 同列宪法域, α/δ 可经 46号审批调整
- 冷启动回退:视听信号不足(完播样本 < 3)→ 回退 P5a 复合奖励(平滑过渡)

### 3.3 跨平台调性迁移(确定性映射表)

```
PLATFORM_TONE = {
  douyin:          {rhythm:"fast",      duration:[15,45],    density:"high"},
  wechat_channels: {rhythm:"brisk",     duration:[30,90],    density:"medium"},
  xiaohongshu:     {rhythm:"relaxed",   duration:[45,120],   density:"medium"},
  bilibili:        {rhythm:"deep",      duration:[180,480],  density:"medium"},
  xiaoyuzhou:      {rhythm:"immersive", duration:[600,1800], density:"low"},
}
```

- 同一选题 → 脚本生成时按目标平台调性参数**确定性适配**节奏/时长/话术密度
  (抖音快节奏→B 站深度解说→小宇宙沉浸叙事——规则映射, 非 LLM 推理)
- **封禁视听元素同步**:blogger_banned_av_elements 表(BGM/转场黑名单)——
  全平台共享禁用 + 平台增量, 某平台封禁元素实时同步至其他平台约束库
  (P5a 敏感词库"全量共享+平台增量"先例)
- 微调研复用:低置信(<0.8)视听决策(新 IP 形象/争议话题语气)主动发起投票

## 四、引擎二:音视频自主创作工坊(P6b)

### 4.1 形式决策与人设匹配(确定性规则)

```
输入: 选题 + 平台 + 信值权益点
形式决策(规则树): douyin→短视频 | bilibili→中视频 | xiaoyuzhou→播客
                  | 时长>8min 素材→直播切片 | 其余→口播短视频
人设匹配: blogger_personas(平台原创 IP) ↔ 平台调性 + 历史表现
```

- **人设库仅两类**:平台原创 IP(虚拟主播)或**已授权声纹/肖像**(blogger_av_licenses
  授权记录:授权方/范围/期限/哈希存证)——**禁止模仿真人未授权声纹/肖像(红线)**
- 人设一致性:同人设的口播风格标记(语速/语调枚举)跨内容保持——防"人格分裂"

### 4.2 确定性脚本生成(模板引擎, LLM 禁入)

```
脚本 = 钩子(P5b 5 类人群钩子复用) × 结构(痛点-解法/故事递进) × 节奏标记(平台调性表)
输出: 分镜列表 JSON [ {镜头序号, 文案(过 sanitize), 情绪标签(warm/professional/
      playful 有限枚举), BGM 槽位(授权库 ID), 素材槽位(授权素材 ID), 时长标记} ]
风格微调指令("更温暖/更专业") → 映射到情绪标签枚举(确定性映射表, 非自由生成)
```

- 每脚本独立 attract 追踪码(归因载体) → 入 A/B 实验(复用 P5b 实验状态机)

### 4.3 音视频合规内生校验(五层防线)

| 层 | 机制 | 实现 |
|----|------|------|
| 生成时 | 字幕/口播文案违禁词置零 | sanitize_text 复用("token 概率置零"确定性实现) |
| 生成时 | **BGM 授权库校验** | 槽位仅可选取 blogger_av_licenses 中 active 的 BGM;未授权直接生成失败 |
| 生成时 | **声纹/肖像授权校验** | persona 授权过期/撤回 → 拒绝生成(前置硬门) |
| 生成后 | 三审闸门复用 + 敏感帧元数据校验 | 素材入库时校验(下述), 生成槽位只能从授权素材选取 |
| 输出时 | **AI 标识 + 不可见水印强制** | 片头片尾固定标识 + 内容哈希嵌入;缺失即生成失败(ValueError) |

- UGC 音视频素材入库:授权登记(authorized/cc_by/purchased)→ 槽位选取优先级
  **已授权 UGC(信值分成)> 存量语义重组 > 外部生成(mock 轨, 成本控制)**
- 人脸/商标防护:素材库仅含已授权素材(入库时校验授权链), 未授权素材不可入槽位

### 4.4 渲染轨道(AV_CHANNEL_MODE 环境变量)

```
mock(默认): 渲染产物 = meta 数据(分镜 JSON + 渲染参数快照 + 占位文件路径)
real(fail-hard): 接入真实渲染管线(TTS + 合成), 失败即异常不留桩
mock_fallback: real 失败降级 mock, 回执留痕
```

- 虚拟主播口型/表情/手势与语音情感同步标记写入 meta(真实轨实现约束)——
  防"恐怖谷效应"的工程约定
- A/B 判据继承:置信样本 ≥50, 平局取合规分高者(β 铁律延伸)

## 五、引擎三:音视频自主发布调度器(P6c)

### 5.1 跨平台自适应渲染(参数表)

```
blogger_render_profiles:
  douyin:     竖版 1080×1920, 码率 8Mbps, 时长 15-45s, 字幕大字居中
  bilibili:   横版 1920×1080, 码率 6Mbps, 时长 3-8min, 字幕常规
  xiaoyuzhou: 纯音频 128kbps, 时长 10-30min, 简介附口播稿
  wechat_channels / xiaohongshu / weibo: 各自参数行
```

- 同一脚本 → 按目标平台参数自动适配(确定性配置表, 非动态推理)
- 播客平台(xiaoyuzhou)特殊:输出音频 + 口播稿文本, 无视频轨

### 5.2 黄金时段动态预测(EMA×完播加权)

- 复用 P5c blogger_publish_windows EMA 曲线(α=0.3), **观测值由"点击数"
  升级为"点击数×0.5 + 完播率×0.5"**——音视频时段决策以完播为先
- 紧急热点(雷达三因子 ≥85)优先插队;常规错峰;冷启动回退静态黄金窗

### 5.3 发布后 1h 互动自愈(不对称处置继承)

| 信号(1h 窗) | 动作 | 权限 |
|-------------|------|------|
| 完播率 < 阈值×0.5 | 追加推广建议书 | 低预算(≤100)自动 / 高预算 46号质押 |
| 弹幕/评论高频疑问 | 置顶回复(模板+FAQ) | 全自动(合规校验) |
| 弹幕负面密度 > 0.3 | 隐藏候选 + 通知人工 | **仅建议**——AI 永不自动隐藏 |
| 音画不同步回执 | 自愈重渲染(retry×3) | 全自动 |

**权限分级**:常规发布 AI 全自动;**高预算推广/新平台首发(bilibili、xiaoyuzhou 前
10 条)/敏感话题 → 运营信值质押审批**;重大策略调整 → 冻结 AI 权限待人工确认。

## 六、引擎四:自治理与进化层(P6d)

### 6.1 六层归因漏斗

```
曝光 → 完播 → 点击 → 注册 → 信值激活 → 首单
        └新增层┘                    └既有四层(P5d)┘
```

- 每音视频绑定唯一追踪码(既有短码体系), 采样点 1h/6h/24h 滚动 + EMA 平滑
- 新增"情感共鸣度"看板指标(共鸣分走势/低共鸣内容预警)驱动内容温度优化

### 6.2 音视频专项自愈分类(扩展 P5d 词表)

```
classify_av_failure(error) 新增三类:
  transcode_failed   "转码失败"/"codec"/"分辨率"     → retry×3 → 换渲染参数 → 人工队列
  audio_desync        "音画不同步"/"sync"             → 重渲染 → 人工队列
  upload_timeout      "上传超时"/"upload timeout"    → retry×3 → 换通道 → 人工队列
```

- 耗尽兜底铁律继承:**永不静默丢弃**, 一律转人工队列留痕
- 自愈动作写入审计流水(auto_heal), 看板自愈流水区可回放

### 6.3 透明度与干预(继承 P5d)

- 看板四区扩展:漏斗(六层)/策略排行/干预史/自愈流水 + **共鸣度指标区**
- **pause 仲裁覆盖全部音视频自主行为**(学习轮/脚本生成/实验固化/自动渲染/
  低预算推广全拒——require_running_async 复用)
- 干预留痕上链(哈希指纹) + 干预记录回流学习系统(source: intervention)

## 七、引擎五:自主合规转发引擎(P6e——跟随模式授权化升级)

> 定位:从"流量抓取"到"可信价值共振"。**转发 ≠ 搬运, 转发 = 信用担保行为**——
> AI 每转发一条内容, 即本站对其合规性/真实性/价值观的背书。
> 流程铁律:**先确权、再合规、后分发、全溯源**。

### 7.1 智能权利确权层(双重授权)

```
第一重·平台授权: 仅转发开放 CC 协议/官方转载白名单/已签 MCN 合约的内容
第二重·原作者授权: 转发邀约(附分润条款+信值权益) → 明确同意后方可执行
授权存证: 双重授权记录生成哈希上链(区块链存证复用)——合规免责凭证
```

- **动态权限管理**:作者撤回授权 → **秒级下架**所有关联转发内容;授权范围变更
  (如仅限非商用)→ 自动触发重审或下线;过期授权自动续期提醒(防"僵尸转发")
- 黑白名单:可转发创作者白名单(简化审核)/高风险源黑名单(永久屏蔽);
  AI 学习+人工复核共同维护, 定期审计

### 7.2 多模态合规深审层

```
待转发内容 → 权利确权校验(未授权→放弃或发起邀约)
          → 多模态深审: 视频(敏感帧/人脸/商标/字幕) + 音频(敏感音素/BGM版权/声纹)
            + 文本(违禁词/夸大宣传/价值观) + 元数据(来源真实性/篡改检测)
          → 综合深审分: ≥90 自动进入二创 | 70-89 人工复审队列 | <70 拒绝+原因反馈
```

- **价值观对齐校验**(确定性规则):与本站"互助/诚信/可持续"理念冲突的内容
  (炫富/焦虑营销/歧视性言论)即使不违法也拒绝转发——价值观词表映射
- 动态风险感知:原内容评论区大规模负面 → 自动暂停转发;原作者涉丑闻/违规 →
  关联内容降级或下架
- 深审判定全确定性(词表+规则+授权库匹配), LLM 禁入

### 7.3 增值二创与溯源层

- **合规二创增强**:自动添加"本站信值解读"画外音/字幕(确定性模板)+ 策展说明
  ("为什么我们推荐这条内容")+ 信值钩子植入(复用 P5b 钩子库, A/B 优化植入策略)
- **强制性来源标注**:视频片头片尾"转自@原作者+授权声明"/播客口播致谢+简介链接
  /图文首行来源+文末原文链接——**禁止任何去标识/模糊化处理**
- 适配各平台格式, 转发版本体验不劣于原版

### 7.4 利益分配与应急层

- **智能分润三轨**:基础分润(播放量)+ 转化分润(注册/下单)+ 长期分润(长尾按月)
  ——**全部生成建议书 → 46号 submit_change → 人工 approve**(永不自动, 复用
  P5b UGC 分成范式)
- 信值激励叠加:授权转发赠"内容贡献者"徽章/高深审分奖信值/累计达标解锁合作权益
- **应急响应 SOP**:侵权投诉/监管通知 → **15 分钟内自动下架** + 通知相关方;
  系统性合规漏洞 → 暂停同类转发 + 人工复查;重大事故 → 保险理赔 + 公开致歉

## 十三、关键设计决策备忘

1. **视听语义的确定性边界**:"看懂/听懂"的工程实现 = 字幕词表+元数据规则+授权库
   匹配+行为率聚合——参考方案的"多模态深度理解"全部收敛为确定性特征, LLM 禁入铁律
   不因模态扩展而松动
2. **γ≥α 宪法化的意义**:"情感真实性权重不得低于转化效率"从口号变为参数校验——
   与 P5a β 拒改同构, 双保险(β 保合规底线, γ 保情感温度)
3. **渲染 mock 轨先行**:AV_CHANNEL_MODE 沿用 PAY60 三态范式——音视频真实渲染
   管线(TTS/合成)成本高且依赖外部, 先交付决策链+meta 产物, real 轨 fail-hard 后置
4. **转发 = 信用担保**:P0-P3d 跟随模式升级为授权化——未授权内容无论流量多高
   绝不转发;分润三轨全部建议书制(46号), 与 UGC 分成范式统一
5. **人设一致性 SOP**:同人设口播风格标记(语速/语调枚举)跨内容锁定——虚拟主播的
   "人格分裂"比内容质量更伤信任
6. **平台扩展最小侵入**:bilibili/xiaoyuzhou 以常量扩展+调性映射表接入, 既有四平台
   行为零变更
7. **不可见水印 = 内容哈希嵌入**:溯源水印与 AI 标识双轨——标识面向用户(广告法),
   水印面向平台治理(防盗用/溯源)
