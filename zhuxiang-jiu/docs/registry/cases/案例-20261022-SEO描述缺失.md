# 案例-20261022-SEO描述缺失

## 一、现象

竹园盘点(audit T0.3)上线首扫即集中暴露: 全站 23 页缺 meta description
(seo_missing, P1)——以 activity-detail.html 为代表(同类发现共 23 处,
清单见盘点台账)。通用主页面(index/products/detail)SEO 齐全, 专题/活动/
工具类详情页整体缺描述。

## 二、根因

多数专题/详情页由各期活动模板复制创建, 模板头部从未包含 meta description
段; 通用页面模板有, 专页模板漏——属**模板级缺项**而非单页疏忽, 故盘点
基线一上线即成片暴露(核实方式: 抽样对比两类模板 head 段)。

## 三、错误代码/配置

activity-detail.html(代表页)head 段:

```html
<head>
  <meta charset="UTF-8">
  <title>…</title>
  <!-- 无 <meta name="description" content="…"> 段 -->
</head>
```

## 四、正确写法

按《资产标准.md》SEO 基线补齐——每页一句 20-40 字描述(含品类词"竹香酒"
与页面主体词), 例:

```html
<meta name="description" content="竹香酒活动专题——全竹发酵竹香型, 入口绵柔, 全国配送。">
```

批量修复建议: 先补流量页(活动详情/资讯详情), 模板层加默认描述兜底。

## 五、预防规则

新页面/新资产接入时对照《资产标准.md》七项口径自检; audit 盘点台账
按 P0-P2 把关(seo_missing=P1); prescribe 按缺口类型出处方(只出不施)。
挂 80号-T0.3 盘点口径。
