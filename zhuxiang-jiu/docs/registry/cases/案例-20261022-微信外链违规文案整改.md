# 案例-20261022-微信外链违规文案整改

## 一、现象

2026-10-21 微信外链申诉"不通过"：商品页在微信内被按《微信外部链接内容管理
规范》拦截判定违规, 申诉被拒(附规范全文与拒绝截图)。全站排查确认 17 处功效
宣称/怂恿饮酒/无依据营养声称文案——酒类内容触碰广告法 22 条(禁止功效宣称、
怂恿饮酒)与 28 条(营养声称), 属获客链路阻断级事故。

## 二、根因

酒类营销文案系统性踩线, 三类红线并存:
- **功效宣称**: 「醒酒快、无酒气、不头疼」「清心怡神, 懂你的身体」——暗示
  酒类具有健康功效;
- **怂恿饮酒**: 「就喝竹奕酒」「畅饮」「尽兴更尽兴」——诱导无节制饮酒;
- **无依据营养声称**: 「富硒泉水」「有益微量元素」「健康密码」——无科学依据
  的营养成分与功能关联。
根因是内容上线**无合规词表准入校验**, 文案创作与审核环节缺失违禁词拦截。

## 三、错误代码/配置

整改前 7 文件 17+3 处(整改实录 13 个核心词全中):

```text
js/data.js / js/main.js / product-detail.html / index.html 等:
"滴滴醇香, 醒酒快、无酒气、不头疼"        ← 功效宣称(ALC-FUNC)
"老友小聚: 畅饮不头疼, 尽兴更尽兴"        ← 怂恿饮酒(ALC-INCITE)
"汲取徂徕山富硒泉水, 天然健康基底"         ← 营养声称(ALC-HEALTH)
"【健康密码】""有益微量元素/有益成分"      ← 营养声称(ALC-HEALTH)
```

## 四、正确写法

三批次整改(提交 5d161d44):
1. **文案清洗 17 处**: 功效表述全部改口感/工艺描述——竹香清雅、入口绵柔、
   回味悠长、全竹发酵工艺; 「健康密码」栏目改「品质密码」(工艺与检测口径);
2. **index 加 noscript 静态资质块**: 11 款真实系列品名+销售主体/生产商/
   食品经营许可证 SC11537090100608+执行标准+鲁ICP备2026059492 号-1+健康
   警示——缓释 SPA 空壳判定, 给审核器静态可见资质;
3. **B1 铁律缓存升位**: data/main.js v=20261021b 共 9 页 18 处引用同步
   (微信/QQ 浏览器云缓存钉死预防, 参见 C-20261021-03)。
整改后全站违规词残留 0 命中, 申诉材料+商品详情页/页脚资质截图提交过审。

## 五、预防规则

以 rules.py 词表(五组规则映射广告法 22/28/9/17 条)为内容**准入校验**;
comply 扫描器以本案例实录为 **B1 基准**——13 个实录核心词回放检出率 100%,
竹园若在整改前上线, 违规文案上线即拦、申诉前即修复。挂 ALC-FUNC/ALC-INCITE/
ALC-HEALTH 词表规则与 B1 回放基准; med 级(绝对化等)边缘案例人工裁量。
