# 竹园资产元数据标准（80号·T0.2）

> 用途: zhuyuan audit(T0.3) 盘点判定口径 —— 资产四态+豁免态、P0-P2 优先级、
> 检测字段 schema。资产对象=主站页面(html)与页面内关键内容块+js 资产。
> 底座: 竹盾 L0 管路由/模块台账(不重复), 竹园管**内容层**健康度。
> 日期: 2026-10-22

## 一、资产四态+豁免态

| 状态 | 含义 | 判定 |
| --- | --- | --- |
| healthy | 内容齐/合规/链接活 | 全检查项过 |
| missing | 缺口: 占位符/空正文/关键模块缺(资质行/警示语/购买按钮) | 占位词命中/正文过短/关键块缺失 |
| outdated | 过时: 营销类超期未更新/引用失效外链/旧版本号 | 时效阈值(营销类 90 天)/死链/陈旧引用 |
| irrelevant | 无关: 与品牌无关的遗留/临时页 | 语义判定+豁免清单外 |
| exempt | 豁免: 内部工具页不参与资产审查 | 命中豁免清单 |

**豁免清单**(初始): module-test.html, ai-promo-radar.html, ai-pdm-dashboard.html,
ai-promo-studio.html, payport-dashboard.html, activity-dashboard.html(内部仪表盘类)。

## 二、优先级判定表(P0-P2)

| 级 | 触发条件(任一) | 处置时限 |
| --- | --- | --- |
| **P0 阻断** | 违禁词存在(comply 联动) / 购买链接失效 / 价格错误 / 资质行缺失(ICP·许可证·主体) | 立即 |
| **P1 严重** | 核心商品参数缺失 / 主图缺失 / SEO(title/description)为空 / 健康警示语缺失 | 当日 |
| **P2 一般** | img 无 ALT / 内链<2 条 / 正文<300 字 / 断链图片 | 本周 |

## 三、检测字段 schema(T0.3 产出格式)

```json
{
  "asset_id": "index.html",
  "asset_type": "page | content_block | js",
  "status": "healthy | missing | outdated | irrelevant | exempt",
  "gap_type": "content_missing | seo_missing | image_broken | alt_missing | fact_outdated | null",
  "priority": "P0 | P1 | P2 | null",
  "evidence": "具体缺失字段或问题描述(证据驱动: 文件+行/缺失项)"
}
```

## 四、检测规则口径(T0.3 实现依据)

| 检查项 | 规则 |
| --- | --- |
| 占位符 | 正文命中 TODO/FIXME/占位/敬请期待/lorem → missing |
| 空正文 | 页面可见文本 < 200 字符 → missing(P2) |
| 关键模块 | 页面须含: 资质行(备案号)/健康警示语; 商品页加购买按钮与价格 → 缺即 missing |
| 断链图 | img src 指向仓库/线上不存在文件 → missing(image_broken) |
| ALT | img 无 alt 属性 → missing(alt_missing, P2) |
| SEO | 无 title 或无 meta description → missing(seo_missing, P1) |
| 时效 | 营销/活动类含"限时/特惠"字样且超 90 天未 git 更新 → outdated |

## 五、判定示例

**健康样本**(index.html): noscript 静态块含 11 系列品名+销售主体+食品经营许可证
SC11537090100608+执行标准+ICP 备 2026059492 号链接+四条健康警示——资质/内容/合规全过
→ `{"status": "healthy", "priority": null, "evidence": null}`

**缺口样本**(人为挖空示例): product-x.html 无 meta description 且主图 404 →
`{"status": "missing", "gap_type": "seo_missing", "priority": "P1",
"evidence": "product-x.html: head 无 meta description"}`

**B2 基准口径**: 以当前 index.html 为健康样本全项通过 + 对其构造"挖空变体"
(临时目录副本移除资质行) → audit 必须检出 1 处 P0 缺口。
