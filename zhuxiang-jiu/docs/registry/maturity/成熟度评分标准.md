# 成熟度评分标准（81号·竹演 score 底座）

> 建立: 2026-10-22（任务 T0.2）· 消费方: `zhuyan/score.py` 三维评分(T1.1-T1.4) / `zhuyan/matrix.py` 四象限(T2.1) / 种子核查(T2.2)
> 方案: [../../81号_进化功能Agent_创新规划方案.md](../../81号_进化功能Agent_创新规划方案.md) · 前沿文档: EvoFunc 成熟度评分算法
> 铁律: **证据驱动**(每分静态取证可追溯) / **静态近似如实标注**(APM 缺位, S_r 为代码特征代理) / **Benchmark 先行**(B3 分档回放)

## 一、功能单元定义（评分对象）

| 单元类型 | 枚举口径 | 数据源 |
| --- | --- | --- |
| API 端点 | backend/routes/*.py 中的路由注册（对齐竹盾 L0 端点台账） | 源码正则提取 |
| 核心模块 | backend/core/*.py（鉴权/配置/锁/指标等关键支撑件） | 目录枚举 |
| 页面功能 | 主站 *.html 非豁免页（豁免清单同竹园 audit：dashboard 类等） | 竹园 audit 台账并轨 |

单元 ID 约定：端点=`METHOD /api/...`；模块=`core/<name>.py`；页面=`<name>.html`。

## 二、总公式与归一化口径

```text
S_maturity = 0.40 × S_b + 0.35 × S_r + 0.25 × S_e − P_penalty
```

归一化（N(x)→[0,1]，两种方式按子指标适配）：
- **比值归一**：率类指标=命中数/基数（如 try/except 覆盖率）
- **阈值映射**：计数类指标按阈值表映射（0/0.4/0.7/1.0 四档），阈值表随各子指标列出

每子指标输出 `(原始值, 归一值, 证据)三元组`——评分报告可追溯。

## 三、业务价值 S_b（权重 0.40）

| 子指标 | 权重 | 数据源/计算逻辑 | 归一化口径 |
| --- | --- | --- | --- |
| 核心链关联度 | 40% | 端点在《业务链定义.md》6 链 27 步中的命中（竹医 L1 同源） | 命中链数：0=0 / 1 链=0.7 / ≥2 链=1.0 |
| 调用频次(静态代理) | 30% | 前端调用点计数（竹医 contract 调用面提取同源） | 计数：0=0 / 1-2 处=0.4 / 3-5 处=0.7 / ≥6 处=1.0 |
| 转化关联 | 30% | 购物链页面(下单支付链步骤页: 详情/购物车/结算)命中=1.0；其他链页面=0.5；非页面单元按调用链折算 | 页面专用维度 |

模块/端点无对应维度时按 0 计并如实标注（不臆造）。

## 四、运行稳健 S_r（权重 0.35——静态代理，如实标注）

| 子指标 | 权重 | 计算逻辑（正则/行级特征） | 归一化口径 |
| --- | --- | --- | --- |
| 异常处理完备度 | 35% | 函数级 try/except 覆盖率=被 try 包裹或显式抛错的函数数/总函数数 | 比值归一 |
| 容错特征 | 30% | 重试/降级/超时/幂等/防重放特征命中计数（竹医 qr 案例 loginTicket 一次性防重放即此类） | 命中：0=0 / 1 类=0.5 / ≥2 类=1.0 |
| 输入校验完备度 | 20% | 参数校验/类型检查/required 断言特征 | 比值归一（校验函数数/入口函数数） |
| 并发安全 | 15% | 锁/原子性/线程安全特征（backend/core/locks.py 同源特征） | 命中=1.0 / 未命中=0 |

> **静态近似声明**: APM/Prometheus 缺位, S_r 为代码特征代理非运行时指标；
> 运行时数据接入挂账（见方案边界）。

## 五、工程复用 S_e（权重 0.25）

| 子指标 | 权重 | 计算逻辑 | 归一化口径 |
| --- | --- | --- | --- |
| 测试保障 | 30% | 单元关联测试文件存在+断言密度（qr/b1-b3 基线测试集命中加权×1.5） | 无测试=0 / 有测试=断言数阈值映射 |
| 契约清晰 | 30% | docstring/注释覆盖率（项目无 Swagger 的近似口径） | 覆盖率比值归一 |
| 低耦合 | 25% | 1/(外部 import 计数)（耦合倒数, 前沿公式口径） | 0 依赖=1.0 / 1-3=0.7 / 4-6=0.4 / ≥7=0.1 |
| 规范性 | 15% | ruff 检查通过率（家族既有口径） | 比值归一 |

## 六、罚分项 P_penalty（一票否决/重扣）

| 类型 | 触发条件（静态取证） | 处置 |
| --- | --- | --- |
| **硬否决** | 硬编码密钥模式（key/token/password=字面量, 排除测试文件） | 总分直判 0 档（低分） |
| 重扣 | 无任何关联测试 | −0.20 |
| 重扣 | SQL 字符串拼接（f-string/%/format 拼 SQL） | −0.20 |
| 重扣 | 危险模式（eval/exec/shell=True, 排除测试与工具脚本） | −0.15/处（封顶 −0.30） |

罚分可叠加，总分下限 0；硬否决不受叠加规则影响。

## 七、分档判定（B3 回放口径）

| 档位 | 区间 | 判定 | 去向 |
| --- | --- | --- | --- |
| 高分（种子候选） | S ≥ 0.70 | 成熟可复制 | 进入种子核查(T2.2 五维标准+排除项) |
| 中分（观察） | 0.40 ≤ S < 0.70 | 部分达标 | 观察等待，进 matrix 四象限 |
| 低分（痛点） | S < 0.40（或硬否决） | 待进化目标 | 进 matrix 优先进化区候选 |

**B3 基准已知答案**（检不出即不合格）：
- 高分样本：扫码登录链端点（/qr/scan 等——核心链命中 S_b 高 + qr 基线测试 S_e 高 + loginTicket 防重放 S_r 高）
- 低分样本：竹园 audit 已证缺口页面（SEO 缺失 P1 类 + 无页面专属测试）
