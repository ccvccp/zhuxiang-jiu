## 六、转段操作（如判定通过）

```
# 服务器执行(转段脚本——四档)
bash attract72_transfer.sh assist
# 或手动:
sed -i 's/^ATTRACT72_MODE=.*/ATTRACT72_MODE=assist/' /opt/zhuxiang/.env
cd /opt/zhuxiang && docker compose up -d backend
# 验证
curl -s -H "X-Role: admin" https://zxjiu.com/api/attract72/model/status  # 期 mode=assist
```

回滚（任一时刻）：

```
cp /opt/zhuxiang/.env.bak-attract72-off /opt/zhuxiang/.env  # 回 off 原始件
cd /opt/zhuxiang && docker compose up -d backend
# 或: bash attract72_transfer.sh off
```
