# 53号·小竹智能登录引擎（AI智能网站入口模块）实施计划

> 依据：《AI智能网站入口模块规划方案》（3S+AI Trust / 多模态登录矩阵 / 语音融合 / 角色专属入口 / 驻留激励 / 六项效果指标）
> 定位：网站入口"信任建立的第一触点"——登录从"关卡"变成"拥抱"，引流与驻留水到渠成
> 架构原则：**复用底座、编排创新**——39号 entry 凭证协议 + 43号风控评分 + 48号语音会话 + 50号声纹双态 + 49号隐私预算均已就绪，53号做智能编排层，零重复造轮子

---

## 一、模块定位与架构

### 1.1 与既有体系的分工（零侵入复用）

```
【复用底座——只读调用零改动】
39号 entry: bio 挑战制凭证(enroll/bind/challenge/verify/revoke)
           + 扫码全协议(qr_create/confirm/scan/status/exchange/cancel)
           + 设备信任清单(trustedUntil 豁免) + step_up 二次核验流
43号风控:   AuthRiskScorer 8因子4级决策(allow/step_up/challenge/block)
           + UEBA compute_deviation 行为偏离
48号语音:   会话/唤醒(detect_wake)/轮次 + voice48_bindings(memberId→trustId)
50号声纹:   verify() 双态(proxy/real) + liveness_score + speaker_digest
49号预算:   check_and_spend(零成本短路/超限409/日切重置)

【53号新建——智能编排层】
态势感知(Pre-Login AI): 行为基线匹配→静默登录 + 意图预判 + 预算预检
多模态编排: 五通道统一编排 + 风险分级响应 + 失败优雅降级
语音融合: 唤醒即认证 + 语音陪伴 + 登录后导览
角色门户: 四态自适应入口(new/active/dormant/high_risk)
驻留激励: 每日奖励 + 连续叙事 + 退出挽留
效果评估: 六指标计算 + 监控看板 + 告警
```

### 1.2 核心设计原则（3S + AI Trust 直译）

| 原则 | 传统定义 | 信值升级定义 | 工程口径 |
|------|---------|-------------|---------|
| Simple 极简 | 减少输入框 | AI 预判意图，界面随角色状态动态自适应 | 意图预判标签→门户分区直达 |
| Secure 安全 | 复杂密码+验证码 | 隐形风控：行为指纹+环境感知 | AuthRiskScorer 复用+决策留痕 |
| Smooth 丝滑 | 快速跳转 | 情感流续接：语音反馈无缝衔接 | 唤醒窗+免唤醒续接复用48号 |
| AI Trust 价值前置 | — | 未完全登录即展示个性化信值洞察 | 价值钩子生成(45/50号只读聚合) |

**关键转变**：登录不是目的，"让角色愿意留下来"才是——认证完成前即投放"钩子内容"（如"欢迎回来，您昨日志愿服务的信值已到账"）。

## 二、数据模型（4 表，前缀 login53，双模式存储）

| 表 | 主键 | 用途 |
|----|------|------|
| login53_profiles | memberId(自然键) | 角色入口档案（角色态四态+行为基线指纹+意图标签+适老/无障碍偏好） |
| login53_events | eventId | 登录事件流水（method/riskScore/decision/durationMs/privacyCost/explainRef/retention5min——合规审计脱敏） |
| login53_retention | memberId+dayKey | 驻留激励台账（每日奖励领取+连续天数+成就解锁） |
| login53_snapshots | snapId | 效果指标快照（六指标+达标态——回溯可比） |

辅助键：events_all（流水列）/ retention seq / snapshots_all。

## 三、多模态登录矩阵（通道×场景×信值增强）

| 通道 | 底座 | 凭证锚点 | 愉悦感设计（话术注册表） |
|------|------|---------|------------------------|
| Passkey 静默 | 39号 bio 挑战制 | 设备指纹匹配+风险<25 → 一键确认 | 解锁动画+"欢迎回家" |
| 刷脸（mock） | 50号 liveness 模拟口径 | 活体分+声纹同步绑定（mock 通道——国标 SDK 外部待办） | 信值光环动效 |
| 声纹+语义双因子 | 50号 verify + 动态口令 | 声纹初筛（proxy 标注不作凭证）+语义动态口令复述 | "小竹"对话式引导 |
| 扫码跨端 | 39号 qr 全协议 | 手机端已认证状态→PC 续接 | "正在同步您的信值档案" |
| 指纹/掌静脉（mock） | 39号 bio | 适老化通道 | 触觉反馈+大字体播报 |

**安全兜底与异常处理**（P1 交付）：
- 风险分级响应：低风险(<25)→静默通过；中(25-50)→追加轻量验证；高(>50)→强制多因子+人工客服选项
- 失败优雅降级：生物识别失败 3 次→自动切换备选方式+语音安抚（不直接报错）
- 反欺诈实时反馈：TTS/深伪疑似→安全挑战（随机动作指令——既防机器又保真人）
- **降级铁律**：评分器异常降级 step_up 不裸放（39号同款）

**声纹红线**（继承 50号）：proxy 态声纹不作身份凭证——声纹登录必须"声纹初筛+语义动态口令"双因子，proxy 仅作加成标注。

## 四、语音融合设计（"小竹"登录话术注册表）

### 4.1 三阶段全流程

| 阶段 | 机制 | 底座 |
|------|------|------|
| 登录前：唤醒即认证 | 自定义唤醒词"小竹，我回来了"→唤醒+声纹初验并行；置信度达标直入主页，不足则语音追问 | 48号 detect_wake+50号 verify |
| 登录中：语音陪伴减焦虑 | 加载过程播报价值预告（"正在同步最新信值报告...您上周的社区服务获得3条点赞"） | 45/50号只读聚合 |
| 登录后：语音导览促驻留 | "早上好！当前信值782，较上周↑15。今日有1项修复任务待完成，需要带您看看吗？"+快捷指令（查详情/去修复/随便逛逛） | 45号档案+48号指令集 |

### 4.2 话术注册表（login53_scripts.py 静态注册——三组 17 场景）

- **正向组（7）**：唤醒即认证/Passkey 静默/刷脸成功/声纹二次确认/扫码跨端/老年模式/视障模式——价值前置+情绪适配
- **异常组（7）**：声纹失败/活体失败/异地新设备/预算耗尽/账号保护/网络超时/儿童访问——**归因外部化+去污名化铁律**（禁用"验证失败/系统错误"等责备语）
- **退出组（3）**：主动退出（非强制挽留）/长时间未操作/连续登录成就

TTS 参数动态配置（success/security_warn/elderly_mode/error_recovery 四态音调语速）。

## 五、角色专属入口（四态自适应门户）

| 角色态 | 判定口径 | 门户行为 | 价值钩子 |
|--------|---------|---------|---------|
| new 新用户 | 注册<7天或无登录史 | "信值是什么"+30秒快速建档引导，弱化登录表单 | 交互式价值演示 |
| active 活跃用户 | 7日内有登录 | 默认 Passkey/刷脸，登录后直达意图预判页 | 个人信值等级光晕+待办摘要 |
| dormant 沉睡用户 | >30天未登录 | "您错过的信值增长机会"+一键恢复 | 可视化错过收益时间轴 |
| high_risk 高危用户 | 43号风控标记 | 强化安全提示+人工协助入口，**去污名化**（禁红色警告，橙色+解释性插图） | 风险归因卡片+透明策略 |

## 六、驻留激励机制

- **登录即奖励**：每日首次登录+简单互动（语音问候）→微量 L2 积分（50号台账口径，防刷封顶）
- **连续登录叙事**：连续 N 天解锁"小竹"专属皮肤/语音包（成就状态台账）
- **退出挽留**：关闭意图检测→语音轻问（**非弹窗拦截，尊重选择**）

## 八、效果评估指标（P5——六指标注册表）

| 指标 | 基线 | 方向 | 计算口径 |

## 九、分期实施计划（P0-P5）

### P0 注册表+态势感知层（奠基层）
- 话术注册表（三组 17 场景+TTS 四态参数）+多模态矩阵注册表+六指标注册表+启动自检
- login53_profiles 角色档案（四态判定引擎：new/active/dormant/high_risk）
- 态势感知：行为基线指纹匹配（>95%→静默/一键——mock 指纹通道）+意图预判标签+隐私预算预检（49号 check_and_spend 只读探针）
- 测试：专项约 20 断言
- QC：话术去污名化扫描（黑名单词表）；角色四态判定正确性

### P1 多模态认证编排引擎
- POST /auth/orchestrate：五通道统一编排（复用 39号 bio/qr+50号声纹+mock 刷脸指纹）→AuthRiskScorer 风险分级→静默/一键/常规/强化四级响应
- 安全兜底：失败优雅降级（3次→备选+安抚话术）+反欺诈安全挑战（TTS 疑似→随机动作指令）+降级 step_up 不裸放铁律
- login53_events 事件流水（method/riskScore/decision/durationMs/privacyCost/explainRef——审计六字段对齐49号口径）
- 测试：专项约 24 断言
- QC：风险分级四响应全路径；降级铁律

### P2 语音融合登录
- POST /voice/wake-login：唤醒即认证（48号 detect_wake+50号 verify 声纹初验+语义动态口令双因子——proxy 红线遵守）
- GET /voice/briefing：登录后语音导览（45号信值+50号积分+待办聚合→个性化摘要+快捷指令）
- 语音陪伴：编排过程价值预告插播（预算预检+钩子生成）
- memberId→trustId 经 voice48_bindings 桥（跨 ID 体系红线）
- 测试：专项约 22 断言
- QC：声纹 proxy 不作凭证；唤醒窗语义

### P3 角色专属入口+价值钩子
- GET /portal 四态门户：new（价值启蒙+快速建档）/active（无感续接+意图直达）/dormant（损失规避+一键恢复）/high_risk（透明保护+人工兜底）
- 价值钩子生成器：45号信值变动+50号积分+待办任务→个性化钩子内容（登录前投放）
- 沉睡唤醒：>30天判定+错过收益时间轴数据
- 测试：专项约 20 断言
- QC：四态切换正确；高危去污名化话术

### P4 驻留激励机制
- POST /retention/claim 每日奖励（语音问候互动→微量 L2 积分——50号台账防刷封顶）
- 连续登录叙事（N 天成就解锁——台账状态）
- POST /exit/farewell 退出挽留（非弹窗拦截——语音轻问）
- login53_retention 台账（memberId+dayKey 幂等）
- 测试：专项约 18 断言
- QC：防刷封顶；幂等领取

### P5 效果评估+监控看板+红队收官
- 六指标计算管道（events 流水聚合+52号 trust_gain 复用）+快照留痕
- GET /dashboard 监控看板（六指标+通道占比+风险分布+角色四态分布）
- 红队复验（52号自身无新攻击面——只读编排层，评估零侵入断言：39号 25 端点/43号风控/48-50号零改动）
- 三件套文档（验收报告+交付总结+运维手册）
- 测试：专项约 20 断言
- QC：六指标全过；宪法断言

**开关矩阵**：`LOGIN53_MODE`（默认 off——off=编排面关闭直通存量 39号登录，**默认零影响**；registry/查询/看板观测面不受影响）。

## 十一、合规底线（全程贯穿）

1. **生物数据本地化**：原始人脸/声纹永不上传——mock 通道仅特征哈希/活体分引用（50号同款）
2. **最小必要采集**：登录阶段仅采集认证所需；行为数据延后授权
3. **透明可控**：门户常驻隐私设置入口（预算可视化——49号联动）
4. **合规审计**：events 流水完整脱敏日志（监管追溯+用户自查——my/events）
5. **异常去污名化**："这不是您的错，可能是他人误操作"——话术注册表强制审查
6. **儿童保护**：<14岁触发监护人授权流程（话术锁定敏感功能）

## 十三、结语

原方案价值锚点全盘继承：**入口模块是"信任的首次交付"。它的成功不在技术指标的完美，而在让用户 3 秒内感受到"这个平台尊重我、理解我、值得我停留"。当登录从"关卡"变成"拥抱"，引流与驻留便是水到渠成的结果。技术只是骨架，对人的敬畏才是灵魂。**

39-52号交付了信任的底座（凭证/风控/语音/信值/评估），53号让入口成为这套信任体系的**第一次温暖交付**。
