**P1 建议: B 路线按量起步 + A 路线继续跑基线, 双轨影子对照**——同剧本双轨出片,
44号档案回流完播率/互动率对比, 数据说话后再定主轨。

## 五、ROI 触发器(78号方法论迁移)

78号 TTS 的触发器是"月账单 > GPU 月租×1.5"——数字人轨**按量计费无月租**, 触发器
改为**单条经济性+表现力双门**:

1. **成本门**: 单条数字人视频 GPU 成本 ≤ 1 元(按量计费护栏, 超限查推理效率)
2. **表现力门**: 影子对照首月, 数字人轨完播率 ≥ 零GPU轨 × 1.2(44号档案 duration_fit 观测)
3. **规模门**: 周产量需求 > 20 条时, 评估包周/包月实例(按量→月租的转正点重算, 78号同款算式)

## 六、P1 实施路径(最小闭环)

1. **素材定版**: 从70号品牌卡体系选定竹小妹口播基准图(正面/半身/稳定光照)
2. **GPU 实例**: AutoDL A10(16G) 按量开通, LivePortrait(开源)环境+权重就位
3. **推理封装**: `sv73_digital_human_service.py`——输入(基准图+78号TTS音频)→
   输出口播mp4; 与 sv73_render_service 同款确定性接口(mp4+时长注册表)
4. **storyboard 扩展**: 模板库增"数字人口播"镜头类型(单镜15s: 口播为主+字幕角标),
   合成层复用 xfade/BGM/字幕零改动
5. **分段语义**: SV73_RENDER_MODE 同款开关——生产只登记, GPU 推理走
   build_sv73_dev.py 同款"开发机一键脚本"范式(AutoDL 版)
6. **影子对照**: 44号档案回流加 track(数字人/零GPU)维度, 首月对照报告定主轨
