## 六、发现的问题: RAG 阈值量纲错位(严重)

### 6.1 根因

旧置信分级阈值 `direct 0.50 / synth 0.25` 按 **n-gram 模式**标定(注释: 完全同文本约 0.51)。生产已开启 **embedding 语义检索**, 同文本=1.0、无关问题噪声≈0.48-0.54——量纲完全不同。

### 6.2 实测分布(生产 36 条库采样)

| 语义带 | 相似度实测 |
|---|---|
| 精确/同义改写(真实命中) | 0.79 ~ 1.00 |
| 半相关条目 | 0.65 ~ 0.78 |
| **完全无关(噪声带)** | **0.48 ~ 0.5425** |

### 6.3 后果(修复前)

1. 无关问题(如"火星探测器发射时间" 噪声 0.5425 ≥ 0.50)被**直接引用**无关答案
2. 所有无关问题过 0.25 融合下限, 以 synthesized 融合无关内容作答
3. unsolved 轨永不触发 → chat 缺口飞轮停滞(新缺口无法产生)

### 6.4 修复方案(提交 `eff0f2f`)

[knowledge_service.py](file:///d:/网站架构设计/zhuxiang-jiu/backend/services/knowledge_service.py) 分轨阈值:

```python
# n-gram 回退轨(embedding 关闭/向量化失败): 沿用 0.50 / 0.25
RAG_DIRECT_SIMILARITY = 0.50
RAG_SYNTH_SIMILARITY = 0.25
# embedding 语义轨(2026-09-14 生产实测校准, env 可覆盖)
RAG_DIRECT_SIMILARITY_EMB = 0.72   # 高于半相关带, 真实命中直接引用
RAG_SYNTH_SIMILARITY_EMB = 0.60    # 高于噪声顶 0.5425, 低于命中底 0.79
```

`_rag_answer_uncached` 按 `_query_embedding` 是否成功动态选轨(语义轨→EMB 阈值, None 回退→n-gram 阈值), 两轨互不干扰。

RAG 阈值修复后, 知识库完整飞轮恢复运转:

```
用户提问(chat/ask)
  ├─ 相似度 ≥0.72 → direct 精确应答(计 hit)
  ├─ 0.60~0.72    → synthesized 融合应答(计 hit)
  └─ <0.60        → unsolved 兜底回复 + 计 miss + 自动建 open 缺口

        57号 P0 缺口诊断(kb_gap_open 等信号 → 必要性评分)
                        ↓

                        ↓
        P2 种子锻造(sandbox) → 人工终审(published 唯一出口)
                        ↓
        P3 会员推荐流(预算计量) → view/feedback 使用信号
                        ↓
        P4 T+1 回流补标(六类信号真值, 44号池双写, seedId 1:1 幂等)
                        ↓
        知识质量进化调度器(6h): 质量淘汰/渐进信任/紧急缺口提醒
```
