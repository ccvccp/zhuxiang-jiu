## 二、宪法对齐(三铁律全程贯彻)

1. **LLM 禁入决策链**: 路由/熔断/路径匹配/碳核算全为确定性规则与公式; 提醒文案为模板+查询层插值。
2. **建议书模式**: 渠道切换/舱位预约/退货处置/整改动作/绿色切换全部生成《建议书/协议/报告》人工确认, 永不自动执行(响应体均带 disposition 字段留痕)。
3. **进化可见可控**: 偏好/模式/负样本全部落库可查; 人机协同裁决拒绝即负样本回流, 决策权永在人工。

**实测亮点**(专项测试内):
- 语义归一化: SF 方言(bill_no/state/parcel_weight)→平台模型, 状态"已签收"→signed; 未映射字段报告
- 配置化接入: 注册 EMS 后零代码即接入归一化(重复注册/内置重复 409 防护)
- 熔断状态机: 揽收率 0.85→open / 0.93→half_open / 无时效样本不判罪(诚实降级)
- 容量预约: 分摊合计=日均预测, 安全系数 1.2 精确
- 三码验真: 公开端点免鉴权, 电话脱敏, IoT 未接入诚实降级, 未绑定码 404"谨防假冒"
- 逆向物流: 未开封→返仓 / 已开封→转赠 / 破损→就地销毁, 三协议确定性匹配
- 管理层归因: 2 笔破损理赔→整改建议书+主因渠道归因
- 碳核算: 渠道占比合计 100%, 深圳跨省/成都同城/西藏偏远三档距离
- 人机协同: 采纳留痕/拒绝负样本/重复裁决 409
