## 一、P3-1 小猪空指令轮优化(10-08 首个判定点)

**背景**: memory 在案 HITL 项——10 条「小猪」唤醒后空指令/
纯唤醒轮落兜底, 真机"喊了没下文"体验信号; wakeScore P1
留痕已覆盖该观测面。

**核查命令**(10-08 与三项联合检查同批跑):

```python
# 容器内: not_woken/wakeup 轮 wakeScore 分布 + 小猪近似音轮画像
async for k in client.scan_iter(match="zhuxiang:voice48:turns:*"):
    # (按 key 类型分派 lrange/hgetall——10-01 联合检查发现
    #  turns 键空间混型, 本批核查须先修扫描器: type() 分派)
```

**判定矩阵**(残分样本 = not_woken 轮 0.3-0.74 分值):

| 判定 | 处置 |
|---|---|
| 样本 <100 轮 | 继续积累, 下周同批再核(流量低属常态) |
| 样本 ≥100 且 0.55-0.74 段集中(近似音误触画像) | **触发优化方案**: ①wakeup 兜底话术按分值分层(高分近唤醒→"在呢!"主动应答) ②未注册 u 韵 0.55 轮画像回看→决定纳入/排除 ③阈值微调评估 |
| 样本 ≥100 但全落 0.0-0.3(环境残声) | **证伪关闭**: 非唤醒词误触而是噪声——转采集层 VAD 门槛评估, 不动意图层 |

**触发后动作**(48 号惯例四步): 小方案一页 → 确认范围 →

## 二、P3-2 唤醒分值 EMA 平滑(10-15 判定, 复用 81号 模板)

**核查命令**(量化"分布稳定 1 周"):

```python
# 近 7 日 woken 轮分值按日聚合: 逐日均值/方差 + 变体分布
# (分值来源: turns 表 wakeScore 字段, P3-1 同款扫描器)
判定: 连续 7 日日均值波动 <15% 且主要变体(小竹/近似音)占比
稳定 → "分布稳定"成立
```

**触发后实施步骤**(直接复用 81号 EMA 范式与灰度铁律):
1. 分时基线: 唤醒分值按小时桶 EMA(α=0.1, 冷启动 ≥3 日)
2. 平滑判定: `score_ema = α×当前 + (1-α)×历史` 挂
   detect_wake_v2 **on 态**(off 默认不变)——短时分值抖动
   (如连续两次 0.7 弱近似)经平滑不误唤醒
3. kill switch: `XIAOZHU_WAKE_EMA=off` 默认, 任一时刻回
   P1 分值判定零差异
4. 单测(基线/冷启动/只紧不松口径迁移)+回归+部署+
   真机(弱近似音连续唤醒场景)
5. 留痕: track 字段增 ema 轨标记(81号 tracks 同款)

**依赖链**: P3-1 先行(判定空指令画像)——若 P3-1 证伪,
EMA 平滑的优先级重估(误唤醒面不存在则平滑收益存疑)。
