## 一、模块概览

58号让意图识别从"分类器"进化为"业务理解引擎"：语料库理解业务边界，置信度分级诚实协作，意图-权限耦合识别即合规，反馈飞轮让每一次纠错都成为下一次准确的养料。当引擎无法确信时它选择追问而非猜测，当阈值随信任动态流动时它让高信值者更流畅、低信值者更安全——**懂业务、知边界、有温度**。

## 三、各期交付明细

### 3.1 P0 意图注册表+置信度引擎+识别底座

- **INTENT_REGISTRY 三位一体**：12 项四侧（product/trust/nav/other）+2 元意图（boundary.unauthorized 越界 deny 域+unknown.unrecognized 澄清域）；每意图七字段（label/side/minRole/sandbox/complianceTemplate/slotSchema/confusableWith/status）；三对易混淆对双向对称；启动自检八类断言 RuntimeError 宪法级
- **第33档案 intent_orchestration**：八因子（corpus_quality 0.15/intent_confidence 0.20/member_trust 0.15/boundary_clarity 0.15/history_success 0.10/compliance_posture 0.10/latency_budget 0.05/coverage_breadth 0.10）→信任分 0-100→三级决策（observe<50/optimize≥50/urgent≥80）
- **evaluate 主链**：决策面 off 409→tier 联动→动态阈值（运行态计算不落库）→L1 语料匹配→三态判定（澄清优于错误执行铁律）→归因链落库（corpusIds/track/tier/thresholds——无归因不计入有效服务）
- 修复缺陷 2 处：混淆对引用不在册意图（启动自检失败）；对抗否决 PARTIAL 过激误伤（改 FULL_MATCH 全含触发）

### 3.2 P1 语料采集流水线+语料库

- **正样本挖掘**：48号 turns 纯读取→action 白名单映射（10 项）→executed 成功代理+同会话负反馈排除+PII 双保险脱敏+去重+单意图 50 上限→active 直通（来源即真值）
- **负样本增强**：failures 三 kind（negative/fallback→pending 人工复核；repeat→事件留痕复核队列）
- **对抗/越界样本**：ingest 唯一入口（意图在册+类型四类+confusableTarget 注册校验+去重铁律）
- 修复缺陷 2 处：测试断言反写；**Redis 态 executed 字符串"0"真值**（本地 mock 原生 bool 掩盖的实机缺陷）

### 3.3 P2 业务耦合+动态信任校准

- **识别即合规**（ii58_compliance.py）：ROLE_RANK 四级+沙箱五级裁决序（deny 任何角色拦截→角色不足越界拦截→sensitive 二次确认 confirm_required→放行）；10 合规模板（valueTags+guardrails）；**三态纯度铁律**（仅 resolved 交付域校验——clarify/partial 不受污染）
- **越界拦截语义**：输出改判 boundary.unauthorized+boundaryIntercepted=True+拒绝话术；归因保留原始意图（审计完整）
- **槽位上下文预填**：指代词→48号上轮 card.subject（"这个多少钱"→"飞天茅台"）；currentPage→page 槽位；来源标记 slotSources 可审计；48号零写入
- **阈值配置域**：calibrate→46号审批总线留痕（config 人工通道）+58号镜像 pending→**人工终审唯一生效出口**；基线三级回退（镜像 active→代码常量）
- 设计偏差声明：镜像同步由"读取时轮询 46号"改为"终审时直接收口"（46号 config 类不自动执行业务变更——避免双源状态漂移）

### 3.4 P3 反馈闭环+主动学习

- **显式反馈**（会员面 assist）：短期表单（evalId+意图重选+自由文本）→属主校验+PII 脱敏→高优先级入标注队列
- **隐式反馈转化**：48号 failures 三 kind 纯读取→feedback 表+标注队列（caseId 去重幂等）
- **主动学习**：evaluate 钩子——0.4-0.7 低置信区间自动入队（auto_ambiguity）；**入队≠生效**（语料库零新增）
- **decide 人工终审**：approve→语料回流四类归类（ingest terminal 轨+review 联动——active 唯一出口仍是 review 函数）；优化永不自动生效铁律保持
- 修复仓储既有缺陷 1 处：`_list` 首参 kind 与 feedback 字段 kind 撞名（TypeError）

### 3.5 P4 决策回流+信值联动+T+1 调度

- **六类真值信号**（七信号源）：终态判定序——越界拦截(+0.6)→显式反馈纠正（高置信≥0.9→-0.8/中低置信→+0.3 弱满足）→对抗混淆(-0.6)→澄清缺口(-0.5)→partial+标注(+0.8)/无标注跳过→resolved(+1.0)；44号池双写（第33档案八因子快照+连续 reward）
- **幂等铁律**：evaluationId 1:1（pooledFeedbackId 终态跳过）
- **高置信错误预警**：≥3→阈值收紧建议（upper+0.02）自动提交 pending——生效唯一出口仍是人工终审；队列纪律跨轮幂等
- **T+1 调度器**：II58_LEARN_MODE 默认 off；main.py 注册；docker-compose 补 58号三开关
- 增强 2 处：evaluate 归因链补 adversarialPenalty 留痕（P0 缺失）；calibrate 提取 submit_calibration_proposal 共用轨

### 3.6 P5 看板+红队+收官

- **四区看板**：度量区（任务完成率/纠错率/澄清接受率/信值增益）+意图区（分布+三态+top5）+语料区（四类+来源+人工验证率）+防御区（越界/对抗计数+阈值镜像健康+宪法断言）
- **红队七向量**（确定性离线可复现）：
  | 向量 | 攻击 | 防御 |
  |------|------|------|
  | RT-01 | 语料投毒（不在册意图/非法类型/混淆方伪造） | INTENT_REGISTRY 封闭白名单+四类封闭 |
  | RT-02 | 意图越界（guest 权限外执行） | minRole 前置校验+越界改判归因保留 |
  | RT-03 | 对抗混淆（易混淆对攻击） | FULL 命中否决×0.5 强制澄清 |
  | RT-04 | 阈值操纵（伪造 tier） | 47号纯读取不可写+fail-soft standard |
  | RT-05 | 反馈污染（虚假正反馈） | 标注队列 pending 人工 decide——语料零直接生效 |
  | RT-06 | 标注注入（恶意标注） | 回流类型四类封闭+在册校验+状态机 |
  | RT-07 | LLM 越白名单（合成建议逃逸） | 三态默认 off+建议仅返回不入库 |
- 补齐 decide 回流目标意图在册校验（P3 遗漏防御项）
- **宪法断言**：44号 33 档案在册+48号 COMMAND_ACTIONS 零改动+55号 SERVICE_REGISTRY 在册

## 结语

58号作为"懂业务、知边界、有温度"的四位一体工程收官：**语料库**理解业务边界（四类样本+版本化+来源溯源），**置信度分级**诚实协作（三态响应+澄清优于错误执行），**意图-权限耦合**识别即合规（前置校验+越界拦截+归因完整），**反馈飞轮**让每一次纠错都成为下一次准确的养料（双通道反馈+主动学习+六类真值信号 44号池双写）。全部优化动作经人工终审生效——优化永不自动生效铁律贯穿六期。
