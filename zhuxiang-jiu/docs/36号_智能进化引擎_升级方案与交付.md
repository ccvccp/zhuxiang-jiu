## 一、升级基线判定(P2 终态 → 差距)

| 维度 | P2 现状(规则/自动化) | P3 升级后(反馈驱动) |
|------|--------------------|--------------------|
| 热点筛选 | 全局四因子权重(Hedge) | **品类维度**(文化/场景/AI提问)ROI 回归 + 安全阀自调 |
| 内容生成 | 固定 system prompt | **5 风格 A/B 轮转** + 冠军识别 + tone 反哺 |
| 流量承接 | 短码→固定落地 | **UCB1 多臂老虎机**三臂(商品/文化/活动)自动倾斜 |
| 合规风控 | 静态词库 | **平台审核反馈 → n-gram 候选 → 人工批准**动态附加词 |
| 商品范围 | 单一品牌 | **全站商品库匹配**(02号 search 复用, 热销兜底) |

## 二、四大进化引擎设计(全确定性)

### 引擎1 热点价值评估进化
- 品类标注: `tag_hotspot_category` 确定性关键词映射(ai_question > scene > culture > general)
- 回归算法: 品类 ROI = (订单×100+注册×10+点击)/曝光; 相对全站均值比值驱动权重步进
- **安全阀**: 单步 ≤±20%, clamp 基线 [0.5×, 1.5×]; 样本 <3 品类跳过(冷启动保护)
- 输出: 高价值热点优先级清单(品类权重 × 热点评分), 进化日志全留痕

### 引擎2 内容风格自适应进化
- 风格库: 文化科普/情绪共鸣/场景故事/产品测评/工艺解说(工艺解说即合规安全形式)
- A/B 分配: 同内容组确定性轮转(变体号 % 5), 冠军风格优先占首变体
- 冠军判定: 样本 ≥3 且 CTR 最高; toneHint 反哺 Step3 prompt(不改 agent 签名)
- 输出: 风格统计(变体/点击/订单/CTR/订单率) + 高转化 SOP

### 引擎3 承接页智能路由进化
- 三臂: 商品详情页(转化)/文化专题页(种草)/活动承接页(促销)
- UCB1: score = 均值 + √(2ln(N+2)/n), 确定性 tie-break 按臂名
- reward: 点击率(点击/曝光); 生成时自动选臂落 content.landingArm

### 引擎4 合规与平台适配进化
- 反馈录入: 平台审核结果(rejected/limited/removed) + 内容语料留痕
- 提取算法: 2-4 字 n-gram; 出现于 ≥2 条拒绝内容 且 拒绝率>通过率 → 候选
- **红线**: 候选仅观察永不自动阻断; 人工批准后注入雷达 check_risk 与内容 compliance_gate 双闸门; 误报可人工拒绝(留痕)
- 白名单防误杀(警示语等强制文本不入候选)

### 商品拓展(全站商铺)
- 匹配: 热点品牌命中词 + 标题关键词 → 02号 ProductRepository.search 全站商品 → 命中数×热销排序 top3; 无命中热销兜底
- 注入: 生成时 productFocus 附入热点摘要(Step1 自然携带), content 记录 productIds + 关联缓存

## 三、进化闭环(反馈链路)

```
热点感知 → 内容生成(风格A/B+商品匹配+落地臂)
  → 合规预审(静态词库+进化附加词) → 多渠道分发
  → 数据回流(learning feedback) → feed_metrics 三路更新
  → [品类统计/风格统计/老虎机reward]
  → 回归运行(引擎1) / 冠军反哺(引擎2) / UCB倾斜(引擎3)
  → 平台审核反馈(引擎4) → 候选风险词 → 人工批准 → 双闸门生效
```

集成点(最小侵入):
1. `generate_contents`: 风格分配+tone 反哺+商品匹配+落地臂+附加风险词(每轮加载一次)
2. `submit_learning_feedback`: 回流成功后 feed_metrics(best-effort, 失败仅告警)
3. `check_risk`/`compliance_gate`: 附加词参数注入(默认空=纯静态零影响)

## 四、铁律与安全阀(对齐项目红线)

| 铁律 | 实现 |
|------|------|
| LLM 禁入判定链 | 四引擎全部数学计算(回归/轮转/UCB1/n-gram), 无 LLM 参与 |
| 进化安全阀 | 品类权重 clamp+步进上限; 老虎机探索项保底; 风格样本门槛 |
| 人工否决权 | 风险词仅人工批准生效; 品类权重调整全留痕可审计可回滚 |
| 进化日志 | 全量留痕(engine/action/detail), 月度运营+法务审计 |
| 失败零影响 | 附加词加载失败回退空(纯静态词库); feed 失败 best-effort |
