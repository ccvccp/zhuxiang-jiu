## 五、模型效果优化(2d668f4)

### 5.1 缺陷一: 推荐面零分(映射域缺失)

- 原状: ROLE_TAG_AFFINITY/SCENE_TAG_BONUS 仅政务域——品鉴种子
  推荐 2.85 分(纯可信度)永远垫底;
- 修复: 映射扩展品鉴域(citizen→品鉴文化/感官语言/审美;
  staff→质检/实操/缺陷识别; 三场景各自加成)。

### 5.2 缺陷二: 中文检索失效(分词缺陷)

- 原状: context_trigger `query.split()` 空格分词——中文整句永不命中;
- 修复: 子串双向匹配(标签 in query / query in 标题/正文)。
