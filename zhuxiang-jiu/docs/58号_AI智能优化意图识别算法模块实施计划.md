> 定位：本站意图识别的**四位一体优化中枢**——"业务语义锚定+动态信任校准"（数据-模型-业务-反馈闭环）
> 范式：意图语料库 → 置信度分级响应 → 意图-权限-合规模板耦合 → 反馈飞轮回流第33档案（让算法理解业务边界，让业务反哺算法迭代）

## 〇、参照方案的本站化优化升级说明

参照方案（用户输入）的四大理念（数据/模型/业务/反馈四位一体+安全合规内生+效果度量+落地路径）全量继承，工程落地做**六项本站化升级**：

| 参照方案要点 | 本站化升级（落地口径） |
|---|---|
| L1 轻量模型（BERT/DistilBERT 微调）+L2 LLM 路由器 | **确定性语料匹配引擎+LLM 三态**（48/55号范式）：L1=意图语料库关键词/同义词加权打分（55号 parse_intent 范式：FULL_MATCH 1.0/PARTIAL 0.6/AMBIGUOUS 0.4），L2=LLM 路由仅 assist 态处理低置信度样本、**只产 action 不产内容**（48号防幻觉红线——数字一律来自执行层）；不训练模型——置信度提升来自语料库进化而非权重更新 |
| 语料库（正样本挖掘+负样本增强+合成数据） | **INTENT_CORPUS 语料库四类样本**（52号 registry 范式封闭分类）：positive 正样本（48号成功会话轮次自动采集——intent 命中+executed+无负反馈的 rawText 脱敏入库）/negative 负样本（48号 failures 三 kind：fallback/repeat/negative 自动转化）/adversarial 对抗样本（易混淆意图对——"修改价格 vs 查看价格"人工构造+运营注册）/boundary 越界样本（权限外意图+合规拒绝话术关联）；合成数据=运营注册轨（LLM 生成仅 assist 润色建议，人工审核入库——共创短语 pending 范式）；语料版本化带时间戳/来源标签/信值权重 |
| 动态阈值校准（信值等级调整置信度阈值） | **47号 tier 联动 TIER_THRESHOLD_DELTA**（47号 TIER_DELTA_GATE 范式）：trusted 0.8+/standard 0.5+ 阈值下调（提流畅）/watched 0.3+/restricted 阈值上调（强管控）——get_profile 纯读取；阈值变更经 46号 submit_change 审批总线（人工复核） |
| 意图-权限映射+合规模板绑定+上下文槽位 | **INTENT_REGISTRY 三位一体注册表**：每意图绑定 minRole 最小权限+sandbox 沙箱级（48号三级 readonly/write/sensitive 范式）+合规模板引用（57号种子 valueTags 关联）+槽位 schema（上下文预填：会话上一轮 intent/页面状态 jump——48号 turns 表纯读取）；**识别即合规**（先权限校验后执行——48号执行器前置） |
| 反馈闭环（显式+隐式+主动学习） | **双通道反馈+标注队列**：显式=会员反馈端点（"不是这个"→48号 negative kind 已有+短期修正意图收集）；隐式=48号 failures 纯读取转化（撤销/重复/转人工三代理）；主动学习=低置信度区间（0.4-0.7）样本自动入标注队列（48号共创 pending 范式+57号终审范式——人工标注 24h 语义经审核回流语料库）；六类真值信号→44号池双写（第33档案） |
| 红蓝对抗+公平性+归因透明 | **确定性红队七向量**（56/57号范式）：语料投毒/意图越界/对抗混淆/阈值操纵/反馈污染/标注注入/LLM 越白名单；分意图×分 tier 公平性视图（46号 fairness 口径）；**归因 ID 强制**（无归因决策不计入有效服务——每次识别携带 corpusId+patternId+track 链） |

**核心原则（继承+强化）**：意图识别的准确性必须以"不破坏信任"为前提。当引擎无法确信时，**"澄清追问"优于"错误执行"**（48号追问而非猜测红线）；所有优化动作（语料入库/阈值调整/pattern 新增）必须经人工审核——**禁止自动生效**（48号 P3 红线：top 未命中语句建议新增 pattern，人工审核入注册表）。"这个改进是让算法更接近业务真相，还是更接近测试集分布？"——答案应永远指向前者。

## 一、模块定位与架构

```
意图轨信号源(48号 turns/failures/custom_cmds+55号意图三态——纯读取)
        │
        ▼
① 意图注册表(INTENT_REGISTRY——三位一体封闭白名单)
   ├─ 意图×权限(minRole+沙箱级)×合规模板×槽位schema
   └─ 启动自检(RuntimeError 宪法级——52号范式)
        │
        ▼
② 语料匹配引擎(L1 确定性——置信度分级)
   ├─ INTENT_CORPUS 语料库四类样本(版本化)
   ├─ 关键词加权打分(55号范式 FULL/PARTIAL/AMBIGUOUS)
   ├─ 动态信任校准(47号 tier 联动阈值)
   └─ 三态响应: resolved≥0.9 / partial 0.7-0.9 / clarify<0.7
        │ 低置信度(assist 态)
        ▼
③ LLM 路由器(L2——只产 action 不产内容)
   └─ 白名单校验+fail-soft 回退 clarify(三态回退范式)
        │
        ▼
④ 业务耦合层(识别即合规)
   ├─ 权限校验前置(minRole+沙箱级→拒绝归因)
   ├─ 槽位上下文预填(会话上轮+页面状态)
   └─ 合规模板加载(意图→57号种子 valueTags 关联)
        │
        ▼
⑤ 反馈飞轮(双通道+主动学习)
   ├─ 显式反馈(会员修正意图收集)
   ├─ 隐式反馈(48号 failures 三 kind 纯读取)
   ├─ 标注队列(0.4-0.7 低置信度→人工标注→语料回流)
   └→ 六类真值信号 → 44号池双写(第33档案 Hedge 学习)
```

**四铁律（安全鸿沟工程化）**：
1. **LLM 不进判定链**——L2 仅 assist 态低置信度路由，只产 action（白名单校验），数字一律来自执行层；off 态纯规则轨（零 LLM 依赖）；
2. **澄清优于错误执行**——低置信度（<0.7）必 clarify 追问，禁止盲执行（48号"追问而非猜测"红线平移）；
3. **识别即合规**——意图-权限映射前置校验（minRole+沙箱级），越权意图拒绝+归因+培训推送（48号越界样本关联）；
4. **优化永不自动生效**——语料入库/阈值变更/pattern 新增全部经人工审核队列（共创 pending+46号审批总线范式）；归因 ID 强制（无归因不计入有效服务）。

**双模型铁律（54/55/56/57号范式平移）**：58号评分（第33档案）与 48号指令轨/55号意图引擎**并行不替换**——58号仅对"意图识别质量"打分回流，纯读取 48号 turns/failures/custom_cmds 与 55号意图统计，零改动既有意图路由/执行器。

## 二、意图注册表（INTENT_REGISTRY——三位一体封闭白名单）

52号 registry 范式。每条意图含七字段：

```python
INTENT_REGISTRY = {
    "product.price_query": {
        "label": "价格查询", "side": "product",
        "minRole": "member", "sandbox": "readonly",
        "complianceTemplate": "product_policy",
        "slotSchema": ["keyword"],
        "confusableWith": ["product.price_modify"],
        "status": "active",
    },
    ...
}
```

**首批 12 项意图**（四侧，对齐 48号 COMMANDS 高频 action 白名单纯读取）：

| 侧 | 意图 | 沙箱级 | 易混淆对（对抗样本域） |
|----|------|--------|---------------------|
| product | product.new_query / product.price_query | readonly | price_query vs price_modify |
| trust | trust.balance_query / trust.score_query | readonly | score_query vs score_report |
| nav | nav.page_jump | readonly | page_jump vs page_bind |
| promo | promo.query | readonly | — |
| chat | chat.human_transfer | readonly | — |
| explanation | explanation.report_query | readonly | — |
| cart | cart.submit_intent | write | submit vs draft |
| trust.conv | trust.convert_intent | sensitive | convert vs exchange |
| generic | general.help | readonly | — |
| deny | boundary.unauthorized（越界元意图） | deny | — |
| unknown | unknown.unrecognized（未识别元意图） | — | clarify 域 |
| consent | consent.voice_confirm（49号确认词域） | sensitive | — |

- **启动自检**（52号范式）：12 项数量/四侧覆盖/沙箱级合法/minRole 合法/confusableWith 双向对称/合规模板在册——RuntimeError 宪法级
- **越界元意图**（boundary.unauthorized）：权限外请求识别→合规拒绝话术+归因+培训推送（48号越界样本关联）——"识别即合规"的否定面工程化

## 三、语料库（INTENT_CORPUS——四类样本+版本化）

### 3.1 样本结构

```python
corpus = {
    "corpusId": 1024, "corpusVersion": 3,   # 版本化（同意图语料新旧共存）
    "intentId": "product.price_query",
    "sampleType": "positive",               # positive/negative/adversarial/boundary
    "text": "这个产品多少钱",               # 已脱敏
    "weight": 1.0,                          # 信值权重（正样本来源可信度）
    "source": "xiaozhu_turn",               # xiaozhu_turn/evolution_failure/
                                            # ops_register/llm_suggest/manual
    "originRef": "t-xxxx",                  # 来源溯源（48号 turnId 等）
    "confusableTarget": None,               # adversarial: 对抗目标意图
    "refutedAction": None,                  # boundary: 正确拒绝话术引用
    "humanVerified": True,                  # 人工终审标记
    "status": "active",                     # active/retired
    "createdAt": "...",
}
```

### 3.2 采集流水线（四通道）

| 通道 | 口径 | 自动/人工 |
|------|------|----------|
| 正样本挖掘 | 48号 turns 纯读取：intent 命中+executed+无同会话负反馈 → 脱敏去重入库 | 自动（status=active 直通——来源即真值） |
| 负样本增强 | 48号 failures 三 kind 转化：negative→negative 型、fallback→unknown 域候选、repeat→低置信复核 | 自动入库+人工复核队列 |
| 对抗样本构造 | confusableWith 意图对——运营构造细微差异（"修改价格"vs"查看价格"）+LLM assist 生成变体建议 | 人工审核（LLM 仅建议） |
| 越界样本收集 | boundary.unauthorized 域——权限外请求+拒绝话术关联 | 人工注册 |
| 合成数据 | LLM 基于合规规则与意图 SOP 生成结构化变体（稀缺场景：口语化/碎片化表达） | LLM 建议+人工审核（共创 pending 范式） |

**数据治理**：全语料带时间戳/来源标签/信值权重，支持回溯审计；语料版本化（新版入库旧版 retired 不删除——57号种子版本化范式）。

## 四、置信度引擎（L1 确定性+L2 LLM 三态）

### 4.1 L1 语料匹配（55号 parse_intent 范式升级）

```
置信度 = Σ(语料命中相似度 × 语料权重)/Σ(权重) × 命中数衰减
相似度: FULL_MATCH(子串全含)=1.0 / PARTIAL(关键词条命中)=0.6 /
        AMBIGUOUS(模糊词)=0.4（55号常量继承）
命中数加成: 多条语料命中同意图 → 置信度上浮(共识效应)
对抗样本否决: 命中 adversarial 对的 confusableTarget → 双方置信度
              各乘 0.5(易混淆域降权——"修改 vs 查看"区分铁律)
```

**三态响应**（动态阈值校准后判定）：
- `resolved`（≥动态阈值上限，默认 0.9）→ 直接意图交付
- `partial`（区间内，默认 0.7-0.9）→ 澄清追问+候选引导（55号 top-4 候选范式）
- `clarify`（<下限）→ L2 路由（assist 态）或纯澄清问句（off/shadow 态）

### 4.2 动态信任校准（47号 tier 联动）

| 47号 tier | 阈值调整 | 语义 |
|-----------|---------|------|
| trusted（trustLevel≥0.8） | 上限 -0.05（0.85） | 提流畅——高信值用户少追问 |
| standard（≥0.5） | 不变（0.9/0.7） | 基线 |
| watched（≥0.3） | 上限 +0.05（0.95） | 加强管控——低信值多确认 |
| restricted（<0.3） | +0.10（0.95/0.8） | 强管控+boundary 复核 |

- tier 经 47号 get_profile 纯读取（fail-soft 未建档走 standard 基线）
- 阈值调整**运行态计算不落库**（校准口径每轮重算）；基线阈值变更经 46号 submit_change 审批总线

### 4.3 L2 LLM 路由器（assist 态——48号 LLM 轨范式）

- **触发**：L1 clarify 态+`II58_LLM_MODE=on`+key 已配
- **输出**：仅 action/intentId（白名单 INTENT_REGISTRY 校验）+槽位建议——**不产内容不产数字**
- **回退**：任何异常→clarify 纯澄清问句（三态回退范式——规则轨兜底永不悬挂）

## 五、第33档案：intent_orchestration 八因子信任分

44号 ai_learning 入册（batch17——既有测试 32→33 计数更新预算：约 33 处 10 文件，56/57号教训预算内消化）。

| 因子 | 权重 | 口径 |
|------|------|------|
| corpus_quality | 0.15 | 语料质量（正样本占比+humanVerified 率） |
| intent_confidence | 0.20 | 意图置信度（近期识别平均置信度） |
| member_trust | 0.15 | 会员信值（47号 tier 基线：trusted 90/standard 70/watched 50/restricted 30） |
| boundary_clarity | 0.15 | 边界清晰度（对抗样本区分正确率——易混淆域命中精度） |
| history_success | 0.10 | 历史识别成功率（回流真值） |
| compliance_posture | 0.10 | 合规态势（越界拦截正确率） |
| latency_budget | 0.05 | 延迟预算（规则轨 P95 达标率） |
| coverage_breadth | 0.10 | 覆盖广度（意图域语料覆盖度） |

输出 0-100 信任分 → 三级决策（`DECISION_THRESHOLDS`）：`observe` 观察（<50——不优化）/`optimize` 优化执行（≥50——语料采集+标注回流）/`urgent` 紧急优化+人工加急（≥80——Bad Case 复盘会触发）。

## 六、反馈飞轮（双通道+主动学习+六类真值信号）

### 6.1 双通道反馈

| 通道 | 口径 | 动作 |
|------|------|------|
| 显式反馈 | 会员识别后点"不是这个"→短期表单收集真实意图（intentId 重选+自由文本） | 高优先级入标注队列（kind=explicit） |
| 隐式反馈 | 48号 failures 纯读取：negative（负反馈词）/repeat（同 query 重复）/fallback（兜底）+55号 clarify 率 | 自动转化回流信号 |

### 6.2 主动学习标注队列

- **入队**：L1 置信度 0.4-0.7 区间样本自动推送（48号共创 pending 范式）
- **标注**：审核员界面（意图修正+对抗标记+越界判定）
- **回流**：标注结果 → 语料库（positive/negative/adversarial/boundary 归类入库）——**人工审核后生效**
- **时效**：24 小时内回流语义（T+1 调度器联动）

### 6.3 六类真值信号（44号池双写——第33档案）

| 信号源 | reward | 语义 |
|--------|--------|------|
| 识别正确+执行成功 | +1.0 | 置信度分级正确 |
| 识别正确+负反馈（高置信错误） | +0.3 | 弱满足（阈值偏松预警） |
| 澄清后完成（partial 域） | +0.8 | 澄清策略正确 |
| 高置信识别错误 | -0.8 | 置信度校准失准 |
| 澄清拒绝/转人工 | -0.5 | 语料覆盖缺口 |
| 越界拦截正确 | +0.6 | 边界识别正确 |
| 对抗混淆命中 | -0.6 | 易混淆域降权失效 |

幂等：evaluationId 1:1（pooledFeedbackId 范式——55/56/57号继承）。

## 九、分期实施计划（P0-P5）

### P0 意图注册表+置信度引擎+识别底座
- INTENT_REGISTRY 12 项三位一体+启动自检（52号范式）
- 语料匹配引擎（55号打分范式+对抗样本否决+动态阈值）
