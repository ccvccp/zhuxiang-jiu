## 六、转段操作（如判定通过）

```
# 服务器执行(改 .env 后重建容器)
sed -i 's/^PAY71_MODE=shadow/PAY71_MODE=assist/' /opt/zhuxiang/.env
cd /opt/zhuxiang && docker compose up -d backend
# 验证
curl -s -H "X-Role: admin" https://zxjiu.com/api/pay71/model/status  # 期 mode=assist
```

回滚（任一时刻）：

```
cp /opt/zhuxiang/.env.bak-pay71-shadow /opt/zhuxiang/.env  # 回 off 原始件
cd /opt/zhuxiang && docker compose up -d backend
```
