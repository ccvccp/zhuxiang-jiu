# 智启元·AI智能财务大模型 创新规划方案 v1.0

> 定位: 财务管理模块升级更名——从「记录型财务(后视镜)」到「认知型财务(自动驾驶仪)」。
> 参照: 《AI智能财务大模型》(FinMind·智财) 方案——四层智能体协同 + 六大创新能力 + 三阶段演进。
> 调和: 本项目宪法铁律(LLM 禁入资金判定链/决策确定性/重大操作人工否决)——智启元继承 FinMind 愿景的**能力版图**, 进化机制全部采用**确定性引擎**(对齐 36号进化引擎/ai_learning Hedge/三检测器既有成熟范式), LLM 仅承担文案润色与意图解析辅助, 永不产出数字与判定。
> 命名: 「财务管理」→「**智启元·AI智能财务大模型**」(ZhiQiYuan Fin-Intelligence)。

## 二、架构: 四层协同(文档 §2 × 项目宪法)

```
L1 意图层: 自然语言财务问答(意图路由→确定性查询, 数字100%来自查询层)
    ↓
L2 智能体集群(确定性 Agent, 全部可解释):
    核算Agent(五单校验+分录建议) / 分析Agent(杜邦+归因+预测)
    / 税务Agent(模拟+政策匹配+风险扫描) / 资金Agent(现金流排程)
    ↓
L3 数据织物: finance_repository + 订单/支付/钱包/发票 只读聚合(编排式零回写)
    ↓
L4 自主进化引擎: 确定性反馈闭环 + 异常自发现 + 全链路决策留痕
```

**铁律调和表**(文档愿景 → 本站实现):

| 文档机制 | 智启元实现 | 依据 |
|---------|-----------|------|
| Fin-LLM 核心大脑 | LLM 仅意图解析辅助+报告润色; 判定/数字全查询层 | 宪法: LLM 禁入判定链 |
| RLHF 强化学习 | ai_learning Hedge 确定性权重学习(既有范式) | 宪法: 确定性规则 |

| 自主决策 | AI 仅"建议+推理链", approve 决定权在 admin | 文档红线同款: 人类最终否决权 |

| 政策实时监控 | 政策库人工维护+版本标记, 自动匹配不自动生效 | 宪法: 禁自动变更口径 |

## 三、六大创新能力 → P0-P3 分期实施

### P0 智启问答与分析中枢(增强辅助, 对齐文档 L1 阶段)
- **NL 财务问答**: 关键词意图路由(收入/成本/税负/现金流/异常五域) → 确定性查询 → 句子模板拼接(数字 100% 插值)
- **杜邦分析**: ROE 三因素分解(净利率×周转率×权益乘数) + 趋势对比
- **归因分析**: 利润变动因素分解(量/价/本/费四因素, 确定性连环替代法)
- **财务健康度**: 五维评分(偿债/营运/盈利/成长/现金, 分段 Sigmoid 复用 68号范式)

### P1 预测与情景沙盘(主动洞察, 对齐文档 L2 前半)
- **滚动预测**: 12 期现金流/收入/成本预测(加权移动平均 + 趋势外推, 确定性公式)
- **What-if 情景模拟**: 输入变动假设(售价±/成本±/销量±) → 秒级多维影响推演(利润/现金流/税负)
- **驱动因素建模**: 收入/成本关键因子识别(相关性系数确定性计算) + 敏感性排序

### P2 税务优化引擎(价值创造, 对齐文档 L2 后半)
- **交易级税负模拟器**: 交易结构(一般销售/折扣/跨境/组合销售)×税率 → 综合税负对比 + 最优建议(留痕, 不自动变更)
- **政策匹配引擎**: 优惠政策库(人工维护带 effective_date) × 业务标签自动匹配 + 节税估算
- **风险热力图**: 税务风险点扫描(进项转出遗漏/关联定价异常/税负率偏离行业均值) 五级热力

### P3 自主进化与决策支持(对齐文档 L3)
- **全域反馈闭环**: 分析报告/预测/税务建议的采纳/修正/拒绝标记 → Hedge 权重学习(预测参数/因子权重)
- **异常自发现**: 财务数据流三检测器(金额spike/科目drop/频率surge, 复用既有范式)
- **资金智能调度**: 90 天逐日现金流缺口预测 + 融资成本比较建议(建议书模式, 走 46号审批)
- **决策备忘录**: 结构化投资/预算决策文档生成(模板+数据插值+假设标注)

### 全期贯穿: 可信与安全
- 推理链留痕(每输出附计算路径) / 敏感数据脱敏展示 / 重大建议全部"建议书模式"(admin approve)
