# 80号·竹园 网站资产自进化 Agent 创新规划方案 v1.0

> 来源: 《竹香酒网站资产智能管理与自进化系统规划书》(BW-AIH 前沿文档)裁剪落地
> 家族定位: 竹盾(78号·空间影响面) × 竹医(79号·时间业务链) × **竹园(80号·资产养护)**
> 纪律: 沿用 79 号铁律——只出不施 / 证据驱动 / MD 为源 / Benchmark 先行
> 日期: 2026-10-22

## 一、模块定位

竹园(zhuyuan)管**资产健康度**: 盘点-补全-评估-优化-审查全链, 确保网站内容
完整度与合规性持续达标。三兄弟分工: 改动前问竹盾, 链路断裂问竹医,
**资产荒芜问竹园**。

## 二、裁剪决策表(前沿方案 vs 本项目)

| 文档原方案 | 本项目决策 | 理由 |
|---|---|---|
| LangGraph 状态机编排 | 裁掉, 用户逐任务驱动(人即总控)+CLI | 开发期工具链形态, 家族一致 |
| 向量库 RAG(Qdrant/Milvus) | 裁掉, 关键词+元数据检索(竹医 cases 已验证) | 资产规模百级, 向量是杀鸡牛刀 |
| 常驻 LLM 生成内容 | 裁掉, 缺口→**建议处方**(只出不施), 人工采纳后生成 | 防幻觉(599 教训)+微信合规整改实战验证人工审核必要性 |
| 五 Agent 角色体系 | **保留职责分离**, 实现为五个检查器模块 | 盘点/评估/审查/优化/合规各司其职 |
| P0-P3 优先级模型(价值×风险×时效) | 保留, 简化为 P0 阻断/P1 严重/P2 一般 | 对齐家族分级口径 |
| 审查驳回→再生成循环 | 保留语义: 处方驳回→重新处方(人工驱动) | 闭环留给竹医 consult 复用 |
| Lighthouse 集成 | 裁掉, **业务探针**(Playwright)优先 | 本会话已实战: 购买按钮首屏/产地模块/评分可见性 |
| CMS Webhook 知识热更新 | 裁掉, git 提交即知识更新(MD 为源) | 无 CMS, 静态站 |
| Redis Stream 任务队列 | 裁掉, 单机顺序执行 | 开发期无并发需求 |
| optimization_cases 案例自进化 | **保留=复用竹医 cases 库**(五段式+检索) | 79 号已建好, 资产案例继续入同一库 |
| 合规词库可执行化(regex) | **保留——本日微信整改 20 处违规词实战沉淀** | 已被市场验证的刚需 |

## 三、五检查器架构(竹园 CLI)

```
zhuyuan audit      资产盘点——完整性缺口检测(占位符/空栏目/断链图/ALT/SEO) → 资产台账
zhuyuan comply     合规审查——广告法违禁词 regex 引擎(醒酒快/不头疼/畅饮/富硒/有益/就喝/绝对化用语...) → 合规报告
zhuyuan probe      性能探针——业务指标(购买按钮首屏可见/资质模块完整/评分展示)Playwright 实测 → 探针报告
zhuyuan prescribe  缺口处方——缺口/违规 → 案例检索+修正建议(复用竹医 consult 模式, 只出不施)
zhuyuan evolve     自进化——审查发现→cases 入库(新案例五段式)→下轮检索命中
```

## 四、Benchmark(已知答案回放, 沿 79 号口径)

**B1 合规基准**: 本日微信外链整改实录做已知答案——17+3 处违规词(醒酒快/无酒气/
不头疼/畅饮/富硒/有益成分/福来就喝/健康密码)回放, comply 检出率必须 100%
(实测残留 0 为过)。B2 盘点基准: index noscript 资质块/11 系列品名做健康资产样本,
人为挖空一处做缺口样本→audit 检出。

## 五、优先级模型(简化三维)

P0(阻断)=违禁词/价格错误/购买链断 —— 立即处理
P1(严重)=核心参数缺失/主图缺/资质行缺 —— 当日
P2(一般)=ALT 缺/内链少/正文短 —— 本周

## 六、与 78/79 号的复用关系

- 资产台账底座: 竹盾 L0 三清单+registry(页面 59/端点 2612)——竹园只做**内容层**盘点(html 正文/文案), 不重复建路由/模块台账
- 案例库: 竹医 cases/ 六案例+检索器直接复用, 竹园新案例(合规/盘点类)按 T0.2 五段式规范续入同库
- 处方: 竹医 grade_prescription/BR/回归映射管线复用, 竹园 prescribe 输出同格式处方
- 度量: zhuyi:stats 模式复制为 zhuyuan:stats(comply_total/violations 等)
