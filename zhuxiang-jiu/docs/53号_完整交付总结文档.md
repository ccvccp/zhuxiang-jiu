## 一、模块概览

**53号是小竹语音家族的入口收口模块**。基于《AI智能网站入口模块规划方案》（3S+AI Trust 设计原则），以"复用底座、编排创新"为架构核心——39号 entry 凭证协议+43号风控评分+48号语音会话+50号声纹双态+49号隐私预算全部就绪，53号做**智能编排层**，零重复造轮子。

```
【复用底座——只读调用零改动】          【53号智能编排层】
39号 entry: bio挑战制+扫码+设备信任  →  态势感知(静默/一键/常规)
43号风控:   AuthRiskScorer 8因子   →  五通道统一编排+四级响应
48号语音:   会话/唤醒/绑定桥        →  唤醒即认证+语音导览
50号声纹:   proxy/real双态+活体     →  声纹初筛+语义双因子
49号预算:   check_and_spend         →  通道成本扣减+预算预检
```

**核心数字**：六期交付 / 专项 220 断言+实机 30 项次 / 20 端点 / 4 表 / 话术 17 场景+五通道+四态+六指标 / 复用底座零改动（宪法断言每期验证）。

## 三、各期交付明细

### 3.1 P0 注册表+态势感知层

- **话术注册表**（三组 17 场景）：正向 7（唤醒即认证/Passkey 静默/刷脸成功/声纹二次确认/扫码跨端/老年/视障）+异常 7（归因外部化+去污名化铁律"这不是您的错"+出路铁律 fallbackAction）+退出 3（非强制挽留）；TTS 四态参数+责备性话术黑名单 8 词启动自检
- **注册表**：五通道矩阵（底座锚点绑定+声纹 proxy 不作凭证铁律）+风险四档阈值（25/50/70/100）+角色四态+六指标
- **四态判定引擎**：high_risk（风控优先）>dormant（>30天）>new（账龄<7天）>active+状态迁移留痕
- **态势感知**：基线匹配三档（>0.95 静默/>0.70 一键）+意图预判+预算预检（49号只读探针——耗尽→零成本通道推荐）
- **价值钩子生成**：45号信值经 48号绑定桥聚合（fail-soft）

### 3.2 P1 多模态认证编排引擎

- **编排流**：通道校验→预算扣减（49号）→风险评分（43号 AuthRiskScorer）→四级响应→令牌签发→事件流水（六字段对齐 49号审计口径）
- **五通道校验**（底座复用）：passkey/fingerprint（39号 bio）/face（50号 liveness——<0.5 TTS 疑似→安全挑战）/voice（声纹+语义双因子铁律）/qr（39号票据一次性消费防重放）
- **四级响应**：silent（<25 直接签发）/one_tap（25-50 确认令牌 60s 二段式）/step_up（50-70 短信话术）/enhanced（风控标记/硬约束强制多因子+去污名化）
- **安全兜底**：反欺诈安全挑战（随机动作指令）/失败优雅降级（同通道 3 次→备选建议）/降级 step_up 不裸放铁律

### 3.3 P2 语音融合登录

- **唤醒即认证**（六步）：唤醒判定（48号 detect_wake 近似音容错）→声纹初验（50号 verify——proxy 标注不作凭证）→语义口令校验（双因子）→会话建立（48号 open_session）→编排签发→导览首播
- **登录后语音导览**：时段问候四档+个性化摘要（信值/积分/待办）+快捷指令三条；全链 fail-soft
- **反语音霸权**：未唤醒前缀拒绝（48号同款红线）；memberId→trustId 经 48号绑定桥（跨 ID 体系红线）

### 3.4 P3 角色专属入口+价值钩子

- **四态门户配置**（液态信任布局）：new（价值启蒙+三步引导+登录表单弱化）/active（无感续接+意图直达页）/dormant（损失规避+错过收益时间轴）/high_risk（透明保护——橙色+禁红色警告+人工兜底）
- **登录前价值钩子**：preAuth 投放（"还没进门就有收获"）四态差异化
- **沉睡唤醒**：错过收益时间轴（天数+估算+恢复路径"无需额外验证"）

### 3.5 P4 驻留激励机制

- **每日奖励**：语音问候互动→微量 2.0 分（50号 voice_login L1 台账口径+source 留痕+dailyCap 防刷继承）——memberId+dayKey 幂等铁律
- **连续登录叙事**：streak 计算（昨日+1/断档重置）+三里程碑（3/7/30）成就解锁+游戏化话术
- **退出挽留**：intercepted=False 非弹窗拦截铁律+功能教育+明日成就预告

### 3.6 P5 效果评估+监控看板+红队收官

- **六指标管道**：成功率（空态满分）/耗时（秒）/留存（驻留信号 proxy）/语音占比/投诉率（proxy）/信任增益（52号复用 proxy）——快照留痕递增
- **监控看板**：六指标+通道占比+风险分布+四态分布+驻留统计——观测面 off 不阻断
- **红队收官**：RT-01~06 全拒绝（伪造令牌/跨会员凭证/通道伪造/预算绕过/挑战伪造/令牌重放）——53号自身零新攻击面（纯只读编排层）

## 六、红线体系（全程贯穿）

1. **零侵入红线**：复用底座只读调用——39号 24 路由/43号风控/48号唤醒词表/49号 17 工具/50号 14 行为+声纹 proxy 默认态（宪法断言每期验证）
2. **off 直通铁律**：LOGIN53_MODE=off 编排面 409——直通存量 39号登录（零接管）
3. **声纹 proxy 不作凭证**：双因子铁律（声纹初筛+语义口令）
4. **预算扣减铁律**：通道成本>0 走 49号——耗尽不签发
5. **令牌一次性**：confirmToken/securityChallenge 消费后重放拒绝
6. **去污名化铁律**：高危话术"这不是您的错"+禁红色警告
7. **非拦截铁律**：退出挽留 intercepted=False（尊重选择）
8. **幂等铁律**：驻留奖励 memberId+dayKey 当日一次
9. **降级不裸放**：评分器异常→step_up 档（43号同款）

## 十一、结语

原方案价值锚点全盘继承：**入口模块是"信任的首次交付"。它的成功不在技术指标的完美，而在让用户 3 秒内感受到"这个平台尊重我、理解我、值得我停留"。当登录从"关卡"变成"拥抱"，引流与驻留便是水到渠成的结果。技术只是骨架，对人的敬畏才是灵魂。**

39-52号交付了信任的底座，53号让入口成为这套信任体系的**第一次温暖交付**。
