# 63号·AI智能后台管理模块 实施计划

> 定位：本站多角色的**动态信任协作网络**——"意图驱动+信值锚定"的智能治理中枢（权限随场景流动、合规在编辑态内生、发布由信值裁决）

> 范式：角色登录 → **63号智能权限引擎（动态授权+情境工作台）** → 编辑产品/服务（**AI 合规护航——编辑态左移）** → 提交 → **智能审核网关（L1/L2/L3 分流）** → 发布运营（灰度兜底）→ 信值结算联动——构成"感知-赋能-护航-裁决-激励"闭环

---

## 一、定位与差异化边界（五权分立）

| 模块 | 职责 | 一句话 |
|------|------|--------|
| **63号 智能后台（本模块）** | 角色的**认知工作台**（动态权限+情境界面+编辑态合规+发布分流） | "角色能做什么、怎么做才合规" |
| 既有 auth_middleware | 身份认证（Token→X-Role 注入——纯消费） | "你是谁" |
| 既有 role_service | 角色/申领台账（静态 RBAC 基础） | "角色名册" |
| 46号 治理中枢 | 变更审批总线 | "规则变更谁批准" |
| 58/59号 | 意图识别/服务编排（63号感知输入——纯消费） | "用户想干什么" |

**核心差异（传统后台 → 本站 63号）**：

| 维度 | 传统后台 | 63号 | 差异 |
|------|---------|------|------|
| 权限模型 | RBAC 固定菜单 | **ABAC 动态授权**（角色×信值×场景×风险实时计算） | "一刀切"→"千人千权" |
| 合规检查 | 发布后拦截 | **编辑态实时护航**（AI 伴随式三档干预） | "事后拦截"→"事前预防" |
| 审核流程 | 全量人工 | **L1 自动/L2 AI 辅助/L3 双人复核**智能分流 | "人力瓶颈"→"精准投入" |
| 同盟商体验 | 学习成本高易犯错 | **情境化引导**（任务驱动+模板推荐+无障碍） | "被动适应"→"主动赋能" |
| 价值闭环 | 操作日志审计 | **信值结算联动**（合规发布奖励/违规扣减+培训） | "纯管控"→"激励相容" |

**总铁律**：AI 的合规建议仅为辅助，**最终发布责任始终归属操作者与审批人**；所有 AI 判断必须**可解释、可申诉、可追溯**；**禁止 AI 直接修改已发布内容**——仅可标记或建议下架。动态权限调整必须**实时可解释**（"因您近期 3 次内容违规，临时关闭批量发布权限，完成合规培训后恢复"——杜绝黑箱授权）。设计自问：**这让角色感到被支持，还是被监视？——答案永远指向前者。**

## 三、四层智能协同架构

### 3.1 智能权限引擎（P1）

**多维上下文感知**（PERMISSION_RULES 四轴）：
- 身份轴：角色类型（同盟商/运营/审核员/管理员）×历史合规率×47号 tier
- 场景轴：操作时段（业务高峰敏感）×设备可信×并发会话
- 内容轴：拟发布内容敏感度×影响范围
- 行为轴：近期操作异常率（43号威胁分输入之一）

**动态权限计算**：
```
Permission_Score = base(角色模板)
  + tier_bonus(47号: trusted +20/standard 0/watched -15/restricted -30)
  + compliance_bonus(历史合规率 90 天窗口)
  - risk_penalty(场景/内容风险)
  ± decay(权限闲置衰减——90 日未用高危权限回收)
```

- **权限衰减**：长期未使用高危权限自动回收（reactivation 经人工）；异常操作→临时降权+管理员通知
- **可解释铁律**：每次权限变化携带 reason（规则 ID+依据+恢复路径）
- **fail-soft**：感知源异常→基线权限（最小权限域）+留痕

### 3.2 情境化工作台（P2）

**WORKBENCH_TEMPLATES 分角色模板**（封闭注册——五类角色）：

| 角色 | 感知策略 | 界面呈现 |
|------|---------|---------|
| 同盟商（新手态） | 新手标记+业务类型（养老/文创） | 隐藏高级配置+高亮合规向导+行业模板+基础 CRUD |
| 同盟商（成熟态） | 批量意图+历史高合规 | 批量工具栏+免审白名单额度（高信值） |
| 内容运营 | 批量操作意图+历史合规率 | 批量工具+分级预览（低信值强制逐条） |
| 合规审核员 | 待审队列风险分布 | 专长领域优先推送+AI 预标注疑点+法规依据+同类判例 |
| 平台管理员 | 全域异常聚合 | 风险热点+信任赤字仪表盘+一键下发新规 |

- **无障碍适配**：设备/偏好检测（49号偏好域）→大字版/语音辅助语义标记+操作停顿检测→简化建议（建议性）
- **智能模板推荐**：同类优质案例预填（57号 published seeds 纯读取——行业模板域）

### 3.3 AI 合规护航助手（P2——编辑态三档干预）

**COMPLIANCE_GUARD 检测域**（确定性规则——左移至编辑态）：
- 文本轨：敏感词表（封闭）+夸大宣传词表+缺失必要条款（产品 schema 必填域）
- 表单轨：必填遗漏+逻辑矛盾+超范围采集
- 隐私轨：PII 泄露检测（48号 mask_pii 正则复用）+49号隐私预算预估

**渐进式干预三档**：
| 档 | 交互 | 语义 |
|----|------|------|
| 提示级 | 浅色标注+悬停说明 | "建议补充服务有效期，提升用户信任" |
| 警告级 | 弹窗+修改建议链接 | "检测到未授权图片，请替换或上传授权书" |
| 阻断级 | 红色锁定+强制学习入口 | "涉及金融资质缺失，请先完成资质认证" |

- **合规知识嵌入**：易错点旁"为什么需要这个？"→法规解读/成功案例（57号种子关联）
- **隐私预算可视化**：实时预估消耗+超支脱敏替代方案

### 3.4 智能审核网关（P3）

**三级分流**（Publish_Score 确定性公式）：

| 级 | 条件 | 流程 |
|----|------|------|
| L1 自动过审 | ≥90 分+无高风险标签+tier≥trusted | 秒级发布+信值奖励；**5% 抽样复检** |
| L2 AI 辅助 | 70-89 分 | AI 预审意见（结构化+条款+判例）→人工确认标注点 |
| L3 深度复核 | <70 分或资金/身份/儿童/医疗域 | **双人独立审核+合规官终审** |

- **审核证据链**：AI 判断依据+人工决策理由+关联合规条款（哈希指纹链——可追溯可申诉）
- **驳回反馈闭环**：驳回原因结构化映射回编辑页字段；**高频驳回点→定向培训推送**
- **灰度发布建议**：高风险变更（价格/服务范围）默认建议灰度——监控反馈达标后全量（建议域）

## 四、第38档案：admin_orchestration 八因子

## 五、数据模型（7 表，前缀 ab63）

| 表 | 键 | 语义 |
|----|-----|------|
| ab63_grants | grantId | 权限裁决记录（上下文快照+权限分+reason 可解释链） |
| ab63_workbench | wbId | 工作台渲染（角色模板+意图关联+呈现配置） |
| ab63_guards | guardId | 编辑态护航事件（检测域+干预档+整改状态） |
| ab63_submissions | subId | 发布提交（内容快照+Publish_Score+分流级） |
| ab63_reviews | reviewId | 审核记录（L1 抽检/L2 辅助/L3 双人——证据链） |
| ab63_thresholds | tier | 分流/权限配置域（46号审批联动） |
| ab63_events | eventId | 全链事件（grant/render/guard/submit/review/appeal/learn_signal/scheduler_run） |

发布状态机：
```
draft → guarded(编辑态护航) → submitted(预检通过)
  → auto_published(L1) / pending_review(L2) / deep_review(L3)
  → published(终态——灰度建议可选)
  /rejected(驳回→修改建议+培训推送)
disputed(申诉中) → adjusted(翻转留痕)
```

复用：44号池（第38档案 batch22）；58号 evaluate（意图感知纯消费）；47号 get_profile（tier）；49号 check_and_spend（隐私预算纯调用）；46号审批总线；57号 published seeds（模板/知识关联纯读取）；43号威胁分（行为轴输入之一）；既有 auth_middleware X-Role（身份轴纯消费）。

## 七、分期实施计划（P0-P5）

### P0 后台注册表+角色感知底座
- PERMISSION_RULES/WORKBENCH_TEMPLATES 封闭注册+启动自检（52号范式）
- 角色×场景感知底座（身份轴+场景轴——纯消费输入）
- 第38档案入册 batch22（37→38 计数更新约 37 处 15 文件）
- 7 表底座；测试约 45 断言；QC：注册封闭；auth/role_service 零改动

### P1 智能权限引擎
- Permission_Score 五因子计算（tier bonus/合规 bonus/风险 penalty/衰减）
- 权限衰减与回收（90 日闲置+临时降权）
- **可解释链**（reason 规则 ID+恢复路径）+fail-soft 基线
- 测试约 40 断言；QC：无黑箱授权；感知源零写入

### P2 情境工作台+AI 合规护航
- 五角色工作台模板渲染（意图驱动导航建议+无障碍标记）
- COMPLIANCE_GUARD 三轨检测（文本/表单/隐私）+三档干预
- 隐私预算可视化（49号预估调用）+知识嵌入
- 测试约 40 断言；QC：三档干预分级正确；LLM 不进判定链

### P3 智能审核网关
- Publish_Score 公式+L1/L2/L3 分流+L1 抽检
- L3 双人复核+合规官终审（46号范式）+审核证据链
- 驳回反馈闭环+灰度发布建议
- 阈值配置域（46号审批+人工终审轨）
- 测试约 40 断言；QC：AI 不直接改已发布内容；L3 永不自动

### P4 审核反馈闭环+培训推送+回流
- 高频驳回点→定向培训推送（7 日转化跟踪）
- 六类后台事件→第38档案池双写（subId 1:1 幂等）
- 权限/分流阈值校准预警（经 46号审批）
- T+1 调度器（AB63_LEARN_MODE 默认 off）
- 测试约 40 断言；QC：回流幂等；预警人工审批

### P5 看板+红队+三件套收官
- 四区看板（度量：合规前置率/自动过审准确率/审核时效/信值健康度+权限+护航+防御）
- 红队七向量：权限提升（伪造上下文降风险分）/护航绕过（阻断级跳过）/分流操纵（刷高 Publish_Score）/审核越权（非双人裁决 L3）/申诉刷分/培训逃避（重复驳回不学习）/模板注入（恶意行业模板）
- 宪法断言（44号 38 档案+auth/role/58/59号零改动）+收官三件套
- 测试约 35 断言；QC：后台安全全链防御

**开关矩阵**：`AB63_MODE`（默认 **off**——off/shadow/assist）/`AB63_LLM_MODE`（建议文案润色，默认 off）/`AB63_LEARN_MODE`（调度，默认 off——三开关铁律）。

## 八、风险控制矩阵

| 风险 | 缓解 | 验证 |
|------|------|------|
| 权限滥用 | 最小权限+动态衰减+高危 MFA（48号 confirmToken）+异常告警 | P1 断言+P5 红队 |
| AI 误判发布 | L1 抽检 5%+人机协同兜底+误判纳入迭代 | P3 断言 |
| 绕过合规 | 前后端双校验+API 限频+绕过留痕上链 | P2 断言+红队 |
| 审核标准漂移 | 规则版本化+AI 预审标准化+定期校准 | P3 断言 |

## 九、一致性声明与外部待办

**零改动宪法**（每期断言验证）：44号学习中枢零改动（仅新增第38档案，38 档案口径）；既有 auth_middleware/role_service 零改动（X-Role 纯消费）；58/59号零改动（意图/场景纯消费）；47号画像/49号预算/43号威胁零改动（纯读取/调用）；46号治理零改动（审批总线调用）；57号 seeds 纯读取。

**外部待办**：真实多模态检测（图像 CV/视频——当前文本+表单确定性轨）；真实 LLM 合规副驾驶对话（当前规则轨+LLM 仅润色）；ABAC 引擎标准化（XACML 对接——生态期）；无障碍真实语音辅助（当前语义标记）；角色生态自定义模板市场（远期）。

**结语**：63号让合规成为角色的自然习惯而非外部约束——权限随信值流动、边界在编辑态被温柔提示、发布由信任裁决；当一位新同盟商编辑产品时，AI 像导师般提醒"补充紧急联系人能提升家属信任"，而非冷冰冰弹出"违规禁止保存"。**AI 不替代人工审核，而是将合规左移至创作时——信任生态始于对创造者的尊重。**
