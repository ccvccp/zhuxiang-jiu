## 二、设计(rule 轨最小面)

### 2.1 意图注册(2 条)

```
agent.apply(招商代理):
    patterns: 代理, 招商, 加盟, 分销, 做代理, 想代理,
              怎么代理, 代理政策, 招商政策, 代理申请,
              想加盟, 渠道合作, 代理条件, 怎么加盟
    examples: "小竹，我想做代理" / "小竹，招商政策是什么" /
              "小竹，怎么加盟"

agent.faq(代理政策要点, 可选轻问答):
    patterns: 代理返利, 返利层级, 代理等级, 代理门槛
```

### 2.2 钩子执行器(rule 轨模板, 48ms 惯例)

- **reply 话术**(官方口径三要点, 合规尾巴硬注入):
  品牌扶持(竹香酒自营品牌+县区代理体系) / 返利层级(引用
  /api/agent/levels 与 rebate tiers 官方档位, **不编造数字**)
  / 申请方式(卡片跳转)
- **card 联动**: 前端有代理申请页则 jump 该页; 无则引导
  "联系人工咨询"(chat.human 意图已有)+ 留言要点
- **语音预登记不做**(P3 候选): AgentApplyRequest 表单字段多
  (姓名/电话/地区/渠道), 语音填表体验差——48号惯例是卡片
  联动而非语音填表; 建议原文"引导填写地区渠道联系方式"以
  页面联动实现

- 话术数字只引官方接口档位(法务口径, 不编造收益承诺)
- 合规尾巴硬注入(招商话术同受"理性饮酒未成年人禁止饮酒"
  红线约束)
- fail-soft: 钩子异常走 chat 轨兜底(既有惯例)
