## 二、核心机制

### 1. 认知健康度(三指标——查询层插值全只读)

| 指标 | 口径 | 阈值 |
|---|---|---|
| 内容多样性指数 | 因果洞察维度分布熵归一(选题角度代理) | <0.30 越界 |
| 渠道匹配准确率 | active 预分配 top 渠道 vs 实际转化渠道命中 | <0.40 越界 |
| 预判偏差率 | active 方案偏差(MAPE 口径) | >0.30 越界 |

- 样本不足(<5)指标不判定(防小样本误冻结)
- **任一越界→frozen 自动冻结**(frozenDomains=experiment_propose+mode_transfer_up);预警带(阈值±20%)→degraded
- **冻结持久**: 指标回域内也不自动恢复——解冻人工专属(`ATTRACT72_IMMUNITY=1` 环境变量双保险, 免疫自动永不解冻铁律)

### 2. 红队四向量(71号 P8 范式首次移植非资金域)

| 向量 | 攻击 | 防御 |
|---|---|---|
| RT-01 刷量注入 | 同指纹 51 次轰炸/隔离后买个性化/匿名刷个性化 | 窗口频次线自动隔离/隔离态降级 default 不拒服务/无指纹兜底 v1.0 一致 |
| RT-02 归因投毒 | 伪造归并请求/意图快照投毒 | 点击必须真实存在(KeyError 拒绝) |
| RT-03 博弈操纵 | 凭空挂单伪造消耗/重放挂单刷消耗 | 消耗必须挂真实归因链/已回写订单幂等拒绝 |
| RT-04 人格漂移 | 主体域外注入/意图标签洪泛(20 个)/样本剧变静默 | 主体域封闭/并集截断 8/history 变更留痕 |

全确定性(构造→断言→留痕, LLM 禁入); off 档无攻击面 409; 未防御向量→自动冻结进化。

### 3. 自主实验沙箱(铁律八)

- 提案链: L1 白名单变量(探索基金占比/落地页变体权重/选题入队阈值——奖励系数/定律边界/合规永不可)→46号 batch48 建议书(pending)→结论
- 沙箱约束: 非核心渠道(kuaishou/bilibili/seo)/小预算(≤50 元)/灰度流量(≥100 样本)
- **双向结晶**: success→增长定律(law)/failure→反知识(anti)/inconclusive→null; 46号 change 结案归档
- 状态机: proposed→concluded(结论域外 409/重复结论 409/不存在 404)

### 4. 进化日志(观测面)

六类聚合时间倒序: 定律结晶/实验提案/实验结论/卡位裁决/预算重博弈/红队/健康度——数字 100% 查询层插值。

### 5. 转段四档(admin+confirm 二次确认)

- 升档逐档(跳档拒绝); 降档随时(安全方向)
- 健康度冻结→升档拒绝; KILL 制动全拒
- **assist→full 须最近一次红队四向量全防御**(生产转段核验口径)
- 运行时即时生效(单进程 env 免容器重建)+attract72_mode_state history 留痕; .env+docker 重建为持久口径

## 四、铁律遵循

1. **LLM 禁入判定链**: 健康度三指标/红队断言/结晶分派=确定性公式
2. **冻结自动+解冻人工专属**: 环境变量双保险, 免疫自动永不解冻
3. **红队全确定性**: 构造→断言→留痕, 无 LLM 依赖
4. **探索沙箱铁律八**: 非核心渠道/小预算/灰度流量, 失败不影响主业务
5. **L1 白名单越界拒绝**: full 档可开放参数封闭, 奖励系数/定律边界/合规永不可
6. **审批唯一**: 实验提案走 46号 submit_change(审批总线 P0 不自动执行业务侧变更)
7. **观测面常开**: 健康度/日志/台账/模型状态不受 MODE/KILL 影响
8. **零破坏 QC**: attract v1.0 零点击写入/雷达零触碰(RT scratch 留痕外)

## 六、运营口径

- 默认 ATTRACT72_MODE=off(观测面常开, 决策面 409)
- 转段路径: off→shadow(≥7 天影子期)→assist(评估签核)→full(须红队全防御+L1 白名单)
- 生产转段: 修改 .env `ATTRACT72_MODE` + `docker compose up -d backend` 重建; 运行时切档 `POST /api/attract72/mode/{target}?confirm=true`(免重建留痕)
- 回滚: `sed -i 's/^ATTRACT72_MODE=.*/ATTRACT72_MODE=off/' .env && docker compose up -d backend`
- 紧急制动: `ATTRACT72_KILL=1`(数据面+环境变量双保险)
- 解冻: `ATTRACT72_IMMUNITY=1` + `POST /api/attract72/meta/unfreeze`
