## 一、项目概览

**一句话定位**：用户说人话，智搜判断「他是谁、他想要什么」，从站内
商品/权益/订单/知识/区域/餐饮多库中查出正确答案或执行正确动作——
Web 搜索页 + 小竹语音双入口。

**Multi-Agent 视角**（对照「网站智能体」方案）：
智搜 = **Router Agent**（意图识别/拆解/分发/融合）+ **Guardrail
Agent**（输入端 L2 硬拦截 + 输出端守门双重校验）；七模型 = 业务专家
层；三参数进化闭环 + 坏案例聚类 + A/B 话术实验 = **Evolution
Engine**——方案四层角色全数落地。

**复用率**：MVP 复用站内 80% 资产，新建面集中在意图层与融合层。

## 二、五层架构最终形态

```
用户输入（Web search.html / 小竹语音 zs.search——规则/LLM/FC 三轨）
        ↓
┌─ L1 意图层(Router Agent) ────────────────────┐
│ 规则锚点得分制(7 意图+强操作词+低置信线)        │
│ × anchor_boost 反馈调权(clamp[0.5,3.0])       │
│ + LLM 兜底(intentWeight 采纳闸, fail-soft)    │
│ + 混合意图拆分(分句→副意图→双路, 上限2)        │
│ + 槽位 9 类(价格/场景/商品/单号/运单/等级/省份) │
└──────────────┬───────────────────────────────┘
        ↓
┌─ L2 合规前置(Guardrail 输入端, 硬规则) ───────┐
│ 未成年购酒/医疗功效/代理收益承诺 → 命中即拦截   │
└──────────────┬───────────────────────────────┘
        ↓
┌─ L3 多路检索(业务专家层) ─────────────────────┐
│ R1 商品(含库存) | R2 权益(会员+过期积分)        │
│ R4 订单(鉴权+智运+精确单) | R5 知识(embedding) │
│ | 区域保护卡(省份×citystore) | 餐饮导流(智图)  │
└──────────────┬───────────────────────────────┘
        ↓
┌─ L4 融合重排(确定性) ─────────────────────────┐
│ 相关0.5+角色0.2+业务0.2×routeBoost+合规0.1恒定 │
└──────────────┬───────────────────────────────┘
        ↓
┌─ L5 生成与动作(Guardrail 输出端 + A/B 实验) ──┐
│ A/B 话术分流(decisionId 奇偶) → 结构化回答     │
│ → guard_output 输出守门(中性替换)              │
│ → 反馈/点击 → 三参数进化 + A/B 双轨计数        │
└───────────────────────────────────────────────┘
```

## 三、各期交付明细

### MVP（ae5c458 + a84ed50）
- **意图层**：7 意图规则锚点表（独占词 2 分/共享词 1 分）+ 强操作词
  加成 + 低置信 chat 兜底；纯符号零 LLM（有效字符闸）
- **合规前置**：minor/medical/agent_promise 三组硬规则——命中即拦截，
  权重永不参与进化
- **双路检索**：R1 商品 + R5 知识（三级检索 2-gram+embedding+rerank）
- **三态灰度**：ZS_MODE off(409)/shadow/assist
- **决策留痕**：意图/槽位/hits/候选 top3/合规/llmAssist/subIntents/
  mode/variant/outputGuard 全审计
- **前端**：search.html

### P1（1402d1b）
- **R2 权益路**：角色×意图二维路由——会员个人化（等级/积分/成长值/
  保级进度），游客体系介绍+注册引导
- **R4 订单路**：鉴权联动——游客零查询（隐私），登录本人隔离+智运
  轨迹摘要；订单号/运单号精确查单（非本人单不放行细节）
- **显式反馈进化**：routeBoost ±0.05 clamp[0.8,1.2]

### P2（374724a + 8636ea7）
- **LLM 意图兜底**：低置信单次调用产出意图+改写问句（fail-soft）；
  intentWeight 采纳闸（≥0.6 采纳，反馈 ±0.02 进化）
- **查询改写**：口语→规范问句供知识路 embedding 检索
- **隐式转化回流**：动作卡点击（sendBeacon）→ +0.03
- **小竹语音接入**：zs.search 指令
- **智搜看板**

### P3（b13cdff）
- **混合意图拆分**：一句话多问→分句→副意图→双路检索→合并回答；
  护栏：合规整句拦截不绕过、子查询上限 1（总路数 2）

### 增强①锚点自动调权（30544d9）
- **anchor_boost{word}**：命中词权重×乘数，反馈 ±0.1 clamp[0.5,3.0]
- 决策留痕补 hits（归因依据）；留痕 anchorTuning；看板条形展示

### 增强②FC 三轨同步 + shadow 完整语义（c202c3a）
- **小竹三轨一致**：TOOL_REGISTRY（只读+描述内嵌禁令）+ executor
  SAFE_READONLY 沙箱白名单 + LLM command 白名单
- **shadow 完整语义**：三态留痕（decision.mode）+ 进化冻结

### 增强③Multi-Agent GAP-1~3（7e11c03）
- **GAP-1 输出端守门**：guard_output 极限词+医疗暗示中性替换表
  （确定性、LLM 禁入、只改话术不改事实数据）+ outputGuard 留痕
- **GAP-2 业务闭环**：招商区域保护联动（agent×省份→citystore）/
  会员过期积分提醒 / 导购库存状态展示
- **GAP-3 创新体验**：宴请×智图餐饮导流卡（订餐 Agent 诚实裁剪版）/
  坏案例聚类（bad-cases 端点+看板区块）

### 增强④A/B 话术框架（f1de15e 方案 + eb914d9 实施，GAP-3c 终项）
- **安全化改造**（对照方案原文）：自动晋升→**建议书模式**（admin
  手动确认，永不自动）；留资转化率→有用率+点击率双指标；两周评估
  →样本量驱动（≥30 且优出 ≥20%）
- **VARIANT_LIB**：equity/agent/product 三意图 × A/B × guest/member
  占位文案（运营修订随时可换）
- **分流**：decisionId 奇偶确定性（50/50、可复现、与会员等级无关）
- **双轨计数**：served/useful/useless/action；shadow 不计入；防刷分
  闸后计数
- **定版语义**：晋升后 variant="P" 全走优胜版；空串重置回实验态
- **3 端点**（ab-stats/ab-decisions/ab-promote）+ 看板第七区块
  （两版指标对照 + 晋升建议横幅 + 确认按钮）

| 层 | 参数/机制 | 范围 | 驱动 |
|---|---|---|---|

## 七、关键工程决策与教训（十条）

1. **Redis 客户端 str 键兼容**（P2 生产 500）：双模式存储必须两种
   模式都测。
2. **Python re 中文边界陷阱**（三轮）：中文也是 `\w`，`\b` 失效——
   改 lookaround。
3. **NFKC 归一化**（四轮）：全角字符统一归一。
4. **进化参数跨段污染**（锚点增强）：测试段间 `_reset_evo()` 隔离；
   生产需看板关注（clamp+留痕+一键重置三重保障）。
5. **clamp ≠ 防刷量**（二轮）：需"同决策同来源只进化一次"闸。
6. **注册表校验器价值**（FC 同步）：声明式一致性校验首跑抓不一致。
7. **数据字典核对**（GAP-2a）：跨模块联用先核实命名口径
   （CityStoreService 大小写/省名前缀）。
8. **参数口径分类**（A/B）：数值 Hash（get_params）与字符串 Hash
   （get_params_raw）分立——ab_active 存 "A"/"B" 崩 float 实证。
9. **断言语义随设计演进**（A/B）："同输入同输出"在实验分流下更新
   为"结果集确定性"——分流让同输入出不同 lead 正是实验目的。
10. **诚实裁剪 + fail-soft**：订餐 Agent 只导流不下单（不做空心
    Agent）；LLM 全链确定性降级，主链永不因 LLM 故障不可用。
