## 一、项目概览

**一句话定位**：用户说人话，智搜判断「他是谁、他想要什么」，从站内
商品/权益/订单/知识/区域/餐饮多库中查出正确答案或执行正确动作——
Web 搜索页 + 小竹语音双入口。

**Multi-Agent 视角**（对照「网站智能体」方案）：
智搜 = **Router Agent**（意图识别/拆解/分发/融合）+ **Guardrail
Agent**（输入端 L2 硬拦截 + 输出端守门双重校验）；七模型 = 业务专家
层；三参数进化闭环 + 坏案例聚类 = **Evolution Engine**。

**复用率**：MVP 复用站内 80% 资产，新建面集中在意图层与融合层。

## 二、五层架构最终形态

```
用户输入（Web search.html / 小竹语音 zs.search——规则/LLM/FC 三轨）
        ↓
┌─ L1 意图层(Router Agent) ────────────────────┐
│ 规则锚点得分制(7 意图+强操作词+低置信线)        │
│ × anchor_boost 反馈调权(clamp[0.5,3.0])       │
│ + LLM 兜底(intentWeight 采纳闸, fail-soft)    │
│ + 混合意图拆分(分句→副意图→双路, 上限2)        │
│ + 槽位 9 类(价格/场景/商品/单号/运单/等级/省份) │
└──────────────┬───────────────────────────────┘
        ↓
┌─ L2 合规前置(Guardrail 输入端, 硬规则) ───────┐
│ 未成年购酒/医疗功效/代理收益承诺 → 命中即拦截   │
└──────────────┬───────────────────────────────┘
        ↓
┌─ L3 多路检索(业务专家层) ─────────────────────┐
│ R1 商品(含库存状态) | R2 权益(会员模型+过期积分)│
│ R4 订单(鉴权+智运轨迹+精确单) | R5 知识(426+条 │
│ embedding+LLM改写) | 区域保护卡(省份×citystore)│
│ | 餐饮导流卡(宴请×智图 dining POI)            │
└──────────────┬───────────────────────────────┘
        ↓
┌─ L4 融合重排(确定性) ─────────────────────────┐
│ 相关0.5+角色0.2+业务0.2×routeBoost+合规0.1恒定 │
└──────────────┬───────────────────────────────┘
        ↓
┌─ L5 生成与动作(Guardrail 输出端) ─────────────┐
│ 结构化回答+副问合并+动作卡片+反馈入口           │
│ → guard_output 输出守门(极限词/医疗中性替换)    │
│ → 显式反馈/动作卡点击 → 三参数进化回流          │
└───────────────────────────────────────────────┘
```

## 三、各期交付明细

### MVP（ae5c458 + a84ed50）
- **意图层**：7 意图规则锚点表（独占词 2 分/共享词 1 分）+ 强操作词
  加成 + 低置信 chat 兜底；纯符号零 LLM（有效字符闸）
- **合规前置**：minor/medical/agent_promise 三组硬规则——命中即拦截，
  权重永不参与进化
- **双路检索**：R1 商品 + R5 知识（三级检索 2-gram+embedding+rerank）
- **三态灰度**：ZS_MODE off(409)/shadow/assist
- **决策留痕**：意图/槽位/hits/候选 top3/合规/llmAssist/subIntents/
  mode/outputGuard 全审计
- **前端**：search.html

### P1（1402d1b）
- **R2 权益路**：角色×意图二维路由——会员个人化（等级/积分/成长值/
  保级进度），游客体系介绍+注册引导
- **R4 订单路**：鉴权联动——游客零查询（隐私），登录本人隔离+智运
  轨迹摘要；订单号/运单号精确查单（非本人单不放行细节）
- **显式反馈进化**：routeBoost ±0.05 clamp[0.8,1.2]

### P2（374724a + 8636ea7）
- **LLM 意图兜底**：低置信单次调用产出意图+改写问句（fail-soft）；
  intentWeight 采纳闸（≥0.6 采纳，反馈 ±0.02 进化）
- **查询改写**：口语→规范问句供知识路 embedding 检索
- **隐式转化回流**：动作卡点击（sendBeacon）→ +0.03
- **小竹语音接入**：zs.search 指令
- **智搜看板**：五区块

### P3（b13cdff）
- **混合意图拆分**：一句话多问→分句→副意图→双路检索→合并回答；
  护栏：合规整句拦截不绕过、子查询上限 1（总路数 2）

### 增强①锚点自动调权（30544d9）
- **anchor_boost{word}**：命中词权重×乘数，反馈 ±0.1 clamp[0.5,3.0]
- 决策留痕补 hits（归因依据）；留痕 anchorTuning before/after
- 看板进化参数区新增锚点调权条形展示

### 增强②FC 三轨同步 + shadow 完整语义（c202c3a）
- **小竹三轨一致**：TOOL_REGISTRY（只读+描述内嵌禁令）+ executor
  SAFE_READONLY 沙箱白名单 + LLM command 白名单
- **shadow 完整语义**：三态留痕（decision.mode）+ 进化冻结（shadow
  下反馈只留痕，三参数全冻结；assist 恢复）

### 增强③Multi-Agent GAP-1~3（7e11c03，对照「网站智能体」方案）
- **GAP-1 Guardrail 输出端守门**：guard_output 极限词+医疗暗示中性
  替换表（确定性、LLM 禁入、只改话术不改事实数据）；answer+结果卡
  输出前净化，命中留痕 outputGuard + 计数——输入端之外的第二道闸
- **GAP-2 业务闭环三件套**：
  - 招商区域保护联动（agent×省份槽位→citystore 可开网店城市卡，
    省名前缀匹配）
  - 会员将过期积分提醒（30 天到期竹叶进权益卡）
  - 导购库存状态展示（有货/库存紧张/补货中）
- **GAP-3 创新体验**：
  - 宴请场景×智图 dining POI 餐饮合作导流卡（订餐 Agent 业务裁剪
    版——只导流不下单，不做空心 Agent）
  - 坏案例聚类观测面：GET /api/search-ai/bad-cases（useless 反馈→
    意图分布+高频问法 top10）+ 看板第六区块（Evolution 视图）

### 进化参数体系（三参数闭环，全部 clamp+留痕+防刷分+shadow 冻结）

| 参数 | 作用 | 范围 | 驱动 |
|---|---|---|---|

| intentWeight | LLM 兜底采纳闸 | [0.4, 0.8] | LLM 决策反馈 ±0.02 |

来源只进化一次；shadow 档进化冻结；结构性参数恒定；输出守门只改
话术不改事实数据。

## 七、关键工程决策与教训

1. **Redis 客户端 str 键兼容**（P2 生产 500）：本地内存模式测不到
   decode_responses=True——双模式存储必须两种模式都测。
2. **Python re 中文边界陷阱**（三轮）：中文也是 `\w`，`\b` 在中文与
   字母间不成立——槽位正则改 lookaround。
3. **NFKC 归一化**（四轮）：全角字母/数字（Ｌ３/ＲＴ）手机输入法常见，
   query 入口统一归一（留痕同步归一口径）。
4. **进化参数跨段污染**（锚点增强）：测试段间锚点调权链式影响后续
   判定——引入段间 `_reset_evo()` 隔离；同时实证进化参数全局生效是
   生产真实行为，需看板关注（clamp+留痕+一键重置三重保障）。
5. **clamp ≠ 防刷量**（二轮）：安全阀只防越界，防滥用需"同决策同
   来源只进化一次"闸。
6. **注册表校验器价值**（FC 同步）：TOOL_REGISTRY 与沙箱白名单
   不一致首跑即被抓——声明式一致性校验值得推广。
7. **数据字典核对**（GAP-2a）：类名 CityStoreService 大小写、省名
   "山东省"带后缀与槽位"山东"前缀匹配——跨模块联用先核实命名口径。
8. **fail-soft 全链贯彻**：LLM 未配置/节流/超时/非法 JSON/纯符号，
   全部确定性降级，主链永不因 LLM 故障不可用。
9. **诚实裁剪**（GAP-3a）：订餐 Agent 不做下单（全站无餐饮外卖
   业务）——以导流卡承接宴请场景，不做空心 Agent。
