## 一、交付内容

### 前端（Taro H5 + 微信小程序双端）

| 模块 | 页面 | 功能 |
|---|---|---|
| 组团团购 | pages/groupbuy | 阶梯试算 + SVIP 申请 + 订单取消 |
| AI 智能客服 | pages/chat | 会话列表 + 消息流 + 转人工 + 满意度评价 |
| 客服工单 | pages/tickets | 全生命周期（创建/补充/确认+评价）+ SLA 标记 |
| 消息中心 | pages/messages | 分类筛选 + 已读/批量已读 + 未读统计 |
| 老酒回收 | pages/recycle | AI 估价 + 兑换新酒/折现回收双链路 |
| 信用先享后付 | pages/credit | 额度总览 + AI 授信下单 + 还款 + 信用流水 |

配套新增 6 个 API 层（chat/credit/groupbuy/message/recycle/ticket.ts）；mine 页新增"资产管理"与"客服中心"区块；首页金刚区新增"老酒回收"入口；NavBar 组件扩展 `onBack`。

### 后端（FastAPI）

新增用户端端点（均含归属校验，静态路径先于动态路由声明）：

| 端点 | 用途 |
|---|---|
| `GET /api/chat/my-sessions` | 我的客服会话列表 |
| `GET /api/ticket/my-list` | 我的工单列表 |
| `GET /api/ticket/my/{ticket_no}` | 我的工单详情（含处理记录） |
| `POST /api/ticket/my/{ticket_no}/reply` | 用户补充工单信息 |
| `GET /api/recycle/my-valuations` | 我的回收估价记录 |
| `GET /api/activity/my-registrations` | 我的活动报名（二期A，随本次镜像一并上线） |

**附带修复**: `ticket_repository.py` Redis 模式下 `ticket:ticket:seq` 计数键被 keys 扫描命中导致列表接口崩溃（`json.loads` 返回 int 后 `.get` 报错，管理端 `/api/ticket/list` 同样受影响），增加 `isinstance(t, dict)` 过滤修复。

## 六、遗留事项与建议

1. **微信小程序端发布**: dist-weapp 产物已构建，需在微信开发者工具中上传并提交审核后新页面方对小程序用户生效（小程序无热更新）。
2. **局域网调试地址**: 本机 IP 已变更导致 `config/index.ts` 中 `LAN_HOST=192.168.0.107` 失效；下次局域网联机测试前需更新为当前 IP（生产环境不受影响，域名感知逻辑优先走 zxjiu.com）。
3. **Redis 数据说明**: 后端容器重建时 seed 脚本会重置种子数据（开发环境幂等设计）；生产如需持久化业务数据，后续可考虑摘除启动 seed 或迁移至独立数据卷。
