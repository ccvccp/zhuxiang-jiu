# 43号·AI智能安全管理模块 交付总结

> 定位：**每个请求进来，AI 都先看一眼**——威胁评分低放行、可疑挑战、高危封禁；每个角色的每个动作都建行为基线，偏离即预警；攻击确认与误报裁决自动回流学习，防线随攻防态势**自动升降级**。把安全从"出事后人工排查"变成"AI 常态化值守、越打越准的免疫系统"。

## 二、五期核心交付

### P0：安全网关中间件 + 威胁评分（第26档案）
- **ASGI 网关**（JWTAuthMiddleware 范式平移）：挂载次序 CORS(外) → **SecurityGateway(中)** → JWT(内)——攻击请求在进入鉴权层之前被评分拦截；白名单快道（健康检查/OPTIONS/挑战应答端点）；BodyPeeker 请求体预读回放（64KB 限制，流式安全）
- **ThreatGateScorer 六因子**：IP信誉 0.20 / 请求频次 0.20 / 注入特征 0.25 / 路径异常 0.10 / 身份风险 0.15 / 时空异常 0.10 → 四档处置（≥70 allow / 50-70 throttle 渐进延迟 / 25-50 challenge 挑战验证 / <25 block 封禁）
- **确定性攻击硬规则**（防单信号被加权合议淹没）：任一注入特征/探针路径命中 → 至少 challenge；多类特征叠加 → 直通 block
- **攻击特征库**：SQLi/XSS/路径遍历/命令注入/扫描器 UA 五类正则 + 探针路径（`/.env`/`/wp-admin` 等）+ query URL 解码（防编码绕过）
- **IP 信誉库三态**：冷启动中性分 80（不因新面孔误杀）/ normal>60 / suspicious 30-60 / blacklisted≤30 直封；攻击扣分（-10/-30/-60 按档位）/ 冷却恢复 / 管理端钉住
- **事件流水**：仅可疑档入流水（正常放行不记，防爆炸）；封禁 TTL 懒清理自动解封
- **防误杀三保险**：observe/shadow/enforce 三级灰度（默认 observe 只留痕）/ fail-open（网关异常全放行）/ `SECURITY_GATEWAY_MODE=off` 一键回退

### P1：挑战验证 + 申诉双通道 + enforce 四档处置
- **挑战通行证**：mock 应答验证（非空即过）→ IP 通行证 TTL 900s 豁免挑战档（throttle/block 不豁免——不是免死金牌）；豁免仍留痕 `challenge_exempt`（审计可见）
- **误报申诉双通道**（42号范式平移）：会员申诉（仅挑战/封禁/豁免事件、当事人、一事件一申诉幂等）→ 管理裁决 `approve` → 事件置 false_positive + **IP 信誉返还扣分 + 自动解封**；`reject` → confirmed 归档
- **事件直接裁决**：管理端不经申诉直接确认攻击/误报（误报同样自动恢复）——**P2 学习真值源**
- **态势总览**：四档分布 + 误报率 `falsePositiveRate`（对齐42号口径）+ 待裁决积压计数

### P2a：UEBA 行为基线（四层流水线）
- **采集层（零侵入）**：网关本就是全量请求必经点，正常分支顺带记三维计数直方图（memberId × hour × module，非全量流水防爆炸）+ 管理端 `admin_operation_logs` 哈希链审计只读聚合
- **基线层**：24h 时段直方图归一化 + 频率 P95 + 功能分布；**双层基线**（个人 → 同角色全局兜底 → 双缺完全豁免，新会员零误报）；每日/手动窗口重算（可解释可重建）
- **检测层四检测器**：D1 时段偏离（基线权重<5% 冷门时段）/ D2 频率偏离（击穿 P95×3 突变系数，防养号）/ D3 敏感功能首次触碰（不可被历史稀释）/ D4 403 堆积试探
- **联动层**：偏离分注入 threat_gate 六因子的 identity_risk（**只降不升**，60s 缓存保网关低延迟）+ `behavior_alert` 入事件流水**复用 P1 裁决/申诉全链路**（零新增管理界面）

### P2b：态势三态自动升降级 + 学习回流（智能自主升级）
- **态势三态**（对标 Cloudflare Under Attack Mode）：peace（频次×1.5 宽松）/ alert（×1.0）/ wartime（×0.3 收紧，可疑即封口径）
- **自动升降级**：攻击密度 EMA（α=0.3）+ **滞后防抖**（连续 2 窗口越线才转换，避免抖动）；管理端 pinned 钉住优先于自动；manual 模式仅手动
- **网关窗口观测**：可疑事件（challenge/block/behavior_alert）计数，窗口满（300s）触发升降级评估；态势系数类级缓存 60s，请求路径零存储往返
- **学习回流三连**（42号 P2 范式平移）：`collect` 已裁决事件真值批量回流（confirmed=AI拦对正反馈 / false_positive=拦错负反馈，eventFed 幂等）→ `run` Hedge 一轮学习 → 六因子权重自动调优 → `status` 权重视图

### 面板前端：安全管理面板（六区块）
- [ai-security-dashboard.html](../ai-security-dashboard.html) + [security-dashboard.js](../js/security-dashboard.js)（42号面板范式平移：ES5/localStorage 连接/30s 自动刷新/Promise.all 并行加载）
- **①态势总览**（三态系数卡+EMA+误报率+手动切换态势+钉住）/ **②攻击事件**（档位/裁决双过滤+一键裁决+六因子明细展开）/ **③申诉队列**（误报恢复双按钮）/ **④IP 处置**（信誉三态+封禁/解封/钉住）/ **⑤UEBA 基线**（24h 时段直方图可视化+重建+偏离记录）/ **⑥学习回流**（collect/run 一键+计数卡片）

## 五、交付过程中的关键修复

| 问题 | 根因 | 修复 |
|------|------|------|
| 单次 SQLi 特征被加权合议淹没（总分 86 仍放行） | 特征分 50×权重 0.25=12.5 扣分过轻 | 评分器增加确定性攻击硬规则：单特征至少 challenge、多类叠加直通 block |
| URL 编码攻击绕过（`%27 OR 1=1` 扫不出） | query 未解码直接扫描 | 扫描前 `unquote_plus` |
| 非 /api 探针路径绕过（`/.env` 不走网关） | 快道白名单含路径前缀判断 | 放开前缀限制，仅 OPTIONS/健康检查/总开关走快道 |
| 通行证豁免后审计断链 | 豁免的挑战档不留痕 | 豁免仍留痕 `challenge_exempt` 且可申诉 |
| 申诉表 KeyError | 仓储 _ensure_store 未注册新表 | 补注册（含后续 posture/baselines 表） |
| finance 仓储 Redis WRONGTYPE（42号实机遗留） | 列表扫描 endswith 匹配不到带日期后缀的 seq 键 | 4 处过滤改 `":X:seq" not in k`（P0 阶段顺带修复） |
| 根目录运行 pytest 18 项假失败 | 根级读不到 backend/pytest.ini 的 asyncio_mode=auto | 根级 pytest.ini（testpaths 指向 backend） |

## 六、配置与运维

**环境变量**（docker-compose 已暴露，带上线检查单指引）：

| 变量 | 默认 | 说明 |
|------|------|------|
| `SECURITY_GATEWAY_MODE` | on | 总开关（off 一键回退，fail-open 铁律） |
| `SECURITY_ENFORCE_LEVEL` | observe | 灰度：observe/shadow/enforce（enforce 才真处置） |
| `SECURITY_RATE_WINDOW / RATE_LIMIT` | 60 / 120 | 频次窗口与上限（态势自动缩放） |
| `SECURITY_BAN_TTL` | 900 | 自动封禁秒数 |
| `SECURITY_UEBA_MODE` | on | UEBA 总开关 |
| `SECURITY_UEBA_BURST_FACTOR / HOUR_WEIGHT` | 3 / 0.05 | D2 突变系数 / D1 冷门阈值 |
| `SECURITY_POSTURE_MODE` | auto | 态势：auto 自动升降级 / manual 仅手动 |

**enforce 上线检查单**（见操作指南 §六）：observe 运行 ≥1 周且误报率 <10% + 待裁决积压清零 + 申诉通道畅通 + 切换后 30 分钟盯封禁数与 200 率。
