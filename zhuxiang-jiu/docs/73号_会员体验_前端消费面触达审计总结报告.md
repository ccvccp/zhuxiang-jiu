## 三、第二阶段: 会员体验中心四页签(提交 681e367)

### 3.1 交付物

- **页面** `pages/member73`(四页签):
  - **地平线**: 等级卡(成长值/缺口/预计到达/新会员影子保护期提示) +
    升级缺口进度条 + 保级窗口(周期要求/已消费/剩余天数/临期警示)
  - **导师**: AI 触达留痕(类型/呈现状态/提示文案/触发分) +
    响应回流三按钮(有帮助/去升级/忽略——仅已呈现时刻显示)
  - **权益**: 升级前后权益对比卡(L5 最高档友好兜底) + 升级告知留痕
  - **代办**: AI 预判卡 + **五动作授权管理**(授权/撤回/代办执行,
    风险档语义标注) + 执行留痕
- **API 扩展**: 13 方法 / 9 VO / 3 字典(五动作名/风险档语义/时刻类型)
- **入口**: 我的页 → 资产管理 → 🤝 会员体验中心(区顶)
- 页面明示宪法铁律: "资金类(支付/绑定)永不授权"

### 3.2 后端配套改动

从 admin-only 放宽为 **memberId 指定时本人可查**(用户权利面板口径,
与信任面板"用户可见自己的数据"设计对齐)。

### 3.3 验证

单测 13/13 + 信任面板回归 12/12; 生产实机四页签全部渲染:
地平线(竹海 SVIP+保级窗实时)、导师(6 条实时留痕, 静默时刻
正确无回应按钮)、权益(L5 兜底)、代办(AI 预判"资料补全"+
五动作授权管理+铁律文案)。
