## 三、升级动作（三项）

### 修① 超时回补调度器（心跳补齐）

新建 [flashsale_scheduler.py](file:///d:/网站架构设计/zhuxiang-jiu/backend/services/flashsale_scheduler.py)：
- `FLASHSALE_EXPIRE_AUTO`（默认 off）+ `FLASHSALE_EXPIRE_INTERVAL_SECONDS`（默认 60s，下限 30s）
- **启动即首轮**（全站范式，不复踩 attract72 sleep-first 坑）
- fail-soft：单轮异常继续；取消 0 单属常态（静默）
- main.py 启动链挂接；**生产已开 on**

### 修② 智法审计输入真实化

[flashsale_routes.py](file:///d:/网站架构设计/zhuxiang-jiu/backend/routes/flashsale_routes.py#L279-L312) add_item 审计输入：
- price_history：单点 → **双点序列**（现售价 + 真实会员价 member_price）
- current：strikethrough=原价（恒不触发）→ **真实划线价 original_price**；member=0 → **真实 member_price**
- 效果：三项检测（先涨后降/划线价无依据/会员价虚标）从数学不可触发变为**均可真实触发**；产品字段缺失时 fail-soft 回退

### 修③ 存量测试环境自包含

[test_flashsale_http.py](file:///d:/网站架构设计/zhuxiang-jiu/backend/test_flashsale_http.py#L22-L30) 补
`AUTH_COMPAT_TRUST_HEADERS=1` 自举——原依赖 shell 前置 env（裸头被
compat 默认剥离 403），对齐 test_support 约定，测试自包含。
