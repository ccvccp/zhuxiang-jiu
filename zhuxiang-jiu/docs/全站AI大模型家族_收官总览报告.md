## 三、家族共享基因（七大范式全模型复用）

1. **四层协同架构**: L1 问答/意图层（关键词确定性路由+句子模板插值）→ L2 确定性 Agent 集群 → L3 数据织物（只读聚合零回写）→ L4 进化引擎（反馈闭环+异常自发现）
2. **_Z*Store 共享存储**: Redis `zhuxiang:z{y|f|w|t|d|k}:{table}:{id}` + INCR 序列 + scan_iter 列表 + 内存回退（六套同构实现）
3. **建议书 disposition**: 裁决/处置/触达/策略类响应一律携带，永不自动执行（智单退款裁决、智客唤醒触达、智图工单处置、智法动态合约等全实证）
4. **formula 推理链留痕**: 预测/评分类响应带确定性公式描述（杜邦分解/ETA 加权/流失三信号/沙盘因子等）
5. **进化安全阀**: Hedge 式权重学习 ×1.05/×0.95/×0.9，clamp [0.4,0.8]（智启元 trendWeight、智单 etaRecentWeight、智客 ltvRetainFactor 同款）
6. **三检测器**: spike>μ+3σ(且μ≥5) / drop<μ−3σ(且绝对值≥20) / surge×3(且样本≥20)——各模型按自身时序域实例化（单量/消费/积分/注册/碳排…）
7. **加权预测口径**: 近期×0.6 + 全期×0.4（pay60 范式，智启元/智运/智酿/智图/智单五模型复用）
