## 八、实机验收记录（2026-09-02，Docker 容器 Redis 模式）

**验收环境**：`docker compose -p zhuxiang-jiu up -d --build backend`；脚本 `backend/verify_pdm_live.py`（基址 `http://127.0.0.2:8000`）

**结果**：**31/31 全绿**——权限矩阵（401/403/perm种子/admin兜底）/ AI 预审三档 / SoD 自审拦截 / perm 直授审核员 / 终审通过消费端可见 / 上下架幂等 / 紧急下架任意态直达 / 编辑双轨 / 版本回滚 / 图片上传审图 / 在售换图回落 / 设计工坊三端点 / 学习回流幂等 / 看板全景

**前端看板（浏览器实测）**：七区块全通——19 件商品六态徽章、图库 4 张（含 2 张 AI 生成标记）、下架建议空态正常、控制台零报错零 CORS 错误、30s 自动刷新正常

**验收中发现并修复的缺陷（Redis 模式存量，commit `3f71f80`）**：
1. pdm `_serialize` 不接受 None/bool（hset 500）——空串占位/转 0/1
2. `_INT_FIELDS` 缺 `lastSubstantiveEditor` 等字段——Redis 反序列化字符串致 **SoD 失效**（安全级）
3. **perm 模块 Redis 模式权限树从未种子化**（`_ensure_store` 仅内存路径调用）——惰性种子修复
4. perm `_serialize` 不接受 bool（授权写入崩溃）+ `defaultDays` 缺 int 字段表（期限校验失败）

**回归**：perm 34 / PDM P0 50 / P1 32 / P2 23 全绿；全量 1179/9 与基线完全一致
