## 二、灰度运行口径(P5)

### 2.1 三态与读取链

| 态 | 语义 | 生效范围 |
|----|------|---------|
| `off`(默认) | 决策面关闭(409) | 6 决策面拒绝; 观测面照常 |
| `shadow` | 观察学习期 | 决策放行, 响应携带 `xinzhiMode: shadow` 留痕 |
| `assist` | 辅助生产期 | 决策生效, 响应携带 `xinzhiMode: assist` |

**读取优先级**: `护栏暂停(guard_pause) > 运行时 override > 环境变量 XINZHI_MODE > 默认 off`

运行时切换(人工留痕, 不需重建容器):
```
POST /api/xinzhi/mode/override?mode=assist   # 切档
POST /api/xinzhi/mode/override?mode=         # 清除(回落 env)
GET  /api/xinzhi/mode                        # 总览(当前态+护栏+决策面清单)
```

### 2.2 决策面/观测面清单

| 类别 | 端点 | off 态行为 |
|------|------|-----------|
| **决策面(6)** | groupbuy 发布/响应/关闭、merchant apply/regrade、guide | 409(决策面关闭) |
| **观测面(永不关停)** | radar、radar/history、products/score、prime、price、feedback(POST/GET)、guide/personas、neighbor、groupbuy GET(大厅)、carbon、merchant simulate/level、mode、whitepaper | 200 正常 |

### 2.3 A/B 护栏(自动暂停机制)

- **监控三指标**: 退款率 / 客诉进线率 / 卸载率(基线 0.05/0.02/0.01)
- **触发条件**: 任一指标 `(当期-基线)/基线 > 3%` → **自动暂停**(等效 off)
- **性质**: 保护机制(功能开关非处罚)——暂停可自动, 恢复须人工:
  ```
  POST /api/xinzhi/mode/guard   # 检查(指标留痕滚动, 截断 50 条)
  POST /api/xinzhi/mode/resume # 人工恢复(决策留痕)
  ```
- **实机证据**: 退款率 0.05→0.10(+100%>3%)→ 自动暂停 → 求购 409 →
  人工 resume → 回 assist 档 → override 清除 → 回落 env=off
