- **可解释性前置** → 每次打分输出 `attribution` 中文归因(组件分×权重明细+风险标签)

## 二、v2 引擎设计(services/trust_verify_v2.py)

### 2.1 四维组件分(graph 维度的工程替代)

指南四维权重的本仓映射——GNN 图谱轨暂不落地(10万节点
交互图数据不具备), 以**证据内容质量代理图风险**(摆拍/
刷单识别本质是内容-团伙特征):

```
content      ← multimodal_check(证据内容质量)     [复用v1]
temporal     ← burst_ratio(时序基线)             [新增]
cross_source ← cross_source_check(源独立性)       [复用v1]
intent       ← intent_check(意图推理)             [复用v1]
```

### 2.2 自适应权重档案(指南 §一口径)

| 档案 | content | temporal | cross_source | intent | 指南语义 |
|------|---------|----------|-------------|--------|---------|
| donation | 0.3 | 0.2 | **0.4** | 0.1 | 捐赠重跨源(防虚假票据) |
| review | **0.4** | 0.3 | 0.2 | 0.1 | 评价重内容(防水军团伙) |
| volunteer | 0.2 | 0.3 | 0.3 | 0.2 | 志愿重跨源+意图 |
| repair_action | 0.2 | **0.4** | 0.3 | 0.1 | 修复重时序(防突击刷分) |

行为子类型映射: 修复 kind(10 种)→repair/donation;
存证因子 L2→review / L3→volunteer; 兜底 review。

### 2.3 时序特征(指南 §二 behavior_burst_ratio)

```
burst_ratio = 近7天事件频次 / (近90天日均频次 × 7)
观察窗 <14 天无基线 → ratio=1.0(不判)
temporal_score = 1 - clamp((ratio-1)/4, 0, 1)
    burst 1.0 → 满分; 3.0 → 0.5; ≥5.0 → 0 分顶格
```
>5 且无合理触发事件 → `behavior_burst` 风险标签
(指南: 行为突增程度伪善信号)。

### 2.4 灰色地带 LLM(指南 §一关键设计)

```
preliminary = fuse(四组件, 自适应权重)
if 0.3 < preliminary < 0.8 and real轨 and llm_enabled:
    intent分量 ← LLM推理 → 重融合
```
mock 态(测试/实机验收)不触发——确定性可测;
LLM 失败回退 None 保持初步分(fail-soft)。

### 2.5 风险标签与归因(指南 verify 返回结构)

```
risk_tags: single_source / content_quality_low /
           behavior_burst / performative_goodness
attribution: "融合分 0.82; 内容鉴别0.95×0.3 + 时序一致
             1.0×0.2 + 跨源验证1.0×0.4 + 意图推理0.95×0.1;
             风险标签: 无"
```

### 2.6 激活方式(工程铁律: v1 零影响)

```
submit_deposit(..., verify_mode="v1")   # 默认, 既有管线
submit_repair(..., verify_mode="v2")    # 显式激活增强引擎
路由透传: body.verifyMode
```
verified 口径不变(≥0.7 且跨源过)——"灰色地带给中等分
+风险标签, 不武断真假"的指南工程忠告通过 riskTags 表达。

## 三、指南中暂不落地的项(工程判断)

| 指南项 | 不落地原因 |
|--------|-----------|
| GNN 图模型(10万节点) | 交互图数据量级不足; 内容质量已代理核心风险; 列入 real 轨外部待办 |
| 特征仓库(Feature Store) | mock 态特征在请求内即时计算(事件流≤千级), 存储层是过度工程 |
| 红队攻击库月更 | 43号威胁情报+46号公平性审计已提供攻击面监控工程替代; 人工流程项 |
| 模型漂移监控(高分占比突增>5%) | 46号 P1 健康巡检漂移检测器已覆盖同口径(事后可桥接) |
| A/B 测试框架 | v1/v2 双轨并行即天然 A/B(verifyMode 显式切换) |
| P99 <500ms 性能基准 | v2 纯函数无 IO(事件时间戳调用方查库传入), 融合为常数时间 |
