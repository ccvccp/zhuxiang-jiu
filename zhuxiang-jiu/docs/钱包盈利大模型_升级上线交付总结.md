## 二、升级交付

### 2.1 模式层(wallet_mode_service.py)

- **三态**: WALLET_MODE = off(默认)/shadow(钱包观察期)/
  assist(钱包辅助期)
- **读取链**: 护栏暂停 > 运行时 override > env > 默认 off
- **状态存储**: `zhuxiang:wallet:mode_state` 整档 JSON 单键
  (智运范式——规避 45号 P0 字段级序列化教训)
- **同步桥接**(62号范式): 进程快照 `_G` +
  `legacy_current_mode()` 同步读取器

### 2.2 护栏三指标(钱包业务语义, 恶化>3% 自动 guard_pause)

| 指标 | 基线 | 语义 |
|---|---|---|
| 提现拒绝率 withdrawRejRate | 0.10 | rejected 提现单/总提现单(审批健康度代理) |
| 提前取出率 earlySettleRate | 0.10 | early_settled 定期/总结清定期(盈利模式健康度代理) |
| 账户冻结率 accountFrozenRate | 0.05 | frozen 账户/总账户(风控压力代理) |

### 2.3 路由层(wallet_routes.py, 22→26 端点)

- **6 决策端点** `@_decision` 门控(off 409 + walletMode 标记):
  open 开通、deposit 充值、pay 消费支付、transfer-regular
  转定期、interest settle-monthly 月度结付、
  reward ship 奖品发货(admin)——即「新增盈利入口」
- **鉴权优先**(小竹参数化范式): `_decision(strict=True/
  admin=True/默认)`——strict 面无 X-Member-Id 放行触发 401、
  admin 面非 admin 放行触发 403(401/403 优先于 409)
- **4 控制面端点**: GET /mode、POST /mode/override、
  POST /mode/guard(缺省仓储实时聚合)、POST /mode/resume

### 2.4 宪法豁免面(资金红线——全站最宽豁免面)

> 法律依据: 《消保法》第9条选择权 + 设计文档 1.7
> 「退出机制: 不得限制提现/不得设置退出障碍」

**8 端点永不关停**(资金退出与用户权利):

| 端点 | 权利 |
|---|---|
| POST /withdraw 提现申请 | 资金退出权 |
| POST /withdrawal/{no}/approve + paid | 在途提现审核链 |
| POST /refund 退款 | 资金权利 |
| POST /deposit/{no}/settle + early-settle | 定期本金取出权 |
| POST /reward/{no}/claim + sign | 奖品领取与签收权 |

观测面 8 GET 永不关停: info/提现单详情/待审核列表/
交易明细/日收益预估/收益规则(公开)/定期列表/奖品列表。

### 2.5 护栏自动巡检(wallet_scheduler.py)

- `run_guard_patrol()` 三指标确定性聚合
  (list_accounts 全量 + 逐户 list_withdrawals/list_deposits,
  上限保护 500 户/100 条每户), 分母 0 冷启动取 0 不误判
- WALLET_GUARD_AUTO 默认 on, WALLET_GUARD_INTERVAL
  默认 3600s; main.py startup 挂载

## 五、回滚与运维

- **回滚命令**:
  `sed -i 's/^WALLET_MODE=.*/WALLET_MODE=off/' /opt/zhuxiang/.env && docker compose up -d backend`
- **运行时切档**: `POST /api/wallet/mode/override {"mode":"shadow"}`
- **护栏恢复**: `POST /api/wallet/mode/resume`
- **巡检开关/间隔**: WALLET_GUARD_AUTO(默认 on)/
  WALLET_GUARD_INTERVAL(默认 3600s)
- off 态语义: 新增盈利入口(开通/充值/消费/转定期/结付/发货)
  409; 资金退出权(提现/取出/退款/领奖/审核链)不受影响
