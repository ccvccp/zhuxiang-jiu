## 三、核心交付明细

### 3.1 P6a·多模态自主学习引擎(585 行)

- **视听信号扩展**(复用 blogger_signals 零新表):完播/分享/收藏(正向)+
  弹幕负面密度(确定性词表,含"无聊/划走/尬/广告狗"弹幕场景增量)+
  评论正面密度(共鸣第 4 分量)
- **情感对齐复合奖励**(宪法域核心):
  `reward = α×转化 + β×合规 + γ×共鸣 − δ×风险,clamp [-1,1]`
  共鸣 = 0.4×完播/0.6 + 0.3×分享/0.05 + 0.2×收藏/0.08 + 0.1×正面密度
- **γ≥α 铁律双级硬拒**:函数级(传参 γ<α → ValueError)+ 存储合并级
  ——"情感真实性权重永不低于转化效率"的工程化,与 P5a β 拒改构成双保险
- **跨平台调性迁移表**:六平台(抖音快节奏/B站深度解说/小宇宙沉浸播客等)
  rhythm/duration/density/form 确定性映射
- **封禁视听元素库**:BGM/转场黑名单,全平台共享+平台增量实时同步
- 学习轮冷启动回退 P5a(平滑过渡);pause 仲裁覆盖

### 3.2 P6b·音视频自主创作工坊(550 行)

- **确定性脚本引擎**:钩子(P5b 五类复用)×结构×节奏标记 = 3 场景分镜列表
  (hook 20%/body 60%/tail 20%),每场景带情绪枚举+时长秒
- **人设库**(红线:仅两类):原创 IP / licensed 授权声纹肖像——
  登记与生成**双重授权硬门**,撤回/过期即时拒绝
- **合规内生五层防线**:文案 sanitize → BGM 授权+封禁库拦截 → 人设授权硬门
  → 三审闸门复用 → AI 标识断言+不可见水印(40 位内容哈希)
- **渲染三态**(AV_CHANNEL_MODE,PAY60 范式):mock meta 产物 /
  real fail-hard 不留桩 / mock_fallback 降级留痕
- **A/B 联动**:版本携带 avWorkId,与 P5b promote/策略库**零改动兼容**

### 3.3 P6c·音视频自主发布调度器(522 行)

- **跨平台渲染参数表**:六平台种子(抖音 1080×1920@8Mbps/B站横屏/
  小宇宙纯音频 128kbps),惰性灌入+热更新
- **完播加权黄金时段**:AV 独立曲线(与 P5c 分离防语义污染);
  观测值 = 点击×0.5 + 完播×100×0.5(点击完播同权——音视频以完播为先);
  EMA α=0.3 收敛+TOP3 时段+冷启动回退
- **新平台首发审批**:bilibili/xiaoyuzhou 前 10 条须人工放行
  (pending_approval 提单留痕)
- **1h 互动自愈**(不对称处置):完播低迷→推广建议 | 高频疑问→FAQ 置顶
  (全自动合规) | 弹幕负面→**仅建议**(AI 永不自动隐藏) |
  音画不同步→**自愈重渲染**(retry≤3 耗尽转人工)
- **推广分轨**:≤100 自动 mock 轨 / >100 pending 建议书永不自动 /
  pause 拒绝自动轨但保留人工审批通道

### 3.4 P6d·自治理扩展(340 行)

- **六层归因漏斗**:曝光→完播→点击→注册→信值激活→首单
  (works 触达计数+总量合计+平均完播)
- **共鸣度看板区**:逐作品共鸣分+平均+低共鸣预警列表(<0.3)+
  趋势榜——驱动内容温度优化
- **AV 专项自愈分类**:转码失败(换渲染参数)/音画不同步(委托 P6c 重渲染)/
  上传超时(换通道)+ P5d 五类兜底;耗尽**永不静默丢弃**
- **AV 决策可解释**:形式→人设→合规内生→渲染→发布五链路回放
- 进化透明度看板六区(自治/漏斗/共鸣/策略/干预/自愈)

### 3.5 P6e·自主合规转发引擎(386 行)

> 转发 ≠ 搬运,转发 = 信用担保行为——流程铁律:**先确权、再合规、后分发、全溯源**

- **智能权利确权层**:双重授权(平台 cc/mcn/whitelist + 原作者明确同意,
  邀约留痕)→ SHA256 哈希存证;来源键唯一性;过期=僵尸转发拒绝
- **多模态合规深审**(确定性规则):风险词一票否决(→0)→
  价值观冲突大幅扣分(−40/词,即使不违法)→ 来源元数据缺失(−10/项);
  三档:≥90 自动二创 / 70-89 人工复审 / <70 拒绝+原因
- **增值二创与溯源**:策展说明("为什么我们推荐"模板)+
  信值钩子(标题关键词→P5b 钩子库映射)+
  来源标注强制("转自@创作者(授权类型)",禁任何去标识)
- **撤回应急**:撤回授权→关联已发布转发内容**秒级全量下架**
- **利润分配**(永不自动):效果上报(播放/转化滚动合并)→
  分润建议书(基础+转化双轨)pending→人工审批后方可给付

## 四、宪法域红线(P6 新增,全部工程化)

| 红线 | 工程实现 |
|------|---------|
| **γ 情感权重 ≥ α 转化权重** | 函数级+存储级双硬拒(与 β 拒改同构双保险) |
| 禁止模仿真人未授权声纹/肖像 | 人设仅原创 IP/授权两类;登记+生成双重授权硬门 |
| AI 标识+不可见水印强制 | 尾分镜断言+40 位内容哈希;缺失即生成失败 |
| 授权缺失绝不转发 | 双重授权前置校验;撤回秒级下架;过期拒绝 |
| 价值观冲突即使不违法也拒绝 | 价值观词表(炫富/焦虑营销/歧视等)大幅扣分 |
| 分润/质押/分成永不自动 | 建议书 pending → 人工审批后方可给付 |
| 高危发布强制审批 | 高预算推广>100/新平台首发前 10 条 → 质押/放行 |
| 人工暂停最高优先级 | pause 覆盖全部 P6 自主行为(仲裁优先于调度) |
| LLM 禁入判定链 | 情感=词表密度;脚本=模板引擎;深审=规则+布尔逻辑 |
| 自愈耗尽永不静默丢弃 | 一律转人工队列留痕(healStatus 落作品) |
