## 二、大模型二代转段内容(全站范式)

### 2.1 三态灰度 SITE_THEME_MODE(site_theme_mode_service.py 新增)

- **三态**: off(默认)/shadow(图标主题观察期)/assist(图标主题辅助期)
- **读取链**: 护栏暂停 > 运行时 override > env `SITE_THEME_MODE` > 默认 off
- **状态存储**: 整档 JSON 单键 `zhuxiang:site_theme:mode_state`
- **同步桥接**(62号范式): 进程快照 `_G` + `legacy_current_mode()`
- **红线**: 主题状态机语义保留; 一代 AI 激活门槛(score≥60)保留; LLM 禁入

### 2.2 护栏三指标(图标主题语义, 恶化>3% 自动 guard_pause)

| 指标 | 口径 | 基线 | 恶化代理 |
|---|---|---|---|
| AI 低分率 aiLowScoreRate | 已评估主题 score<60 占比 | 0.10 | 主题设计质量恶化 |
| 回滚率 rollbackRate | rollback 日志/总操作日志 | 0.10 | 变更被撤销恶化 |
| 图标失效引用率 brokenIconRefRate | quickGrid emoji 引用不在图标库占比 | 0.10 | 数据一致性恶化(前端破损) |

**口径修正实录**: 首版图标引用口径含 tab* 图标——实测默认主题种子 tabHome: "home" 是 **Taro 内置图标名非图标库实体**, 冷启动误判; 修正为只校验 quickGrid 金刚区 emoji 引用(库实体)。

### 2.3 三面口径(16 端点)

| 面 | 端点 | 口径 |
|---|---|---|
| 决策面(7 写) | 主题创建/编辑/AI 评估/激活/归档/日志回滚/图标新增 | off 409 + themeMode 标记 |
| **C 端运行时换肤(2 公开)** | **active(当前主题)/icons(图标库)** | **永不关停**(C 端导航栏/tabBar 运行时依赖——大模型关闭不破坏线上皮肤) |
| 观测面(3 管理 GET) | 主题列表/日志/推荐 | 永不关停 |
| 控制面(4) | mode / override / guard(缺省实时聚合) / resume | JWT admin 门禁 |

### 2.4 鉴权优先(本模块范式特色)

- require_admin 为 **FastAPI Depends**——401/403 在参数解析阶段完成, **天然先于装饰器门控 409**; 装饰器无需参数化鉴权跳过逻辑(区别于 X-Role 头模块的 strict/admin 参数化范式)
- v8.1 JWT 强校验(堵死 X-Role 头伪造)语义保留——实机复验伪造头 401

### 2.5 自动巡检(site_theme_scheduler.py 新增 + main.py 挂载)

- SITE_THEME_GUARD_AUTO 默认 on, SITE_THEME_GUARD_INTERVAL 默认 3600s(最小 60s)
- 聚合源: list_themes/list_logs/list_icons(上限 1000); 默认主题种子三指标全 0(冷启动安全)

## 五、回滚与运维

- **回滚命令**:
  `sed -i 's/^SITE_THEME_MODE=.*/SITE_THEME_MODE=off/' /opt/zhuxiang/.env && docker compose up -d backend`
- **运行时切档**(免容器重建):
  `POST /api/site-theme/mode/override {"mode":"shadow"}`
