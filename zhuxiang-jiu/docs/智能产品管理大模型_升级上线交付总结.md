## 二、大模型二代转段内容(全站范式)

### 2.1 三态灰度 PDM_MODE(pdm_mode_service.py 新增)

- **三态**: off(默认)/shadow(PDM 观察期)/assist(PDM 辅助期)
- **读取链**: 护栏暂停 > 运行时 override > env `PDM_MODE` > 默认 off
- **状态存储**: 整档 JSON 单键 `zhuxiang:pdm:mode_state`
- **同步桥接**(62号范式): 进程快照 `_G` + `legacy_current_mode()`
- **红线**: 产品展示基础 7 端点零改动; 观测面永不关停; 人工终审语义保留(AI 只辅助); SoD 职责分离不受 mode 影响; LLM 禁入

### 2.2 护栏三指标(智能产品管理语义, 恶化>3% 自动 guard_pause)

| 指标 | 口径 | 基线 | 恶化代理 |
|---|---|---|---|
| 终审驳回率 manualRejectRate | rejected / 终审已决(rejected+on_sale) | 0.10 | 人工终审质量恶化 |
| 图片违规标记率 imageFlagRate | flagged / 总图片 | 0.10 | 审图恶化 |
| AI 预检拦截率 aiRejectRate | aiReview.action==reject / 全部已预审 | 0.10 | AI 预检恶化 |

**口径铁律**(承智图教训): 流程态(draft/ai_reviewing/manual_reviewing)不进终审分母——商品流转在途是业务常态, 已决状态才进恶化口径; 分母 0 取 0(冷启动不误判)。

### 2.3 三面口径(30 端点)

| 面 | 端点 | 口径 |
|---|---|---|
| 决策面(16 写) | 商品创建/编辑/提交/AI 预检/终审/上下架/版本回滚/图片全链(上传/重传/销毁/管理/回滚)/学习回流/AI 生图/AI 文案 | off 409 + pdmMode 标记 |
| 安全阀豁免(1) | **force-delist 紧急下架** | **永不关停**(违规商品即刻下架的安全处置权) |
| 观测面(9 GET) | 商品列表/详情/待审队列/版本/上架建议/A-B 测试/图片列表/详情/看板 | 永不关停 |
| 控制面(4) | mode / override / guard(缺省实时聚合) / resume | admin 门禁 |

### 2.4 自动巡检(pdm_scheduler.py 新增 + main.py 挂载)

- PDM_GUARD_AUTO 默认 on, PDM_GUARD_INTERVAL 默认 3600s(最小 60s)
- 聚合源: pdm_repository list_pdm_products + list_images(上限 1000)
- run_guard_patrol 可独立调用(控制面 guard 缺省聚合)

### 2.5 鉴权优先(参数化装饰器, 小竹 strict 范式)

- @_decision(strict=True 默认): 无 X-Member-Id 放行函数体触发 401; 服务层 perm_grants 403 自然发生——401/403 优先于门控 409

## 六、回滚与运维

- **回滚命令**:
  `sed -i 's/^PDM_MODE=.*/PDM_MODE=off/' /opt/zhuxiang/.env && docker compose up -d backend`
- **运行时切档**(免容器重建):
  `POST /api/pdm/mode/override {"mode":"shadow"}`
- **护栏暂停恢复**: `POST /api/pdm/mode/resume`(人工留痕)
- **巡检开关**: PDM_GUARD_AUTO=off 可关(默认 on——护栏是保护机制)
- **巡检间隔**: PDM_GUARD_INTERVAL(默认 3600s, 最小 60s)
- **off 态语义**: PDM 决策 16 写端点(商品/版本/图片/AI 工坊/回流)409; **force-delist 安全阀 + 观测面 9 GET + 产品展示基础 7 端点零影响**
