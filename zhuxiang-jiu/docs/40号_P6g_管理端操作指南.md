## 二、自主引擎页签操作(P6g 新增)

### 2.1 治理开关(唯一写操作)

**暂停自主行为**(红色警示按钮):
1. 点击「暂停自主行为」→ 弹出理由输入框
2. **理由必填**(留痕审计; 空理由将被前后端双重拦截)
3. 确认后即时生效: AI 全部自主行为冻结(学习/创作/发布/自愈/
   租用受控写), 观测面(看板/漏斗)不中断
4. 干预记录落库 blogger_interventions(留痕审计)

**恢复自主行为**:
1. 点击「恢复自主行为」→ 确认弹窗
2. 恢复须显式操作——**永不自动恢复**(宪法口径)

## 三、审批操作(admin 决策面)

### 3.1 租金结算(P6f-1)

```
admin/av/rental/bills 生成 → pending
admin/av/rental/bills/{id}/approve → 信值扣减经 47号执行
admin/av/rental/bills/{id}/reject → 驳回
```
铁律: 租金**永不自动**——admin 不 approve 不扣款。

### 3.2 绩效结算(P6f-2)

```
admin/av/performance/reports 生成月报(五分项)
admin/av/performance/{id}/settle → 建议入账(总分×0.1 信值)
admin/av/performance/{id}/approve → 47号入账留痕
```

### 3.3 real 渲染审批(P6f-1)

```
admin/av/rental/scripts/{id}/real-approve
```
租用会员默认 mock 轨; real 轨须 admin 预审(成本+合规双闸)。

## 四、宪法红线速查(操作时必守)

| 红线 | 操作含义 |
|------|---------|
| β/γ 拒改 | 无任何调整入口; 传入即 409 |
| 分润/租金/绩效永不自动 | 不 approve 永不结算 |
| 授权撤回秒级下架 | 撤回授权前确认(关联内容全下架) |
| pause 观测不冻结 | 暂停期间看板照常可查 |
| ownerId 隔离 | 租用会员只见自己的数据 |
| 白皮书零 PII | 公开端点无个体数据 |

## 五、故障排查

| 现象 | 处置 |
|------|------|
| 受控写 409「自主行为已暂停」 | 检查治理开关; 显式 resume |
| 开放端点 401 | 检查 X-Api-Key/X-App-Code 双头凭证 + pro 档 |
| 开放端点 403 | tier 非 pro——超级会员专属 |
| 白皮书 piiHits>0 | 不应出现; 立即上报(宪法红线) |
| Redis 读数异常(bool 类) | 已修复; 若复发查 _deserialize_bools |
