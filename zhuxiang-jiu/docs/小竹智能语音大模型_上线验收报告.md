### 2.3 工程创新: 参数化双头鉴权新范式

小竹鉴权与 65号 X-Role 单头不同——X-Member-Id(低门槛,
游客 0 合法)+ X-Role admin 双头。装饰器参数化适配:

- `@_decision` 默认: 低门槛 member 面直接门控
- `@_decision(strict=True)`: strict 面无 X-Member-Id 放行
  函数体触发 401
- `@_decision(admin=True)`: admin 面非 admin 放行触发 403

保证 401/403 优先于 409 语义(65号范式的双头扩展)。

  显式声明——401/403/409 语义完全正确(专项 3 断言实证)
