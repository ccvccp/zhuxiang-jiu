# 智客·AI智能会员大模型 创新规划方案 v1.0

> 定位: 会员管理模块升级——从「档案登记簿(静态)」到「会员智能运营中枢(增长引擎)」。
> 参照: 智启元/智法/智图大模型既有范式(四层协同+确定性引擎+建议书模式)。
> 铁律: LLM 禁入会员判定链; 数字 100% 查询层; 运营策略永不自动执行(建议书模式)。
> 命名: 「会员管理」→「**智客·AI智能会员大模型**」(ZhiKe Member-Intelligence)。
> 基线盘点: member_routes 19 端点(注册/登录/L1-L5 等级/成长值/积分/地址)全保留零改动, 智客叠加运营层。
> **边界声明**: 与 68号信值雷达划界——智客专注消费频次/等级生命周期/积分行为/运营决策; 不碰信值五维(诚信/互助/专业/活跃/成长)与 TV 资产域。

## 一、基线盘点(现有能力 × 目标差距)

| 能力域 | 现状 | 智客目标 | 差距 |

| 权益运营 | 等级折扣(价格引擎内) | 权益匹配+唤醒策略建议书 | 无运营闭环 |

## 二、架构: 四层协同

```
L1 问答层: NL 会员问答(五域意图路由→确定性查询)
    ↓
L2 智能体集群(确定性 Agent):
    洞察Agent(健康度+RFM) / 预警Agent(流失+LTV)
    / 运营Agent(权益+唤醒) / 进化Agent(反馈+检测)
    ↓
L3 数据织物: member + orders(by member) + points 只读聚合
    ↓
L4 自主进化引擎: 反馈闭环+异常自发现+推理链留痕
```

## 三、四大能力 → P0-P3 分期

### P0 会员洞察中枢
- **NL 会员问答**: 意图路由(会员量/等级分布/消费/积分/流失五域) → 确定性查询
- **会员健康度**: 五维评分(活跃/消费/等级成长/积分/生命周期, Sigmoid 分段)
- **RFM 画像**: 最近消费 R/频次 F/金额 M 确定性分层(五档×五档×五档 → 分层标签)

### P1 流失预警与 LTV
- **流失预警**: 登录间隔拉长/消费衰减/等级下滑 三信号加权 → 红黄绿分级
- **LTV 预测**: 历史消费×留存系数(等级×活跃加权) → 会员终身价值估算
- **等级生命周期沙盘**: What-if(消费±/成长值±) → 保级/升降级推演

### P2 权益运营引擎
- **权益匹配**: L1-L5 差异化权益建议(生日/专属/免邮阈值, 建议书)
- **积分运营**: 积分沉淀/过期风险/兑换倾向分析
- **唤醒策略**: 沉睡会员分级触达建议书(渠道×时机×权益, 人工确认后执行)

### P3 自主进化与决策支持
- **反馈闭环**: 策略采纳/修正/拒绝 → 参数权重学习(安全阀 clamp)
- **异常三检测器**: 消费 spike/积分 drop/注册 surge
- **决策备忘录**: 会员日活动/等级门槛调整 结构化建议书

### 全期贯穿: 可信与安全
- 与 68号雷达边界: 智客输出仅消费/等级/积分域, 不输出信值分 / 推理链留痕 / X-Role: admin
