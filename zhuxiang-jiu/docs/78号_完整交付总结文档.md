## 一、模块概览

78号解决的核心问题：项目已过大规模新建期（48-52 号等家族模块林立），进入"每次只动一小块"的增量维护期——此时最大风险不是缺功能，而是**改动面看不见**（不知道动了这文件会波及谁）、**知识断层**（junior 接手不知道哪些是红线）、**破坏性回归**（巡检形同虚设、基线缺失）。竹盾以"开发期工具链、非常驻大模型"为形态，四条铁律落地：

| 铁律 | 工程落法 |
|------|---------|
| ① 资产图谱为底座 | 2612 端点/480 运行时开关/59 页面/红线 R1-R6+行为资产 B1-B5 全量锁定，MD 为源、JSON 脚本生成禁手编 |
| ② 每笔核心改动先出影响报告 | zhudun impact：改动面 × registry → 四级风险（红/高/中/低）+反向引用+回归建议+检查清单映射，报告入 git 即 PR 附件即教材 |
| ③ 门禁三态可逃生 | pre-commit 竹盾段：assist（默认，提示不阻断）/ full（缺报告阻断）/ off（紧急旁路）；ZHUDUN_OVERRIDE=1 单次逃生——一切放行留痕可审计 |
| ④ 度量闭环 | stats 上报 Redis + patrol 每日巡检竹盾段 + gate 三指标看板 + guard_pause 降档判定 |

**默认零影响**：全只读分析、非常驻大模型（跑完即走）、业务提交在 assist 档永不阻断、可整体摘除无残留。

## 三、各期交付明细

### P0 资产图谱与红线（T0.1-T0.7）

- **L0-端点清单**：2612 端点/124 模块，鉴权面标注（EXACT/GET 前缀/JWT 与 @_decision 门控），扫描器覆盖子路由器/f-string 常量参数/模板/WS；
- **L0-模块清单**：561 服务+96 仓储+607 环境开关（运行时生效 480），418 运行时开关首次入库登记，两通道回滚模板；
- **L0-页面清单**：三源铁律（仓库根+taro public+deploy 直部署），九页 dist 双向零差集，nginx 路由资产取证；
- **红线标记**：R1 支付回调/R2 鉴权/R3 模型门控/R4 Redis 混型/R5 语音/R6 部署 + 行为资产 B1-B5，每条附当日实证代码位置；
- **registry.json**（744KB）：端点/开关/模块/页面/九页来源/红线文件面+行为资产，MD 为源脚本生成；
- **首个真实护航**：T0.4 盘点中发现 UA 分流 map 缺失漂移 → 走全链（登记→影响报告→ECS nginx 补双层 map→双端三路验证内容全等）→ 报告+conf 快照归档。

### P1 影响评估全链（T1.1-T1.9）

- **cli.py 三子命令**：index（图谱重建，吸收 P0 四件扫描器）/ impact（影响评估 --base 可配）/ gate（T3.3 真实现）；
- **impact 输入层**：git diff --name-only 对照基线 ∪ status 未跟踪（-uall 修复 porcelain 折叠目录漏文件）；3 种改动形态全列；
- **反向引用**：符号提取（文件名/模块名/顶层 def/class/registry 路由 path）单遍 union 正则，对齐人工 grep 子串语义；
- **红线命中判定 redline_assess**：改动面 × registry 后缀匹配 → 红/高/中/低四级，高级附行为资产与开关回滚值；
- **六段式影响报告**：改动面/风险分级汇总/回归建议（按最高级）/反向引用/检查清单映射/签字确认行；秒级时间戳防同名；
- **stats 度量上报**：zhudun:stats hash 累加（reports_total/red_hits/risk_*）+ zhudun:index:last_run；Redis 不可达静默降级；fakeredis 可注入单测；
- **pre-commit 自动预检**：竹盾段置钩子最前（实测坑：旧钩子"无 JS 变更 exit 0"会短路后置段）——F1 语法阻断（py_compile/node --check）/B1 v=升位/C4 绝对 URL 告警。

### P2 巡检与基线（T2.1-T2.4）

- **patrol-single.ps1**：单端巡检真实落地（勘误：设计文档的巡检任务三机查无，按"试点即生产"落地）——A6 存活探针（health/backend8147/nginx -t/Redis 键面）+ 业务键面探测 + 绝对阈值检查 + 汇总，每日 08:30 计划任务；
- **特性基线 test_feature_baseline.py**：16 断言锁三大行为资产现行为——B1 运费（¥99 免邮 6 条，含 599 满减 30 现行为发现：首跑抓到臆想断言错、代码对）/ B2 评价双写（FakeRepo 零 Redis 依赖+LOCK_MODE=asyncio）/ B3 注册面 age_gate（18 岁临界 4 条）；
- **探测面升级**：consistency-probe-ecs.ps1 全页遍历（totalPages 循环防第一页 50 条截断）+ patrol 字段缺失判 DRIFT 不放行（修复"探测失败静默放行"真实缺陷，拦截模拟 3/3）；
- **ZHUDUN_MODE 三态门禁**：off=紧急逃生旁路 / assist（默认）=缺报告提示不阻断+留痕 WAIVED-NO-REPORT / full=P3 预留。

### P3 门禁与度量（T3.1-T3.4）

- **full 门禁+Override 逃生**：full 档窗口（ZHUDUN_REPORT_WINDOW_MIN，默认 1440 分钟）内无影响报告 → 阻断 exit 1；ZHUDUN_OVERRIDE=1 单次放行留痕 OVERRIDE-USED（事后须补报告）；
- **patrol [2.5/4] 竹盾段**：读 zhudun:index:last_run + stats 五指标——NEVER/>14 天 WARN 建议 zhudun index，≤14 天 PASS；WARN 不计入 drift（registry 旧非线上漂移）；
- **gate 三指标看板**：报告量 reports_total（采纳度）/ 红线命中 red_hits（每报告均值）/ 放行率（waived+override 占比，门禁被绕工程度）；guard_pause 判定=放行率超 30%（ZHUDUN_PAUSE_RATE 可配）建议降档 full→assist 并留痕 GUARD-PAUSE；Redis 不可达降级不崩溃；--json 机器可读无副作用。

## 四、命令与门禁清单

| 入口 | 用法 | 说明 |
|------|------|------|
| index | `python agent-infra/zhudun/cli.py index` | 资产图谱重建（L0 三清单+registry.json），全链重跑与 git 锁定版 diff=0 |
| impact | `python agent-infra/zhudun/cli.py impact --base <base>` | 影响评估全链出报告（默认基线 origin/master） |
| gate | `python agent-infra/zhudun/cli.py gate [--json]` | 护栏三指标看板+guard_pause 降档判定 |
| 门禁档位 | `ZHUDUN_MODE=off / assist(默认) / full` | pre-commit 竹盾段三态 |
| 单次逃生 | `ZHUDUN_OVERRIDE=1 git commit ...` | full 缺报告时人工放行（留痕，事后补报告） |
| 窗口/阈值 | `ZHUDUN_REPORT_WINDOW_MIN=1440` / `ZHUDUN_PAUSE_RATE=30` / `ZHUDUN_REDIS_URL` | 可配项 |
| 每日巡检 | patrol-single.ps1（08:30 计划任务） | [1/4] 存活 → [2/4] 键面 → [2.5/4] 竹盾新鲜度 → [3/4] 阈值 → [4/4] 汇总 |

## 五、数据模型

| 键/文件 | 类型 | 内容 |
|---------|------|------|
| zhudun:stats | Redis hash | reports_total / red_hits / risk_红 / risk_高 / risk_中 / risk_低（impact 每跑累加） |
| zhudun:index:last_run | Redis string | 最近全链重建时间戳（patrol 新鲜度判定消费） |
| .git/hooks/.zhudun_waiver.log | 追加文件 | WAIVED-NO-REPORT / OVERRIDE-USED / GUARD-PAUSE 三类留痕行（gate 放行率分子） |
| docs/registry/*.md | git 文件 | L0 三清单+红线标记（唯一事实源，MD 为源铁律） |
| docs/registry/registry.json | git 文件 | 机器可读索引（脚本生成禁手编） |
| docs/registry/reports/*.md | git 文件 | 影响报告×7+M0/M1 复核报告（PR 附件+junior 教材） |
