## 三、上传步骤

1. **导入项目**: 微信开发者工具 → 项目列表 → 导入 → 目录选择 `d:\网站架构设计\taro-app`（工具读取 project.config.json 自动加载 dist-weapp）
2. **本地预览**: 工具栏「预览」扫码真机验证（游客可浏览商品; 登录 13800000002 为 admin 账号可进「我的→站点管理」六工作台）
3. **上传**: 工具栏「上传」→ 填版本号（建议 `1.1.0`, 对应 AI 家族上线版）与备注（建议: "全功能版: 消费主链+六大AI管理工作台"）
4. **提交审核**: 小程序管理后台「版本管理→开发版本」→ 提交审核 → 选择类目与页面（首页）
5. **发布**: 审核通过后「发布」全量上线

## 四、审核注意事项（酒类电商）

- **资质**: 未上传《食品经营许可证》前, 含酒类售卖页面的版本大概率被驳回——先在管理后台完成资质再提审
- **未成年人**: 站点已有年龄门（注册生日校验/ageConfirmed）, 详情页含"过量饮酒有害健康·未成年禁止购买"提示语, 提审时在备注中说明
- **支付**: 小程序端微信支付需在管理后台开通并绑定商户号（当前版本先以登录浏览/管理端为主也可提审, 视经营节奏决定）

## 五、边界说明

- AI 工作台（zy/zf/zw/zt/zd/zk 六页）为**管理端工具**: 请求自动注入 `X-Role: admin`, 仅 admin 账号登录后数据可见, 普通消费者访问该数据一律 403（生产已验证）
- 消费主链（商品/购物车/下单/会员/积分）对所有用户开放
- 小程序产物与 H5 同源同构（同一 src 构建）, 后端 API 为生产环境 zxjiu.com

## 六、常见问题

| 问题 | 处置 |
|------|------|
| 工具报「urlCheck」请求失败 | 详情→本地设置→勾选「不校验合法域名」仅限调试; 正式包必须在后台配置域名白名单 |
| 想重新构建 | `cd taro-app` 后 PowerShell: `$env:TARO_OUTPUT_DIR="dist-weapp"; npm run build:weapp`（**勿直接 `npm run build:weapp`——默认输出会写入 dist/ 覆盖 H5 产物**） |
| 包体积逼近上限 | 当前 1.86MB; 若后续超 2MB, 考虑 AI 工作台改分包（subPackages） |
