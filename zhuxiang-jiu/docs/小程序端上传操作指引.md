## 三、上传方式 A：自动化（推荐, miniprogram-ci 已就绪）

**首次配置（仅一次, 需管理员微信扫码登录 mp.weixin.qq.com）**:
1. 管理后台 → 「开发管理」→「开发设置」→「小程序代码上传」→ **生成密钥** → 下载 `private.wxafcff83a4c2a2b7f.key`
2. 将密钥文件拷贝到 `taro-app/` 根目录（已被 .gitignore 排除, 不会入库）
3. 若该页开启了「IP 白名单」: 将本机公网 IP 加入（或临时关闭白名单）

**执行上传（此后每次一条命令）**:
```
cd taro-app
npm run upload:weapp                          # 默认版本 1.1.0
node scripts/upload-weapp.js --version 1.2.0 --desc "自定义描述"
```
脚本内置预检（产物 48 页完整性 + 密钥存在性 + IP 白名单提示）; 失败时打印精确引导。

**上传后（管理后台操作）**: 「版本管理→开发版本」→ 提交审核 → 审核通过 → 发布。

## 七、常见问题

| 问题 | 处置 |
|------|------|
| 工具报「urlCheck」请求失败 | 详情→本地设置→勾选「不校验合法域名」仅限调试; 正式包必须在后台配置域名白名单 |
| 想重新构建 | `cd taro-app` 后 PowerShell: `$env:TARO_OUTPUT_DIR="dist-weapp"; npm run build:weapp`（**勿直接 `npm run build:weapp`——默认输出会写入 dist/ 覆盖 H5 产物**） |
| ci 上传报 IP 不在白名单 | 管理后台「小程序代码上传」处关闭白名单或加入本机公网 IP |
| ci 上传报密钥无效/权限 | 确认密钥属于 AppID `wxafcff83a4c2a2b7f` 且未在后台被禁用/重置 |
| 包体积逼近上限 | 当前 1.86MB; 若后续超 2MB, 考虑 AI 工作台改分包（subPackages） |
