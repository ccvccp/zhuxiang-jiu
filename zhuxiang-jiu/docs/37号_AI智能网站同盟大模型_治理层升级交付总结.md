## 二、交付内容

### 2.1 三态灰度（ALLIANCE37_MODE）

- `off`：决策面关闭（409）——观测面不受影响
- `shadow`：观察学习期（决策放行+留痕标记）
- `assist`：辅助生产期（决策生效）——**默认值**
- 读取链（优先级）：护栏暂停 > 运行时 override > 环境变量 > 默认 assist

### 2.2 观测面 / 决策面划分

- **观测面（永不关停——宪法口径）**：商户/商品/评价/结算/报表/考核/范围/就近推荐/定制列表/白皮书等全部 GET 查询
- **决策面（off 拒绝 409，共 23 端点）**：入盟申请/人工审批/商户状态（激活/转正/暂停/终止）/商品上下架/下单/结算/冲正/批量结算/分润配置/评价提交/评价折叠/考核执行/范围申请/场景编排/线下核销/定制全链（提交/报价/确认/推进）

### 2.3 护栏机制（三指标恶化 >3% 自动暂停）

| 指标 | 基线 | 语义 |
|------|------|------|
| refundRate 退款率 | 5% | 交易质量 |
| complaintRate 客诉进线率 | 2% | 服务质量 |
| terminationRate 商户清退率 | 3% | 生态健康 |

- 判定口径：`(cur - base) / base > 3%`（确定性阈值比较，LLM 禁入）
- 自动暂停 = 保护机制（功能开关，非处罚，等效 off 运行时态留痕）
- 恢复须人工 `POST /api/alliance/mode/resume`（决策留痕）

### 2.4 治理端点（5 个）

| 端点 | 用途 |
|------|------|
| `GET /api/alliance/mode` | 灰度总览（模式+护栏+决策面清单公示，观测面） |
| `POST /api/alliance/mode/override?mode=` | 运行时切档（人工留痕，免容器重建，空串清除回落 env） |
| `POST /api/alliance/mode/guard` | 护栏检查（三指标留痕+自动暂停） |
| `POST /api/alliance/mode/resume?note=` | 人工恢复（决策留痕） |
| `GET /api/alliance/whitepaper?year=` | 年度同盟生态白皮书（四章节） |

### 2.5 年度白皮书（四章节固定结构，LLM 禁入）

1. 同盟生态框架（八大类目/入盟门槛/15%分润/GeoGrid）
2. 年度数据（商户分布/商品/订单 GMV/分润/评价星级/考核等级/场景/定制）
3. 红线工程化案例（5 条宪法域公示：假溯源清退/连续C级/密度仲裁/决策面铁律/LLM禁入）
4. 开放倡议（CC BY-NC-SA 4.0，零个体数据，样本门 <3 不出数）
