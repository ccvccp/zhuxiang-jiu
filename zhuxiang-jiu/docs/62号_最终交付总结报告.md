## 二、分期交付明细

### P0 信任要素注册表+资产登记底座（`6e06a3b`）

- **TRUST_ELEMENTS 封闭注册**：三角色（enterprise/organization/personal）× 九资产域（8 正域+risk 负域）共 13 要素（10 正 3 负），分角色差异化权重
- **证据封闭域**：evidenceSchema 24 字段校验，域外拒绝；负资产证据必填（防漏报洗白）
- **资产登记底座**：主体×角色×要素域×证据快照四维校验落库+sha256 指纹链+九态状态机（registered 首态）
- **第37档案入册**：asset_valuation 八因子评分器（44号 batch21，全站计数 37→38 更新 21 文件）
- **启动自检**：RuntimeError 宪法级（角色域全覆盖/负域必负/证据字段合法性）

### P1 因果估值引擎+归因报告（`e758ffc`）

- **CAUSAL_RULES 封闭注册**：13 条规则三元组（要素→结果→强度）覆盖全部 13 要素+版本化 v1+objective 动态权重乘子（stability/growth——risk 域乘子恒 1.0 铁律）
- **贡献度公式**：`contribution = Σ(要素得分×因果权重×置信度系数) − riskDeduction`；负资产得分取 max（fail-safe——严重度不因证据不全减免）
- **置信度三档**：high≥0.8 直接生效（active）/ medium≥0.5 抽检复核（assessed+spotCheck）/ low<0.5 强制人工（pending_review）
- **归因报告**：规则 ID 强制锚定+证据引用+因子快照，无锚点自动标记"未验证"（归因幻觉防线）
- **objective 46号审批双模**：submit→46号审批→apply 终审，未裁决不可生效
- **LLM 不进判定链**：纯确定性计算，同输入同输出

### P2 流动性评级+场景折算+衰减激活+反事实压测+阈值配置域（`fc2d2fe`）

- **流动性四档**：high（认证类，限频 10/日+场景校验）/ medium（经验类，限频 5）/ low（关系类，仅自证不可流转）/ risk→none（负资产恒不可流转）
- **衰减模型**：`decay = base × exp(-λ×idleDays)`，90 日半衰期（λ=ln2/90），半衰期经 46号审批可校准 30-365 日
- **激活机制**：理由封闭域（合规使用/知识更新两类防任意洗衰减）+ reactivated 态+idleDays 归零
- **场景信值折算**：四场景（投标/融资/合作准入/免审接入）×域系数×乘子×衰减，仅可流转档纳入；**45号 L2 platform_conduct 增益域 deposit 调用**（56号补偿同款 fail-soft 范式，45号零改动）
- **反事实压测**：要素摘除重算 Δ%（摘除正资产净贡献下降/摘除负资产净贡献回升）
- **阈值配置域**：46号审批双模（decay 半衰期/scenario 乘子单域单次）

### P3 公平性审计+申诉通道（`5820f5d`）

- **申诉三态机**：submitted→reestimated（自动重估）→resolved（人工裁决 uphold 维持/overturn 翻转）
- **翻转留痕**：originalValue/originalEvidence 快照+finalValue/finalDelta 差异——uphold 恢复原证据回滚原值，overturn 采纳重估值
- **负资产洗白防线**：risk 域数值证据不可减持（penaltyRecords 只可增）
- **公平性审计**：46号 compute_metrics 纯函数零改动复用（均值差异比 20%+通过率差 15pp 双指标+小样本误报防线）+超阈告警仅标记不下结论
- **申诉不受开关影响**：mode save/restore 范式（60/61号回流同款铁律）
- **关键 bug 修复**：`_list` 排序键与评估表主键不一致（assessmentId≠assessId）导致内存模式版本链漂移——`_KEY_FIELD_BY_KIND` 显式映射修复

### P4 业务结果验证回流+T+1 调度（`f66d3c3`）

- **验证信号三档**（确定性）：`偏差 = |实际−预测|/预测` → within_tolerance≤10%（+1）/ moderate_deviation 10-30%（+0.3）/ severe_deviation>30%（−1）
- **44号池双写**：第37档案八因子快照+assessId 1:1 幂等（pooled 标记跳过+回写）
- **偏差预警**：severe 占比≥40% 且样本≥3 → 权重复审建议经 46号审批（人工终审轨——AI 不可自改权重）+同域 pending 不重复提交
- **衰减批量结算**：T+1 全资产流动性档案刷新
- **T+1 调度器**：AV62_LEARN_MODE 默认 off+AV62_LEARN_INTERVAL 默认 24h（下限 300s），main.py lifespan 集成

```

          ↓

```
