## 一、模块概览

**52号是小竹语音家族（48-51号）的收口模块**。全站 AI 智能语音模块——48号中枢（21 端点）/49号可信 FC（17 工具）/50号信值积分（14 行为）/51号知识图谱（22 路由）——交付了值得托付的机制，52号将这份托付转化为**五维 20 项指标体系+四态决策引擎+双开关告警调度**。评估面只读聚合、零写入既有表、默认零影响（双开关 off 直通）。

```
48号中枢(21端点) ─┐
49号FC(17工具)   ─┼─→ 52号评估引擎(只读聚合 10 表)
50号积分(14行为)  ─┤      ├─ 五维 20 项指标(注册表封闭)
51号图谱(22路由)  ─┘      ├─ 四态决策(veto/mandatory/priority/pass+regression)
                          ├─ 评估报告(信值合规影响评估章节)
                          └─ 阈值告警(基线+漂移·当日同键去重)
```

## 三、各期交付明细

### 3.1 P0 指标注册表+决策规则（奠基层）

**交付物**（[us52_registry.py](../backend/services/us52_registry.py) 480 行 + [us52_repository.py](../backend/repositories/us52_repository.py) 快照/会话框架 + [us52_routes.py](../backend/routes/us52_routes.py) 6 端点）

- **四态决策引擎**（`decide`）：veto（安全韧性任一未达→禁止上线）/ mandatory（功能/包容/透明度未达→限期修复）/ priority（信任未达→下迭代最高）/ pass（纳入线上监控）+ **regression 负向改进红线**（牺牲 privacy/explainability/fairness 一律视为负向——铁律最高优先）
- **启动自检 6 类断言**（`_validate_registry`，RuntimeError 宪法级）：20 项数量/五维分布（5+4+5+4+2）/基线域/veto 域仅安全韧性/数据源白名单/proxy 指标 proxyNote
- **快照框架**：`compute_snapshot` 手工注入 `{metricKey: value}` → 逐项判定+决策+留痕（P1-P4 计算管道逐期接入）；未注册指标拒绝（注册表封闭）
- **6 端点**：GET registry / dimensions / metrics/latest / snapshots + POST metrics/compute / release-gate

**验收**：专项 40 断言（注册表结构/决策四态+regression 红线/快照判定/off 铁律 409/未注册拒绝）+回归 154。
