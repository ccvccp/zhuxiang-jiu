## 一、定位与目标能力

**一句话定位**：用户说人话，智搜判断「他是谁、他想要什么」，从站内
商品/权益/招商/订单/知识五库中查出正确答案或执行正确动作——全站
统一智能入口（文本 + 小竹语音）。

**目标能力（验收场景）**：

| 用户输入 | 角色 | 系统行为 |
|---|---|---|
| "竹奕酒多少钱一瓶？" | 游客 | 商品检索 → 价格/规格/入口链接 |
| "帮我找适合送礼的竹香酒" | 会员 | 商品检索×会员价 → 礼盒推荐 + 会员权益提示 |
| "我想做代理，怎么申请？" | 游客 | 招商政策 RAG 摘要 + 留资表单引导 + 高价值线索标记 |
| "我的政策" | 已认证代理 | **角色路由**：返回其区域/等级/返利规则（非通用政策） |
| "会员有什么权益？" | 会员 | 会员模型 → 该会员当前等级权益 + 升级路径 |
| "查一下我的订单发货了吗" | 登录用户 | 订单系统(Bearer) → 物流轨迹摘要（智运联动） |
| "麒麟/瑞麒是什么" | 任意 | 品牌知识库 RAG（统一口径，含今日入库麒麟文化） |
| "酒能治病吗" | 任意 | **合规拦截**：医疗断言拒绝 + 保守回答 |

## 二、总体架构（五层）

```
用户输入（Web/小程序/小竹语音→文本）
        ↓
┌─ L1 意图层 ──────────────────────────────┐
│ 角色判定(X-Member-Id→role/等级/代理态)    │
│ → 意图分类(规则优先+LLM兜底) → 槽位提取    │
└──────────────┬──────────────────────────┘
        ↓
┌─ L2 合规前置层(硬规则, LLM禁入) ──────────┐
│ 未成年购酒引导/医疗功效/代理收益承诺       │
│ → 命中即拦截返回保守话术(留痕)             │
└──────────────┬──────────────────────────┘
        ↓
┌─ L3 多路检索层 ───────────────────────────┐
│ R1商品: 产品库(名称/价格/库存/场景标签)    │
│ R2权益: 会员等级/积分/升级规则             │
│ R3招商: 招商政策+代理规则(RAG)             │
│ R4订单: 订单+物流(智运联动, 需鉴权)        │
│ R5知识: 知识库426+条(品牌/麒麟/竹文化/法律)│
│   ——复用 knowledge_service 语义检索+重排  │
└──────────────┬──────────────────────────┘
        ↓
┌─ L4 融合重排层(确定性) ───────────────────┐
│ 综合分 = 相关性×0.5 + 角色匹配×0.2         │
│        + 业务权重×0.2 + 合规风险×0.1       │
│ 低置信 → 转人工/保守回答(留痕)             │
└──────────────┬──────────────────────────┘
        ↓
┌─ L5 生成与动作层 ─────────────────────────┐
│ 结构化回答(引用来源) or 动作卡片           │
│ (跳商品页/留资表单/查订单页/联系客服)      │
└──────────────────────────────────────────┘
        + 进化回流(意图命中/点击/转化 → 学习)
```

## 三、意图体系（7 类 + 兜底）

| 意图 | 触发示例 | 关键词锚点(规则层) | 槽位 |
|---|---|---|---|
| product 商品 | 多少钱/买/送礼/礼盒/库存 | 商品名、价格区间、场景(送礼/宴请/收藏) | productName, priceRange, scene |
| equity 会员权益 | 权益/积分/等级/升级 | 等级名、权益项 | level, benefitItem |
| agent 招商代理 | 代理/加盟/招商/政策/区域 | 区域、代理类型 | province, agentType |
| order 订单物流 | 订单/发货/物流/退换/发票 | 订单号、运单号 | orderNo, waybillNo |
| help 平台帮助 | 注册/下单/支付/账户 | 操作词 | operation |
| brand 品牌咨询 | 竹奕酒故事/工艺/麒麟/瑞麒/竹文化 | 品牌词 | brandTopic |
| attract 活动引流 | 活动/优惠/秒杀/拼团 | 活动类型 | activityType |
| chat 闲聊兜底 | 以上皆非 | — | — |

**角色×意图 二维路由**（同一意图不同角色不同答案）：
- agent × 游客 → 通用政策摘要+留资
- agent × 已认证代理 → 「我的政策」个性化返回
- equity × 游客 → 会员体系介绍+注册引导
- equity × 会员 → 当前等级权益+升级路径

## 四、多路检索（站内资产映射——零新建存储）

| 检索路 | 复用站内资产 | 检索方式 |
|---|---|---|
| R1 商品 | products 表 + 商城页 | 关键词+结构化过滤(价格/库存) |
| R2 权益 | 会员模型(等级/积分规则) | 结构化查询 |
| R3 招商 | 知识库 brand/policy 域 | RAG(语义) |
| R4 订单 | order_routes + 智运轨迹 | 结构化(需 Bearer+本人校验) |
| R5 知识 | 知识库 426+ 条(含 legal 域 125 条) | **复用 knowledge_service.search**(2-gram+embedding+rerank 三级已建) |

## 五、合规拦截层（白酒场景硬规则，全链确定性）

1. 未成年购酒引导 → 拒绝+提示法定年龄（对齐注册 18 岁门）
2. 保健/治疗/解酒功效 → 拒绝（复用 MEDICAL_CLAIM_WORDS）
3. 代理收益/保底承诺 → 拒绝+引用官方政策原文（法律域已入库 125 条）
4. 极限词（复用 BANNED_WORDS 广告法词库）
5. 低置信(<0.55) → 转人工/保守回答，永不编造
6. 招商回答必须带来源引用（政策条目 id）

## 六、自主学习进化（对齐 etaWeight 反馈范式）

**进化参数（clamp 安全阀）**：
- intentWeight：意图分类器规则层与 LLM 层的采纳权重 [0.4, 0.8]
  （>0.6 更信规则命中统计，<0.6 更信 LLM 判定）
- routeBoost{intent}：各检索路的历史点击通过率加成 ±0.05（clamp [0.8, 1.2]）

**回流信号（全部已有埋点体系可挂）**：
- 显式反馈：回答下方「有用/没用」按钮 → adopted/rejected
- 隐式信号：回答内动作卡片点击（跳商品/留资提交）→ 转化正样本；
  换个问法重搜 → 负样本
- 灰度回流：意图命中分布 vs 召回来源分布 vs 转化率（看板监控）

**进化红线**：合规层权重永不参与进化（硬规则恒定）；参数调整留痕
可回滚（对齐六模型人工裁决红线）。

## 七、三态灰度与护栏（六模型标准范式）

- ZS_MODE：off（409 决策面关闭）/ shadow（返回建议+留痕标记）/
  assist（生产档）——读取链：护栏暂停 > 运行时 override > env > off
- 护栏三指标（恶化 >3% 自动暂停）：拦截误伤率 / 低置信转人工率 /
  意图误分类投诉率（客服工单联动）
- 决策留痕：每次意图判定+路由+重排 top3 候选全留痕（可审计）

## 八、API 设计（/api/search-ai/*）

| 端点 | 面 | 说明 |
|---|---|---|
| POST /query | 决策 | 统一问答入口 {text, context} → {intent, slots, answer, actions, sources, confidence} |
| GET /intent-stats | 观测 | 意图分布/命中率/低置信率 |
| GET /routes | 观测 | 检索路召回分布与转化 |
| GET /decisions | 观测 | 决策留痕(近50) |
| POST /evolution/feedback | 决策 | 显式反馈(adopted/rejected) |
| GET /status | 观测 | 大模型总览(对齐智法/智运) |
| GET/POST /mode* | 控制 | 三态+护栏+resume(4端点) |

## 十、实施分期

**MVP（P0，建议先行）**：
1. 意图层：规则锚点分类（7 意图全关键词表）+ 角色判定（复用 auth 头）
2. 合规前置层（复用三个词库）
3. R5 知识路 + R1 商品路（两条最有价值检索路）
4. 确定性重排 + 结构化回答（LLM 仅品牌咨询路启用）
5. 三态灰度 off 起步 + 决策留痕
6. 搜索框入口（官网/商城顶栏「AI 搜索」）

**P1**：R2 权益路 + R4 订单路（鉴权联动）+ 动作卡片 + 显式反馈进化

**P2**：LLM 意图兜底 + 向量改写（复用知识库 embedding）+ 看板 +
隐式转化回流 + 小竹语音接入
