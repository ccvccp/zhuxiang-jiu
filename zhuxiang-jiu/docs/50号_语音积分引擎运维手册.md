## 二、看板⑧语音积分分区判读

单次 `GET /api/xiaozhu/dashboard` 聚合（fail-soft；off 时显示空态）。

| 指标 | 判读口径 |
|------|---------|
| events/byLayer/byBehavior | 事件总量与分布——L1 应占多数(日常交互) |
| poolTotal/frozenMembers | 激励池总余额/冻结数——**frozen>0 立即核对处置台账**(冻结=闸门或降级) |
| pendingEvents | 待 T+1 结算事件数——持续高位=结算 job 未开或持续拒收 |
| settlements.byStatus | done=入账/rejected=验真拒收(看 reason 补源重试)/skipped=冻结或未绑定 |
| adjudications.byPattern | **五模式分布——tts/scripted 骤升=刷分攻击面预警** |
| adjudications.byStatus | pending(含未申诉)/upheld/overturned |

## 三、日常巡检

```bash
# 1. 看板快照(每工作日)
curl -H "X-Role: admin" http://127.0.0.2:8000/api/xiaozhu/dashboard
# 关注: ⑧enabled/off 态; frozenMembers; byPattern

# 2. 结算批次(每周)
curl -H "X-Role: admin" http://127.0.0.2:8000/api/xiaozhu/voice50/settlements
# rejected 批次读 reason——孤证补独立源后重试(settle 幂等)

# 3. 处置台账(事件驱动——闸门命中后)
curl -H "X-Role: admin" http://127.0.0.2:8000/api/xiaozhu/voice50/adjudications
# pending+appealedAt 非空 → 待复核(≤48h SLA)

# 4. 手动补偿结算(发版后/补跑)
curl -X POST -H "X-Role: admin" -H "Content-Type: application/json" \
  -d '{"dayKey":"2026-09-04"}' \
  http://127.0.0.2:8000/api/xiaozhu/voice50/settle
```

## 四、反作弊处置 SOP（v2.0 §六）

### 五模式触发后

| 模式 | 自动处置 | 运维动作 |
|------|---------|---------|
| tts_spoof | 归零+L1 扣 10 | 审计留痕；用户可申诉(原始录音+设备日志) |
| scripted_repeat | 当日冻结 | 申诉须说明合理业务场景 |
| shared_account | 积分域锁定 | 强制核验；家庭成员报备备案 |
| privacy_extraction | L2 扣 20 | **上报安全团队**(处置台账+note) |
| budget_exhausted | 拒积分 | 引导调整设置；临时额度需理由 |

### 申诉复核（≤48h SLA）

```bash
# 申诉(会员)
curl -X POST -H "X-Member-Id: <会员>" -H "Content-Type: application/json" \
  -d '{"note":"家庭设备录音凭证..."}' \
  http://127.0.0.2:8000/api/xiaozhu/voice50/adjudications/<adjId>/appeal

# 复核(admin): upheld=维持 / overturned=翻转并解冻
curl -X POST -H "X-Role: admin" -H "Content-Type: application/json" \
  -d '{"upheld":false,"reviewNote":"确认误判"}' \
  http://127.0.0.2:8000/api/xiaozhu/voice50/adjudications/<adjId>/decide
```

台账保留 **180 天**（监管调阅口径）。闸门 fail-soft：检测器异常放行计分并告警（日志 `voice50_gates_failsoft`）。

## 六、衰减与对冲运营

| 项 | 口径 |
|----|------|
| 月度衰减 | 90 天无语音交互 → 池月 5%，保底 30%（底薪不没收）；**只作用池，已入账信值永不回退** |
| 手动触发 | `POST /api/xiaozhu/voice50/decay`（admin——建议月度例行） |
| 修复对冲 | 会员池余额抵扣历史违规 ≤50%/次，走 45号修复通道；`POST /api/xiaozhu/voice50/offset`（body: violationEventId） |

## 七、故障排查

| 现象 | 排查 |
|------|------|
| 看板⑧显示"引擎未启用" | VOICE50_MODE=off——正确空态；需启用则开开关重建容器 |
| pendingEvents 持续高位 | ① 结算 job 未开（VOICE50_SETTLE_MODE）② rejected 持续（读批次 reason——孤证/summary 意图）③ 会员未绑定（skipped: unbound） |
| 会员反馈"积分被冻结" | 查 risk-state → 处置台账（闸门模式）或 l1PenaltyTotal>20（降级）；申诉翻转/POST unfreeze 恢复 |
| 申诉 409 | 非本人/重复申诉/已复核（_handle 语义） |
| 结算重复跑 | 幂等设计——settled 事件不重拾；rejected 可重试（补源后） |
| 闸门误判 | 处置台账 detail 字段（模式+检测细节）→ 复核 overturned 自动解冻 |

## 八、回滚预案

| 场景 | 动作 |
|------|------|
| 关闭引擎 | VOICE50_MODE=off（等价软回滚——钩子空转，台账/看板分区停更） |
| 关闭结算 | VOICE50_SETTLE_MODE=off（T+1 停跑；pending 事件保留可后补） |
| 全量回退 | 回滚至 b48f206（50号实施计划）之前——50号为纯增量（17 端点+7 表+钩子），48号 21 端点不受影响 |
| 数据残留 | `zhuxiang:voice50:*` 键空间独立——按需 DEL |

## 九、运维红线（摘要）

1. 衰减/处置/冻结**只作用积分域**——语音入口永不阻断（反语音霸权）；
2. 入信值必经 45号 deposit 验真（T+1 聚合，溢出不桥接）；
3. 申诉 ≤48h SLA；处置台账 180 天；
4. 群体系数不碰预算分级（预算只按会员自主偏好）；
5. 双开关 off 是交付默认态（off 直通铁律）；
6. 闸门 fail-soft 放行时记 warning——巡检关注 `voice50_gates_failsoft` 日志（检测器异常≠安全）。
