## 一、模块概览

55号将用户自然语言意图转化为安全、个性化、可治理的二维码服务交付：

```
用户("我要办老年优待证")
  → ① 意图理解(规则轨三态 resolved/partial/clarify)
  → ② 服务资源注册表(SERVICE_REGISTRY 12 项封闭白名单)
  → ③ LLM 澄清(mock/real 三态——LLM 不进路由链)
  → ④ 动态码生成(HMAC+exp+nonce+千面适配)
  → ⑤ 隐私预算校验(49号 check_and_spend, 超限降级)
  → ⑥ 扫码核销(验签四态+防重放+跨端续接)
  → ⑦ 全链追踪(七类信号回流+44号学习+45号信值结算)
```

**核心数字**：六期交付、20 端点、专项 223 断言、实机验收 220 项次（5 脚本 ×2 轮幂等）、13 套件回归零失败、9 处实施缺陷即修即录、44/46/48/51/49号零改动宪法全程保持。

## 七、实施缺陷修复（9 处）

P0 L0 零成本 falsy 误判；P2 detail 反序列化缺漏/expire 缺 codeId/feedback 重复 lpush；P4 拨测白名单漂移/儿童 template 误判/46号导入错误；P5 红队格式非法未捕获/向量会员污染——全部即修即录，专项+实机双重复验。

## 八、配置与运维

**开关矩阵**：`QR55_MODE`（默认 off——生成/核销面，存量二维码链路零影响）；`QR55_LEARN_MODE`（默认 off——T+1 调度）。可调：`QR55_LEARN_INTERVAL`（86400/下限 300）、`QR55_REGRESSION_THRESHOLD`（0.3）、`QR55_SECRET`（缺省 dev）。

**部署态**：镜像 zhuxiang-jiu-backend 容器 healthy；观测面（registry/model/codes/stats/governance/attribution/dashboard）off 可达；红队需显式 on。
