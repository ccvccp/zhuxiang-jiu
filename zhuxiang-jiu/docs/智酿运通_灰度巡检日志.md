**域外缺陷闭环（顺手赚钱模块，非 zw 域）**：
- 现象: 08:39 `/api/pocket/my/stats` 未捕获异常 `type str doesn't define __round__`
- 根因: `pocket_repository._deserialize` 类型白名单未覆盖 settings 数值键——Redis 模式下 `monthRewardSticker` 等以 str 返回，`ready_month×str` 字符串重复后 `round()` 崩溃；且 `0×"30.0"=""` 使**任何会员**调用必崩（首次读初始化返回内存浮点，第二次起读 Redis 即触发）
- 修复: `_INT_FIELDS`/`_FLOAT_FIELDS` 补齐 settings 键（checkinReward/monthRewardPoster/monthRewardSticker 浮点，maxActiveSites/aiScoreThreshold/durationDays/minAddressLen 整数）；`enabled` 布尔已有处理无需改
- 验证: 本地类型恢复断言 + pocket 回归 26/26 + ruff 全绿 → 部署重建 → 服务器 Redis 二次读路径 settings 类型全恢复 + `my_stats(3)`（即原崩溃场景）正常返回 0.0 → 日志零 ERROR → 公网五端点冒烟 200
- 注: 该缺陷为 Redis 模式潜伏缺陷，与灰度模块及两次部署无关（触发时点在智单智客浏览器验收窗口）
