### 2.3 实机发现并修复的真实缺陷

**bool 反序列化陷阱**(Redis 模式独有, 内存模式不可见):
- 现象: resume 返回 200 但 autonomy_state 仍 paused=True
- 根因: `_serialize` 将 bool 存为 1/0, Redis hgetall 读回
  字符串 "0"/"1", `bool("0")` 恒 True——`_deserialize` 无 bool 还原
- 修复: 新增 `_deserialize_bools`(指定字段 "0"/"1" 显式还原);
  `get_autonomy_state` Redis 分支接入
- 影响: P6g-2 红队(内存模式)未覆盖——**Docker 实机作为最后防线
  的价值实证**
- 回归: 本地 P5d/P6f1/P6g3 套件复验全绿; 实机 30/30
