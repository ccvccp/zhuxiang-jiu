# 智能知识库训练模型 · 创新升级交付总结

> 依据: 《智能知识库训练模型》(D:\智能知识库训练模型) 文档愿景 + 工程化裁剪
> 原模块: AI智能知识库训练模块 → **智能知识库训练模型**

## 一、升级总览

| 维度 | 升级前 | 升级后 |
|---|---|---|
| 定位 | 静态知识库（数据→模型单向映射） | **认知操作系统**（业务-系统-模型三元闭环） |
| 生成范式 | 单轨（rule 或 llm） | **双师对抗-协同**（生成器×判别器，推理时 generation-judge） |
| 治理 | 合规筛查（入库时一次） | **治理规则即奖励函数**（四维持续评分） |
| 演化 | 缺口队列 | 缺口 + **负例库/黄金标准库**（对抗样本回流） |
| 灰度 | KNOWLEDGE_CHAT_LLM 二态 | **DUAL_MODE 三态**（off/shadow/assist + 护栏） |

## 二、核心创新落地

### 2.1 双师对抗-协同引擎（P0）

- **生成器**（`_dual_generate`）：双候选生成——稳健 0.2 + 探索 0.8 双温度，幻觉治理口径与既有 `_rag_llm_synthesize` 一致（仅依据编号资料 + [编号]引用）
- **判别器**（`_dual_judge` + `_dual_llm_judge`）：LLM 四维 JSON 评分，解析失败回退本地启发式（防单点）
- **判别器模型**：`LLM_MODEL_JUDGE` 环境变量（默认空 = 同模型双角色；可配异构模型）
- **接入点**：`rag_answer(provider="dual")`，synthesized 场景触发；全否决/无候选自动回退单轨；缓存 key `question|dual` 天然隔离

### 2.2 治理规则即奖励函数（P1）

判别器四维加权（总 100 分，<60 否决）：

| 维度 | 权重 | 口径 |
|---|---|---|
| 合规性 | **40** | **宪法域硬门槛**（本地 compliance_score≥70 + 品牌禁忌，LLM 不可推翻） |
| 事实一致性 | 30 | LLM 判别（回退：资料词覆盖启发式） |
| 结构化质量 | 15 | LLM 判别（回退：长度区间启发式） |
| 引用完备 | 15 | LLM 判别（回退：[编号]标注计数） |

**样本库**（铁律：仅为建议数据）：
- 否决候选 → 负例库；双师一致高分（≥80）→ 黄金标准库
- 黄金标准不自动发布、负例不自动退役——流转必经既有 review/publish 人工链路

### 2.3 漂移与平衡监控（P2）

- **胜率比健康带**：生成器否决率 50%±10%，超带 guard 自动降档 off（保护非处罚）
- **评分直方图**：判别器评分 5 桶分布统计（KL 散度的工程化裁剪）
- **观测面端点**（admin，永不关停）：
  - `GET /api/knowledge/dual/stats`（否决率/黄金数/负例数/直方图）
  - `GET /api/knowledge/dual/mode` + `POST .../mode/override` + `POST .../guard` + `POST .../resume`
  - `GET /api/knowledge/dual/samples?kind=negative|golden`

### 2.4 三态灰度（DUAL_MODE）

读取链：护栏暂停 > override > env > off（全站范式，chat_mode_service 同构）。
`off` 零影响（单轨照常）→ `shadow` 双师留痕不呈现 → `assist` 胜出答案呈现。
