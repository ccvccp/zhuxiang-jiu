# 智图·AI智能地图大模型 创新规划方案

> 定位: 位置地图管理模块升级——「全域角色时空服务中枢」
> 日期: 2026-09-14 · 地图底座: 百度地图(测试期, 前端 AK 经 env 注入)
> 核心命题: 从"地理可视化"升级为"全业务时空交互操作系统"

---

## 一、宪法对齐声明(先决约束)

1. **LLM 禁入决策链**: 意图解析为确定性"业务本体+关键词"规则引擎(非 LLM 自由生成); 匹配/排序/调度/沙盘全部确定性公式。LLM(如配置)仅可润色话术文案——未配置走规则模板, 双轨均正常。
2. **建议书模式**: 月台分配/异常派单/资源调度/选址决策一律生成《建议书/工单/预案》, 人工确认后执行, 永不自动。
3. **进化可见可控**: 行为留痕/反馈闭环全部落库可查; 拒绝记负样本。

## 二、三大能力跃迁(承接既有 13 端点)

| 跃迁 | 原模块 | 智图 |
|---|---|---|
| 意图理解 | 关键词+固定分类(地址/门店/代理商) | 六角色语义+复合意图解析(确定性本体) |
| 资源聚合 | 门店/代理商位置数据 | 全业务 POI+实时状态+跨业务匹配 |
| 主动服务 | 用户搜地图 | 角色自适应视图+异常派单+沙盘 |

## 三、四层引擎(四服务)

**P0 意图引擎(zt_intent_service)**
- 业务本体表: "买酒/用餐/品鉴/住宿/提货/停车/送原料"等 12 类意图词 → POI 能力标签组合(确定性映射)。
- 复合意图解析: "找附近能吃饭还能买酒的地方" → 餐饮+酒水零售双标签 AND 匹配(分词→意图词→能力向量)。
- 六角色画像: 消费者/供货商/采购商/运营/代理商/管理层(角色→视图能力矩阵)。

**P1 资源聚合引擎(zt_resource_service)**
- 全业务 POI 统一时空底座: 门店/品鉴馆/餐饮/仓储/月台/服务点六类 POI(含经纬度+能力标签+实时状态: 库存/座位/排队/营业)。
- 复合排序: 综合分 = 0.4×距离分 + 0.25×评分 + 0.2×库存/座位余量 + 0.15×营业状态(确定性加权, 同输入同输出)。
- 供货商月台预约: 预约时段→分配建议(排队最短月台)+场内导航要点; 收货状态实时可视。
- B 端多仓货源匹配: 各仓库存/距离(haversine)/时效→推荐仓组合+成本测算。

**P2 全域调度引擎(zt_command_service)**
- 态势一张图: 订单+运力+POI 负载+异常聚合(按业务线/区域/时段下钻)。
- 异常派单: 检测(延迟/缺货/满座/排队超阈值)→定位责任岗位→《处置预案工单》建议(人工确认)。
- 资源弹性调度: 瓶颈识别(爆仓/满座/运力紧张)→调配方案建议书(备用仓/预留座位/众包运力)。
- 代理商驾驶舱: 辖区授权边界+门店分布+销量热力(留痕接口)+合规风险点。
- 管理层风险雷达: 合规/安全/供应链指标分级告警+归因。

**P3 进化引擎(zt_evolution_service)**
- 行为流萃取: 搜索→下单→核销→评价全链留痕(学习点标注)。
- 时空战略沙盘: 选址/渠道调整模拟——确定性因子加权(人口代理×商圈密度×竞争距离×成本), 输出收益/风险量化预测(建议书)。
- 时空绩效画像: 按区域/时段的 POI 效能评估(坪效代理指标)。
- 反馈闭环: 采纳/拒绝负样本回流。
