## 三、统一技术范式(全站大模型标准)

### 3.1 核心九项(每模型必备)

1. **三态灰度**: `<PREFIX>_MODE` = off(默认)/shadow(观察期)/
   assist(辅助期)——73/74 通过红队核验后升级 full
2. **读取链**: 护栏暂停 > 运行时 override > env > 默认 off
3. **状态存储**: 整档 JSON 单键 `zhuxiang:<prefix>:mode_state`
   (规避 45号 P0 字段级序列化教训)
4. **同步桥接**(62号范式): 进程快照 `_G` +
   `legacy_current_mode()`——服务层一代门控零调用点迁移
5. **护栏三指标**: 业务语义定制, 恶化>3% 自动 guard_pause
   (保护机制可自动, 恢复须人工 resume 留痕)
6. **决策门控**: `@_decision` 装饰器(off 409 + xxMode 响应
   标记), 鉴权 401/403 优先于 409
7. **4 控制面**: GET /mode、POST /mode/override、
   POST /mode/guard、POST /mode/resume
8. **自动巡检**(65号起): `<PREFIX>_GUARD_AUTO` 默认 on,
   间隔 3600s, 仓储层确定性聚合(LLM 禁入判定链)
9. **两永不关停**: 宪法豁免面(用户权利)+观测面(GET)

### 3.2 宪法豁免面设计(用户权利优先)

| 模型 | 豁免面口径 |
|---|---|
| 65号 | 关店(经营者退出)/人工兜底 S6/上架巡检/回流 collect |
| 小竹 | sessions 删除(被遗忘权)/隐私偏好/confirm 核销/voice50 appeal |
| 钱包 | **全站最宽 8 端点**: 提现申请(资金退出权)/审核链/退款/本金取出/奖品领取——off 只锁新增盈利入口 |
| 通用原则 | 观测与纠错永不关停(宪法口径) |

### 3.3 参数化双头鉴权范式(小竹定型, 钱包复用)

```
@_decision                    # 低门槛面直接门控
@_decision(strict=True)       # 无 X-Member-Id 放行→401 优先
@_decision(admin=True)        # 非 admin 放行→403 优先
```
