# 48号·小竹智能语音中枢——完整方案(全景版)

> 2026-10-01 整理 | 性质: 既有体系的全景结构化文档(供交接/
> 演进依据)——区别于"从零设计"方案: 九层架构全部已生产运行,
> 本档把 P0 至今(含当日唤醒评分 P1/招商意图 P2)的全资产整理
> 成可交接形态 | 配套: project_memory 小竹条目(百余条实证)

## 〇、定位与形态

小竹 = zxjiu.com 全站语音交互入口: 用户在网站(H5 悬浮球
浮层)/小程序通过语音唤醒、说话、提问 → 识别意图 → 联动
品牌介绍、招商代理(新)、会员信值、订单购物与合规问答 →
TTS 播报 + 卡片/页面联动。

**形态定版**: 全站浮层化(主站悬浮球原地展开 iframe, 同域
共享登录态) + 免提连续对话(VAD 断句循环) + 小程序录音上传。

## 一、九层架构(全部已落地)

```
用户语音 → ①唤醒层 → ②采集层 → ③ASR 层 → ④意图层
         → ⑤合规守护 → ⑥执行层 → ⑦TTS 播报 → 卡片/页面联动
                            ⑧观测进化层 + ⑨数据层 横切
```

### ① 唤醒层
- 双唤醒词定版: **"小竹小竹"/"你好小竹"**(正是外部建议首推
  词——已现实); 近似音容错 7 音(小朱/小珠/小猪/小主/晓竹/
  小竹竹——ASR 误听映射); 句中唤醒容错(录音开头丢字常态);
  叠词残余剥离
- 免唤醒窗: 会话级 + **member 级 5 分钟窗**(跨会话延续,
  token 竞态实证修); 点击录音=明确唤醒(wakeup_free)
- **概率型唤醒评分(P1, 2026-10-01 上线)**: 分级表(精确 1.0/
  强近似 0.9/同韵 0.8/弱近似 0.7)+ 句中位置衰减(×0.75/×0.65)
  + 未注册 u 韵 12 字观察留痕(0.55 不唤醒——误唤醒面首个
  量化观测); `XIAOZHU_WAKE_SCORE_MODE=off` 默认零差异留痕
  积累, 阈值 0.7=旧表命中面完全等价(env 可调)

### ② 采集层
浏览器 ScriptProcessor 采 PCM→16bit WAV→base64(48kHz);
nginx body 上限 10m(约 100s 语音); VAD 静音 0.8s 断句;
**自愈双机制**: 哑流(近零能量持续 3s→硬重置 30s 退避)/
残化流(连续 3 轮空转写→重置采集链 60s 退避)

### ③ ASR 层
阿里百炼 Fun-ASR(主)+ 智谱 ASR(备)双 provider; **连接架构
V4.4 定版**: armed 预热池(段间保活 25s ping)+后端→百炼一段
一连接(百炼掐线不可依赖, 确定性压倒微优化)+SSLContext 复用
+段内重试一次; **空转写健康轮二打 V5.2**(源 rms≥0.006 判
百炼抖动自动重识别); 前置预检三道: 纯语气词(嗯/啊/咳)/
英文环境声幻觉(_is_en_noise)/碎片拦截(≤3 字毫秒级回)

### ④ 意图层(28 指令)
- **rule 轨 48ms 模板** + LLM 增强轨(XIAOZHU_LLM_MODE)+
  智能应答轨(affirm/negate/next/command/chat 五分类)
- 指令族: wine 四问(verify/craft/recommend/reviews)/
  product(新品/价格/属性)/order/cart 全家(加购/改量/撤销/
  提交/支付)/**trust 五连**(余额/查分/兑换/修复/转换)/
  nav+page 导航/map 附近门店/promo 优惠/privacy 预算/
  explanation 归因/session 历史/help/**招商代理 2 条
  (2026-10-01: agent.apply 14 变体+agent.faq 5 变体, faq
  前置防泛化截胡)**
- 路由铁律: **first-match 注册序**(具体意图前置于泛化子串);
  指代消解(这个/它→上一轮对象); 商品页意图锚定(hash→
  postMessage 预取商品名→指代词前缀注入); 自定义指令
  (voice48_custom_cmds)

### ⑤ 合规守护
- 三态灰度 `XIAOZHU_MODE`(off 409/shadow 留痕/assist 全链)
  + **护栏三指标自动 guard_pause**(ASR 失败率 0.10/风控处置
  率 0.05/语料拒审率 0.10, 恶化>3% 自动暂停, 7 天滑动窗)
- 合规尾巴硬注入("理性饮酒未成年人禁止饮酒"全回复);
  POLITE/ATTACK 词表; **反语音霸权红线**(未唤醒不执行);
  支付安全 L1-L3(黑名单/频次/金额窗+voicepay 四因子评分+
  GLM 只拦不放, VOICEPAY_MODE 三态); 跨文化方言词表

### ⑥ 执行层
26+2 指令钩子全真实调用(订单/加购/支付/信值资产全链);
800ms 超时熔断统一 wait_for(降级话术, 资金 confirm 面分流
不参与降级); fail-soft 全覆盖

### ⑦ TTS 播报
合成+下载+播放链; **barge-in 打断**(文本归一化+逐句 LCS
相似度≥0.75 回声判定+纠正词强制切断+延迟埋点); 五态状态机
(idle/listening/processing/speaking, smT 原子转换, 非法
转换留痕宽恕); 播报 80 字上限(防超长音频断续); X5 兼容
(主页面播音频/forEach+setTimeout 错峰并发)

### ⑧ 观测进化层
护栏指标看板+失败轮分诊三型(弱音频/健康空转写/连接层)+
smoothness 轮级评分(rule/smart/chat 分轨)+T+1 学习回流+
周报(XIAOZHU_WEEKLY_AUTO)+诊断三件套(ws_asr_final 留痕/
XIAOZHU_WS_DUMP/analyze_dump.py)

### ⑨ 数据层
voice48_* 九表: sessions/turns/bindings/points/points_acc/
failures/custom_cmds/proactive/fc_audit(+privacy_budget)
