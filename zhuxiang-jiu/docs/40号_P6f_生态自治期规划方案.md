# 40号·AI智能DV博主大模型——P6f 生态自治期规划方案

> 依据:《40号_P6_全链交付总结报告》§九后续展望 + 用户指示"开始规划 P6f 生态自治"
> 定位:P6 五期已交付"站内自主"(音视频学习/创作/发布/自治理/合规转发);
> **P6f 升级为"生态自治"**——把自主引流能力从"平台自用"开放为"生态共建":
> 超级会员租用 AI 引流员、AI 播客/主播按信值绩效取酬、行业合规标准输出、
> AI 视听行为可信度评估——构建"创作者愿意授权、用户信任推荐、平台安心
> 分发、生态按信值分配"的正向飞轮
> 架构原则:**开放不等于放权**——一切对外能力经 API 网关(既有 ApiKeyService
> 三档限值+双闸限流);一切绩效/租金/分成走 46号建议书(永不自动);
> 一切标准输出无个人身份信息(67号白皮书先例);LLM 禁入判定链铁律不变
> 核心命题:**生态自治的度量衡是信值**——租用是信用行为(违规扣配额)、
> 绩效是信值兑现(P6d 漏斗+共鸣度驱动)、标准是信值外显(行业白皮书)、
> 可信度是信值镜像(AI 视听行为五因子)

## 一、升级定位:从"站内自主"到"生态自治"

| 维度 | P6 现状(站内自主) | P6f 升级后(生态自治) | 关键保障 |
|------|------------------|---------------------|---------|
| 能力边界 | 平台自用 AI 引流员 | **超级会员租用**(API 开放, 三档限值) | 既有 API 网关复用+租用配额质押 |
| 激励结构 | 创作者授权分润(P6e) | **AI 播客/主播信值绩效**(按漏斗+共鸣取酬) | 绩效建议书→46号人工 approve |
| 行业影响 | 站内合规体系 | **行业合规标准输出**(白皮书+开放数据集) | 全量聚合无 PII+确定性模板 |
| 信任基建 | 站内看板+审计 | **AI 视听行为可信度评估体系**(五因子) | 观测口径实时聚合(对齐 API 健康先例) |

**复用底座(零重复造轮子)**:
- ApiKeyService(P?):申请/审批/free-basic-pro 三档限值/QPS+日配额/用量
  记录/X-API-Key 中间件鉴权——P6f-1 直接扩展 AV 引流端点组
- ApiLearningService 健康五因子+三检测器(尖峰/骤降/错误激增)——
  P6f-4 可信度评估直接沿用该范式
- 46号 submit_change(审批建议书)——全部绩效/租金/分成提单
- 47号 tier_of(纯读取)——租用资格与绩效系数的账户层
- P6a-e 五引擎(信号/脚本/渲染/漏斗/共鸣/授权链)——租用调用的就是它们
- 44号 ai_learning(API 裁决真值回流)——可信度数据回流学习

## 二、四维生态自治架构

```
【会员层】超级会员(47号 tier ≥ pro 档)申请租用 AI 引流员
    │  ①引流能力开放(P6f-1)
    ▼ API 网关(既有): X-API-Key 鉴权 + QPS 窗口 + 日配额
       + AV 专用端点组(选题/脚本/渲染/发布 只读+受控写)
       + 租用账本(用量记录→租金建议书→46号)
    │
    ▼ ②AI 播客/主播信值绩效(P6f-2)
    绩效 = 确定性聚合(P6d 六层漏斗 + 共鸣度 + P6e 转发效果)
    → 绩效分月报(全量聚合) → 绩效建议书 → 46号人工 approve
    → 47号信值入账(AI 人设/授权创作者双轨)
    │
    ▼ ③行业合规标准输出(P6f-3)
    白皮书(年度): 全量聚合数据(授权率/深审分布/撤回响应/水印覆盖)
    + 开放数据集(脱敏) + CC BY-NC-SA 许可(67号先例)
    → 发布责任归属操作者与审批人(AI 仅展示)
    │
    ▼ ④AI 视听行为可信度评估(P6f-4)
    五因子: 履约率/合规率/共鸣质量/授权完整度/自愈稳定
    (对齐 API 健康五因子先例: 确定性公式+权重固定)
    + 三检测器(可信度尖峰/骤降/违规激增)
    → 可信度分档(影响租用配额系数) + 看板区(观测面)
    │
    ▼ 治理红线(全层贯穿, 宪法域)
    绩效/租金/分成永不自动(46号) | 标准输出无 PII |
    LLM 禁入(聚合=确定性公式) | pause 覆盖开放端点(降级只读) |
    违规处置: 扣配额/停租走建议书, 永不自动执行
```

## 三、引擎一:引流能力开放(P6f-1)

### 3.1 租用模型(API 网关扩展, 最小侵入)

```
租用资格: 47号 tier ≥ pro(超级会员) + API Key 状态 approved
端点组(新增 /api/open/av/*, 走既有 X-API-Key 中间件):
    GET  /open/av/topics          选题推荐(只读: 热点+信值契合)
    POST /open/av/scripts         脚本生成(受控写: 复用 P6b 全链)
    POST /open/av/renders         渲染(mock 轨; real 须单独审批)
    GET  /open/av/works/{id}      作品详情(仅自己的)
    GET  /open/av/funnel          六层漏斗(仅自己的调用归因)
限值: 沿用 free/basic/pro 三档(QPS+日配额); AV 组计入同一配额池
```

- **租用账本**:每次受控写调用记入 rental_ledger(API 维度 memberId/
  endpoint/次数/计费单位)——**租金结算生成建议书**(46号 approve 后
  从会员信值扣减, 永不自动)
- **隔离红线**:租用者的脚本/作品与平台自营**命名空间隔离**
  (ownerId 贯穿; 自己只能看自己的漏斗);渲染 real 轨须 admin 审批
  (成本与合规双闸)
- **降级保护**:pause(全局自治暂停)时开放端点组降级为**只读**
  (选题/漏斗可看, 生成/渲染暂停——观测不中断, 行为冻结)

### 3.2 用量与计费(确定性)

- 计费单位:脚本生成=1 单位/次、渲染=5 单位/次(mock)、real 轨=50 单位
- 单价由 admin 配置(建议书口径);月度账单=单位数×单价(全量聚合)
- 超配额:网关 429(既有双闸限流语义), 不产生负债

## 四、引擎二:AI 播客/主播信值绩效(P6f-2)

### 4.1 绩效公式(确定性, LLM 禁入)

```
月度绩效分 = 0.35×漏斗贡献 + 0.25×共鸣质量 + 0.20×合规表现
           + 0.10×授权贡献 + 0.10×自愈稳定        (0-100)

漏斗贡献: 归因激活数/首单数(P6d 六层漏斗末端两层, 归一化)
共鸣质量: 该人设全部作品共鸣均分(P6a 共鸣公式)
合规表现: 深审通过率+零价值观冲突+水印覆盖 100%(P6b/P6e)
授权贡献: P6e 转发授权链引入量+撤回零发生
自愈稳定: 自愈成功率+人工队列占比低(P6d 自愈流水)
```

- **双轨兑现**:AI 人设(平台资产→平台账)与授权创作者(P6e 分润轨)分开结算
- **绩效建议书**:月度全量聚合→`submit_change(46号)`→人工 approve→
  47号信值入账——**永不自动**(宪法域)
- 绩效分档:≥80 金牌/60-79 银牌/<60 观察期(影响下月租用配额系数
  1.2/1.0/0.8——档位变更同样走建议书)

### 4.2 防操纵红线

- 绩效数据源=归因体系(追踪码防篡改, P2a 三层去重)——刷量进不了漏斗
- 共鸣度权重 γ≥α 铁律延伸:绩效公式中**共鸣质量权重(0.25)不低于
  漏斗贡献权重之外任何单一转化项**——防"唯转化论"侵蚀生态温度

## 五、引擎三:行业合规标准输出(P6f-3)

### 5.1 年度白皮书(确定性模板+全量聚合)

```
章节(固定): ①自主引流合规框架(授权链五步法)
           ②年度数据: 授权登记量/深审三档分布/撤回响应时长
             (P95)/水印覆盖率/价值观冲突拦截量
           ③红线工程化案例(γ≥α/一票否决/秒级下架)
           ④开放倡议与许可
数据源: 全模块聚合(零个人身份信息——67号白皮书先例)
生成: 确定性模板+代码出数(数字永远来自查询层, 非生成)
发布: AI 仅展示; 终稿责任归属操作者与审批人(46号 approve)
```

- **开放数据集**:脱敏聚合表(按平台×月度的漏斗/共鸣/合规分布),
  CC BY-NC-SA 许可(对齐 67号开放 API 先例)
- 行业对接最小集:监管/研究机构可申请只读 Key(P6f-1 网关同轨)

### 5.2 标准输出的边界

- 不输出:任何创作者/会员个体数据、未脱敏授权链、内部评分明细
- 输出前校验:PII 扫描(48号 mask_pii 复用)+聚合样本数 ≥ 最低门
  (冷启动 <3 不出——快照铁律先例)

## 六、引擎四:AI 视听行为可信度评估(P6f-4)

### 6.1 五因子模型(对齐 API 健康五因子先例)

| 因子 | 权重 | 度量(确定性) |
|------|------|------------|
| 履约率 | 0.30 | 作品按约发布率(含租用承诺时段) |
| 合规率 | 0.25 | 三审通过+深审自动档占比; 硬拒/冲突/投诉率反向 |
| 共鸣质量 | 0.20 | 全作品共鸣均分(P6a 公式) |
| 授权完整度 | 0.15 | 人设/BGM/素材/转发授权链 active 占比 |
| 自愈稳定 | 0.10 | 自愈成功率+转人工占比低+零静默丢弃 |

```
可信度分 = Σ 因子分×权重, 0-100; 五因子观测口径实时聚合
分档: ≥85 卓越 / 70-84 良好 / 50-69 观察 / <50 限制
```

- **三检测器**(对齐 API 异常检测先例):可信度尖峰(>μ+3σ 且 μ≥5)、
  骤降(<μ−3σ 且绝对值≥20)、违规激增(×3 且样本≥20)——全确定性
- **联动**:可信度分档→租用配额系数(1.2/1.0/0.8/0.5)——
  **档位变更走 46号建议书**(永不自动);违规激增→暂停租用审核
  (建议书), 绝不直接封禁
- **看板**:P6d 进化看板新增"可信度区"(观测面, 不受 pause 影响)

## 十一、关键设计决策备忘

1. **开放的最小侵入**:不新建网关——既有 ApiKeyService/中间件/限流
   原样复用, AV 端点组只是"新的受保护路由前缀"
2. **租用=信用行为**:租金与违规处置全部建议书制——生态开放的每一步
   都留审批留痕, 与站内"惩罚永不自动"同构
3. **绩效公式的温度**:共鸣质量权重(0.25)压过任何单一转化项——
   γ≥α 铁律在生态层的延伸, 防"唯转化论"把 AI 播客变成流量机器
4. **可信度=信值镜像**:五因子全部来自既有确定性度量(漏斗/共鸣/
   合规/授权/自愈), 无新增主观评分——可信度不是新指标, 是信值的
   另一种聚合视角
5. **白皮书先审后发**:数据全量聚合+模板出数, 但终稿 46号 approve——
   "AI 仅展示, 责任在人"的口径覆盖行业输出
6. **降级而非停摆**:pause 时开放端点转只读——观测与纠错永不关停
   (观测面不受行为冻结影响的宪法口径)
