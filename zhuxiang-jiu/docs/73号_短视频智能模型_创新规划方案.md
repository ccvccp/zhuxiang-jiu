## 一、参考方案 vs 项目资产适配（优化的灵魂）

参考文档按"从零建 AIGC 矩阵"视角推荐 GPU 重资产栈（ComfyUI/LoRA/LivePortrait/Wav2Lip/Midjourney/RunwayML）。**本项目已有五层现成资产**，73号的正确姿势是"复用补缺"而非"另起炉灶"：

| 参考文档模块 | 文档推荐 | 项目现状 | 73号适配决策 |
|---|---|---|---|
| 感知层·多源热点 | 抖音/微博/百度/小红书 API+NLP 聚类+Prophet 预测 | **36号雷达已有**（六源 API 配置位+mock_fallback+15min 调度） | 复用 36号，P1 加"热点×网站主推匹配引擎"（标签映射） |
| 决策层·剧本生成 | 分镜 JSON（画面/景别/台词/BGM/字幕）+转化率优化+IP 人设 | 36号有文案生成（LLM 轨+三审闸门），**缺分镜结构化** | P0 新增分镜剧本引擎（storyboard JSON 对接 70号渲染参数） |
| 执行层·IP 视频生产 | 数字人/2D 动画（GPU 工作站+ComfyUI+LoRA） | **70号已有**品牌卡→ffmpeg 轮播（IP 角标/色板/字体/xfade） | P0-P1 升级 70号：运镜（zoompan）/字幕动画/TTS 配音轨——**纯 ffmpeg 零 GPU**；数字人轨列远期 |
| 分发层·RPA 发布 | Playwright/Appium+防检测+SEO 标签+评论互动 | **36号发布矩阵+channels/douyin-bot**（双平台实证+防检测已有+keepalive/guard 闭环） | 完全复用；P2 扩平台（小红书/微博） |
| 数据闭环 | 完播率/点赞率→剧本权重 | 36号品类 ROI 回归+44号池 | P2 复用 44号范式接剧本风格权重 |
| 合规 | 敏感词过滤 | **三审闸门+AI 生成声明标注**（抖音实证） | 完全复用，剧本层前置过闸 |

**核心优化判断**：参考文档第一/二阶段的 80% 工作量在本项目已建成并实战检验（#37/#39/#41 双平台发布实证）——73号增量聚焦两件：**分镜结构化（决策层缺口）**与**运镜级视频升级（执行层缺口）**，其余四层做编排串联。

## 二、总体架构（五层流水线）

```
36号雷达(热点) → 匹配引擎(网站需求×热点) → 73号分镜剧本引擎(LLM→storyboard JSON)
      → 70号升级渲染(运镜/字幕动画/TTS→mp4) → 36号发布矩阵(RPA×双平台)
      → 效果回流(44号池) → 剧本风格权重(闭环)
              ↓ 全程
      三审闸门(剧本/文案合规) + AI 生成声明(平台合规) + 观测面(admin)
```

## 三、分期实施路线

### P0 编排闭环 + 分镜引擎（本期）
1. **分镜剧本引擎**（`services/sv73_script_service.py`）：
   - 输入：热点词条 + 网站主推品类（36号雷达/商品库对接）
   - LLM 生成 **storyboard JSON**（确定性 schema：每镜卡片文案≤12字/镜头时长 3-5s/BGM 情绪档/字幕高亮词/CTA 尾镜/总时长 15-25s）——LLM 仅产文案结构，**数字与参数全注册表约束**
   - Mock-first：LLM off/失败 → 确定性模板派生（热点词×五类镜头模板），产出不中断
   - **人设注入**：竹小妹 IP 口吻（注册表 prompt 段）
2. **70号渲染升级**（`services/promo_video_service.py` P2 扩展）：
   - **运镜**：zoompan 缓推（每镜 1.0→1.08 倍，Ken Burns 效果）——ffmpeg 单滤镜零 GPU
   - **字幕动画**：drawtext alpha 渐入+高亮词描边（分镜 JSON 驱动）
   - **TTS 配音轨**（可选轨）：48号小竹语音 TTS 输出→ffmpeg mux（LLM off 则纯 BGM 模板）
   - **IP 图驱动**：每镜 IP 角标位置/尺寸/进出场（分镜 JSON 的 ipOverlay 段→复用 70号 _ip_badge）
3. **全链编排**（`services/sv73_pipeline_service.py`）：热点→匹配→剧本→渲染→发布队列（挂 36号 rpa_pending 惯例）一键跑通；`SV73_MODE`（off/shadow/real 三态）+ `POST /api/sv73/pipeline/run`
4. 专项测试 + 回归（36号/70号/48号零改动断言）

### P1 匹配引擎 + 语音轨深化（下期）
- 热点×品类标签映射库（36号雷达热点结构→网站主推标签打分排序）
- TTS 情感档对齐 BGM 情绪（48号 voice 情感参数）
- 视频模板库（竖版/横版/快节奏三模板）

### P2 数据闭环 + 平台扩展（远期）
- 发布回流→分镜风格权重（44号 ai_learning_feedback 池，剧本档案入册）
- 小红书/微博 RPA 通道扩展（36号矩阵既有凭据位）
- 数字人口播轨评估（LivePortrait 级需 GPU 工作站——列"远期增强"，参考文档方案 A/B 届时论证）

## 四、风险与控制（对照参考文档 §五）

| 风险 | 参考文档对策 | 73号适配 |
|---|---|---|
| IP 一致性 | 训练 LoRA | **零训练方案**：70号 IP 角标/色板/字体物理一致（像素级复用），规避一致性风险 |
| 平台风控 | 防检测+频率控制 | **已有实证**：拟真指纹（剥 --enable-automation）+日上限闸门+人工 review 强制+keepalive/guard |
| 内容合规 | 敏感词过滤 | 三审闸门（complianceScore）+ AI 生成声明标注（抖音"含AI生成内容"实证） |
| 算力成本 | 云 GPU | **零 GPU 路线**（ffmpeg/zoompan/drawtext 全本机）——参考文档成本模型不适用，免费 |
| 热点滞后 | Prophet 预测 | 降级为"新鲜度权重"（抓取时间衰减打分，确定性）——时序模型列远期 |
