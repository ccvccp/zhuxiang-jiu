# 61号·AI智能系统升级决策模块 实施计划

> 定位：本站智能大模型感知升级后的**可信决策副驾驶**——"风险预判-影响模拟-人机协同-回滚自愈"的认知安全阀（连接"模型能力进化"与"业务安全稳定"）

> 范式：56号生产升级资产 → **61号裁决升级决策（本模块）** → 46号审批总线收口 → 既有 CI 部署 → 44号池回流真值——构成"生产→参谋→裁决→执行→进化"完整决策链

---

## 一、定位与差异化边界（与既有模块的三权分立）

| 模块 | 职责 | 一句话 |
|------|------|--------|
| 56号 升级管理 | 升级资产的**生产者**（Agent 四角色生成版本化资产包） | "怎么生成升级" |
| **61号 升级决策（本模块）** | 升级决策的**参谋部**（风险预判+影响模拟+分级建议+归因报告） | "该不该做、风险多大、人类需介入多深" |
| 46号 治理中枢 | 变更的**审批总线**（submit_change/review_change 唯一收口） | "谁批准" |

**核心差异（传统升级决策 → 本站 61号）**：

| 维度 | 传统 | 61号 | 差异 |
|------|------|------|------|
| 决策依据 | 固定阈值/人工经验 | 多维信值评估+业务影响模拟 | "拍脑袋"→"数据驱动推演" |
| 干预机制 | 全人工或全自动 | **L1/L2/L3 分级自治+关键节点人机协同** | "要么不管要么全管"→"精准介入" |
| 风险控制 | 事后监控+手动回滚 | 事前影子沙箱+事中自适应建议 | "亡羊补牢"→"未雨绸缪" |
| 知识沉淀 | 故障复盘文档 | **决策图谱+因果归因库** | "离散经验"→"可推理知识" |
| 信任构建 | 操作者个人信誉 | 过程透明+结果可溯+信值绑定 | "黑盒信任"→"白盒共识" |

**总铁律**：AI 决策的边界由**"业务容错度"与"信值置信度"**共同划定——高信值场景常规优化可高度自治，低信值或高敏感变更必须人类兜底。**AI 的职责是缩小人类决策的不确定性范围，而非替代人类承担最终责任。** 最好的决策系统，是让人类在安全边界内自由探索。

## 三、四维创新架构

### 3.1 感知层：变更语义与影响全景（P0/P2）

- **变更语义解析**（SEMANTIC_TAGS）：确定性关键词规则→结构化变更意图标签（`payment_opt` 支付链路优化/`ui_adapt` 界面适配/`compliance_rule` 合规规则/`algo_param` 算法参数/`core_refactor` 核心重构/`permission_change` 权限变更六大类+敏感级）
- **影响面预测**（IMPACT_MODEL）：变更类型×模块依赖表（DEPENDENCY_MAP 封闭注册）→受影响角色/功能/信值要素清单+预估影响幅度（如"同盟商上架成功率 -3%"）
- **历史相似案例检索**：决策图谱（CASE_LIBRARY——标签×结果×因果三元组）匹配先验（"历史类似变更失败率 12%"）
- **环境适宜性**（WINDOW_CHECK）：业务高峰标记/近期故障率/信值分布稳定性→升级窗口适宜度

### 3.2 决策层：三级决策矩阵（P1——本模块核心）

```
riskScore = w1×sensitivity(敏感级) + w2×impactScope(影响面)
          + w3×historyFailRate(历史失败率) + w4×confidence(信值置信度反向)
          ± errorBudget(容错预算域调节)
```

| 级 | 判定（示例口径） | 人机协同形态 |
|----|----------------|-------------|
| **L1 自治级** | 敏感级=观测类+影响<1%+历史成功>99%+容错预算充足 | AI 直接执行**仅限建议域**（决策快照+异步通知+事后审计抽查）；**执行永远走 46号总线**——本站"终审人工铁律"下 L1=快速通道语义（低摩擦确认） |
| **L2 协同级** | 中风险/中信值 | AI 生成 **Top3 决策方案**+风险评估+推荐项+理由——人类选择或修改（一键确认） |
| **L3 管控级** | 高风险（核心重构/权限/合规规则）或容错预算耗尽 | AI **仅输出分析报告与建议**——人类全程主导（高风险双人复核：46号范式） |

- **动态阈值校准**：决策阈值经 46号审批+人工终审（58/59号阈值域范式复用）；窗口不适宜自动升一级
- **反对意见机制**（Dissent）：AI 检测人类决策与已知风险冲突（如忽略未修复 Bug）→**风险提示弹窗语义**（决策记录挂 dissentFlag+需二次确认+理由留痕）——AI 可说"不"，人类可驳回但必留痕

### 3.3 验证层：影子沙箱与灰度建议（P2）

- **影子评估管线**（确定性，不执行代码）：静态规则校验（敏感 API/PII 红线——56号范式）+指标回放推演（近期决策信号回放→预估新决策的指标漂移）
- **灰度方案建议**：1%→5%→20%→100% 阶梯+每阶段校验指标集+异常暂停条件——**建议文档形态**（实际放量由各模块开关矩阵执行）
- **回滚预案校验**：消费 56号预生成回滚预案→完整性校验（步骤可执行性/数据清理覆盖）+5 分钟可恢复断言

### 3.4 治理层：透明可溯可进化（P3/P4）

- **决策归因报告**（ATTRIBUTION_SCHEMA）：每决策附带完整推理链 JSON（"推荐 L2 协同，因影响支付链路且当前信值波动较大，历史类似变更失败率 12%"——因子快照+规则命中+先验引用）
- **RLHF 反馈闭环**：人类对 AI 建议的采纳/修改/拒绝三态+修正内容→`decision_feedback`（P4 collect 池双写第36档案——持续优化决策模型权重）
- **审计留痕**：决策全链事件（assess/simulate/recommend/decide/dissent/appeal）+哈希指纹链
- **信值联动**：成功升级→相关模块决策置信度增益；失败→扣减+复盘触发；AI 长期准确→自治域逐步放宽（经 46号审批）

## 四、第36档案：decision_orchestration 八因子

44号 ai_learning 入册（batch20——既有测试 35→36 计数更新：预算约 35 处 13 文件）。

| 因子 | 权重 | 口径 |
|------|------|------|
| decision_accuracy | 0.20 | 决策准确率（采纳后结果良好/总采纳） |
| autonomous_ratio | 0.15 | 自治域占比（L1 直通/总量——过高需复核） |
| simulation_hit_rate | 0.15 | 影响预测命中率（预估与实际偏差<阈值） |
| dissent_effectiveness | 0.15 | 反对意见有效性（预警被证实/总预警） |
| member_trust | 0.10 | 会员信值（47号 tier 基线） |
| rollback_success | 0.10 | 回滚预案可靠性 |
| latency_budget | 0.05 | 决策链路 P95 达标率 |
| coverage_breadth | 0.10 | 决策场景覆盖度（标签域覆盖） |

→ 信任分 0-100 → 三级决策：observe（<50 建议域收窄）/optimize（≥50 阈值与图谱回流）/urgent（≥80 决策复盘会）。

## 五、数据模型（7 表，前缀 dm61）

| 表 | 键 | 语义 |
|----|-----|------|
| dm61_requests | requestId | 升级决策请求（56号提案/44号信号/人工发起→语义标签） |
| dm61_assessments | assessId | 风险评估（riskScore+因子快照+影响面+先验引用） |
| dm61_simulations | simId | 影子沙箱推演（静态校验+指标漂移预估） |
| dm61_decisions | decisionId | 决策记录（L1/L2/L3+方案集+人类裁决+归因链+dissent） |
| dm61_feedback | feedbackId | RLHF 反馈（采纳/修改/拒绝+修正内容） |
| dm61_thresholds | tier | 决策阈值配置域（46号审批联动） |
| dm61_events | eventId | 全链事件（request/assess/simulate/recommend/decide/dissent/appeal/learn_signal/scheduler_run） |

决策状态机：
```
received → tagged → assessed → simulated → recommended
   → decided(人类裁决: adopted/modified/rejected)
   → executed_track(经46号总线后回执) → closed
（dissent 可发生在 recommended→decided 任意点）
```

复用：44号池（第36档案 batch20）；56号提案+回滚预案（纯消费）；46号 submit_change/review_change（决策执行唯一通道）；47号 get_profile（tier）；58号意图/59号场景（触发源关联）；43号威胁分（环境感知输入之一）。

## 七、分期实施计划（P0-P5）

### P0 决策注册表+语义标签+请求底座
- SEMANTIC_TAGS 六类+DEPENDENCY_MAP+启动自检（52号范式）
- 决策请求底座（语义标签轨+环境感知+状态机）
- 第36档案入册 batch20（35→36 计数更新约 35 处 13 文件）
- 7 表底座；测试约 45 断言；QC：标签封闭；56/46/44号零改动

### P1 三级决策矩阵+人机协同
- riskScore 四因子+容错预算域+L1/L2/L3 判定
- Top3 方案生成（确定性——规则模板）+推荐理由
- 人类裁决流（adopted/modified/rejected+归因链）
- 窗口适宜性（自动升级）；测试约 40 断言；QC：L3 永不自治；裁决留痕

### P2 影子沙箱+阈值配置域
- 影子评估管线（静态校验+指标回放推演——不执行代码）
- 灰度方案建议+回滚预案校验（56号预案消费）
- 决策阈值配置域（46号审批+人工终审轨）
- 测试约 40 断言；QC：沙箱零代码执行；建议不执行

### P3 决策归因+反对意见+决策图谱
- ATTRIBUTION_SCHEMA 完整推理链报告
- 反对意见机制（dissent+二次确认+理由留痕）
- 决策图谱（案例库+相似检索+先验概率）
- 测试约 40 断言；QC：AI 可说不+人类可驳回必留痕

### P4 RLHF 反馈闭环+回流+T+1 调度
- 采纳/修改/拒绝三态反馈→第36档案池双写（requestId 1:1 幂等）
- 决策置信度校准预警（AI 判定偏差→阈值复审建议）
- T+1 调度器（DM61_LEARN_MODE 默认 off）
- 测试约 40 断言；QC：回流幂等；校准建议人工审批

### P5 看板+红队+三件套收官
- 四区看板（度量：决策准确率/自治占比/预测命中/预警有效+请求+决策+防御）
- 红队七向量：标签伪造（语义欺骗）/矩阵操纵（伪造信值降档）/沙箱逃逸（注入执行语义）/先验投毒（伪造案例库）/裁决伪造（越权 decide）/反馈污染（刷采纳）/图谱污染（错误因果注入）
- 宪法断言（44号 36 档案+56/46/58号零改动）+收官三件套
- 测试约 35 断言；QC：决策安全全链防御

**开关矩阵**：`DM61_MODE`（默认 **off**——off/shadow/assist）/`DM61_LLM_MODE`（报告润色，默认 off）/`DM61_LEARN_MODE`（调度，默认 off——三开关铁律）。

## 八、风险控制矩阵

| 风险 | 缓解 | 验证 |

## 九、一致性声明与外部待办

**零改动宪法**（每期断言验证）：44号学习中枢零改动（仅新增第36档案，36 档案口径）；56号零改动（提案/预案纯消费）；46号零改动（审批总线调用）；47号画像/43号安全零改动（纯读取）；58/59号零改动（触发源关联纯消费）。

**外部待办**：真实 LLM 语义解析（当前确定性标签轨——LLM 仅报告润色）；TEE 沙箱执行真实代码（当前影子推演——同 56号安全鸿沟）；多 Agent 协同决策（远期）；强化学习决策策略优化（当前 RLHF 池回流范式）；决策标准行业沉淀（生态期）。

**结语**：61号让"变更"从风险源变为信任增长点——高信值常规优化在自治域低摩擦通行，高风险变更被精准推送到人类案头并附完整推演；AI 可以说"不"，人类可以驳回但必留痕；每一次决策都在教第36档案更懂"何时该自治、何时该请示"。**AI 缩小人类的不确定性范围，而非替代人类承担最终责任——让团队在安全边界内自由探索。**
