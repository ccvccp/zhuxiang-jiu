## 二、四检查器架构

| 检查器 | 命令 | 职责 | 前沿映射 |
| --- | --- | --- | --- |
| score 评分 | `zhuyan score` | 三维成熟度评分(业务价值 S_b/运行稳健 S_r/工程复用 S_e)+罚分项 → 评分报告归档 | 感知层(成熟度评估) |
| matrix 矩阵 | `zhuyan matrix` | 价值×质量四象限分类(优先进化区/战略保护区/观察等待区/维持现状区) | 认知层(痛点定位) |
| analogize 类比 | `zhuyan analogize [--target]` | 种子指纹检索+差距分析+反模式拦截 → 进化方案(只出不施) | 认知+决策层(类比匹配+策略) |
| evolve 进化 | `zhuyan evolve` | 进化案例五段式入库(人工确认门, 复用 cases 库) | 执行层(知识沉淀) |

辅助件: `stats` 度量管道(zhuyan:stats hash, 复制家族模式) + `loop` 闭环演示
(score→matrix→analogize→evolve 一条命令四环)。

## 三、三维评分落地口径(公式: S = 0.4·S_b + 0.35·S_r + 0.25·S_e − P_penalty)

评分对象=**功能单元**: backend/routes API 端点 + core 关键模块 + 主站页面
(页面复用竹园 audit 台账)。全部因子静态取证, 每分可追溯(证据驱动铁律)。

| 维度 | 子指标(项目数据源) | 权重 | 说明 |
| --- | --- | --- | --- |
| 业务价值 S_b | 核心链关联度: 端点在《业务链定义.md》6 链 27 步中的命中(竹医 L1 同源) | 40% | 防边缘工具误判为模板 |
| | 调用频次(静态代理): 竹医 contract 调用面提取的前端调用点计数 | 30% | APM 缺位下的如实近似 |
| | 转化关联: 购物链页面(下单/详情/购物车/结算)加权 | 30% | 页面单元专用 |
| 运行稳健 S_r | 异常处理完备度: try/except 覆盖率(函数级正则计数) | 35% | 静态近似, 如实标注 |
| | 容错特征: 重试/降级/超时/幂等代码特征命中 | 30% | 竹医 qr 案例的 loginTicket 防重放即此类 |
| | 输入校验完备度: 参数校验/类型检查特征 | 20% | |
| | 并发安全: 锁/原子特征(backend/core/locks.py 同源) | 15% | |
| 工程复用 S_e | 测试保障: 测试文件存在+断言密度(qr/b1-b3 基线测试集加权) | 30% | 无测试=黑盒炸弹 |
| | 契约清晰: docstring/注释覆盖率(无 Swagger 的项目近似) | 30% | |
| | 低耦合: import 外部依赖计数倒数 | 25% | |
| | 规范性: ruff 通过率(家族既有口径) | 15% | |
| 罚分 P_penalty | 一票否决/重扣: 硬编码密钥模式 / 无测试 / SQL 拼接 / 危险模式 | — | 命中任一, 总分封顶或直降档 |

动态校准(HITL): 推荐被采纳/被拒 → 模式权重 Δ 调整记录进进化案例(轻量版)。

## 四、反模式规则库(第一重 Fast Filter——五类规则, 项目语境适配)

| 反模式 | 检测规则(触发条件) | 项目触发例 |
| --- | --- | --- |
| 过度缓存 | 模板含缓存特征 + 目标属强一致场景(支付/库存扣减/余额) | 支付回调加缓存 |
| 异步误用 | 模板含异步/队列特征 + 目标为同步契约端点 | 登录验证转异步 |
| 批量陷阱 | 模板含 batch/ bulk 特征 + 目标为单条操作端点 | 商品详情批量拉取 |
| 分布式事务滥用 | 模板含 saga/tcc/两阶段特征 + 目标为单库单表操作 | 简单状态更新 |
| 日志风暴 | 模板含全量打印特征 + 目标为高频端点(调用面计数>阈值) | 心跳/埋点端点全量日志 |

第二重(语义推理)/第三重(运行时上下文)**裁剪为**: 规则命中后输出结构化警示
+人工评审——不引入 LLM 与 APM(如实标注防线等级)。

## 五、Benchmark 口径(先行铁律, 双基准)

- **B3 评分分档回放**: 已知答案——高分样本(扫码登录链端点: 修复后+qr 基线测试齐=
  S_r/S_e 双高)+低分样本(竹园 audit 已证缺口页面/无测试端点)→ score 分档
  高/低全中=PASS;
- **B4 反模式拦截回放**: 五类规则各构造已知触发例 fixture → analogize 拦截
  5/5=100% 全中(已知答案检不出即不合格)。
