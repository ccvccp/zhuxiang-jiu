## 二、升级交付

### 2.1 模式层(xx65_mode_service.py)

- **三态**: XX65_MODE = off(默认)/shadow(开店观察期)/assist(辅助经营期)
- **读取链**: 护栏暂停 > 运行时 override > env > 默认 off
- **状态存储**: `zhuxiang:xx65:mode_state` 整档 JSON 单键
  (智运范式——规避 45号 P0 字段级序列化教训)
- **同步桥接**(62号 av62 范式): 进程快照 `_G` +
  `legacy_current_mode()` 同步读取器——`xx65_service.current_mode()`
  委托之, 服务层一代内联门控零调用点迁移至集中模式层,
  与路由层门控同源不漂移

### 2.2 护栏三指标(65号业务语义, 恶化>3% 自动 guard_pause)

| 指标 | 基线 | 语义 |
|---|---|---|
| S1 合规拦截率 complianceBlockRate | 0.10 | AI 生成内容被三道防线拦截占比 |
| 店铺违规率 shopViolationRate | 0.05 | active→suspended 违规冻结占比 |
| S5 撤销率 campaignRevokeRate | 0.05 | 营销承诺 5 分钟窗口撤销占比 |

(cur-base)/base > 3% → 自动暂停(等效 off, breachTrail 留痕);
恢复须人工 resume。护栏是保护机制(非处罚), 可自动。

### 2.3 路由层(xx65_routes.py, 29→33 端点)

- **11 决策端点** `@_decision` 装饰器: 门控(off 409)+
  shadow/assist 响应标记 `xx65Mode`:
  intents/parse, shops apply/claim/activate, products/draft,
  drafts/publish, campaigns create/revoke, quota-adjust,
  dispute-assist, redteam
- **鉴权优先**: 403(无/非法角色)先于 409(模式门控)——
  装饰器预检 x_role, 无效角色放行函数体触发 403
- **4 控制面端点**: GET /mode(灰度总览+红线公示),
  POST /mode/override(运行时切档免容器重建),
  POST /mode/guard(护栏检查), POST /mode/resume(人工恢复)
- **宪法豁免面永不关停**: close(经营者退出)/human-review(S6)/
  inspect(合规防线)/feedback collect(回流)不加门控
- **观测面永不关停**: registry/model-status/shops/drafts详情/
  products/order-window/campaigns recommend+report/health/
  coach/learn-status/dashboard

## 四、生产部署

- .env: `XX65_MODE=assist`(决策面开启)
- 重建: `docker compose up -d backend`
- **回滚命令**:
  `sed -i 's/^XX65_MODE=.*/XX65_MODE=off/' /opt/zhuxiang/.env && docker compose up -d backend`
- 运行时切档(免容器重建): `POST /api/xx65/mode/override {"mode":"shadow"}`
- 三层自验: 容器 env → 本地 health → 公网 mode(assist)
