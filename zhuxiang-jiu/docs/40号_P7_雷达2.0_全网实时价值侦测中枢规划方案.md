# 40号·AI智能雷达2.0——全网实时价值侦测中枢规划方案(P7 期)

> 依据:用户提供的《Value-UEBA 雷达 2.0 升级参考》+ 40号 P0-P6g 十一阶段终态
> 定位:P0-P3 的雷达是"作品侦测器"(侦测已发布作品→评分跟随);
> **P7 升级为"价值信号预言机"**——从被动"热点跟随者"进化为主动
> "价值信号捕手":在流量洪峰形成前识别其背后的真实需求、情绪脉络
> 与合规边界,为自主创作/合规转发/引流转化赢得"黄金窗口期"
> 架构原则:**实时≠快,而是判得准、连得上、控得住**;
> "大模型"仍是确定性系统(事件聚类=指纹范式, 情绪=词表密度,
> 预测=历史周期统计)——LLM 禁入判定链铁律不变
> 核心命题:**速度服务于价值,而非取代价值**——高热度但低契合/高风险的
> 事件自动标记"观察区"或"禁区",而非盲目推送

## 一、定位重构:从"流量报警器"到"信值机会预言机"

| 响应模式 | 入库待决策 | **L1-L4 分级响应**(自动触发/队列/储备/屏蔽) | 信息过载→行动就绪 |

### 3.2 事件流 Mock 源(槽位确定性范式扩展)

```
事件批次种子 = radar|{channelId}|{date}|{slot(15min)}
→ 同槽位确定性(事件内容/热度基数/情绪样本一致——可测聚类去重)
→ 跨槽位推进(演示"事件发酵": 同一事件跨槽位热度/情绪演化)

```

- **多模态确定性实现**:ASR 转写稿/OCR 标签 = mock 生成器的确定性
  字段(真实管线为 _fetch_real 预留轨, P3b 适配器范式);

- 真实接入预留:平台 API/RSS/爬虫走 `radar_source_adapter`

### 3.3 事件聚类与情绪场域

- **事件指纹去重**:SHA256(平台+频道+事件主题规范化)——同一事件
  跨槽位/跨平台聚合(作品指纹 P0 先例升级为事件级)
- **情绪场域建模**(确定性, LLM 禁入):
  - 单内容情绪 = 词表密度(P6a NEGATIVE/POSITIVE 词表扩展事件场景)
  - **群体情绪热力图** = 弹幕/评论样本聚合密度
  - 复合情绪轨迹 = 同事件跨槽位情绪密度变化(爆发-发酵演化代理)
  - **刷量过滤**:同 IP/同 UA 聚簇计数(P2a 点击质量门范式复用),
    聚簇占比>50% 的情绪样本降权——区分真实用户与水军

## 四、引擎二:三维价值评估引擎(P7b)

### 4.1 三维评分(全确定性公式)

```
事件价值分 = 信值契合度(0-100) × 合规安全系数(0-1, 硬闸)
            × 转化潜力(0-1)

信值契合度: 事件关键词→站内模块映射表(确定性知识映射)
    "暴雨/应急" → 应急物资信值购+邻里互助叫帮(契合 85+)
    "节日送礼" → 礼品模块+信值抵扣(契合 80+)
    "美食探店" → 市级网店+好店推荐(契合 75+)
    "租房贵/消费吐槽" → 信值抵扣房租/理性消费(契合 70+)
    无映射命中 → 契合<40 → 自动降级(不强行蹭热点)
合规安全系数(硬闸, <0.6 无条件拦截——无论热度多高):
    版权风险: BGM/素材指纹比对授权库(P6b 库复用)
    政策风险: RISK_BLOCK_WORDS+政治军事扩展词表(种子频道语料驱动)
    舆情风险: 反转词表("辟谣/反转/打脸"命中→系数×0.5)
    价值观风险: P6e 价值观词表(炫富/焦虑营销等)
转化潜力: 同类事件历史归因统计(44号+attract 漏斗)
    = 历史同类事件的(注册×0.4+激活×0.6)/点击 归一化
    冷启动(<3 样本): 回退全网均值 0.5
```

### 4.2 L1-L4 分级响应(整数阈值)

| 级 | 条件(确定性) | 动作 |
|----|-------------|------|
| **L1 紧急高价值** | 价值分≥75 且 契合≥70 且 安全≥0.8 且 生命周期=爆发/发酵期 | 生成任务包→**46号人工确认**→触发创作/转发 |
| L2 常规机会 | 价值分≥50 | 待处理队列(优先级=价值分×生命周期权重) |
| L3 观察储备 | 价值分≥30 或 契合<40 | 知识库储备(供策略参考, 不推送) |
| **L4 风险屏蔽** | 安全系数<0.6 **或** 命中禁区词表 | 屏蔽+原因留痕备查(永不静默丢弃) |

## 五、引擎三:事件演化预测与干预层(P7c)

### 5.1 生命周期分段(历史周期统计——非 ML)

```
同类事件历史: 爆发期(0-6h) → 发酵期(6-24h) → 峰值期(24-48h)
              → 衰退期(48h+)
分段依据: 事件跨槽位热度序列 vs 同类事件历史均值曲线(整数比较)
早期信号: 同类事件在种子频道池中首次出现且热度环比>2×
峰值拐点预警: 热度环比连续 2 槽位下降 → 预警"避免在下滑期投入"
```

### 5.2 跨平台关联挖掘(确定性规则)

- **机会窗**:同事件指纹在 A 平台热议(热度>阈值)而 B 平台沉默
  (无同指纹事件)→ B 平台为差异化切入窗
- **叙事变异**:同指纹事件跨平台标题词差集(分词词表比对)→
  选择与本站调性(酒/美食/礼品/生活)契合度最高的叙事版本
- **联动造势识别**:同指纹事件在 ≥3 平台热度同步陡增(同槽位
  环比均>5×)→ 标记"疑似操纵性流量"→ 情绪样本降权

### 5.3 合规预演沙盘(高分事件专用)

- L1 候选事件自动生成**预案**:{推荐角度, 禁用表述(风险词差集),
  素材建议(仅授权库内), 钩子方向(P5b 钩子库映射)}
- 预案通过合规校验(词表+授权库)后方可入执行队列——降低试错成本

## 六、引擎四:自主响应触发层(P7d)

- **上下文任务包**:不只推标题——"推荐角度+合规要点+素材建议+
  钩子方向"四件套(确定性模板)
- **人机协同确认流**:L1 任务经 46号确认后触发;确认界面展示
  雷达决策依据(三维分+生命周期+风险提示)+备选预案
- **人工决策回流**:确认/否决结果回流 46号→评分校准(P7e)
- 下游执行器复用:L1 触发 P6b 创作(脚本全链)或 P6e 转发
  (授权链)——**零新增创作逻辑**

## 七、引擎五:自治理与进化层(P7e)

- **效果归因闭环**:每个 L1 任务包带唯一溯源 ID→attract 漏斗
  全程跟踪→"高分事件是否真带来高转化"校准三维权重
- **雷达效能周报**(确定性聚合):触发数/命中率(高分→高转化
  一致率)/误报率(L1 被人工否决率)/漏报案例库(L3 事后高转化
  事件自动入库学习)
- **阈值自适应**(收紧不放松):触发内容违规率/下架率异常升高
  (×3 且样本≥20, 三检测器范式)→ 自动收紧 L1 阈值(75→85)+
  通知人工审计——**阈值只可自动收紧, 放宽须 46号建议书**
- **算力成本自适应**:非核心频道/低谷槽位降频采集(槽位×频道
  权重表)——mock 轨中表现为批次规模参数

## 十二、关键设计决策备忘

1. **种子频道=合规测试集**(本方案最独特设计):用户指定的 12 频道以
   时政军事为主体——不是要跟随它们,而是用它们**验证"高热度高风险
   事件自动屏蔽"铁律**。财经(任汉军)/历史(闫树军)类频道验证
   L1-L3 价值梯度——种子集天然覆盖 L1-L4 全分级测试需求
2. **"实时"的确定性实现**:流式=事件级 15min 槽位推进(mock 槽位
   种子范式扩展)——不引入真流式基础设施, 保留全部可测性;
   真实 API 为适配器预留轨(P3b 范式)
3. **多模态=确定性字段**:ASR/OCR 在 mock 轨中是生成器字段,
   判定链消费的是文本化结果(词表/映射表)——"视听本质"的工程
   实现仍是文本代理, LLM 禁入铁律不因模态松动(P6 同款决策)
4. **安全系数短路设计**:三维评分中安全系数是硬闸而非乘数——
   政治/军事命中的事件不进入乘法(避免高契合×高热度的乘积
   稀释风险), 直接 L4
5. **阈值只紧不松**:误报率优化的自然诉求是放宽阈值——设计上
   收紧走自动轨、放宽走 46号建议书, 防止"狼来了"式渐进失守
6. **事件→任务→创作三层解耦**:雷达只负责"发现与评估"(L1-L4),
   任务包是"翻译层"(四件套), 创作执行完全复用 P6b/P6e——
   雷达升级不触碰创作管线任何一行
