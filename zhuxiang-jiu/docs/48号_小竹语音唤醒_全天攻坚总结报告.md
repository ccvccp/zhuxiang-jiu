### 2.2 下午：三层灵敏度治本

- **259a8d0** 热词注入 + 拼音弱匹配 + v3 转写留痕首上生产（此前唤醒失败轮 50h 零证据链）
- **削顶勘误**（analyze_dump.py 三件套实证）: 所有失败轮 peak=32768 满量程钉死、rms 千级偏强——**推翻「弱音频」假设**：

  - **0742fb1** autoGainControl:false（X5 系统 AGC 源头削顶）——后证 X5 无视此约束
  - **d0dfb35** V3.5 压缩收紧（0.8 起压×0.15 斜率×0.95 封顶）+ 增益跨段保留——「小竹小竹。」完整转写首次出现

### 2.3 晚间：百炼连接架构四代演进

百炼掐线规则实测：同一连接时而 4 task 时而 2 task 即 1007 掐断——**寿命不可依赖**：

| 代 | 架构 | 败因/教训 |

| V4.0 | 连接池化复用 | 引用漂移雪崩（旧段 PCM 灌进新连接 → 1007 循环） |
| V4.2 | session 连接绑定 | 池+轮换+探活在随机规则前永远差一步 |
| V4.4 | **一段一连接定版** | 「确定性压倒微优化」——段间零共享状态 |
| V4.5 | SSLContext 模块复用 | 握手凭证复用扬弃连接复用（新连接+快握手） |

- **9b0d500** 建连 3s 快败 + 段内自动重试一次（armTimer 8s 容忍）
- **f1b731f** V4.4 定版（-176 行复杂度）
