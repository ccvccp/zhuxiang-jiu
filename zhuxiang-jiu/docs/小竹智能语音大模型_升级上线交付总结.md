## 二、升级交付

### 2.1 模式层(xiaozhu_mode_service.py)

- **三态**: XIAOZHU_MODE = off(默认)/shadow(语音观察期)/
  assist(语音辅助期)
- **读取链**: 护栏暂停 > 运行时 override > env > 默认 off
- **状态存储**: `zhuxiang:xiaozhu:mode_state` 整档 JSON 单键
  (智运范式——规避 45号 P0 字段级序列化教训)
- **同步桥接**(62号范式): 进程快照 `_G` +
  `legacy_current_mode()` 同步读取器

### 2.2 护栏三指标(小竹业务语义, 恶化>3% 自动 guard_pause)

| 指标 | 基线 | 语义 |
|---|---|---|
| ASR 失败率 asrFailRate | 0.10 | 轮次 intent=asr_failed 占比(语音识别质量代理) |
| 风控处置率 adjudicationRate | 0.05 | P50 处置台账/P50 行为事件(声纹异常与激励操纵密度代理) |
| 语料拒审率 corpusRejectRate | 0.10 | 语料捐赠 rejected 占比(社区语料质量代理) |

### 2.3 路由层(xiaozhu_routes.py, 44→48 端点)

- **24 决策端点** `@_decision` 装饰器(门控 off 409 +
  shadow/assist 响应标记 `xiaoMode`):
  会话三入口(sessions/voice/text)、bindings 增删、
  points redeem、commands custom 三面、proactive scan、
  dashboard/fc 公平桥接、fc redteam、voice50 全决策面
  (settle/evidence/corpus/qa/companion/fairness/rules/
  group-profile/unfreeze/decay/offset/decide)
- **鉴权优先新范式**(小竹双头鉴权适配):
  装饰器参数化 `_decision(strict=True/admin=True/默认)`——
  strict 面无 X-Member-Id 放行函数体触发 401、
  admin 面非 admin 放行触发 403(保证 401/403 优先于 409)
- **4 控制面端点**: GET /mode、POST /mode/override、
  POST /mode/guard(缺省从仓储层实时聚合)、
  POST /mode/resume
- **宪法豁免面永不关停**: sessions 删除(个保法被遗忘权)/
  privacy preferences(隐私偏好权)/confirm 核销(已确认动作
  执行权)/voice50 appeal(申诉纠错)
- **观测面永不关停**: commands/sessions 视图/bindings/
  context/actions/points/failures/dashboard/fc audit/
  privacy budget/voice50 my·risk-state·rules·settlements·
  adjudications
- **一代专项开关语义保留**: XIAOZHU_LLM_MODE(文案轨)/
  XIAOZHU_PROACTIVE_MODE(主动关怀)——独立于大模型灰度

### 2.4 护栏自动巡检(xiaozhu_scheduler.py, 65号最新范式)

- `run_guard_patrol()` 三指标确定性计算
  (scan_turns 全表只读/P50 台账与事件/语料状态),
  分母 0 冷启动取 0 不误判
- XXIAOZHU_GUARD_AUTO 默认 on(独立于一代专项开关——
  护栏是保护机制), XXIAOZHU_GUARD_INTERVAL 默认 3600s
- main.py startup 挂载; 控制面 /mode/guard 缺省聚合
