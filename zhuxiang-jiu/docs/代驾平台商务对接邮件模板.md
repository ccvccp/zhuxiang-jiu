## 三、发送前自查清单

- [ ] 替换全部【】占位（公司全称/域名/手机号/预估采购量）
- [ ] 附件：营业执照扫描件 + 食品经营许可证（滴滴入驻会要，先备好）
- [ ] 邮箱用公司企业邮箱（个人邮箱通过率低）
- [ ] 开发人员手机号确认（该号将注册商户开放平台，长期有效勿随意换）
- [ ] 预估采购量口径与财务确认（影响平台给的价格档位）

## 四、回复后的推进对照

| 平台动作 | 对应本站动作 |
|---------|------------|
| 开通平台权限 | 用开发手机号登录 dop.kuaidadi.com 商户入驻 |
| 发放入驻指引 | 按清单提交资质，等审核（3 个工作日） |
| 发放 appKey/appSecret | 记录到密码管理，`.env` 占位（勿入库） |
| 提供测试环境参数 | 指南 §一 第 6 步：测试司机账号 + 全链路验证 |
| 确认回调配置 | 回调地址填 `https://【域名】/api/ride/partner/callback` |
