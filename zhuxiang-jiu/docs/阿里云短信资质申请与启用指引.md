# 阿里云短信资质申请与启用指引

> 版本 v1.0 · 2026-09-23
> 目标：从企业资质落地到生产真实短信通道（保证金到期通知 + 登录验证码）
> 前提：企业主体已落地（泰安市元禾生物科技有限公司——微信小程序主体变更已过审，服务类目：商家自营 > 食品饮料）
> 代码侧**零改动**：b1f464c 已留好通道（sms_aliyun.py 纯标准库 RPC），五项 env 注入即自动从模拟留痕切真实发送
> 审核总耗时预估：资质 ~2 个工作日（最长瓶颈）→ 签名/模板 ~2 小时-2 个工作日，全部可并行等待

## 一、前置材料清单（一次备齐）

| 材料 | 用途 | 备注 |
|---|---|---|
| 营业执照 | 企业实名 + 资质 + 签名证明 | 统一社会信用代码需清晰 |
| 法人身份证信息 | 企业实名认证 | 姓名+证号（部分流程需法人支付宝扫码） |
| 管理员身份证正反面照片 | 短信资质申请 | 可与法人同一人 |
| 管理员手机号 | 审核回访电话 | **保持畅通——阿里云会电话回访** |

## 二、阿里云账号企业实名认证（如仍为个人认证）

1. 控制台右上角头像 → **实名认证**
2. 若显示"个人实名" → **变更认证** → 选**企业认证**
3. 填统一社会信用代码 → 上传营业执照 → 法人验证（法人支付宝扫码，或管理员信息+授权书）
4. 审核：即时 ~ 1 个工作日

## 三、短信资质申请（2024 工信部新规核心步骤）

路径：控制台 → **短信服务** → 左侧 **资质管理** → **新增资质**

1. 适用场景：选**通用**（通知+验证码均可发）
2. 主体类型：企业 → 统一社会信用代码 + 营业执照上传
3. 管理员信息：姓名、身份证号、正反面照片、手机号
4. 提交 → **审核约 2 个工作日**（期间有电话回访，如实回答"企业官方通知：会员保证金到期提醒与登录验证码"）

> 个人认证账号在此步结构性阻断（2024 新规后仅企业/事业单位可申请）——这正是此前定案"方案 B 维持现状"的原因，企业主体落地后阻断即解。

## 四、签名申请（关键决策点）

路径：短信服务 → 国内消息 → **签名管理** → **申请签名**

**签名名称三选一**（主体已定：泰安市元禾生物科技有限公司——执照名**不含"竹香"**，签名决策变为品牌与速度的权衡）：

| 选项 | 证明材料 | 判定 |
|---|---|---|
| **"竹香网"（网站名，推荐）** | ICP 备案截图（备案主体=元禾生物） | **首选一次到位**——品牌一致、用户信任度高；需先完成 zxjiu.com 备案（详见下注），短信无紧迫性（月量级个位数、站内信已闭环），等得起 |
| "元禾生物"（企业字号简称） | 营业执照直接可证 | **快速通道**——当天可申；缺点是签名与竹香品牌不搭，用户收码可能当陌生短信 |
| "竹香"（商标） | 商标注册证（注册人=元禾生物） | 若商标已注册可直接用；未注册则不可行 |

> 签名变更无沉没成本（后续可增补新签名作废旧签名），介意品牌可先"元禾生物"过渡、备案后增补"竹香网"。
>
> **ICP 备案前置**：zxjiu.com 当前解析在阿里云新加坡——备案须有国内接入（阿里云中国站购最低配 ECS 取备案服务号即可），备案主体填元禾生物，审核 ~7-20 个工作日。备案落地同时解锁：短信签名"竹香网" + 国内 CDN/GA 加速通道（H2 遗留的 ~150-250ms 收益）。

其余项：
- 适用场景：**验证码 + 通用**（两项都勾）
- 申请说明：如实写"企业官方通知短信：会员保证金到期提醒、登录验证码"
- 关联资质：选第三步通过的资质
- 规则：2-12 字符，中文/字母/数字
- 审核：2 小时 ~ 2 个工作日

## 五、模板申请（**两个，缺一不切换**）

> 代码侧耦合：`is_configured()` 要求四凭据齐备（含验证码模板码），保证金通知链路 = 四凭据 + 通知模板码。**只申请保证金模板不申请验证码模板，通道不切换。**

路径：国内消息 → **模板管理** → **申请模板**（共两次）

**模板一：登录验证码**
- 模板类型：验证码
- 模板名称：登录验证码
- 模板内容（变量名必须为 `code`——代码传参 `{"code": ...}`）：

```
您的验证码为${code}，该验证码5分钟内有效，请勿泄露。
```

**模板二：保证金到期通知（变量五枚，与代码逐字对齐）**
- 模板类型：通知短信（通用）
- 模板名称：保证金到期提醒
- 模板内容（代码模块头注释原文，勿改动变量名）：

```
尊敬的店主：您的网店${name}保证金将于${date}到期（剩余${days}天），年任务完成率${rate}%，按当前进度预计退还${refund}元。详情请登录平台查看。
```

- 变量：`${name}` / `${date}` / `${days}` / `${rate}` / `${refund}`——代码 `send_margin_reminder` 传参键逐字一致
- 关联签名：同一签名
- 审核：2 小时 ~ 2 个工作日；通过后记下两个 **模板 CODE**（形如 `SMS_123456789`）

## 六、RAM 子账号创建（凭据最小面）

1. 控制台 → **RAM 访问控制** → 用户 → **创建用户**
   - 登录名：`zxjiu-sms`
   - 访问方式：**仅勾选 OpenAPI 调用**（不要控制台密码）
   - 创建后立即保存 **AccessKey ID / AccessKey Secret**——**Secret 仅此一次可见**
2. 用户页 → 添加权限 → 搜索 `AliyunDysmsFullAccess` → 确定
   - 可选加固：自定义策略仅授权 `dysmsapi:SendSms` + `dysmsapi:QuerySendDetails`（既定方案为 FullAccess，二选一）
3. 泄露处置：RAM 用户禁用/删除即可——凭据独立于主账号，无连带风险

## 八、生产实证（沿用 b1f464c 验收模式）

1. 容器内验证开关：`margin_ops remind` 输出短信联动段（`is_margin_configured()` 生效、不再走模拟留痕）
2. **实证闭环**（避免误发真实店主——与 b1f464c 同款路径）：
   - 选一 settled 状态保证金，快照记录原值
   - 临时改 locked → `margin_ops remind` 两轮（验证真实下发 + 幂等）
   - 管理员手机号收到短信——核对五变量内容（店名/到期日/剩余天数/完成率/预计退还金额）
   - 还原 settled 原值 → `margin_ops audit` 复平
3. 日志核验：容器日志出现 `sms_aliyun_sent phone=... bizId=...`（阿里云回执 ID，对账排查凭据）
4. 频控注意：同一号码 1 条/分钟；超限报 `isv.BUSINESS_LIMIT_CONTROL`（SmsError 结构化透出）

## 九、成本预估（可忽略量级）

- 国内文本短信 ~0.045 元/条（按量计费）
- 保证金提醒量级：小时轮 × 30/7/1 档位到期店数（当前个位数店）→ **月成本 < 1 元**
- 充值：短信服务概览页充 10 元即可跑很久

## 十、常见驳回速查

| 现象 | 原因与处置 |
|---|---|
| 签名驳回 | 网站名签名（"竹香网"）需 ICP 备案——换企业字号简称 |
| 模板驳回 | 变量名与申请不符（必须逐字 `${name}/${date}/${days}/${rate}/${refund}` 与 `${code}`）；资金类措辞需中性（"预计退还"可过，"保证退款"类绝对化表述不可） |
| 资质驳回 | 管理员信息与提交人不一致 / 营业执照照片模糊 |
| 回访未接 | 审核电话漏接会挂起——1 个工作日后主动在工单里回复或重新提交 |
