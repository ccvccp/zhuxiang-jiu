# 48号·小竹语音 EMA 平滑——小方案(摸底证伪, 触发条件型候选)

> 2026-10-01 立项评估 | 来源: 外部建议"唤醒得分/意图得分/ASR
> 置信度三路 EMA 平滑" | 结论速览: **前提不成立, 本批证伪关闭**;
> 真实候选留触发条件(§三), 防止按错误假设立项开发

## 一、需求原文与摸底实证

外部建议: "平滑唤醒得分、意图得分、ASR 置信度, 避免小竹误
唤醒或频繁打断"——**前提假设 48号 存在概率型置信度信号**。

摸底实证(xiaozhu_service.py 全链路):

| 建议信号 | 48号 真实实现 | 有无连续分值可平滑 |
|---|---|---|
| 唤醒得分 | `detect_wake`: **确定性前缀匹配**("小竹"+近似音容错映射表, 句中唤醒截取)——二值判定 | **无** |
| 意图得分 | 规则映射表 + LLM 增强轨(XIAOZHU_LLM_MODE 二值开关, 规则轨兜底) | **无**(轨选择非置信度驱动) |
| ASR 置信度 | 智谱 ASR 转写文本(不返回 confidence 字段) | **无** |

**结论**: 48号 是确定性规则链路(前缀匹配/映射表/二值轨),
不存在"唤醒得分/意图得分/ASR 置信度"三类概率信号——
**EMA 平滑(为连续分值降噪)无对象可作用, 前提证伪**。

## 二、重复建设排除(勿造轮子)

语音观测/告警面已被 **52号语音可用性评估引擎** 覆盖:
五维指标计算 → 静态基线+动态漂移 → 快照留痕 → 日度告警
(us52_service 五维监控看板 P5)。误唤醒率/转写质量若需
观测, 应挂 52号 维度扩展, 不在 48号 新建观测通道。

既有护栏亦在位: XXIAOZHU_GUARD_AUTO(护栏巡检, 默认 on)
+ 反语音霸权铁律(未唤醒不执行, xiaozhu_service 头注 ⑨)。
