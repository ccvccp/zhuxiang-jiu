# 71号·AI智能支付端口大模型 L1 分级开放评估报告（模板）

> 适用：assist 期稳定运行后的治理分级开放评估（`PAY71_EVOLUTION_LEVEL: L0 → L1`）

> L1 语义（注册表 EVOLUTION_LEVELS）：受限进化——低风险参数（riskLevel=low）建议书可提交 46号审批（仍需人工审批，进化永不自动生效铁律不变）
> 可开放参数域（L1 白名单——EVOLVABLE_PARAMS 中 riskLevel=low）：
> - `probeRequiredSuccesses`（半开探测恢复次数，factory=3，值域 1-10）
> - `reconRetryMax`（补单重试上限，factory=3，值域 1-10）
> 高风险参数（precursorFuseThreshold 熔断阈值）与权重族（allocationContextWeights）**不在本次开放范围**（须 L2/走 P3 轨）
