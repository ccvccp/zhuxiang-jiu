## 一、模块定位与架构

竹演（zhuyan）= **进化功能 Agent**，竹氏三兄弟之外的第四位（进化引擎位）：
竹盾管空间影响面、竹医管时间业务链、竹园管资产养护、**竹演管功能成熟度与进化方案**。

前沿 EvoFunc 方案裁剪 10 项决策（AST→正则特征/向量库→关键词加权/图库→import 计数/
APM→静态代理指标/LLM 精排→规则推理链/代码生成→**只出不施**），保留核心思想：
三维成熟度公式、痛点四象限、种子五维标准、反模式 Fast Filter、推理链可解释、HITL 确认门。

代码结构（11 模块 + 10 测试文件）：
`cli.py`(四子命令全实装) / `fingerprint.py`(2651 单元指纹) / `stats.py`(zhuyan:stats 度量) /
`score.py`(S_b+S_r+S_e+罚分+总分+B3) / `matrix.py`(四象限) / `seed.py`(五维种子核查) /
`antipattern.py`(五类 Fast Filter+B4) / `analogize.py`(三策略类比) / `evolve.py`(EVO 草稿确认门) /
`loop.py`(闭环四环演示) / `conftest.py`(测试隔离六注入)。
