## 七、技术沉淀

| 主题 | 记录 |
|---|---|
| 进货/销售口径 | sum_monthly_purchase 与 sales 同源(当月订单 totalAmount 合计)——双达标=订单总额≥9000 |
| storeCode 格式 | CS-{cityCode}-{序号 3 位}(next_store_code 城市内递增) |
| 折扣三档 | 70(月销>9000)/80(5000-9000)/90(<5000, 新店默认) |
| AI 回流清理面 | 考核终态触发 on_store_assessed 回流——测试后须清 drift+feedback 双键 |
| 时序竞争案例 | 风暴期 stats=0 与 Redis 有店"矛盾"实为 53s 排队窗口内 hgetall 早于 apply 执行——非缺陷 |
| PowerShell 探测范式 | 嵌套引号(ssh+bash+$VAR+JSON)三重转义必乱——scp 脚本文件远程执行最稳 |
