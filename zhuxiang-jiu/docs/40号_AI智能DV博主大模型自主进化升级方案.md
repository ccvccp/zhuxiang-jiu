# 40号·AI智能DV博主大模型——自主进化升级方案(P5 期)

> 依据:《AI智能平台流量DV博主大模型全自主形态优化方案》——"自主学习+自主创作发布"的数字引流员
> 定位:P0-P3d 已交付"跟随模式"(侦测大V作品→合规转发引流);P5 升级为"**自主模式**"——AI 在信值围栏内自主选题、自主创作、自主发布、自主进化
> 架构原则:**"大模型"不是训练 LLM,而是把引流体系建成持续自我优化的在线学习系统**(54号"小竹"先例)+ 创作生成全确定性(模板引擎+词表约束,LLM 禁入判定链铁律)
> 核心命题:**自主不等于失控**——学习目标函数硬编码合规权重(β>0 永不调零);一切惩罚/质押/分成经 46号审批;人工干预通道优先级高于任何自主行为

## 一、升级定位:从"跟随"到"自主"

|---------|----------------------|---------------------|---------|

| 发布 | 黄金时段静态+LRU 账号轮询 | 动态时机决策+账号画像协同+发布后 1h 自适应调控 | 高预算/新平台/敏感话题强制 46号质押审批 |

- 47号 tier 读取——UGC 分成/信值质押的账户层
- 现有账号矩阵(P3c)、归因体系(attract)、区块链存证、三审闸门——原样复用

## 三、引擎一:自主学习引擎(P5a)

### 3.1 多源信号三通道

| 通道 | 信号源 | 权重方向 | 采集方式 |
|------|--------|---------|---------|
| 正向 | 点击率/完播率/注册转化/信值激活/停留时长 | reward ≥ 0 | attract 归因聚合(现有)+滚动采样 |
| 负向 | 举报率/跳出率/评论负面情绪(词表)/平台限流通知 | reward < 0 | 发布后 1h/6h/24h 三采样点 |
| 合规 | 版权投诉/广告法违规计数/账号健康度降幅 | 硬约束 | 三审留痕+账号矩阵 receipt 交叉 |

- 负面情绪判定:**确定性情感词表**(继承 38号先例,LLM 禁入)——负面词命中密度 > 阈值即记信号
- 平台限流通知:账号矩阵已有 cooling 触发词,直接复用为信号源
- 信号落库 `blogger_signals`(带 followId 归因),不等待 T+1,滚动窗口实时吸收

### 3.2 信值对齐复合奖励函数(宪法域核心)

```
reward = α × 信值转化效率 + β × 合规得分 − γ × 风险损失

α = 0.5(转化主目标)   β = 0.3(合规权重)   γ = 0.2(风险惩罚)
```

- **信值转化效率** = 漏斗归一化: `(注册数×0.4 + 信值激活数×0.6) / 曝光分位基准`,clamp [0,1]
- **合规得分** = compliance_score / 100(三审闸门现成分数)
- **风险损失** = 举报率×0.5 + 限流次数×0.3 + 投诉数×0.2,clamp [0,1]
- 现有 `compute_reward`(流量分量)保留,作为"信值转化效率"的冷启动回退(归因数据 < 3 样本时)
- **宪法铁律:β ∈ [0.1, 1.0] 硬编码,α/γ 可经 46号审批调整,β 任何变更直接拒绝**——"合规不可妥协"的工程化

### 3.3 微调研机制(人机共学)

- 创作决策置信度 < 80%(钩子模板历史样本 < 5 或 A/B 未收敛)→ AI 主动发起 3 选项投票
- 运营投票 → 即时更新策略库先验权重(确定性映射,非推理)
- 投票记录作为高质量反馈注入学习轮(标记 `source: human`)

### 3.4 跨平台知识迁移(确定性规则)

- 现有平台偏置(引流率差×λ, clamp ±8)保留
- 新增**钩子跨平台表现矩阵**:`策略类型 × 平台` 效果表;新平台冷启动时按调性映射规则借用同调性平台 TOP3 钩子(规则映射表,非 LLM 推理)
- 敏感词库:全平台共享禁用词表(生成时约束)+ 平台增量表(评论截流限流词已有,统一收敛)

## 四、引擎二:自主创作工坊(P5b)

### 4.1 多版本并行生成(个性化钩子矩阵)

```
输入: 选题主题 + 信值权益点 + 目标人群画像
输出: 5+ 版本 = 钩子变体(3) × 结构模板(2) 的确定性组合

钩子库(blogger_strategies.type=hook):
  学生党→价格锚点钩 | 宝妈圈→场景种草钩 | 银发族→情感陪伴钩
  商务人士→礼赠体面钩 | 酒友圈→品鉴专业钩
结构库(type=structure): 痛点-解法-信值钩子-行动号召(现有四步链复用)
```

- 每版本独立过合规内生校验 → 独立追踪短码 → 入 A/B 实验
- 生成范式沿用 `WorkAgentService` 四步 Agent 链(确定性模板),**升级为变体参数化**

### 4.2 合规内生校验(从"后置三审"到"生成时约束")

| 层 | 机制 | 实现 |
|----|------|------|
| 生成时 | 违禁词**生成即置零**(模板槽位候选词表中直接剔除违禁词) | "token 概率置零"的确定性实现:候选词表 = 全量词表 − 禁用词表 |
| 生成后 | 三审闸门原样保留(一审硬拒/二审评分/三审人工) | 现有 compliance_gate 零改动 |
| 输出时 | **AI 标识水印强制**:所有自主生成内容末尾固定携带"AI 创作·内容仅供参考" | 广告法 AI 标识合规要求 |

### 4.3 A/B 小流量测试

- 实验状态机: `running → promoted(胜出固化) / aborted`
- 胜出判据:复合 reward 滑动窗口对比(置信样本 ≥ 50 点击),平局取合规分高者(β 铁律延伸)
- 胜出钩子 → 策略库 `stats.winCount +1` → 排行驱动后续选题默认钩子
- 三限护栏不变:实验版本共享单账号日帽(3 条),实验组+对照组合计不破日帽 10

### 4.4 UGC 素材智能复用与信值分成

- 素材入库:高信值用户上传(授权登记 `license` 字段)→ `blogger_ugc_assets`
- 创作选材优先级: 已授权 UGC(信值分成) > 存量语义重组 > 外部 API 生成(成本控制)
- **分成结算永不自动**: 使用次数累计 → 生成分成建议书 → 46号 submit_change → 人工 approve 后 47号信值入账

## 五、引擎三:自主发布调度器(P5c)

### 5.1 动态时机决策

- `blogger_publish_windows`:平台 × 小时档效果曲线(EMA 平滑,α=0.3)
- 决策规则:效果曲线 TOP3 时段 ∩ 避开竞品集中投放窗(评论截流已有热度数据) → 候选窗
- 紧急热点(雷达三因子 ≥ 85)优先插队,常规内容错峰
- 现有 `next_publish_time` 静态黄金时段作为冷启动回退

### 5.2 多账号智能协同

- 账号标签画像:现有 `alias` 扩展 `tags` 字段(手作达人/生活省钱/品鉴专业)
- 分配规则:内容钩子类型 ↔ 账号标签匹配度 + 历史表现(LRU 保留为平局裁决)
- 新号冷启动降频(日帽 1)/老号稳定增频(日帽 3,上限不变);账号异常自动切换备用号(现有状态机复用)

### 5.3 发布后自适应调控(1h 窗口)

| 信号(1h 互动) | 动作 | 权限 |
|---------------|------|------|
| 互动 < 阈值×0.5 | 生成追加推广建议书 | **高预算 → 46号质押审批后执行**(金额受控) |
| 评论高频疑问 | 自动生成置顶回复(模板+FAQ 库) | 全自动,回复走合规校验 |
| 负面舆情苗头(负面词密度突增) | 隐藏争议内容候选 + 通知人工 | **隐藏动作需人工确认,AI 仅建议** |

## 六、引擎四:自治理与进化层(P5d)

### 6.1 分钟级归因漏斗

- 每内容绑定唯一追踪 ID(现有短码体系),漏斗: `曝光→点击→注册→信值激活→首单`
- 采样点: 发布后 1h / 6h / 24h(滚动更新,EMA 平滑)——现有 T+1 沉淀窗口保留为终值口径
- 归因防篡改:追踪码 + 多源交叉验证(点击质量门已有三层去重/聚簇/特征)

### 6.2 异常自愈状态机(确定性)

```
发布失败 ─→ 重试×3(指数退避) ─→ 换账号 ─→ 换通道 ─→ 人工队列(留痕)
内容下架 ─→ 原因词表匹配分类 ─→ 修正版重提(合规分提升后) ─→ 仍失败 ─→ 人工队列
账号受限 ─→ cooling + 备用号接管 + 权重降档留痕(现有 failStreak 复用)
学习污染 ─→ fraudShare > 30% 暂停学习(现有熔断) + 告警
```

### 6.3 进化透明度看板 + 人类干预通道

- 看板四区:策略库排行 / A/B 实验矩阵 / 漏斗归因 / 决策解释报告("AI 为何这样决策"= 规则命中链路回放)
- 干预操作: `pause`(暂停 AI 全部自主行为,最高优先级) / `rollback`(策略回滚至指定版本) / `inject`(规则注入即时生效)
- **干预留痕上链**(复用区块链存证)+ 干预记录回流学习系统(`source: intervention` 高权重反馈)

## 十二、关键设计决策备忘

1. **"大模型"口径与 54号一致**:在线学习系统(Hedge+Champion/Challenger),不是训练 LLM——全站 AI 叙事的工程统一性
2. **reward 双层结构**:冷启动回退现有 compute_reward(流量分量),归因数据充足后切换复合奖励(信值对齐)——平滑过渡不破坏现有学习闭环
3. **A/B 与三限共存**:实验版本共享账号日帽,实验不豁免任何护栏——自主性不侵蚀安全边界
