## 五、架构说明（对齐设计文档）

- **53号 = 编排骨架**：五通道（密码/短信/OAuth/生物/语音）+ 四级风险响应（静默/一键/常规/强化）+ 话术注册表（三组 17 场景）+ 角色四态门户（new/active/dormant/high_risk）+ 驻留激励
- **54号 = 自进化大脑**：复用 44号 Hedge 在线学习 + 46号治理红线——登录决策回流标注 reward → challenger 影子版本 → 双指标晋升评估 → 版本自主升级/回滚 → EMA 漂移监控；与 43号 `auth_risk` 并行评分取 max（双模型互补不侵入）
- **零接管铁律**：off 态直通存量 39号 entry 登录；本次 on 态激活后存量登录链路验证零影响

## 六、回滚方案（秒级）

```bash
# 一级回滚(关编排, 存量登录恢复直通):
sed -i 's/^LOGIN53_MODE=.*/LOGIN53_MODE=off/' /opt/zhuxiang/.env
cd /opt/zhuxiang && docker compose up -d backend
```

54号学习闭环经 `LOGIN54_LEARN_MODE` 独立控制（默认 off，T+1 决策回流按需开启）。
