## 五、验收中发现并解决的问题(工程记录)

### 5.1 图标引用口径修正(实施实证驱动)

- **现象**: 首版图标失效引用率含 tab* 图标——专项冷启动
  断言失败(默认主题种子误判)
- **根因**: 默认主题 tabHome: "home" 等是 **Taro 内置图标名**
  (前端 iconType), 非图标库实体; 图标库实体是 quickGrid
  金刚区 emoji
- **修正**: 口径收窄为只校验 quickGrid emoji 引用(库实体)——
  修正后冷启动三指标 0 全绿
- **沉淀**: 引用完整性校验须区分图标语义层(Taro 内置名 vs
  库实体), 前端组件名不是库引用

### 5.2 Depends 鉴权范式(范式沉淀)

- require_admin 为 FastAPI **Depends**——401/403 在参数解析
  阶段完成, 天然先于装饰器门控 409
- 装饰器无需 strict/admin 参数化鉴权跳过逻辑(区别于 X-Role
  头模块的参数化范式)——JWT Depends 模块的门控更简洁

## 六、回滚与运维

- **回滚命令**:
  `sed -i 's/^SITE_THEME_MODE=.*/SITE_THEME_MODE=off/' /opt/zhuxiang/.env && docker compose up -d backend`
- **运行时切档**(免容器重建):
  `POST /api/site-theme/mode/override {"mode":"shadow"}`
- **护栏暂停恢复**: `POST /api/site-theme/mode/resume`(人工留痕)
- **巡检开关**: SITE_THEME_GUARD_AUTO=off 可关(默认 on)
- **巡检间隔**: SITE_THEME_GUARD_INTERVAL(默认 3600s, 最小 60s)
- **off 态语义**: 决策 7 端点 409; **C 端 active/icons + 观测
  3 GET 零影响**——off 态线上皮肤与浏览完全无碍
