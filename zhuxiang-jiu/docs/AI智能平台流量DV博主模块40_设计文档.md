# 40号·平台流量DV博主模块 设计文档 v1.0

> 定位：**借大V的流量，养自己的站**——AI 雷达持续侦测站外平台博主（达人/KOL）的最新作品，AI 全自动完成"理解作品 → 评估引流价值 → 合规制作跟随内容 → 挂专属短码发布"，把站外大 V 流量精准导入本站，全程零人工、低成本。
>
> 与 36号的本质差异：36号蹭的是**热点**（平台热榜快照，公共流量），40号跟的是**博主**（KOL 账户池增量作品，私域粉丝流量）——粉丝粘性高、转化率天然更好，且同一位博主可持续跟随形成"流量寄生"效应。
>
> 方法论：对标成熟玩法（抖音蹭大 V 热梗评论区截流 / 小红书达人二创跟随 / 微博大 V 转发矩阵），叠加本项目既有 AI 基建（Mock-first 确定性模拟源 / GLM Agent 链 / vision 多模态 / 第 21 可学习档案 / attract KOL 码归因闭环），并开创**"合规跟随"内容范式**规避版权风险。

---

## 1. 设计目标与核心概念

### 1.1 一句话模型

**"AI 盯博主 → 新作品秒级侦测 → 价值评分决策 → 合规跟随内容全自动生成 → 挂 KOL 码发布 → 点击注册归因 → 效果回流让 AI 越盯越准。"**

- 低成本引流三板斧：**零人工**（侦测/制作/发布/归因全 AI 链）、**零搬运**（合规跟随范式不碰版权）、**零浪费**（Hedge 学习淘汰低价值博主，火力集中在高转化博主）

### 1.2 合规跟随范式（本模块核心创新，版权风险的解法）

**绝不搬运原作品**。跟随内容是"转述+致敬+引导"三段式：

```
[转述] 刚刷到 @老李品酒 发了条作品：53° 竹香型白酒的盲测挑战…
[致敬] 他的"绵甜不辣喉"评得很准 —— 我们泰安老厂竹香系列确实是这个口感
[引导] 想知道盲测同款什么味道？戳 → zhuxiang-jiu.com/r/KOL12
```

- **原创性保证**：文案由 LLM 重新创作（转述非复制），配图走自有产品图/AI 生成图，**不引用原作品画面**（规避著作权）
- **出处声明硬校验**：发布前置校验——跟随内容必须含 `@原作者标识` 与 `出处语义`（无 → 三审拒绝），致敬式引用符合《著作权法》合理使用惯例
- **存证留痕**：每条跟随内容落库"原作品元数据快照 + 出处声明文本"，必要时调 37号 `add_blockchain_evidence` 存证（evidenceType 扩展 `citation`）
- **平台规则护栏**：单博主单日跟随 ≤1 条（防骚扰式刷屏被平台限流），跟随间隔 ≥4h 错峰

### 1.3 与既有模块关系（复用不合并）

| 模块 | 关系 |
|------|------|
| `promo`（36号） | **同门不同猎物**：雷达模拟源模式/Agent 三级降级链/三审闸门/发布调度三限/通道三态回执**全套模式复用**；36号盯热榜、40号盯博主池，选题互不重叠（去重口径互查） |
| `attract`（11号） | **归因闭环零新建**：KOL 码体系（`KOL{influencerId}_{platform}_{hex}`）与逐博主归因已存在——跟随内容挂码，点击→注册→下单全链路复用 |
| `traffic`（11号） | 博主即 influencer：`record_lead` + `get_influencer_attribution` 直接承载博主维度流量记账 |

| `hub`（35号） | 注册"博主引流"意图与能力（可选 P2） |

## 2. 总体架构：六个子系统

### 2.1 博主池管理（blogger_pool）

admin 可配的 KOL 账户池（Mock-first 惯例：种子内置 8 位演示博主）：

- **博主档案**：平台/账号 ID/昵称/粉丝量级/领域标签（酒类/美食/礼品）/互动率估计/跟随状态（active/paused）/权重（初始=f(粉丝量)，后续由学习回流修正）
- **准入门槛**：领域标签必须与酒/美食/礼品/生活相关（强相关权重高），无关领域博主不允许入池（避免引流人群不精准）
- **生命周期**：active →（连续 N 条零引流）→ auto-paused（AI 自动止损，学习回流驱动）→ admin 手动 re-active
- 每博主独立**发布游标**（lastSeenWorkAt），支撑增量扫描

### 2.2 作品雷达（work_radar）

Mock-first 确定性模拟源（对齐 36号 `_mock_fetch` 种子法）：

- **增量扫描**：按博主池逐个拉取"最新作品列表"——种子 = `date + 6h 槽位 + bloggerId`，同槽位确定性（同博主同槽位返回同一批作品），槽位推进模拟"博主发了新作品"；配置 `BLOGGER_{PLATFORM}_API_KEY` 走 `_fetch_real` 预留（平台开放 API/自建爬虫代理，未配置回退 mock）
- **作品元数据**：作品 ID/发布时间/标题文案/互动数（赞评转）/封面图 URL/视频时长——**封面 URL 是 vision 理解入口**
- **指纹去重**：SHA256(平台 + bloggerId + 作品 ID)，48h 窗口重复作品跳过
- **风险一票否决**：复用 36号 `RISK_BLOCK_WORDS`（政治/未成年/医疗/灾害题材作品直接 discarded，不进入评分）

### 2.3 作品理解 Agent（work_agent，四步链改造）

复用 36号 Agent 骨架（每步独立降级 + agentTrace 留痕），步序重定义：

1. **Step1 作品理解**：`chat()` 理解标题文案 + `vision()` 看封面图（图片不可达 → 纯文本轨）→ {作品主题, 情绪, 提到的酒类相关词}
2. **Step2 粉丝画像匹配**：博主档案领域标签 × 作品主题 → {目标受众, 跟随调性, 禁忌词}（回退博主池静态画像）
3. **Step3 跟随内容生成**（生成步）：三段式合规跟随文案 + 平台适配（复用 36号 `_RULE_TEMPLATES` 降级轨——模板同样三段式结构）+ 自有产品图/AI 生成图选择 + **KOL 短码挂链**（best-effort 调 attract 创建）
4. **Step4 出处自查**：校验生成文案含 `@原作者` + 出处语义 + 无搬运原句（n-gram 比对原作文案，重合度 >40% 自动重写）

### 2.4 引流价值评分与决策（work_gate）

**`BloggerWorkScorer` 评分器**（第 21 档案，五因子，高分=值得跟随）：

| 因子 | 权重 | 判据 |
|------|------|------|
| 博主权重 | 0.25 | 粉丝量级分档（百万级满分）+ 互动率 |
| 品牌契合 | 0.25 | 作品主题与酒/竹香/礼赠场景相关度（Step1 输出） |
| 作品热度 | 0.20 | 互动数相对该博主历史基线的放大倍数 |
| 引流潜力 | 0.15 | 作品是否含"推荐/测评/开箱"类高转化语义 |
| 竞争密度 | 0.15 | 该作品下已跟随账号数估计（少 → 加分，蓝海截流） |

决策三档（沿用 36号阈值范式）：**≥70 auto_follow（全自动发布）/ 50-70 manual_queue（人工确认）/ <50 pass（跳过留痕）**。

### 2.5 合规三审与发布调度（follow_pipeline）

- **三审闸门**（复用 36号结构）：一审规则硬拒（搬运重合度>40% / 缺 @原作者 / 缺出处声明 / 饮酒动作等禁词）→ 二审 AI 合规分（沿用 100−极限词×30−缺警示×35−缺年龄×35，≥80/60-79 强制人工/<60 拒）→ 三审人工（manual_queue 内容）+ **出处声明存证**
- **发布调度三限**（模式复用 36号，参数重定义）：
  - 黄金时段：复用 36号 `GOLDEN_WINDOWS`
  - 单日上限：`BLOGGER_DAILY_CAP=10`（全博主合计）
  - 单博主冷却：**同博主 1 条/24h**（防刷屏限流）
- **发布通道**：复用 36号 `promo_channel_service` 三态回执（real/mock/mock_fallback），发布成功后 best-effort 百度 SEO 推送（落地页含 KOL 码）

### 2.6 归因闭环与自学习（attribution_loop）

- **挂码引流**：跟随内容短链 `/r/KOL{id}_{platform}_{hex}` → attract 点击分流（产品页落地）→ 注册归并三合一 → 下单回写——**博主维度引流量/注册/GMV 全口径可量化**（复用 `get_influencer_attribution`）
- **Hedge 效果回流**：已发布跟随内容引流量 >0 → auto_follow 决策 correct（+1）；零点击 → 失误（-1）；连续 3 条零引流博主 → auto-paused（AI 止损）。因子快照 = 评分五分量 + contributions
- **博主权重自进化**：归因 GMV 回写博主池权重（引流好的博主自动升权、优先侦测）

## 3. 数据模型（Redis Key，前缀 `blogger:`）

| Key | 类型 | 内容 |
|-----|------|------|
| `blogger:pool:{bloggerId}` | Hash | 博主档案（平台/账号/粉丝量/标签/状态/权重/游标） |
| `blogger:works:{workId}` | Hash | 侦测作品（元数据/评分快照/决策/状态） |
| `blogger:follows:{followId}` | Hash | 跟随内容（三段式文案/原作品快照/出处声明/短码/发布回执） |
| `blogger:work_fingerprints` | Set | 作品指纹去重（48h TTL） |
| `blogger:audits:{id}` | Hash | 决策/发布流水（对齐 36号留痕口径） |
| `blogger:seq:{entity}` | String | 自增 ID |

## 4. API 设计（routes/blogger_routes.py，前缀 `/api/blogger`，约 24 端点）

**博主池（admin）**
- `POST/GET /api/blogger/pool`（增/列）/ `GET/PUT/DELETE /api/blogger/pool/{id}` / `POST /{id}/pause|activate`（admin 手动干预）

**雷达与侦测（admin/调度器）**
- `POST /api/blogger/radar/scan`（手动触发全池扫描）/ `GET /api/blogger/works`（作品列表， 状态筛选）
- `GET /api/blogger/works/{id}`（详情含评分快照与决策理由）

**跟随流水线（admin/调度器）**
- `POST /api/blogger/works/{id}/decide`（手动重决策）/ `POST /api/blogger/follows/{id}/review`（三审人工）
- `GET /api/blogger/follows`（跟随内容列表）/ `GET /api/blogger/reviews/pending`（待人工队列）
- `POST /api/blogger/publish/run`（手动触发发布出队）

**归因与报表（admin）**
- `GET /api/blogger/report/overview`（博主池全景/侦测量/跟随量/引流漏斗）
- `GET /api/blogger/report/blogger/{id}`（单博主归因：点击/注册/GMV/权重变化）
- `POST /api/blogger/learning/feedback|collect|run` + `GET status`（Hedge 回流，对齐 36号 P2 端点形态）

**调度器**：`BLOGGER_RADAR_AUTO`（默认 off，周期扫描）/ `BLOGGER_PUBLISH_AUTO`（默认 off）——对齐 36号调度器惯例

## 5. AI 能力落位

| 能力 | 实现 | 降级 |
|------|------|------|
| 作品理解 | `vision()` 看封面 + `chat()` 理解文案 | 图片不可达 → 纯文本轨 |
| 粉丝画像匹配 | `chat()`（glm 主档→备档） | 博主池静态画像 |
| 跟随文案生成 | `chat()` 三段式生成 | `_RULE_TEMPLATES` 三段式模板轨 |
| 价值评分 | `BloggerWorkScorer`（第 21 档案） | 纯规则因子 |
| 搬运检测 | n-gram 重合度（本地算法，无 LLM 依赖） | — |
| 出处存证 | 37号 `add_blockchain_evidence`（best-effort） | 失败留库不阻断 |
| 自学习 | ai_learning Hedge（第 21 档案） | — |

## 6. 合规与红线

- **版权红线**：不搬运原作品画面/原句（n-gram>40% 硬拒）；三段式跟随含 @原作者与出处声明（合理使用惯例）；全部跟随内容留原作品快照可追溯
- **酒类广告法**：复用 36号三审词库全口径（饮酒动作/权威背书/功效暗示硬拒 + 警示语/年龄提示）
- **平台规则**：单博主 1 条/24h + 跟随间隔 ≥4h（防限流）；账号矩阵分散发布（P2 预留多发布账号）
- **风险题材**：作品涉政治/未成年/医疗/灾害 → 一票否决不入池评分
- **止损机制**：连续零引流博主自动 paused（防无效成本）

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 平台限流/封号 | 单博主 1 条/24h + 错峰 + mock 轨先行验证流程 |
| 版权投诉 | 三段式原创文案 + 出处声明 + n-gram 搬运检测 + 快照存证 |
| 引流人群不精准 | 博主入池领域门槛 + 品牌契合因子 + 学习淘汰 |
| AI 理解偏差（作品主题误判） | 评分仅决策参考，auto_follow 阈值 70 偏保守；agentTrace 全程可追溯 |
| 与 36号选题撞车 | 跟随内容与热点内容分库分码；发布日帽共享全局 `PROMO_DAILY_CAP` 口径核对 |
| 大 V 负面舆情连坐 | 风险词一票否决 + 博主舆情黑名单字段（P2） |
