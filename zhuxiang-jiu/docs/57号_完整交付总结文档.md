## 一、模块概览

**57号·AI智能知识库模块**实现"信值驱动的知识生命周期"闭环：在 Value-UEBA 约束下，让知识从"被动存储"升级为"主动认知引擎"——趋势感知（缺口诊断）→定向采集（源白名单）→三重合规鉴别（版权/隐私/内容安全）→认知种子工坊（多模态封装+版本化）→人类终审发布→角色植入学习（确定性推荐+情境触发）→使用反馈→决策回流（44号第32档案 Hedge 学习）。未经合规鉴别的原始资源**永存沙箱隔离态**，唯一出口是"三关全过→合规指纹→种子封装→人类终审"。

**战略位形**（Value-UEBA 体系）：

| 模块 | 守护面 |
|------|--------|
| 43号安全管理 | 攻击面 |
| 44号API智能管理 | 消费面 |
| 45号信值 | 社会面 |
| 55号二维码AI智能管理 | 交互面 |
| 56号AI智能升级管理 | 智能进化方向 |
| **57号AI智能知识库** | **认知基座与信任源头** |

**三铁律**（安全鸿沟工程化，贯穿六期）：
1. **未经合规鉴别的原始资源永不暴露终端用户**——quarantined 沙箱隔离态，唯一出口是三关全过+合规指纹+人类终审
2. **种子必带合规指纹与信值标签**——无指纹不入库/不出口、无信值标签不入推荐池（可断言、可追溯、可召回）
3. **隐私预算全程封顶**——采集（鉴别计量）+浏览（view 计量）双段 49号 check_and_spend，超支熔断 halted 不降级放行

**与既有 knowledge_* 的边界**（双模型铁律——54/55/56号范式平移）：57号第32档案与既有 knowledge_* 知识库训练模块**并行不替换**——57号仅对"缺口诊断与种子价值"打分回流，纯读取既有模块的缺口队列与统计，零改动其路由/服务/仓储。

### 3.2 P1 定向采集+三重合规鉴别中心（2b94e0d）

- **采集运行器**：open 缺口按优先级排序→低优先级观察队列留痕→建议源白名单解析（内置+动态域，白名单外跳过）→mock 确定性内容生成（四源类型模板）→资源落库 **quarantined 沙箱隔离态**+缺口 open→collecting
- **三重合规鉴别中心**（三关串行，56号信值沙箱范式——LLM 不进判定链）：
  - **版权关**：源白名单+contentHash 指纹去重（换皮重采嫌疑）+授权协议标注
  - **隐私关**：PII 三型 lookaround 扫描（`\b` 在数字与汉字间不成立的本站化升级）+渐进式掩码脱敏（身份证前3+11*+后4/手机前3+4*+后4/银行卡前4+8*+后4）+49号系统账号计量+缺口级封顶（halted 不降级）
  - **内容安全关**：高危三模式→blocked/中风险两模式→quarantined 待人工/低风险直通
- **合规指纹**：sha256(contentHash+sourceId+timestamp+verdict)——仅 passed/quarantined 生成（无指纹不入库铁律）
- **verdict 四态**：passed→compliant/blocked→rejected/quarantined 保持/halted 熔断隔离

### 3.3 P2 知识种子工坊+人类终审（0080b3e）

- **种子工坊**：craft 锻造主链——SEED_TYPES 封闭枚举（text/image/video/qa_pair/workflow）→compliant+指纹双重校验→多模态 content 四形态（text 正文/qa_pair Q&A/image mediaRef+alt/video mediaRef+transcript+keyframes）→KNOWLEDGE_REASON 注释即证据（缺口+信号+来源+用途）→sandbox 态落库
