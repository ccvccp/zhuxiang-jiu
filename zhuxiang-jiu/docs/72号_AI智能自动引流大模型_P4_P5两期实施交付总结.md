## 一、P4 短链记忆(规划 §四 4.2)

### 1. 实现清单

| 组件 | 文件 | 内容 |
|---|---|---|
| 注册表 | services/attract72_registry.py | 变体域(trust_first/benefit_first/default)/反作弊状态机(normal/isolated/released)/指纹频次线 50/隔离窗 3600s/ctx 有效期 3600s——启动自检 ⑯ |
| 服务 | services/attract72_p4_service.py | ctx 编解码/动态落地页决策/跨会话记忆/反作弊四模块 |
| 仓储 | repositories/attract72_repository.py | attract72_device_memory + attract72_landing_variants 两表 |
| 路由 | routes/attract72_routes.py | 5 端点(观测/快环——不受 MODE 门控) |

### 2. 核心机制

- **ctx 编解码**: `?ctx={base64}` 仅携带 fp(16 截断)/cid(32 截断)/意图标签(去重排序截 6)——无 PII 铁律; 无效/超期(>3600s)降级 None → default 变体, 行为与 v1.0 完全一致(向后兼容)
- **动态落地页决策**(确定性查表, LLM 禁入):
  - 隔离态 → default(不个性化不拒服务)
  - 老客(high_engagement 标签或 avgDwell≥120s) → benefit_first
  - bounce_risk → trust_first; 回访 → benefit_first
  - 新指纹 → trust_first; 无指纹 → default
- **跨会话记忆**: 指纹 upsert, 滚动均值 `avgDwell=(prev×(n-1)+cur)/n`, 转化/注册归并继承, 意图标签并集(截 8)
- **反作弊**: 窗口频次 `clicksTotal-windowBaseClicks>50` → 自动隔离; 人工解冻(观测面留痕)重置窗口基准——解冻后再超线才再隔离
- **变体台账**: 曝光计数滚动(impressions/conversions)

### 3. 端点(5)

```
POST /api/attract72/landing/dynamic        动态落地页决策(快环)
POST /api/attract72/memory/visit           跨会话记忆累积(快环)
GET  /api/attract72/memory/{fingerprint}   跨会话画像查询(观测面)
POST /api/attract72/memory/{fingerprint}/release  反作弊人工解冻(admin)
GET  /api/attract72/landing/variants       变体分布台账(观测面)
```

## 二、P5 热点卡位(规划 §四 4.6)

### 1. 实现清单

| 组件 | 文件 | 内容 |
|---|---|---|
| 注册表 | services/attract72_registry.py | 势能权重(0.25/0.25/0.30/0.20 和=1)/安全下限 0.5/追投阈值 0.6/裁决域(chase/observe/reject)/状态机(pending/confirmed/executed/closed)——启动自检 ⑰ |
| 服务 | services/attract72_p5_service.py | 机会清单/四维势能/卡位决策三段留痕/结果回流 |
| 仓储 | repositories/attract72_repository.py | attract72_hotspot_decisions 表 |
| 路由 | routes/attract72_routes.py | 6 端点(机会/台账=观测面; 决策/确认/执行=决策面) |

### 2. 四维势能(确定性公式, LLM 禁入)

| 维度 | 公式 | 权重 |
|---|---|---|
| 时效性 | `max(0, 1-事件龄/48h)` 黄金窗线性衰减 | 0.25 |
| 相关性 | 品牌契合词表命中密度(≥3 词满分, 词表 17 词) | 0.25 |
| 安全性 | L1=1.0 / L2=0.8(L4 风险屏蔽永不消费) | 0.30 |
| 转化潜力 | `valueScore/100` 封顶 1.0 | 0.20 |

三裁决(安全硬编码优先): `safety<0.5 → reject`(高风险自动拒追); `total>0.6 → chase`; 其余 `observe`。

### 3. 卡位决策链(MODE 门控)

- **off** → 409(决策面关闭); **KILL** → 409 制动
- **shadow** → 落档不执行(status=pending, executed=False, mode=shadow), 不可人工确认(影子期签核后转段)
- **assist** → 方案产出(pending) → 人工确认(confirmed) → 执行(executed, 方案注入 40号创作情境参考——**永不直接操作 40号账号**) → 结果回流(closed, expectedPotential vs actualRoi 闭环)
- 幂等: 同雷达事件重复决策 → 409; 价值分 <30 → 409; 事件不存在 → 404
- 一体化方案: 渠道(RADAR_CATEGORY_CHANNELS 类别映射)×发布时机窗(黄金窗前 1/3, 小时对齐)×预算注入建议(100×势能, 46号审批后生效)×短链承接变体(相关≥0.5 → benefit_first)
- observe 裁决无方案(plan=None); full 档卡位仍属"操作 40号情境"域, 永远 assist 语义(铁律)

### 4. 端点(6)

```
GET  /api/attract72/hotspot/opportunities   机会清单(观测面, 价值下限过滤+势能排序)
POST /api/attract72/hotspot/decide          卡位决策(决策面 off 409)
GET  /api/attract72/hotspot/decisions       决策台账(观测面, verdict/status 筛选)
POST /api/attract72/hotspot/{id}/confirm    人工确认(shadow 期拒绝)
POST /api/attract72/hotspot/{id}/execute     执行(须 confirmed)
POST /api/attract72/hotspot/{id}/outcome     结果回流(预期 vs 实际)
```

## 四、铁律遵循

1. **LLM 禁入判定链**: 变体选择/四维势能/三裁决=确定性查表公式, 全程无 LLM
2. **只读消费**: 40号雷达数据零修改(P5 深拷贝对比断言); attract v1.0 零触碰(P4/P5 零点击写入断言)
3. **隐私最小化**: ctx 仅脱敏画像片段(键域断言 fp/cid/it/ts); 指纹日志仅前 4 位
4. **向后兼容**: 无 ctx 行为与 v1.0 一致(default 变体断言)
5. **决策可解释**: 每决策留痕 potential/verdict/plan/mode/status 全量
6. **可回滚**: ATTRACT72_KILL 制动 + 解冻人工专属
7. **卡位执行永不直接操作 40号账号**: 仅注入创作情境参考(assist 语义)
8. **惩罚性处置永不自动**: 隔离为服务降级非处罚; 解冻须人工
