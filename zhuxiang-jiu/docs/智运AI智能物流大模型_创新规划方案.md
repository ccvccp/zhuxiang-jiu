# 智运·AI智能物流大模型 创新规划方案 v1.0

> 模块定位：物流接口管理模块升级更名 → **智运·AI智能物流大模型**
> 品牌家族：智启元(AI财务) × 智法(AI法务) × **智运(AI物流)**
> 依托：既有 18 端点物流底座（下单/状态机/轨迹/结算）+ smart_route_carrier 智能路由
> 状态：规划中(2026-09-11)

---

## 一、核心升级：从"接口管理"到"智能调度中枢"

| 维度 | 原设计(物流接口管理) | 深化设计(智运大模型) |
|------|--------------------|--------------------|
| 路由 | 规则表静态匹配 | 多维路由决策(规则+物流商质量评分+容灾健康度) |
| 轨迹 | 状态同步+展示 | ETA 预测 + 延误预警 + 异常四检测器 |
| 风控 | 文档规划(未落地) | 四防风控评分(防破损/防丢失/防延误/风险前置) |
| 回执 | 签收信息记录 | 团购验货回执 + 理赔工单(建议书) |
| 分析 | 无 | 成本分析 + 运量预测 + 反馈进化 |

**铁律调和**(对齐项目宪法域)：物流商切换/理赔审批/异常处置全为建议书模式(永不自动执行)；全链确定性规则(LLM 禁入判定链)；叠加式升级(既有 18 端点零改动)。

## 二、四期实施(八大引擎映射)

### P0 智能路由中枢(zw_route_service) — 文档§二深化
- **多维路由决策**：复用 smart_route_carrier 规则基座 + 叠加质量评分加权
- **物流商质量评分**(确定性)：历史签收率 40% + 时效达标 30% + 费率竞争 30%(基于数据织物聚合)
- **容灾健康监测**：物流商近期失败率/停滞率 → 健康度分 → 切换《建议书》(永不自动)

### P1 轨迹智能(zw_track_service) — 文档§四深化
- **ETA 预测**：承运商历史签收时效均值 × 当前进度外推(确定性)
- **延误预警**：停滞检测(48h 无轨迹更新，文档 4.4)
- **异常四检测器**(文档 4.4)：揽收超时(4h)/运输停滞(48h)/派送失败/签收超时(7天)

### P2 风控与回执(zw_risk_service) — 文档§五+§八补深化
- **四防风控评分**：防破损(酒类+重量+易碎系数)/防丢失(偏远+高货值)/防延误(时效+历史)/综合前置(0-100 四级)
- **验货回执**(团购专属)：结构化开箱验货单(应收/实收/差异/照片清单/验货人)
- **理赔工单**：破损/丢失/延误/污损四类(建议书，赔付审批须人工)

### P3 分析与进化(zw_analysis_service + zw_evolution_service) — 文档§六+§十深化
- **成本分析**：物流商费率对比 + 月度成本趋势(数据织物聚合)
- **运量预测**：加权移动平均(0.6 近期+0.4 全期，复用智启元范式)
- **反馈闭环**：路由时效权重 etaWeight ±0.1(clamp [0.4, 0.8] 安全阀)
- **孪生总览**：四引擎健康度(路由/轨迹/风控/分析)+ 三率观测(签收率/准时率/破损率)

