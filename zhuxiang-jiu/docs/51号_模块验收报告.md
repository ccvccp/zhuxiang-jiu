## 二、红队测试结论（P5）

五类攻击向量 12 用例跑真管道（`POST /api/kg51/redteam`，admin）：

| 向量 | 用例 | 防线 | 结论 |
|------|------|------|------|
| A 虚假三元组注入 | RT-01~03 | unverified 物理隔离 + 置信度源上限钳制 | 全阻断 |
| B PII 探测 | RT-04~06 | attrs 白名单过滤（digest-only） | 全阻断 |
| C 预算绕过 | RT-07~08 | 服务端静态值计算（无注入面）+ 429 语义 | 全阻断 |
| D 越权查询 | RT-09~10 | 权限矩阵（他人主体 409） | 全阻断 |
| E 一致性污染 | RT-11~12 | PII 禁入基线双闸 + 总线侧拦截 | 全阻断 |

**交付期缺陷（红队发现并修复）**：`_upsert_triple` 缺少置信度源上限钳制——红队 RT-02 伪造用户源 0.99 置信度可直入 verified。修复：`_clamp_confidence()` 硬兜底（user≤0.6 / system≤0.98 / authority≤1.0），超限即钳制。此为未来 LLM 抽取轨（KG_EXTRACT_MODE）接入前的注入防线。
