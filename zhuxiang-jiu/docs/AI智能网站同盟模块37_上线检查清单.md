## 四、37号功能逐项验收（上线后）

按序执行，每步核对判据（请求头 `$H = @{"X-Role"="admin"}`，基址 `$B = "http://localhost:8000"`）：

### 4.1 类目与入盟（P0）

- [ ] **类目字典**：`GET $B/api/alliance/categories` → 8 类目（水/茶/酒/菜/肉/鱼/器/境），酒类 `traceLevel=full`、其余 `lite`
- [ ] **门槛拦截**：Lv2 会员 `POST /api/alliance/apply` → 409"会员等级不足"
- [ ] **正常申请**：Lv5+实名+资质齐会员申请 → 状态 `manual_reviewing` 且 `aiReview.score ≥ 80`（快车道）
- [ ] **AI 直拒**：无实名无资质申请 → 状态 `rejected` 且 `aiReview.score < 60`
- [ ] **重复拦截**：同会员再申请 → 409"在途申请"（申请表与商铺双重检查）
- [ ] **人工审核**：`POST /api/alliance/applications/{id}/audit {"approved":true}` → 签约建档（商户 `signed`）
- [ ] **状态机**：activate → `probation`；confirm → `active`；直接 signed→active 非法转移路径 409

### 4.2 商品三道门禁（P0）

- [ ] **非酒类缺凭证**：`POST /api/alliance/products`（无 traceCredentials）→ 409"须提交简化溯源凭证"
- [ ] **非酒类上架**：带凭证 → `active`，且 `trace.evidenceHash` 非空（**P1 上链存证生效**）
- [ ] **酒类溯源门禁**：无批次号 → 409；批次未 `released` → 409；已放行批次 → 上架成功且 `trace.traceVerified=true`
- [ ] **合规门禁**：名称含"史上最好" → 409 禁用词
- [ ] **商户暂停联动**：suspend 商户 → 其在售商品全部自动 `offline`

### 4.3 交易与 15% 分润（P0 核心）

- [ ] **分润预览**：`GET /api/alliance/share-preview?amount=100` → 佣金 15.00 = 平台 6.0 / 类目服务 3.0 / 推荐人 2.25 / 市店 2.25 / 发展基金 1.5（五方合计=佣金）
- [ ] **下单扣库存**：`POST /api/alliance/order` → `paid`；商品库存原子扣减；超量 → 409
- [ ] **结算**：`POST /api/alliance/orders/{orderId}/settle` → `commission = amount×0.15`、`ledgerEntries` 5 条全 created（**role 总账双写**）、`walletTxNo` 非空非 PENDING（**货款入账**；商户未开户时为 PENDING_NO_WALLET 属正常，需开户后重试口径）
- [ ] **幂等**：重复 settle → 返回同一 settlementId
- [ ] **冲正**：reverse → `reversed`；重复冲正 409
- [ ] **T+1 跳过**：新单（<24h）`POST /api/alliance/settle-run` → 不结算（skipped）
- [ ] **配置校验**：`PUT /api/alliance/share-settings` 比例和≠1 → 409
- [ ] **总账核对**（旁证）：ai-learning overview 或 role 总账中 `sourceModule=alliance` 流水 5 条/单

### 4.4 评价与 AI 审评（P0+P1）

- [ ] **结算前评价拦截**：未结算订单评价 → 409
- [ ] **正常评价**：结算后 5 星好评 → 展示且 `aiReview.action=show`；星级聚合回写商户
- [ ] **恶意差评自动折叠**："垃圾黑店"+1 星（对均分 5 商户）→ `folded=true` 且 `aiReview.action=fold`，**不计入星级**
- [ ] **一单一评**：重复评价 409

### 4.5 GeoGrid 地图（P1）

- [ ] **密度仲裁**：同网格同类目第 gridCap+1 家商户申请范围 → 409"网格密度已满"（茶 3/酒 5）
- [ ] **就近推荐**：`GET /api/alliance/geo/nearby?lat=36.06&lng=120.38&category=tea` → 距离升序、仅 active 商户、含 ratingAvg/distanceKm

### 4.6 月度考核（P1）

- [ ] **执行考核**：`POST /api/alliance/assessment/run?month=YYYY-MM` → 返回 assessed/等级
- [ ] **等级判定**：大户（GMV≥2×线+4.8星）= S；零单 = C
- [ ] **连续 C 处置**：预置 2 个月 C 级历史后考核 → suspend；3 个月 → terminate（商户状态实际变更）

### 4.7 场景与定制（P2）

- [ ] **类目校验**：小聚编排配菜商户传酒庄 → 409
- [ ] **一单三子单**：`POST /api/alliance/scenes/gathering` → 3 子单（wine/dish/venue）、totalAmount=酒+菜×人数+境、核销码 `RP-` 开头
- [ ] **线下核销**：`POST /api/alliance/redeem {"code":...}` → 场景 `redeemed` + **三子单全部结算**（分润起算）
- [ ] **幂等核销**：重复 redeem → 409"已使用"
- [ ] **定制状态机**：demand→quote→confirm（本人校验）→producing→delivered；终态再转移 409

**验收中发现并修复的 bug（37号 P0 引入，本日修复）**：
- `place_order` orderId = `ALO{时间戳}{productId:04d}{buyer%100:02d}` —— 同一买家同一秒内对同一商品下两单 orderId 碰撞，第二单覆盖第一单（丢单+结算错位+第二单评价被"一单一评"误拦）。修复：改为 `ALO{时间戳}{order_seq:06d}`（repo 自增序列保证唯一）；37号专项 118 项回归全绿
