### 1.3 与现有模块的边界（叠加式铁律）

- **40号博主** = 内容生产与发布主体（DV账号/音视频创作/自治/信任）——72号永不生成音视频、永不操作账号
- **40号 P7雷达** = 全网信号侦测唯一（事件聚类/情绪场域/价值评分/预警）——72号只读消费雷达事件，永不修改雷达数据
- **attract v1.0** = 短链/归因/报表/SEO/裂变底盘——72号叠加认知层，v1.0 端点零改动（仅 /r/{code} 增强可选 ctx 参数，向后兼容）
- **46号** = 审批总线唯一（预算系数/定律升格/参数开放均 submit_change 纯调用）
- **57号知识库/51号图谱** = 知识存储唯一——72号定律表为"引流域视图"，同步写入 57号知识条目（复用现有 RAG 通道）
- **68号臻选/45号信值** = 转化承接与反馈源——72号消费其反馈数据做选题回流，零改动

**拼图定位**：attract v1.0=流量**通道**（进得来、算得清）→ 40号=内容**主体**（做得好、发得出）→ 40号P7=环境**耳目**（看得见、判得准）→ **72号=增长大脑**（为什么进得来、怎样可预判地进来、下次怎样更好）。

## 四、六大能力升维（智能重构 × 进化机制 × 宪法铁律）

### 4.1 内容工厂 → 意图驱动选题认知引擎（P1）

- **智能重构**：选题来源从"人工录入+ROI回流"两源扩为**四源**：manual/ai_roi（既有）+ **ai_trend**（雷达事件×历史同类选题转化基准自动生成，势能超阈值入队）+ **user_voice**（68号臻选反馈+45号信值回流聚类，高频疑问/痛点自动提炼选题）；每选题带意图画像（目标人群情绪基调/场景标签）
- **进化机制**：选题-转化要素对照入因果引擎（P2）；人格匹配分注入生成参数（generate 时携带 channelPersona/audienceIntent 扩展槽位，v2 单点预留兼容）
- **铁律**：LLM 禁入选题判定（势能分/匹配分=确定性公式）；ai_trend 选题 shadow 期只入观察区，人工确认后进入生成队列（"人类仅可 veto"本站化为"shadow 期默认 veto"）

### 4.2 短链系统 → 用户关系记忆神经元（P4）

- **智能重构**：/r/{code} 增强可选参数 `?ctx={base64}`（用户画像片段/来源内容ID/意图标签——落地页按 ctx 决策渲染变体：老用户直显权益、新用户强化信任）；clicks 增强 userIntentSnapshot/deviceFingerprint/contentSentiment 三字段（P1 意图快照联动）；**跨会话记忆**（deviceFingerprint→行为画像累积，注册后归并继承）
- **进化机制**：落地页变体选择=匹配分查表（画像×变体历史转化分布）；**反作弊免疫**（同指纹异常频次分布监控→自动隔离，模式沉淀入红队记忆）
- **铁律**：ctx 仅携带脱敏画像片段（无 PII）；AB 分流逻辑零改动（ctx 与 AB 正交，叠加生效）；向后兼容（无 ctx 参数行为与 v1.0 完全一致）

### 4.3 归因中心 → 因果推理与定律结晶引擎（P2）

- **智能重构**：attributions 增强 causal_driver/loss_reason/counterfactual_score 三字段；**每日离线因果任务**：要素（内容角度/平台/发布时段/渠道类型/钩子类型）× 出现/不出现分组转化对照 → 反事实得分（组间差异/样本量加权置信度）；高频验证洞察自动升格为**增长定律**（如"周末晚间×情感故事×品鉴型人格=高转化"——带 confidence/boundary/validatedCount）
- **进化机制**：定律驱动三处消费——选题（ai_trend 匹配分）、人货场匹配器（预期转化预估）、预算博弈器（渠道潜力识别）；定律过期衰减（连续 N 窗口未复现→降置信→归档）；**反知识**（验证无效的要素组合同样结晶，防重复试错）
- **铁律**：因果得分=确定性公式全留痕（分组样本/差异值/置信度可复现）；定律升格走 46号建议书；洞察数字 100% 查询层插值

### 4.4 报表中心 → 增长知识交互中枢（P2/P6）

- **智能重构**：新增**因果洞察看板**（哪些要素真正驱动转化/哪些导致流失/反知识清单）+**定律台账**（置信度/边界/验证次数/消费次数）+**预判偏差看板**（72h 预分配 vs 实际消耗偏差曲线）；自然语言查询（"为什么上周抖音ROI下降"→确定性关键词路由→查询层取数→LLM 仅组织解释文案）
- **进化机制**：进化日志（每日"学到什么/改变了什么/为何改变"自然语言报告——供人类监督与价值观校准）
- **铁律**：查询数字确定性生成；解释模板中数字全插值；49号可信函数调用复用

### 4.5 ROI引擎 → 预判式预算博弈器（P3）

- **智能重构**：**budget_forecast 预分配**（每 6h 生成未来 72h 各渠道预算预分配+置信度；输入=历史同期分布+外部信号（节日日历/雷达事件/渠道生命周期位）+定律加权）；实际消耗偏离>15% 自动触发**重博弈**（再生成方案+diff 留痕）；**三层时间尺度**：分钟级（热点追投窗）/日级（渠道调配）/月级（战略储备）；**探索基金** 5-15% 浮动（进化 ROI 反馈调节）
- **进化机制**：预判偏差率入元认知健康度；渠道成熟度自适应阈值（新渠道宽容/成熟渠道敏感——v1.0 REBALANCE_STEP 的进化版）
- **铁律**：**奖励系数变更永远 46号建议书**（重博弈只生成方案与 diff，执行=46号审批后 currentRate 变更——v1.0 双轨制继承）；预算池总量月度锁定（此消彼长不新增总成本——v1.0 铁律继承）

### 4.6 热点运营 → 雷达联动卡位决策器（P5）

- **智能重构**：消费 40号 P7 雷达 L1+ 事件 → **四维势能评估**（时效性=雷达剩余黄金窗/相关性=品牌契合词表命中/安全性=雷达合规边界/转化潜力=历史同类热点引流基准）→ 综合势能超动态阈值进入决策队列 → **卡位决策一体化方案**：渠道选择×发布时机窗（精确到小时段）×预算注入建议×短链承接方案（含动态落地页变体）；决策三段留痕（shadow=方案存档不执行/assist=方案+46号或人工确认后推送 40号博主与 attract 分发/full=低风险项自动执行）
- **进化机制**：卡位结果回流（预期 vs 实际曝光/转化）→ 热点定律（"社会情绪类热点×共情叙事×延迟卡位=高品牌好感"）；成功模式抽象为热点卡位模板
- **铁律**：势能四维全公式可复现；**高风险热点（安全性<阈值）自动拒追**（"热点安全硬编码"）；卡位执行永不直接操作 40号账号（只产出建议注入其创作/发布情境参考——71号 assist 语义平移）

## 五、三层自进化引擎（参考方案快适应/深反思/元认知——本站宪法化）

### 5.1 快适应层（在线微更新，域内自动+全留痕）

- 画像滚动更新（每次点击/互动→意图快照→人格画像置信度微调）
- 落地页变体匹配分在线统计（变体×画像转化分布滚动窗口）
- 反作弊分布监控（指纹频次异常→自动隔离，模式入红队记忆）
- 预算消耗偏离监控（>15%→触发重博弈，重博弈方案生成域内自动）

### 5.2 深反思层（每日离线，洞察→建议书）

- 因果推理任务（要素对照→洞察池）
- 定律生命周期管理（新洞察入池/验证计数/过期衰减归档/反知识结晶）
- 进化日志生成（自然语言"今日学到什么"）
- 预判偏差复盘（72h 方案 vs 实际逐渠道 diff→博弈器权重建议书）

### 5.3 元认知层（漂移监控+红队+自省）

- **认知健康度**三指标：内容多样性指数（选题角度分布熵）/渠道匹配准确率（匹配分 top 渠道实际转化命中）/预算预判偏差率（滚动 MAPE）——任一超阈值**自动冻结进化并告警**（71号分布监控冻结范式平移）
- **红队四向量**：刷量注入（伪造点击流）/归因投毒（伪造归并请求污染因果样本）/博弈操纵（伪造消耗骗取重博弈倾斜）/人格漂移（画像异常突变）——分布监控+自动冻结+解冻人工专属
- **自主实验沙箱**（v3.4"安全探索协议"）：元认知发现盲区（低置信区域）→ 自动生成最小实验提案（假设/变量/样本量/成功标准）→ 沙箱约束（非核心渠道/小预算/灰度流量）→ 46号确认后运行 → 结论双向结晶（知识/反知识）

## 六、三段自主度模式与治理（71号范式移植——引流域首创 full 档）

```
ATTRACT72_MODE 环境变量四档（默认 off，.env 变更须 docker compose up -d 重建）:

off     观测面常开(报表/知识/健康度只读), 决策面关闭(409)
shadow  决策面开·留痕不执行——预分配方案/卡位方案/实验提案只落库
        (影子期≥7天, 评估模板签核后转段——71号惯例)
assist  决策面开·建议注入——方案推送人工确认位(选题入队/推送40号情境
        参考/46号建议书), 执行永远显式确认
full    低风险域自主执行(选题入队/落地页变体/沙箱实验), 高风险项仍走
        46号审批(L1白名单参数可开放——71号 L1分级开放范式平移)

ATTRACT72_KILL 一键制动(数据面+环境变量双保险)——回退off, 观测面保留
```

**创新点**：71号支付域"资金永不自动"故无 full；引流域不碰资金，**full 档首次开放**——但受 L1 白名单约束（可开放参数：探索基金占比/落地页变体权重/选题入队阈值；不可开放：奖励系数/定律边界/合规参数）。

## 九、宪法铁律（十则）

1. **LLM 禁入判定链**：势能四维/因果得分/匹配分/预分配=确定性公式（词表密度/历史统计/查表），LLM 仅组织文案与解释模板
2. **资金类永不自动**：奖励系数变更永远 46号建议书；重博弈只产方案与 diff
3. **三段四档门控**：ATTRACT72_MODE 决策面门控，观测面常开；转段须评估签核（71号惯例）
4. **零重复**：侦测唯一（40号P7）/创作发布主体唯一（40号博主）/审批唯一（46号）/知识存储唯一（57/51号）
5. **数字确定性**：报表/证据/日志数字 100% 查询层插值，可复现公式
6. **决策可解释**：每决策留痕输入特征×规则依据×数值明细（71号链路图范式）
7. **可回滚**：ATTRACT72_KILL 双保险；未执行决策可撤销
8. **探索沙箱**：自主实验限非核心渠道/小预算/灰度流量，失败不影响主业务
9. **知识置信**：定律带 confidence/boundary/validatedCount，过期衰减归档，反知识同权结晶
10. **隐私最小化**：ctx 仅脱敏画像片段；指纹画像不含 PII；导出报告脱敏

## 终局愿景（参考方案 v3.5 精神·本站版）

当引流系统不再只回答"流量从哪来"，而能回答"**为什么这次会来、下次怎样更准**"；当归因从"记账"变成"懂因果"，预算从"看昨天"变成"预判后天"，热点从"人工追"变成"雷达见、大脑判、主体发"；当每一次进化都留痕、可解释、可回滚，人类只守价值观锚点与制动权——引流模块便从"流量搬运工"蜕变为网站的"增长文明载体"。

72号是这一蜕变的实践起点：让每一次触达都有意图理解，让每一分预算都有预判依据，让每一条定律都有因果证据，让每一次自主都有治理边界。
