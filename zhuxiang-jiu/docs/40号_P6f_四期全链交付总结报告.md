## 三、核心交付明细

### 3.1 P6f-1·引流能力开放(370 行)

- **最小侵入开放**:`/api/blogger/open/av/*` 端点组直接复用既有 API 网关
  (X-Api-Key + X-App-Code 双头凭证 + QPS/日配额)——不新建网关,
  只是新的受保护路由前缀;pro 档硬门(403 拒绝非超级会员)
- **五端点组**:选题推荐(只读)/人设登记(原创 IP)/脚本生成
  (复用 P6b 全链合规)/渲染(mock 默认)/作品+六层漏斗+指标(仅自己)
- **ownerId 命名空间隔离**(宪法红线):人设/脚本/作品/指标全部 memberId
  贯穿,越权访问一律 404 语义
- **租用账本**:受控写计费(脚本=1/mock 渲染=5/real 渲染=50 单位,
  endpoint 维度留痕);**月度租金建议书** pending→admin approve
  (47号信值扣减留痕)——永不自动;real 渲染 admin 双闸预审
- **pause 降级保护**:全局自治暂停时开放端点组降级只读
  (观测不中断,行为冻结)

### 3.2 P6f-2·AI 播客/主播信值绩效(292 行)

- **五分项绩效公式**(确定性,LLM 禁入):
  `总分 = 100 × (0.35×漏斗贡献 + 0.25×共鸣质量 + 0.20×合规表现
                + 0.10×授权贡献 + 0.10×自愈稳定)`
- **共鸣权重铁律延伸**:0.25 不低于任何单一非漏斗项——γ≥α 在生态
  绩效层防"唯转化论"
- **双轨主体**:persona(AI 人设,平台资产)与 creator(P6e 授权创作者)
  独立月报;数据源全既有模块(P6d 漏斗/P6a 共鸣/P6b 合规/P6e 授权/P6d 自愈)
- **分档联动**:≥80 金牌(系数 1.2)/60-79 银牌(1.0)/<60 观察(0.8)
- **结算建议**(永不自动):settle 保持 pending+建议入账(总分×0.1 信值)
  →admin approve(47号入账留痕)/reject/重复处置拒绝
- **防操纵**:漏斗数据来自归因体系(追踪码+三层去重),刷量进不了漏斗;
  空主体自动落观察档
- **附带修复**:总分百分制化(五分项加权和×100,修复 0-1 尺度与分档
  阈值失配);P5c EMA 收敛断言 flaky 根治(8/8 稳定)

### 3.3 P6f-3·行业合规标准输出(226 行,零新表)

- **年度白皮书**(确定性模板四章节):授权链五步法框架/年度数据
  (授权/深审/撤回/水印覆盖/价值观拦截——数字永远来自查询层)/
  红线工程化案例(γ≥α 双硬拒/一票否决/秒级下架/分润永不自动)/
  开放倡议(CC BY-NC-SA,67号先例)
- **PII 双防线**:scan_pii 确定性正则(手机/身份证/邮箱,48号语义复用)
  +mask_pii 打码;白皮书全量扫描以 piiHits 显式呈报
- **零个体数据**(宪法红线):拒绝轨深审入口即阻断不留库(年度分布
  只反映准入转发)
- **开放数据集**:平台×漏斗聚合(仅计数)+转发摘要;**样本门**
  (<3 作品平台过滤,冷启动保护,被过滤平台显式列出)
- **发布责任**:publishNote 注明"AI 仅展示,终稿责任归属操作者与审批人"
- **2 公开只读端点**:`/av/industry/whitepaper?year=`、`/dataset`

### 3.4 P6f-4·可信度评估(268 行,零新表)

- **五因子模型**(可信度=信值的另一种聚合视角,零新增主观评分):
  `可信度 = 100 × (0.30×履约率 + 0.25×合规率 + 0.20×共鸣质量
                  + 0.15×授权完整度 + 0.10×自愈稳定)`
  对齐 API 健康五因子先例(固定权重+百分制)
- **三检测器**(对齐 API 异常检测先例):spike(>μ+3σ 且 μ≥5)/
  drop(<μ−3σ 且绝对值≥20 防冷启动误报)/violation_surge(×3 且样本≥20)
- **分档联动租用系数**:≥85 卓越(1.2)/70-84 良好(1.0)/50-69 观察(0.8)/
  <50 限制(0.5);**档位变更须走 46号建议书(永不自动)**——
  linkageNote 每次评估显式注明;违规激增→暂停租用审核建议书,
  **绝不直接封禁**
- **三类主体观测面**:persona/creator(P6e 去重)/member(账本去重,
  ownerId 命名空间);**观测面不受 pause 影响**(测试验证)
- **3 admin 端点**:subjects/{type}/{id}/recalculate(带历史时序触发检测器)

| 绩效防操纵 | 归因防篡改+共鸣权重不低于转化项铁律 |
| 标准输出无 PII | mask_pii 复用+聚合最低样本门+零个体数据 |
| LLM 禁入判定链 | 绩效/可信度=确定性公式;白皮书=模板出数 |
