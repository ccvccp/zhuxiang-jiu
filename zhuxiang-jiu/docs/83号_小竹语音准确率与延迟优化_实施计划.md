## 三、分期边界

### P0(本期): 可观测先行 + 热词补全
- voice83_latency_service: latReport 落地数据日聚合
  (四段 P50/P90+超标计数, 48号 smoothness_report 同范式);
  GET /api/voice83/latency(观测面, admin)
- 热词: 地区词进 ASR_HOTWORDS 基线+分页面热词表
  (page-ctx → _asr_hotwords 注入联动)
- 断言 ≥20: 聚合对账/热词场景命中/观测面

### P1: 置信度实证 + 事件埋点
- 百炼返回字段勘验(spike) → 有置信度: 接阈值澄清;
  无: 边界记录(诚实, 不造假接入)
- 唤醒/打断/离开事件并入 latReport 通道

**P1 spike 实证结论(2026-10-07 生产勘验)**:
真机语音样本(tts_judge.wav, 303KB)喂百炼 qwen-audio-3.0-asr-flash
原始响应: 转写成功("你好小竹，今天天气怎么样？给我推荐一款好酒。"),
结构 output.sentence.words[] 含 begin_time/end_time/fixed/punctuation,
**无 confidence/score/prob 任何置信度字段**。
→ ASR-09/ACC-05「置信度回退」无可依赖信号源, **记边界: 不做**
(不发明假指标——fixed/静默启发式属发明非真置信度)。
附带勘验: 纯音/无声样本返回 400 ASR_RESPONSE_HAVE_NO_WORDS
(链路/鉴权通, 空内容明确拒绝非静默)。

### P2: 按基线数据决策
- G1 报表跑两周 → 看真实 SLA 现状 vs 用户四条验收线
  (700/150/200/100ms) → 超标段定向优化(此时才评估投机
  预热/并行流水线值不值得做)
- 82号 影子 promote 后, 节奏参数与 G1 数据联合分析

## 四、铁律

- 继承: 三态开关默认 off/观测面无门槛/fail-soft/守卫部署;
- LLM 不产数字——SLA 全部确定性计时聚合;
- **不做无基线的优化**: P0 只建可观测+配置级热词, 一切
  行为级优化等 G1 数据说话(P2);
- DAVAS 维持 48号搁置定论, 不因新清单翻案;
- 语音链文件改动走 voice48+voice82 交叉守卫(已就位)。

## 五、验收

- P0: 报表出数(四段 P50/P90/超标)+热词分场景命中实证;
- P1: 置信度可行性结论落档(有/无二值, 不模糊);
- P2: 真实 SLA vs 用户四线对照表 → 定向优化清单再立项。
