## 四、测试基础设施说明

三套测试均采用与 `test-xinzhi.js` / `test-attract72.js` 一致的纯 Node 范式：

1. **TS 内存转译**：无需构建产物，直接加载 `.ts` 源文件
2. **Module 拦截**：`Module._load` mock 拦截 `@tarojs/*`、网络请求等平台依赖
3. **miniReact 运行时**：页面级断言通过轻量 React 运行时渲染组件树验证

