# 小竹本地合规引擎（DFA）落地交付报告

> 日期：2026-10-04 | 依据：用户 DFA/正则 Guardrail 方案 + zxjiu 专属词库
> 模块：`services/local_guardrail_service.py`（新增）+ 对话链路双端集成

---

## 一、方案校准（与现状的差异说明）

- 小竹现状**无 LLM Guardrail**（上轮已查明：辱骂词仅积分惩罚不拦截、
  PII 脱敏已有正则）——因此本方案价值不在"降级 LLM"，而在三块增量：
  **DFA 引擎**（替代词表 `in` 全扫）、**酒类+招商专属词库**
  （五类拦截/二级替换/分类话术——原缺失）、**Redis 热更新**（原无）
- 语义型合规（暗示疗效/多轮漂移）按方案"重要提醒"保留 LLM system
  prompt 约束兜底——本地挡明确违规的分层铁律照搬

## 二、引擎实现（用户方案全量落地）

### DFA 核心
- Trie 树构建（进程内一次），查询 O(len(text)) 与词库规模无关
- 变体对抗预处理：去空格/标点/emoji + 统一小写（"未 成 年"穿透命中）
- 词→分类倒排（命中归因分类）+ 最长优先匹配

### 词库（用户 YAML 内容照收，v1.0.0）
| 层 | 分类 | 内容 |
|---|---|---|
| 一级拦截(5类) | minor_protection | 未成年/未满18岁/初中生/高中生/小学生/underage/小孩买酒/儿童饮酒 |
| | franchise_redline | 保底收益/稳赚不赔/零风险/包回本/年入百万/躺赚/保证盈利/无风险/必赚/包赚钱 |
| | alcohol_claims | 治疗/治愈/抗癌/降血压/降血脂/降血糖/药酒疗效/延年益寿/壮阳/补肾/预防疾病/消除疲劳/保健品效果 |
| | excessive_drinking | 拼酒/灌醉/不醉不归/一口闷/喝倒/斗酒/感情深一口闷 |
| | general_compliance | 代开发票/套现/洗钱 |
| 二级替换 | 广告法/价格/加盟夸大 | 最佳→优选、顶级→高端、最低价→当前优惠价、独家代理→区域保护… |
| 分类话术 | block_responses | 每类标准合规应答（禁止向未成年人销售/投资有风险/不能代替药物/文明饮酒） |

注：用户词库的"治疗"单字级词在本词库保留（"能治疗失眠吗"实测拦截话术正确）；
"小孩/儿童/学生"裸词因误杀面大（"儿童座椅"类场景）改为组合词
（小孩买酒/儿童饮酒）——误杀监控数据积累后再评估放宽。

### 热更新
- Redis `zhuxiang:xiaozhu:guardrail:rules` = JSON
  `{version, blocklist, replacemap, block_responses}`
- 版本变更进程内原子重建 DFA（引用互换并发安全）；失败保持旧词库
- 运营后台改词库零重启生效（替代 YAML 文件方案——与全站 Redis 配置范式一致）

## 三、对话链路集成（双端）

| 端 | 位置 | 行为 |
|---|---|---|
| 输入端 | 高敏确认拦截后、指令路由前（1329 区） | 命中即拦：intent=blocked、track=guardrail、分类话术返回，**省 rule+LLM 全链路** |
| 输出端 | LLM chat reply 后验（截断守卫后） | 二级替换（广告法/价格/加盟夸大词），不阻断 |
| PII | 沿用既有 mask_pii（落库前） | 手机/卡号/身份证（已有，不重复） |
