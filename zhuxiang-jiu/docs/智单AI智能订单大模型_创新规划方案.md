# 智单·AI智能订单大模型 创新规划方案 v1.0

> 定位: 订单管理模块升级——从「交易流水账(后视镜)」到「订单智能中枢(领航仪)」。
> 参照: 智启元/智法/智图大模型既有范式(四层协同+确定性引擎+建议书模式)。
> 铁律: LLM 禁入订单判定链; 数字 100% 查询层; 裁决/处置永不自动执行(建议书模式)。
> 命名: 「订单管理」→「**智单·AI智能订单大模型**」(ZhiDan Order-Intelligence)。
> 基线盘点: order_routes 17 端点(创建/价格引擎/九态状态机/退款审核/超时调度)全保留零改动, 智单叠加洞察层。

## 二、架构: 四层协同

```
L1 问答层: NL 订单问答(五域意图路由→确定性查询, 数字100%插值)
    ↓
L2 智能体集群(确定性 Agent, 全部可解释):
    洞察Agent(体检+画像) / 预测Agent(ETA+沙盘)
    / 风控Agent(退款评分+异常检测) / 进化Agent(反馈+备忘)
    ↓
L3 数据织物: order_repository 只读聚合(九态/金额/时间线/会员)
    ↓
L4 自主进化引擎: 反馈闭环+异常自发现+全链路推理留痕
```

## 三、四大能力 → P0-P3 分期

### P0 订单洞察中枢
- **NL 订单问答**: 关键词意图路由(单量/GMV/退款/履约/异常五域) → 确定性查询 → 句子模板拼接
- **订单健康体检**: 四维评分(状态分布/资金安全/履约时效/退款率, 分段确定性打分)
- **订单画像**: 会员×商品×时段三维聚合(谁在买/买什么/何时买)

### P1 履约预测与沙盘
- **履约 ETA 滚动预测**: 支付→签收时长加权预测(0.6 近期+0.4 全期)
- **What-if 沙盘**: 发货时效±/取消率±/客单价± → GMV/退款/履约影响推演(确定性公式)
- **订单量预测**: 12 期滚动预测(加权移动平均+趋势外推)

### P2 退款裁决与风险
- **退款风险评分**: 金额异常/频次异常/会员风险/商品域 四因子加权 → 建议书
- **裁决辅助**: 结构化建议(approve/reject/manual+推理链), 决定权在 admin
- **异常订单检测**: 高频下单/大额囤货/秒退款 → 风险分级(建议书, 不拦截)

### P3 自主进化与决策支持
- **反馈闭环**: 裁决/预测的采纳/修正/拒绝 → 参数权重学习(安全阀 clamp)
- **异常三检测器**: 单量 spike/状态 drop/取消 surge(复用既有范式)
- **决策备忘录**: 大促备货/超时策略调整 结构化建议书(模板+数据插值)

### 全期贯穿: 可信与安全
- 推理链留痕(每输出附公式) / 建议书模式 / X-Role: admin 全端点
