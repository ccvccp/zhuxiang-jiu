## 二、问题一: 发布中心查看无内容

### 2.1 排查过程

| 检查项 | 实测结果 |
|---|---|
| POST /api/promo/publish/queue | `{"data":[],"count":0}` 队列为空 |
| 内容状态分布 | 总数 6, **published: 6**(全部已发布出队) |
| report/overview | contents.published=6, hotspots: 50 总/30 跟进 |
| 已发布内容 receipt 实查 | mode/publishId/exposureEstimate/publishedAt/shortCode 字段完整 |

### 2.2 根因定性

**非 bug**——发布队列是「待发」语义, 6 条内容全部于 09-11 发布出队后队列自然清空。原页面仅显示待发队列, 空态提示「队列为空」造成"无内容"观感, 已发布成果与回执无处可看。

### 2.3 修复方案(提交 `22d15a7`)

发布中心新增「已发布内容(N)」历史区块:

- 数据源: 复用 contents 列表, 过滤 `status=published`(后端列表本就携带全量字段, 零后端改动)
- 每卡展示: #编号+标题 / 发布平台 / 发布时间 / 引流短码 / 发布回执三件套(通道模式·发布ID·曝光预估)
- VO 层补 `ContentReceiptVO` 与 `publishedAt/receipt` 字段

## 三、问题二: 总览单日发布限额数字无变化

### 3.1 排查过程

| 检查项 | 实测结果 |
|---|---|
| API report/overview | `dailyCap: {used: 0, limit: 20}` |
| Redis 日计数键 | `zhuxiang:promo:daily:*` 当日(20260914)无键 |
| 已发布内容 publishedAt 分布 | 6 条全部为 2026-09-11 |
| 计数代码链 | `process_publish_queue` 出队时 `incr_daily_published(日期键)`, 键 48h TTL |

### 3.2 根因定性

**非 bug**——`dailyCap.used` 是**当日**发布+入队计数(防刷屏限流口径):

1. 6 条内容发布于 09-11, 当日计数为 6/20
2. Redis 日键 48h TTL, 09-13 已自然过期
3. 今日(09-14)无新发布/入队 → 0/20 属正确显示

数字"没有变化"实为"每日归零循环"的正常语义。

### 3.3 修复方案(提交 `b2c06cf`)

为消除误解, 总览页自解释化:

- 标签改为「单日发布限额**(今日发布+入队)**」, 明确当日口径
- 新增「**累计已发布 N 条**」行(取 overview.contents.published), 发布成果常驻可见

### 3.4 单元测试

新增断言「页面-限额口径标注」(标签文本+累计行渲染), **39/39 全绿**。
