## 四、36号功能逐项验收（上线后，全链路）

按序执行，每步核对判据：

- [ ] **通道状态**：`GET /api/promo/channels/status` → 五平台 effectiveMode 与配置一致（mock 或 real；real+未配 KEY=mock）
- [ ] **雷达扫描**：`POST /api/promo/radar/scan` → scanned=25 / new=20 / discarded=5 / decisions=20（模拟源口径；风险热点 5 条被否决）
- [ ] **决策三档**：`GET /api/promo/decisions?pendingOnly=true` → 5 条待人工裁决（50-70 分区间）；抽查 reason 可解释
- [ ] **种子初始化**：`GET /api/promo/audience/profiles` → 5 平台；`GET /api/promo/authority/sources` → 4 条国标/协会信源
- [ ] **三维匹配**（抽查）：`POST /api/promo/audience/match` `{platform:"xiaohongshu", angle:"婚宴", productTone:"礼盒"}` → matched=true；换 douyin → matched=false
- [ ] **Agent 生成**：`POST /api/promo/contents/generate` → 合规分=100、状态 pending、短码 `A-` 开头、`authorityRefs` 非空；内容详情 `agentTrace` 四步走轨（配 LLM_KEY 为 glm-5.3/glm-4-flash，未配为 rule——均为正常）
- [ ] **溯源报告**：内容详情 `provenanceViolations` 为空（规则轨模板无数字声明）
- [ ] **人工审核**：`POST /api/promo/contents/{id}/review` `{"approved":true}` → 状态 approved；再调一次 → 409（状态非法）
- [ ] **入队发布**：`POST /api/promo/contents/{id}/publish` `{"publishAt":""}` → queued + 黄金时段 scheduledAt
- [ ] **出队回执**：`POST /api/promo/publish/process` → published + `receipt.mode`（mock/real）+ `publishId` + `exposureEstimate`
- [ ] **自动 SEO**：`GET /api/promo/seo/pushes` → 最新记录 status=ok，urls 含 sitemap + 新落地页
- [ ] **归因闭环**：浏览器访问 `/r/{短码}?utm_source=douyin` → 302 落地页带 clickId；`POST /api/attract/attach` + `attach-order` 后 `GET /api/promo/report/overview` → attribution.clicks/registered/ordered/GMV 计数准确（**此处为零则 attract 修复未包含，回退第一节检查 b459c34**）
- [ ] **Hedge 回流**：`POST /api/promo/learning/feedback` `{"contentId":N}` → 有点击内容 correct=true；重复提交 → 409（幂等）
- [ ] **attract 点击流回归**（旁证）：`GET /api/attract/clicks` 与 `GET /api/attract/report/funnel` 返回 200 非 500
