# 82号·小竹语音对话逻辑学习进化模型——实施计划

> 2026-10-07 立项 | 惯例对齐: 81号/66号轨同范式(需求描述→现状映射→分期边界→验收断言)
> 承接: 48号小竹语音链(P0-P6 全链稳定, 六连修后真机验收)——本模块是其"认知进化层"

## 〇、方案定位: 需求原文 × 务实解读

需求核心: 小竹语音从"听懂一句话"进化为"理解一个角色、预判下一步、掌握对话节奏"。

| 需求原词 | 本项目落地形态 |
|---|---|
| 角色习惯建模 | **画像三表**(角色/对话/业务偏好), 键=member_id(登录)或脱敏设备指纹(游客) |
| 对话目标预判 | **意图转移矩阵**(EMA 平滑)——确定性统计, 非 LLM 产概率(全站铁律) |
| 节奏自适应 | **参数白名单映射**: 画像→VAD 静默容忍/TTS 节奏/追问深度/打断策略(封闭集合) |
| 在线强化进化 | **44号学习域范式**: 会话信号→评分器→challenger→人工 promote(auto_apply=False) |
| 隐私可控 | 继承 48号红线(音频即转即删)且更严: **只存特征与标签, 不存对话原文** |

三阶段(用户方案自带, 映射 P0/P1/P2):
- P0 规则+轻量画像(角色识别+对话画像采集+追问策略开关)
- P1 目标预判(Next-Goal 转移矩阵+预载答案)
- P2 在线强化(奖励信号+voice82 策略评分器+影子→assist 灰度)

## 二、数据结构设计

### 2.1 画像三表(Redis, 键空间 zhuxiang:voice82:)

```
profile:role:{key}      角色画像: {role, confidence, sources[], updatedAt}
  role ∈ visitor|dealer|agent|staff (封闭集合)
  来源信号: 登录态/URL 前缀(/distributor /product /cart)/历史意图分布

profile:dialog:{key}    对话画像: {speechRate, pauseMs, interruptRate,
                                   correctRate, avgTurns, updatedAt}
  EMA 平滑(α=0.3), 冷启动用全局默认

profile:biz:{key}       业务偏好: {intentDist{价格/政策/库存/样品/物流/
                                   结算/售后}, topGoal, updatedAt}

matrix:goal             意图转移矩阵: {from_intent → {to_intent: ema_count}}
  降维存储: 每意图仅保留 Top5 后继(防无限膨胀)
```

键 {key} = `m{member_id}` 或 `d{sha1(设备指纹)[:12]}`(游客脱敏)。

### 2.2 奖励信号(确定性, 会话结束钩子采集)

| 维度 | 正例 | 负例 |
|---|---|---|
| 任务完成 | 留资/样品申请/代理咨询提交 | 中途退出 |
| 对话效率 | 完成目标轮次≤历史 P50 | 同问重复≥2 次 |
| 体验 | 打断率低于画像基线 | 频繁打断/转人工 |
| 业务价值 | 进入招商流程 | 直接关闭 |

信号落 `signal:session:{id}`(TTL 7 天), 供 44号评分器消费。

### 2.3 节奏参数白名单(封闭集合, 集合外永不可调)

```
vad_silence_ms     ∈ [400, 2000]   静默容忍(画像 pauseMs 推)
tts_pace           ∈ {slow, normal, brisk}
probe_depth        ∈ {0, 1, 2}     追问深度(角色+偏好推)
confirm_threshold  ∈ [0.5, 0.9]    确认触发阈
interrupt_first    ∈ {on, off}     打断时先结论后细节
```

## 三、数据流(P1 全量)

```
语音输入 → ASR 转写(48号链, 不动)
  → 角色识别(登录态+xz-page-ctx+画像)            [82号]
  → 意图识别(fc_gateway 复用) + 状态追踪(既有)
  → Next-Goal 预判(转移矩阵 Top3+置信度)          [82号]
  → 策略选择(追问/确认/推荐/转人工/结束)          [82号]
  → 节奏参数(白名单映射, 会话级注入)              [82号]
  → TTS 输出(48号链, 不动)
  → 会话结束钩子 → 信号采集 → 画像 EMA 更新 → 评分器(P2)
```

## 四、分期边界

### P0 规则+轻量画像(首期)
- voice82_dialog_service.py: 画像三表 CRUD + 角色推断器(纯规则: 登录态+URL+历史意图)
- 对话画像采集钩子: 会话结束聚合(语速/停顿/打断/纠错)——挂 evolution 既有会话管道
- 追问策略开关: probe_depth 按角色静态映射(经销商=0 直入政策, 访客=1)
- 观测面: GET /api/voice82/profile/{key}(admin)
- 断言 ≥25: 角色推断四分支/画像 EMA/白名单边界/游客脱敏键/清除入口

### P1 目标预判
- matrix:goal 转移矩阵构建(每次意图确认后更新 EMA, Top5 裁剪)
- 预判器: 当前意图+角色 → Top3 后继+置信度(确定性计数, 归一化)
- 预载策略: 预判 Top1 置信度≥0.6 时预热对应知识(招商政策摘要/样品表单)
- 观测面: GET /api/voice82/predict-demo(干跑对比)
- 断言 ≥25: 转移收敛/Top5 裁剪/置信度边界/预载触发/冷启动降级

### P2 在线强化
- 奖励信号四维落地(§2.2) + voice82_strategy 评分器注册 44号(batch57→58 全站同步)
- 策略 challenger: 参数映射候选版(auto_apply=False, promote 走人工)
- VOICE82_MODE 三态: off(默认)/shadow(预判+策略只留痕不生效)/assist(生效)
- 灰度: 影子 ≥200 会话且正反馈占优 → 人工评估 promote
- 断言 ≥30: 信号对账/评分器入册/三态门槛/影子不生效/回滚

## 五、铁律(继承全站宪法 + 本模块新增)

**继承**:
- VOICE82_MODE 三态默认 off; 观测面无门槛; 决策面 off→409;
- LLM 不产数字不进判定链——预判=统计, LLM 仅话术;
- fail-soft: 82号故障不阻断语音主链(画像查不到→全局默认参数);
- 学习永不自动上线(auto_apply=False, 44号范式);
- 调度挂 hrm81 run_gated("voice82_learning")(批任务闸门)。

**新增(本模块红线)**:
- **不存对话原文**: 只存意图标签+统计特征(比 48号"即转即删"更严);
- **参数白名单制**: §2.3 封闭集合外任何参数不可被学习调整;
- **用户可清除**: DELETE /api/voice82/profile/{key} 一键清画像;
- **保护引擎联动**: 82号注册 PROTECTED_MODULES(voice48 族扩展)——
  凡动 asr_stream_service/voice-wake-widget.js/xiaozhu-voice.html,
  必走 guarded_deploy(套件+指纹基线全绿才放行)。

## 六、验收与路线

- 每期: 专项断言全绿 + test_asr_stream/test_xiaozhu 族回归 + lint;
- 涉语音链文件的部署: 守卫部署(生产语音零中断为第一优先);
- A/B 首选场景(用户指定): 招商咨询路径 + 样品申请路径;
- 里程碑: P0 画像可见 → P1 预判干跑对比 → P2 影子 200 会话 → promote 评估。

## 七、风险与边界

| 风险 | 缓解 |
|---|---|
| 冷启动画像噪声 | 全局默认参数兜底; EMA α=0.3 平滑; 前 10 会话只采不调 |
| 游客指纹合规 | sha1 脱敏+无 PII; 清除入口; 不跨站关联 |
| 预判错误引导 | 置信度<0.6 不预载; 预判仅备料不代答 |
| 学习越界 | 白名单封闭集+promote 人工+回滚=Discard challenger 一键 |
| 打扰语音主链 | 全部钩子 fail-soft; 保护引擎守卫部署 |
