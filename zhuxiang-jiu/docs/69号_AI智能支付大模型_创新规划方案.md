> 定位：从 60号"支付管理"（订单底座×收银台×风控×对账×回流）升维为"支付大模型"（认知路由×认证步进×交易授信×生物特征×多模态×自进化引擎）——叠加式升级，60号/55号/39号/45号/46号/47号 零改动。

## 一、核心设计理念：从"通道连接"迈向"宪法约束下的认知进化"

### 1.1 双核驱动范式（本站版）

参考方案确立"认知决策+安全进化"双核；本站在此之上叠加**项目宪法第三核**，构成"确定性执行"三核范式：

```
┌─────────────────────────────────────────────────────┐
│  核一 认知决策: 意图理解 → 通道优选 → 认证步进 → 授信评估   │
│         (确定性多因子引擎——LLM 禁入判定链)               │
├─────────────────────────────────────────────────────┤
│  核二 安全进化: 双环学习(快环在线基线+慢环建议书审批链)      │
│         (进化假设 → 沙箱 → 影子 → AB → 灰度 → 基线跃迁)   │
├─────────────────────────────────────────────────────┤
│  核三 宪法约束: 资金永不自动 / 处罚永不自动 / 四可审计      │
│         (参考方案"无需人工干预"→分级进化治理)             │
└─────────────────────────────────────────────────────┘
```

## 四、七大支付能力升维（智能重构 × 进化机制 × 宪法铁律）

### 4.1 智能二维码 → 情境感知与环境自适应码（P5，联动 55号）

- **智能重构**：码内动态参数（时段/地域/设备类型/商品类型）→ 推荐支付方式+优惠组合+防伪水印（qr55_crypto 扩展字段）；异常环境（夜间/陌生设备）自动嵌入二次验证挑战；商户侧对账摘要
- **进化机制**：分时段×地域×设备类型的扫码成功率/欺诈率统计基线（快环）；"某类设备夜间欺诈率上升→增强验证码建议书"（慢环，46号审批）
- **铁律**：码生成永远用户/商户主动触发；防伪水印算法确定性；55号隐私预算链零改动（扫码核销时扣减惯例保持）

### 4.2 微信/支付宝/银行卡/云闪付 → 无感优选与群体健康度路由（P1）

- **智能重构**：通道注册表（四通道×费率/限额/到账时效/健康度）；支付瞬间确定性评分选道；首选失败静默重试备选（用户支付动作内的执行域，非新资金操作）
- **进化机制**：各通道健康度信号（成功率滚动窗口/平均耗时/故障计数）快环在线更新；费率调整/白名单变更→慢环建议书（admin 确认）
- **铁律**：路由决策=查表评分（LLM 禁入）；路由全程留痕（routeScore 明细入归因链）；渠道凭证 .env 注入不落盘（60号惯例继承）

### 4.3 刷脸/指纹 → 活体意图验证与端侧模板终身学习（P4）

- **智能重构**：60号 P2 strong 档 FIDO"语义占位"落地为真实生物域；活体意图验证：不仅验"你是谁"，还验"你是否自愿"（胁迫语义线索：面部僵硬/语音颤抖的**确定性特征表**→静默降级密码验证+人工介入留痕）
- **进化机制**：端侧模板增量更新（每次成功微调，原始特征永不上传）；服务端仅收置信度哈希+验证结果；误拒案例回流→特征表阈值建议书
- **铁律**：生物模板端侧存储（合规红线）；降级/人工介入为安全动作可自动（保护用户方向）但全留痕；胁迫检测永不做资金操作

### 4.4 密码支付 → 自适应步进认证与风险熵动态调节（P2，升级 60号 P2）

- **智能重构**：告别一刀切——风险熵引擎六轴确定性计算（金额轴/信值轴/行为轴/环境轴/通道轴/历史轴）；熵值分档→步进梯度：低熵免密→中熵 OTP+滑动验证→高熵动态口令+生物+双人复核
- **进化机制**：隐式行为基线（操作节奏/按键间隔/滑动轨迹的统计基线，快环在线更新）；行为偏离→熵升高→认证增强；历史误拦截回流→轴权重建议书（慢环）
- **铁律**：熵计算确定性（无 LLM）；梯度阈值走 46号审批（60号 P2 惯例继承）；fail-soft（熵引擎故障→light 档+留痕，不阻断业务）

### 4.5 闪银/信用支付 → 交易级实时授信（P3，联动 45号/47号）

- **智能重构**：从"预授信额度"转向"交易级评估"：支付瞬间综合商品属性×用户信值（45号 TV 档案）×信任画像（47号）×现金流预测（60号 P4 已有）→ 授信建议（可分期数/利率档/临时额度）
- **进化机制**：每笔还款/逾期/提前结清回流（60号六类事件已有 compliance_streak/payment_anomaly 通道）→ 授信因子统计基线；新消费模式→迁移学习建议书
- **铁律**：**调额/授信生效=建议书+用户主动申请+admin 确认**（资金域永不自动）；利率档=确定性规则表（无 LLM 定价）；45号 TV redeem 熔断链零改动（69号只是评估消费方）

### 4.6 多模态交互支付 → 无障碍普惠（P6）

- **智能重构**：语音（"帮我把这箱竹香经典付了，用上次那张卡"）/手势/眼动入口→意图解析（规则轨三态，复用 55号 P0 意图引擎范式）→60号收银台联动开单
- **进化机制**：不同群体（老年/残障）交互习惯统计→意图解析准确率基线；失败案例→无障碍改进建议书
- **铁律**：意图解析规则轨（LLM 仅澄清问句生成，对齐 55号 clarify 域）；资金确认永远显式（语音支付最后一步回显金额+确认词）；49号隐私预算联动（49号零改动）

### 4.7 跨境/数字货币 → 合规预研沙盘（P9 远期）

- **定位**：本站白酒零售+助竹生活场景，跨境非核心——**仅做合规沙盘预研**（40号 P7c 范式），不实接渠道
- **内容**：币种/管辖区识别规则库草案、汇率对冲建议书模板、监管政策追踪观测面
- **铁律**：永不实接数字货币渠道（合规红线，央行数字货币仅试点参与方）；沙盘内数据全合成

## 五、自进化引擎（双环学习——本规划核心创新）

### 5.1 快环（在线适应，域内自动+全留痕）

```
触发: 每笔支付回执（60号归因链已有）
动作: 确定性统计更新——
  · 通道成功率滚动窗口（7日/日/时三窗）
  · 行为基线漂移增量（节奏/轨迹特征）
  · 熵轴六维分布直方图
边界: 仅统计基线（只读观测的延伸）——
  · 不改路由权重（权重建议由评分函数消费基线实时计算）
  · 不改认证阈值（阈值是慢环资产）
留痕: 每次基线更新带 version+ts，可回放
```

### 5.2 慢环（离线反思，建议书→审批→基线跃迁）

```
输入: 快环基线异常（漂移检测）+回流信号（60号六类+拦截/误拦案例）
     +红队对抗结果（55号 redteam 范式）
生成: 进化假设建议书（disposition 范式——
     proposedAction/expectedGain/riskAssessment/rollbackPlan）
通道: 46号审批总线 submit_change（零改动纯调用）
生效: 审批通过→52号基线管理发布（灰度三态 off→shadow→assist）
     →新基线版本化，旧基线可回滚
```

### 5.3 进化分级治理（对齐参考方案 L0-L3，本站宪法化）

| 级 | 场景 | 自主度 | 本站映射 |
|---|---|---|---|
| L0 观察学习 | 全部新参数 | 仅预测+建议，不参与决策 | PAY69_MODE=off（默认） |
| L1 受限进化 | 低风险统计参数（基线窗口/观测口径） | 域内自动+留痕 | shadow 态（影子≥7天） |
| L2 协同进化 | 路由权重/熵轴/授信因子 | 建议→46号审批→灰度 | assist 态+审批链 |
| L3 生态进化 | 跨模块联邦（68号/37号/同盟） | 远期规划 | 本方案不含（红线：数据主权） |

## 八、合规红线（四可原则）

1. **可解释**：路由/熵/授信/生物每个决策节点绑定确定性特征明细（routeScore/entropyAxes/creditFactors 留痕入归因链）
2. **可审计**：进化全链四要素（动因/数据/结果/审核）入 46号台账；快环基线版本化可回放
