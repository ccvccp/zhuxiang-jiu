## 一、模块定位

竹园(zhuyuan)是 80 号网站资产智能管理与自进化 Agent, 竹氏三兄弟第三位: 竹盾管空间(改动影响面)、竹医管时间(业务链)、**竹园管资产养护**。前沿 AI 管理系统规划书裁剪为轻量 Python CLI 工具链(禁常驻 LLM/向量库/LangGraph), 五检查器职责分离: **audit 盘点 / comply 合规 / probe 探针 / prescribe 处方 / evolve 自进化**, 辅以 stats 度量与 loop 闭环演示。
