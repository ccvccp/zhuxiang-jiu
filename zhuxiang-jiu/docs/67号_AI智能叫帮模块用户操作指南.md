# AI智能叫帮 · 用户操作指南

> 让求助不再羞耻，助人不再廉价。在这里，每一次互助都会被记录为您的**信值**——它比金钱更珍贵，是您在这个社区里值得被信任的证明。

---

## 一、这是什么？

AI智能叫帮是一个**邻里互助平台**：您可以发布自己力不能及的求助，也可以接下别人的求助搭把手。

它有两种互助方式：

| 方式 | 说明 | 完成后获得信值 |
|---|---|---|
| **公益互助** | 无偿帮忙，社区优先响应 | 按时长 100% 记录 |
| **有偿互助** | 双方协商价格，平台**零佣金** | 按公益标准的 10% 记录 |

**信值有什么用？**
- 它是您互助履历的量化证明，显示在您的档案中；
- 累计信值 ≥ 20 后解锁**有偿接单**资格；
- 服务评分（他人给您的星级评价）会伴随您的互助生涯。

---

## 二、如何进入

1. 打开 https://zxjiu.com 并登录；
2. 进入「我的」页面；
3. 在「经营活动」区块点击 **AI智能叫帮**（描述为"信值互助 · 公益100%/有偿10% · 零佣金"）。

> 未登录状态下进入页面会提示登录，互助全程需要实名账号参与。

## 三、页面总览

进入后页面从上到下分为四部分：

```
┌─────────────────────────┐
│  我的互助信值卡片          │  ← 总信值 + 荣誉徽章 + 公益/有偿/评分三格
├─────────────────────────┤
│  互助大厅 | 发布求助 | 我的互助 │  ← 三个主标签
├─────────────────────────┤
│  （当前标签的内容区）       │
├─────────────────────────┤
│  互助信值规则说明          │  ← 页面底部常驻规则
└─────────────────────────┘
```

**信值卡片**说明：
- **总信值**：公益信值 + 有偿信值的合计；
- **荣誉徽章**：按公益信值判定的等级（🥉铜心 → 🥈银心 → 🥇金心 → …），带进度条显示距下一级的距离，详见第七节；
- **公益信值 / 有偿信值(10%)**：双轨分开累计，一眼看清自己的贡献结构；
- **服务评分(n)**：他人对您的平均星级（被评价次数）；
- 若总信值不足 20，卡片下方会提示「公益互助积累 20 信值后解锁有偿接单」。

## 四、互助大厅：接单帮人

### 4.1 浏览求助

大厅展示附近待接单的求助，顶部有两排筛选：

- **模式筛选**：全部 / 公益 / 有偿；
- **类型筛选**：全部 / 维修互助 / 陪护出行 / 搬运帮手 / 照看陪伴 / 技能传授 / 其他求助。

列表排序规则：**紧急求助优先置顶 → 您常接的类型在前 → 距离近的在前 → 新发布的在前**。

> 💡 **个性化推荐**：系统会学习您常接的互助类型（历史完成频次较高的类别），命中时卡片上会显示"✨ 您常接「XX」类互助"金色徽章并排在前面——帮熟悉的事，更顺手。

### 4.2 看懂一张求助卡

每张卡片包含：

| 元素 | 说明 |
|---|---|
| 「紧急」红标 | 求助者开启了紧急求助，优先展示 |
| ✨ 偏好徽章 | 系统识别为您常接的类型（个性化推荐） |
| 公益 / 有偿 ¥xx | 互助模式；有偿会显示协商价格 |
| 类型 + 标题 + 描述 | 求助内容 |
| 类别 · 时长 · 信值 +X · 距离 X km | 完成后帮助者可获得的信值、与您的距离 |
| 💛 社区已捐 X 信值 | 该单已获得的社区捐赠（完成时额外奖励帮助者） |
| 📍 地址 | 求助发生地点 |
| 「接单」按钮 | 点击即参与（自己发布的单不显示此按钮） |
| 「💛 为这份公益捐赠信值」 | 高信值用户可见，详见第六节 |

### 4.3 接单流程

```
看到合适的求助 → 点「接单」→ 确认弹窗（显示可得信值）
→ 接单成功（跳转到"我的互助"）→ 联系求助者 → 点「开始服务」
→ 服务做完后任一方点「确认完成」→ 双方互相评价 → 信值到账
```

**接单须知：**
- 公益单**零门槛**，新用户也能立即接单赚首笔信值；
- 有偿单需累计信值 ≥ 20；
- 同时只能有 **1 单**进行中，完成当前单后才能接下一单；
- 不能接自己发布的求助。

## 五、发布求助：发出您的需求

### 5.1 AI 智能填单

切换到「发布求助」标签，输入标题和描述后，系统会**自动分析**您的需求：

- 💡 自动识别求助类型（如写到"灯坏了"会自动选中维修互助）；
- 💡 自动推荐互助模式（如提到"独居老人""腿脚不便"会推荐公益模式并提示社区优先响应）；
- ⚠ 如内容包含违禁项（代考、涉黄、赌博等），会直接提示不可发布。

### 5.2 填写表单

| 字段 | 说明 |
|---|---|
| 求助标题 | 必填，60 字以内 |
| 详细描述 | 选填，写清时间地点/特殊情况，帮助别人了解需求 |
| 模式选择 | 「公益互助(信值 100% 记录)」或「有偿互助(信值 10% · 零佣金)」 |
| 求助类型 | 六选一，AI 已帮您预选，可手动修改 |
| 时长(分) | 预计耗时，最少 10 分钟 |
| ¥ 协商价 | 仅有偿模式显示，须大于 0，由双方线下协商 |
| 地址 | 选填文字描述，如"历下区甸柳小区 3 号楼" |
| 紧急求助 | 开启后单子在大厅**优先置顶**展示 |

点击「发布求助」后弹出单号与信值预览，即进入大厅等待接单。

### 5.3 互助接力（偏远地区适用）

发布表单中开启「互助接力」开关，可将求助拆成 **2~5 段**，由多位邻居分段接力完成：

- 每段独立接单、独立开始/完成，大厅会显示"接力 x/N段"和当前段位置；
- 一段完成后，求助自动回到大厅等待下一段的帮助者；
- 总信值按段均分（末段补差，总和恒等），每段完成即时到账；
- **已有完成段的接力单不可取消**——已履约的善行不可撤；
- 适合跨村/跨镇的物资转运等一位邻居难以全程完成的场景。

### 5.4 发布须知

- 每人最多同时保持 **3 单**待接单，避免求助积压；
- 公益单完成后，**您（发布者）也会 +1 感谢信值**——受助也是有价值的记录；
- 有偿单的价格请双方提前沟通清楚，平台仅做确认与留痕，**不收取任何佣金**，也不参与资金环节。

## 六、我的互助：履约与评价

「我的互助」标签分为三个区块：

1. **我接的互助**：您作为帮助者的单子；
2. **我发布的求助**：您作为求助者的单子；
3. **信值流水**：每一笔信值变动的明细（何时、何因、加减多少）。

### 6.1 单子的一生

```
待接单 ──(有人接单)──→ 已接单 ──(开始服务)──→ 服务中 ──(确认完成)──→ 已完成
  │                     │
  └──(取消)──→ 已取消   └──(帮助者取消, 扣 2 信值)──→ 已取消
```

**各阶段可执行的操作：**

| 状态 | 帮助者可做 | 发布者可做 |
|---|---|---|
| 待接单 | — | 取消 |
| 已接单 | 开始服务 / 取消(扣 2 信值) | 取消 |
| 服务中 | 确认完成 | 确认完成 |
| 已完成 | 评价 | 评价 |

> 服务一旦开始就不能取消了——双方请沟通好再点「开始服务」。

### 6.2 评价

单子完成后，双方都可以给对方打 1~5 星并留言（每个方向一单一评）：

- **发布者评价帮助者**：星级会累计进帮助者的服务评分；
- **帮助者评价发布者**：作为对方的信用参考；
- 评价请客观真实，恶意差评同样会伤害社区信任。

### 6.3 互助故事卡

完成互助后，单子卡片上会出现「故事卡」按钮。点击可查看一张温暖的互助故事卡：

- **类别文案**：每种互助都有一句专属的话（如照看陪伴是"一次耐心的陪伴, 是最长情的告白。"）；
- **双方评价摘录**：互助中彼此最真实的反馈；
- **分享文案**：一键复制，可分享到朋友圈或社区，让善意被更多人看见。

## 七、荣誉体系与信值捐赠

### 7.1 荣誉徽章（数字功德碑）

您的信值卡中会显示当前荣誉等级——善行会被永远铭记：

| 荣誉 | 所需公益信值 | 徽章 |
|---|---|---|
| 见习互助者 | 0 | 🌱 |
| 铜心志愿者 | 10 | 🥉 |
| 银心志愿者 | 50 | 🥈 |
| 金心志愿者 | 100 | 🥇 |
| 白金守护者 | 300 | 🏆 |
| 功德圆满 | 1000 | 🌳 |

徽章下方有进度条，显示距下一级还差多少公益信值。

### 7.2 信值捐赠：让善意流动

如果您是高信值用户（累计信值 ≥ 50），可以在大厅看到"💛 为这份公益捐赠信值"入口：

- **捐什么**：从自己的信值中捐出 1~10 点，注入某个待接单的公益求助；
- **给谁**：该求助完成时，捐赠池将**全额额外奖励给帮助者**——让伸手帮忙的人得到更多认可；
- **限制**：每个求助每人限捐一次；捐赠即时从您的信值中扣减；
- **意义**：您的每一笔捐赠都记录在信值流水中，是反哺社区的善行证明。

### 7.3 信值传承：数字功德碑

在「我的互助」页有"🌳 信值传承 · 数字功德碑"入口——**公益信值可以传承给亲人，让善行代代相传**：

- **可传承范围**：仅**公益信值**（有偿信值不可传承）；发起人需有 ≥10 公益信值；
- **流程**：发起人指定受让人（成员编号）与额度（留空 = 全部公益信值）→ 受让人在传承页**确认承继** → 即时划转；
- **留痕**：转出与承继双边信值流水记录，永久可查；
- **限制**：每人同时仅一笔待确认传承；不能传承给自己；实际划转额按确认时点的公益信值净值封顶；
- 荣誉等级跟随公益信值净值实时变动——传承后原持有者等级相应下调，承继者获得相应信值。

## 八、信值规则速查

### 8.1 信值怎么算

**公益信值 = 类型基准 × 时长（小时，不足 1 小时按 1 小时计）**

| 求助类型 | 基准信值/小时 | 示例（公益 90 分钟） |
|---|---|---|
| 照看陪伴 | 12 | 12 × 2 = 24 |
| 维修互助 | 10 | 10 × 2 = 20 |
| 技能传授 | 10 | 10 × 2 = 20 |
| 陪护出行 | 8 | 8 × 2 = 16 |
| 搬运帮手 | 8 | 8 × 2 = 16 |
| 其他求助 | 6 | 6 × 2 = 12 |

**有偿信值 = 同口径公益信值 × 10%**（例如上表 20 分的有偿单记 2 分）。

### 8.2 奖惩一览

| 行为 | 信值变化 |
|---|---|
| 完成公益互助（帮助者） | + 信值奖励（100% 记录）+ 荣誉等级提升 |
| 完成有偿互助（帮助者） | + 信值奖励（10% 记录） |
| 公益单完成（发布者） | +1 感谢信值 |
| 完成带捐赠的公益单（帮助者） | + 基础信值 + 社区捐赠池全额 |
| 信值捐赠（高信值用户） | − 捐赠额（即时扣减，入单捐赠池） |
| 信值传承划转（发起人） | − 划转额（公益信值，受让人等额承继） |
| 完成互助接力的某一段（该段帮助者） | + 段信值（总信值/段数） |
| 接单后无故取消（帮助者） | −2 |
| 服务被差评 ≤ 2 星（帮助者） | −5 |

## 九、常见问题

**Q1：我是新用户，信值是 0，能接单吗？**
能。公益单零门槛，正是为您积累首笔信值设计的。只有**有偿单**才需要累计信值 ≥ 20。

**Q2：有偿的钱怎么结算？平台抽成吗？**
价格由双方协商、线下当面结算，平台**零佣金**、不经手资金，仅对协商结果做确认与留痕。

**Q3：为什么我看不到某条求助？**
大厅默认展示基准位置 20 公里内的待接单求助，可用筛选切换模式或类型。距离以济南市区（历下区）为基准计算，逐单显示具体公里数。

**Q4：接单后临时有事去不了怎么办？**
在「已接单」状态可取消，但会扣减 2 信值（用于约束随意放鸽子）；一旦点了「开始服务」便不可取消，请谨慎操作。

**Q5：对方服务很差，我能给差评吗？**
可以。完成互助后您可给 1~5 星评价；作为发布者给出 ≤2 星的差评，系统会按核实口径扣减帮助者 5 信值。请基于真实体验评价。

**Q6：信值可以提现或转让吗？**
不可以。信值是社区信任的记录，不是流通货币。它的价值在于：解锁有偿接单资格、展示您的互助履历与服务评分。但高信值用户可以通过**信值捐赠**反哺公益（详见 7.2 节）。

**Q7：发布什么样的内容会被拒绝？**
包含违禁内容（代考、代写论文、涉黄、赌博、洗钱、刷单、办证等）的求助会被系统自动拦截，无法发布。

**Q8：大厅里"✨ 您常接「XX」类互助"是什么意思？**
这是系统的个性化推荐：您历史上完成较多的互助类型会被标记并排在列表前面，方便您更快找到顺手的事。紧急求助始终优先展示，不受偏好影响。

**Q9：荣誉等级会降级吗？**
荣誉实时跟随您的**公益信值净值**：多帮人、多行善就稳步晋级；若在公益互助中有违约扣减，数值回落也可能导致等级下调。持续行善是保持荣誉的唯一方式。

**Q10：我捐出的信值去哪了？**
即时进入该求助的捐赠池。若该求助最终完成，捐赠池全额奖励给帮助者（与基础信值叠加）；若求助被取消，捐赠池随单关闭（后续版本将支持退还）。每笔捐赠都记录在您的信值流水中，随时可查。

**Q11：接力互助的单子我怎么接？**
和普通单一样点「接单」——你接的是当前活跃段（大厅卡片会标注当前第几段及位置）。完成后该段信值即时到账，下一段自动开放给其他邻居。同一个人可以接多个段（不违反在忙规则，因为每次只占一段）。

**Q12：传承发起后受让人一直不确认怎么办？**
待确认传承会一直保留（不设过期）。发起人无法单方面撤回，划转以受让人确认时点的公益信值实际净值为准（不足 10 时确认会失败）。如需变更额度或受让人，请与对方协商后由其拒绝确认之外的方式处理（当前版本暂不支持撤回，后续将增加撤回功能）。

**Q13：信值卡里"🌱 互助碳减排"是什么？**
您的每次互助也在为环境出力：搬运代替货运出行、陪护拼车代替各自驾车、维修延长物品寿命……系统按"时长 × 类别系数"确定性折算您的碳减排量（公益单 100%、有偿单 50%、接力单按段均摊）。它是**只读的荣誉记录，不可交易、不可兑换**——善意本身不需要标价。

## 十、互助公约

- **量力而行**：接单前看清时长、地点与要求，不逞强；
- **守时守约**：接了就认真做，有事提前取消；
- **与人为善**：老人耳背请大声说话，受助了记得道声谢；
- **如实评价**：好服务给好评，差体验敢差评，不恶意也不客套。

> 最好的互助，是让人忘记算法的存在，只记住被善待的瞬间。
