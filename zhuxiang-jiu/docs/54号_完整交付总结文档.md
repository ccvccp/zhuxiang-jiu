## 一、模块概览

**54号是小竹登录体系的收口大模型**。53号多模态编排交付了"通道选择"，54号在其上构建**八因子信任分模型 + 自进化闭环**：决策回流 → Hedge 在线学习 → 评估晋升 → 漂移监控 → 治理红线。核心铁律：与 43号 auth_risk **并行评分取 max**（互补不替换不侵入）；与 44号学习中枢、46号治理中枢**全链复用**（不重造轮子）；双开关默认 off **零影响交付**。

```
53号登录事件(六字段审计) ──→ 54号决策回流(七类信号源真值标注)
                                    │
43号 auth_risk ──┐                  ↓ 44号反馈池双写
                 ├─→ max 合成 ──→ Hedge 学习(护栏[0.5,2.0])
54号八因子信任分 ─┘                  ↓
                              挑战者影子 → 晋升(自动/手动)
                                    ↓
                       滑动窗口回归检测 → 自动回滚+冻结
                                    ↓
                    46号治理(冻结/审批/三检测) + 看板+红队防御
```

**核心数字**：六期交付 / 专项 200 断言（验收日全量复跑全过）/ **实机 44 项次（22 项×2 轮幂等）** / 红队 RT-01~04 全拒（内存态+Redis 态双层复验）/ 13 端点 / 2 表 + 复用 44号双池 / 1 调度器 / 核心代码约 2780 行 / 44/46/53号零改动（宪法断言每期验证）/ 9 笔提交（计划+六期代码+文档三件套+实机验收）/ Docker 部署态：镜像 dc8841081c12 容器 healthy。
