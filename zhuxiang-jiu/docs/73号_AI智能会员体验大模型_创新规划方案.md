## 一、核心设计理念：隐私约束下的体验自主进化

### 1.1 参考方案四位一体 → 本站五维范式

参考方案确立"会员意图预判+权益动态编排+愉悦度驱动进化"三位一体与"隐私约束下的体验自主进化"；本站叠加**项目宪法第五维**，构成"确定性执行"五维范式：

```

│ 维一 意图预判: 关键动作瞬间×升级视野×下一步操作            │
│         (确定性触发分——"你已接近, 只差一步")              │
├─────────────────────────────────────────────────────────┤
│ 维二 无感度量: 操作步骤/认知负荷/等待时间/打扰频率          │

│ 维三 权益编排: 升级前后权益对比卡片+秒级生效清单            │

├─────────────────────────────────────────────────────────┤
│ 维四 信任对齐: 四可原则(可解释/可撤回/可验证/可遗忘)       │

```

### 1.3 与现有模块的边界（叠加式铁律）

- **member v1.0** = 等级底盘（成长值/积分/资料）——73号**永不直接变更等级**，升级永远由消费自然累积成长值触发
- **智客 zk** = 运营智能层（**网站视角**：群体洞察/流失预警/权益匹配建议书）——73号 = 体验共生层（**会员个体视角**：引导时机/无感代办/权益告知/信任面板）。**分界线：智客回答"网站该对会员群体做什么"，73号回答"这位会员此刻的体验该怎样"**；智客 benefit-match（群体建议书）≠ 73号 benefits/reveal（个体实时告知）
- **45号信值/68号雷达** = 信值五维域（诚信/互助/专业/活跃/成长）——73号消费 member 成长值与智客健康度作输入，**永不输出信值分**（68号边界继承智客口径）
- **50号积分引擎** = 积分域——73号仅消费积分余额做权益领取代办
- **46号** = 审批唯一；**49号** = 隐私预算唯一（画像删除与脱敏导出联动）

**拼图定位**：member=等级**底盘**（是什么等级）→ 智客=运营**大脑**（网站怎么运营会员）→ **73号=体验**神经末梢**（会员个体的每次触达是否恰到好处）**。

## 四、六大能力升维（智能重构 × 进化机制 × 宪法铁律）

### 4.1 会员自主管理 → 生命周期自愈观测（P1）

- **智能重构**：消费智客 churn-scan/health（只读）+member 有效期/保级消费——生成**个体升级视野**（当前等级→下一等级缺口金额/预计自然到达时间[历史消费速率确定性外推]/保级风险窗）
- **进化机制**：新会员冷启动=影子期（7 天只观测不引导——71号影子冷启动范式）；保级风险窗临近→关怀触发分独立计算
- **铁律**：等级判定零重复（member _calc_level 唯一）；LTV/流失判定零重复（智客唯一）——73号只做"视野呈现"

### 4.2 升级智能引导 → 情境嵌入式价值唤醒（P1 核心）

- **智能重构**：**触发分**=f(动作类型权重, 成长值缺口比例, 场景上下文[时段/入口], 静默窗, 24h 打扰余量)——确定性查表；超阈值→生成 hint 文案（"您已完成本次消费，距离 L3 竹林会员仅差 ¥xxx"——数字 100% 查询层插值）；呈现形式（进度条微动/卡片/浮层语义）按历史响应率排序
- **进化机制**：每 hint 记录 shown→响应（点击/升级完成/忽略）→响应率滚动统计→低效形式降权；"价值感知断点"（连续忽略≥N→缺口叙事策略变更）
- **铁律**：**引导只产文案与时机，升级动作永远消费自然累积**（member 成长值机制零改动）；静默窗内永不触发；24h 打扰封顶

### 4.3 权益实时告知 → 动态可视化与即时兑现（P1）

- **智能重构**：**升级前后权益对比卡片**（L2→L3：折扣变化/专属权益/免邮阈值——member 等级规则表确定性生成）；升级完成事件→即时告知留痕（reveal 记录+秒级生效清单：积分加速/专属标识即生效类 vs 需领取类区分标注）
- **进化机制**：权益使用率回流→展示优先级动态排序；低频权益折叠/高频置顶
- **铁律**：权益内容零编造（等级规则表唯一事实源）；"秒级生效"仅限既有即效权益，需领取类明确标注领取入口

### 4.4 繁琐操作替代 → 预判式代办与授权台账（P3）

- **智能重构**：**下一步操作预判**（订单完成→评价/收货地址确认/积分兑换到期——历史序列频率统计 top1）；**代办白名单三档**：低风险（资料补全/积分权益领取提示）授权后可代、中风险（续费预填——预填不代付）、高风险（跨平台绑定/支付类——仅单步确认引导，永不代办）；grant/revoke 台账（per-action 粒度）
- **进化机制**："隐性容忍度"=授权位图本身（grant 记录即边界）；代办中断案例→失败原因回流
- **铁律**：**授权域外永远拒绝**（越权=红队 RT-03 级事件）；revoke 即时生效且留痕；代办执行全部可解释（依据+快照）

### 4.5 互动无感化 → 无感度得分与环境自适应（P2）

- **智能重构**：**无感度四维公式**（0-100）：操作步骤数（越少越好）/认知负荷（表单字段数）/等待时间（接口均时）/打扰频率（24h 触达次数）——加权确定性计算；**时段静默**（夜间窗免打扰——注册时默认开启可改）+**每日打扰封顶**
- **进化机制**：无感度得分=进化验收核心指标（任何进化提案附"无感度影响预估"）；越封顶→当日非必要触达自动熔断（保护方向自动+留痕）
- **铁律**：无感度计算全留痕（四维原始值可复现）；静默参数变更走 46号建议书（用户改自己设置除外——用户即否决权）

### 4.6 信任透明化 → 四可面板与遗忘（P4）

- **智能重构**：**用户侧信任面板**（登录态自助查询）：可解释（"AI 为我做了什么"——本会员全部触达/代办留痕+依据）/可撤回（授权一键 revoke）/可验证（个人信任报告：打扰统计/响应统计/权益获益汇总）/可遗忘（画像删除——73号表硬删除+删除 seq 留痕，智客分析层引用 best-effort 置空）
- **进化机制**：负反馈学习（连续 revoke/忽略→该会员触发分全局降权）；信任报告周期统计
- **铁律**：面板仅本人数据（member 鉴权惯例）；删除永不影响 member 账户本体（只删 73号体验层数据）；admin 侧报告与用户侧面板数字同源

## 五、三层自进化引擎（参考方案快适应/深反思/元认知——本站宪法化）

### 5.1 快适应层（在线微更新，域内自动+全留痕）

- 触发分阈值随响应率微调（滑动窗口）
- 24h 打扰计数滚动维护；封顶熔断/次日恢复
- 展示形式排序随点击率滚动更新
- 代办预判 top1 随行为序列频率更新

### 5.2 深反思层（每日离线，统计→建议书）

- 响应率全量统计→形式淘汰清单→46号建议书
- 无感度四维日报（哪些环节最费操作）
- "价值感知断点"挖掘（连续忽略模式）
- 授权撤销模式分析（哪类代办最遭拒→叙事优化建议）

### 5.3 元认知层（漂移监控+红队+自省）

- **漂移监控**：触达总量异常（骚扰化）/响应率骤降（形式失效）/撤销率异常（信任受损）→**自动冻结进化+告警**
- **红队四向量**：RT-01 打扰轰炸（伪造高频触发骗过封顶）/RT-02 诱导升级（伪造紧迫感文案——文案模板外的注入）/RT-03 越权代办（白名单外动作伪造授权）/RT-04 画像投毒（异常字段注入伪造缺口）
- **冷启动影子期**：新会员 7 天只观测（触发分计算但不呈现——影子留痕）

## 六、三段四档模式（71号范式平移——体验域档位设计）

```
MEMBER73_MODE 环境变量四档(默认 off):

off     观测面常开(视野查询/无感度统计/信任面板只读), 触达面关闭
shadow  触达面开·留痕不呈现——hint 文案生成入库但不推送
        (影子期≥7天, 用户级冷启动同样适用)
assist  触达面开·建议注入——hint/代办建议推送前端确认位,
        代办执行永远显式授权
full    低风险触达域自主(hint 呈现/静默规则/形式排序——
        L1 白名单内); 代办/权益变更仍 assist(授权显式)

MEMBER73_KILL 一键静默(数据面+环境变量双保险)——
回退 off, 观测面保留(参考方案"紧急静默"宪法化)
```

**档位创新**：体验域"只产文案不碰资金/等级"——full 档开放面比 72号更宽（触达呈现可 full），但**代办域因涉用户授权永远 assist**（授权显式性优先于自主性）。

## 八、API 设计（22 端点，前缀 /api/member73；member v1.0 + zk 20 端点零改动）

**升级视野与引导（P1，8）**：
- `GET /api/member73/horizon/{member_id}` 升级视野（缺口/预计到达/保级窗——member 登录态或 admin）
- `GET /api/member73/mentor/dict` 触发分字典公示（观测面）
- `POST /api/member73/mentor/decide` 时机决策（快环——触发分计算+静默校验，MODE 门控呈现位）
- `GET /api/member73/mentor/moments` 时机留痕（admin 观测）
- `POST /api/member73/mentor/{id}/respond` 响应回流（快环）
- `GET /api/member73/benefits/preview/{member_id}` 升级前后权益对比卡片
- `POST /api/member73/benefits/reveal` 升级完成实时告知（决策面 off 409）
- `GET /api/member73/benefits/reveals` 告知留痕（admin 观测）

**无感度与环境（P2，4）**：
- `POST /api/member73/effortless/observe` 交互观测上报（快环——步骤/字段/等待）
- `GET /api/member73/effortless/{member_id}` 无感度得分（观测）
- `GET /api/member73/adapt/{member_id}` 自适应参数（静默窗/频率余量——观测）
- `POST /api/member73/notify/mute` 静默时段设置（用户面——本人）

**预判代办（P3，5）**：
- `POST /api/member73/delegate/grant` 授权（用户面——本人）
- `POST /api/member73/delegate/revoke` 撤回（用户面——本人）
- `GET /api/member73/delegate/grants/{member_id}` 授权台账（本人/admin）
- `POST /api/member73/delegate/predict` 下一步预判（决策面）
- `POST /api/member73/delegate/execute` 代办执行（决策面——白名单+授权校验）

**信任面板（P4，3）**：
- `GET /api/member73/trust/panel/{member_id}` 四可面板（本人）
- `POST /api/member73/trust/forget` 画像删除（本人——可遗忘）
- `GET /api/member73/trust/report/{member_id}` 个人信任报告（本人/admin）

**治理（P5，2）**：
- `GET /api/member73/model/status` 模式/健康/版本（观测）
- `POST /api/member73/redteam` 红队四向量（决策面 off 409；monitor 类入 effortless/漂移观测）

## 九、宪法铁律（十则）

1. **LLM 禁入判定链**：触发分/无感度/预判排序/时机三态=确定性公式（查表+统计），LLM 仅组织 hint 文案模板（数字 100% 插值）
2. **等级变更永不自动**：升级永远由消费自然累积成长值触发（member 机制零改动）；73号只产时机与文案
3. **授权白名单宪法**：代办仅白名单三档内执行；授权域外永远拒绝；revoke 即时生效留痕
4. **资金类永不代办**：续费只预填；支付/跨平台绑定仅单步确认引导
5. **四可原则**：可解释（动作日志+依据）/可撤回（一键 revoke）/可验证（个人报告）/可遗忘（硬删除+seq 留痕——49号隐私预算联动）
6. **零重复**：等级判定唯一（member）/信值唯一（45·68号）/运营洞察唯一（智客）/审批唯一（46号）——73号只做体验编排
7. **打扰封顶**：24h 触达上限；封顶越线→当日非必要触达熔断（保护方向自动+留痕）；静默窗内永不触发
8. **决策可解释**：每 hint/reveal/delegate 留痕输入特征×规则依据×数值明细（71号链路图范式）
9. **可回滚**：MEMBER73_KILL 双保险静默；授权可撤回；影子期留痕不呈现
10. **数据最小化**：moments 上下文仅脱敏字段；trust_log 面板仅本人可见；画像删除不影响账户本体

## 终局愿景（参考方案精神·本站版）

当会员不再为"如何升级"而困惑——因为视野引擎总在他完成关键动作的瞬间轻声告知"你已接近，只差一步"；不再因"被推销"而反感——因为无感度得分让每次打扰都恰如其分，深夜永远安静；不再为"操作繁琐"而放弃——因为授权过的琐事早已静默完成；不再因"被窥探"而警惕——因为四可面板让他随时知道 AI 做了什么、为何而做、并可一键撤回与遗忘——会员体系便从冰冷的等级制度，蜕变为有温度、有分寸、有成长的体验伙伴。

73号是这一蜕变的实践起点：让每一次触达都有时机依据，让每一分打扰都有无感度约束，让每一次代办都有授权边界，让每一次进化都有信任回报。
