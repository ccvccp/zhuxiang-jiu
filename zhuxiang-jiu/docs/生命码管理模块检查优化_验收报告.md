## 四、排查沉淀（工程范式）

1. **用户端端点鉴权头**：activate/scan/transfer 需 `X-Member-Id` 头——body 中 userId 不替代鉴权头（缺失 401）。
2. **Redis 清理盲区教训**：实体键（`box:{id}`/`life:{id}`/`scan:{id}`）的批次信息在**值**不在键名——仅按键名清理必漏实体键，须"键名或值"双匹配。
3. **前缀区分**：`zhuxiang:trace:*`（带冒号）不匹配 `zhuxiang:traceprod:*`，避免清理误伤。
4. **AI 决策门**：激活链路含 `enforce_trace_activation`（22号追溯 AI 升级），`AI_ENFORCE_MODE` 默认 observe 仅评分快照不拦截，enforce 模式 high 拦截——fail-open 兜底。
5. **trace 测试范式**：脚本式（python 直跑），pytest 会收集 0 项——勿误读为"无测试"。
