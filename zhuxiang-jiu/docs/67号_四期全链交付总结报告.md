## 一、模块定位

AI智能叫帮模块是**信值驱动的互助网络**（非劳务交易中介），践行"让求助不再羞耻，助人不再廉价，信值成为比金钱更珍贵的通行证"的设计哲学：

- **公益优先**：公益互助信值 100% 记录（社区优先响应），有偿互助仅 10%（比公益低 90%，比例不可篡改）
- **平台零佣金**：有偿价格双方协商、线下结算，平台零资金流零抽成，仅确认与留痕
- **信值约束**：双轨信值双向约束求助者与帮助者——门槛准入、违约扣减、差评惩罚
- **确定性铁律**：需求解析、匹配评分、信值结算、碳折算、信任指数全部为可解释规则代码，**LLM 禁入判定链**
- **信值为锚、公益为尊、AI 为桥**：技术精度转化为人性温度——最好的算法是让人忘记算法的存在

### 2.1 P0 基础互助（信值网络地基）

**全生命周期闭环**：发布 → 接单（分布式锁防抢单并发）→ 开始 → 完成（信值结算）→ 双向评价；取消支持违约扣减。

- **需求智能解析**：关键词规则表识别六类求助（维修/陪护/搬运/照看/技能/其他）+ 公益/有偿模式推荐 + 违禁词安全预检（代考/涉黄/赌博等拒发）
- **LBS 大厅**：紧急优先 → 距离近 → 新单排序；半径 ≤200km 强校验（Pydantic 边界）
- **双轨信值公式**（宪法级口径）：公益 = 类别基准 × 时长(h) × 100%；有偿 = 同口径 × 10%（`PAID_TRUST_RATIO=0.10` 不可配置）
- **门槛设计**：公益接单零门槛（冷启动：新用户零信值即可助人赚首笔信值）；有偿需 ≥20
- **奖惩确定性**：接单后取消 −2、差评 ≤2 星 −5、公益单发布者 +1 感谢信值

### 2.2 P1 智能调度（人性化连接）

- **三维匹配引擎**（信值匹配 40% + 同类经验 30% + 地理最优 30%）：Top3 候选 + 可解释推荐理由（信值/经验/评分/距离），观测面不自动派单
- **意愿偏好学习**：历史完成频次 ≥1/3 的类别视为偏好类，大厅命中置前并显示"✨ 您常接「XX」类互助"徽章；排序优先级：紧急 > 偏好 > 距离 > 新单（紧急不可被偏好覆盖）
- **互助故事卡**：确定性模板（类别文案 + 双方评价摘录 + 分享文案），让善意被看见、被传播
- **安全护航**：类别化破冰提示（如"老人耳背请大声说话"）+ 超时温和提醒（预计时长 150%）；**观测不干预，惩罚/处置永不自动**（46号铁律）
- **信值捐赠**：高信值用户（≥50）可向公益单捐 1-10 信值，完成时全额额外奖励帮助者——让善意流动
- **荣誉体系**（数字功德碑）：🌱见习(0) → 🥉铜心(10) → 🥈银心(50) → 🥇金心(100) → 🏆白金守护者(300) → 🌳功德圆满(1000)，实时进度条

### 2.3 P2 生态深化（善行代代相传）

- **信值传承**（数字功德碑核心）：仅公益信值可传承（有偿不可——宪法口径）；双方确认制（发起 → 受让人确认 → 即时划转，按确认时点净值封顶）；双边流水留痕；幂等（每人同时仅一笔待确认）
- **传承撤回**（v2，POST /heritage/{id}/cancel）：双向退出权——受让人可拒收沉默、发起人可反悔；仅 pending 可撤、仅发起人可撤（受让人/无关人 409）；即时生效、留痕不删除（审计口径）；撤回后解锁重新发起；本地实测 10/10 断言 + 生产 e2e 验证
- **企业 CSR 信值包**：企业认捐 10-10000 信值入包（平台零资金流）；定向捐给待接单公益单入捐赠池；每包每单限一次；**不动用个人信值**（包池独立）；B 端反哺 C 端
- **互助接力**（偏远地区场景）：2-5 段分段完成，各段独立接单/开始/完成；段信值均分（末段补差，**总和恒等**）；段完成自动回大厅；全段完成才整单收口（捐赠池归末段帮助者）；**已完成段的接力单不可取消**（已履约的善行不可撤）；段历史帮助者保留可见性

### 2.4 P3 社会影响力（信任的社会输出）

- **碳积分互通**：确定性折算（时长 × 类别系数：搬运 2000 / 陪护 800 / 维修 500 / 技能·照看 100 / 其他 50 克/小时；公益 100% / 有偿 50% / 接力按段均摊）；**只读观测不可交易**（防金融化）——善意本身不需要标价
- **社会信任指数**：100 ×（40%完成率 + 30%好评率 + 20%公益占比 + 10%参与度），四因子全可解释；**生产首报 81.0 分（高信任）**
- **年度互助白皮书**：全量聚合（单量/完成率/双轨信值/类别·荣誉分布/接力·捐赠·传承生态/碳减排总量），零个人身份数据，政府/NGO 可引用口径
- **开放 API**：最小数据集 + CC BY-NC-SA 许可 + 隐私声明，对接政府/NGO 互助平台就绪

1. **荣誉 nextAt 跳级**：降序阶梯取首个更大值导致银心显示"1000 晋升"（应为 100），改为取最小更大值——本地+生产复测通过

5. **categories 路由缺 await**（P0 部署期）：500 修复

## 六、宪法级红线（四期一以贯之）

| 红线 | 落地方式 |
|---|---|
| 有偿信值比例 10% 不可篡改 | `PAID_TRUST_RATIO` 常量，无任何配置通道 |
| LLM 禁入判定链 | 解析/匹配/评分/结算/折算/指数全部确定性规则，可解释输出 |
| 平台零佣金零资金流 | 有偿线下结算、CSR 包池独立、碳积分不可交易 |
| 惩罚/处置永不自动 | 差评/违约扣减经核实口径；护航超时仅温和提醒 |
| 公益为尊 | 公益 100% 记录、零门槛、优先响应、紧急置顶、传承仅限公益信值 |
| 隐私红线 | 白皮书/开放 API 零个人身份数据（CC BY-NC-SA） |
