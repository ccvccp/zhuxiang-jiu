## 一、渠道三态语义(先看懂再配置)

`PAY60_CHANNEL_MODE` 环境变量控制渠道行为(与 pay60 渠道适配层同源口径):

| 模式 | start_pay 行为(业务场景) | 说明 |
|---|---|---|
| `mock`(默认) | 确定性回执自动落账, 返回即 paid + dispatch | 当前生产状态, 全链留痕可审计 |
| `real` | 返回 paying + payParams, **等待真实渠道回调** | fail-hard: 凭证未注入直接拒绝, 绝不静默降级 |
| `mock_fallback` | 尝试 real, 失败回退 mock(留痕 fallback=true) | 灰度观察用 |

- 未接线场景(retail 订单等)不受自动落账影响, 始终等待显式回调。
- 回调幂等: 24h TTL 渠道交易号锁 + paid 状态机双保险, 网关重复通知不重复入账。
- 支付单超时: 30 分钟(`PAY_EXPIRE_SECONDS`), 超时可 `POST /api/payment/{pay_no}/close` 关闭。

## 四、配置步骤(代码就绪后按序执行)

### 4.1 服务器 .env 注入凭证(不落盘原则)

编辑 `/opt/zhuxiang/.env` 追加:

```bash
# --- 05号收款 · 渠道三态(PAY60) ---
# 灰度期建议先 mock_fallback; 稳定后切 real
PAY60_CHANNEL_MODE=mock_fallback

# 渠道主凭证(pay60 fail-hard 校验项; real 模式缺失即拒绝)
PAY60_CHANNEL_KEY=<微信APIv3密钥 或 支付宝应用私钥>

# 分渠道凭证(渠道执行器读取, 建议 JSON 单键或分键)
PAY60_WECHAT_MCHID=1900000000
PAY60_WECHAT_APPID=wxXXXXXXXXXXXXXXXX
PAY60_WECHAT_APIV3KEY=<32位APIv3密钥>
PAY60_WECHAT_SERIAL_NO=<证书序列号>
PAY60_WECHAT_PRIVATE_KEY=<商户证书私钥PEM 或 挂载路径>
PAY60_ALIPAY_APPID=2021000000000000
PAY60_ALIPAY_PRIVATE_KEY=<应用私钥PEM 或 挂载路径>
PAY60_ALIPAY_PUBLIC_KEY=<支付宝公钥 或 挂载路径>
```

权限收紧:

```bash
chmod 600 /opt/zhuxiang/.env
```

> 私钥建议以文件挂载注入(`docker-compose.yml` volumes 只读挂载
> `./data/keys:/app/data/keys:ro`), .env 中只存路径引用, 凭证永不落镜像。

| 渠道 | 配置处 | 填写值 |
|---|---|---|
| 微信 | 商户平台「支付配置」 | `https://zxjiu.com/api/payment/callback/pay` |

### 4.5 切换验证清单(逐层)

1. **容器 env**: `printenv | grep PAY60` 确认三态与凭证注入;
2. **mock 回执关闭**: 钱包充值创建支付单 → `POST /api/payment/{pay_no}/start`
   返回 **paying**(非 paid)——real/灰度回退前不再自动落账;
3. **小额真实支付**(¥100 充值): 真实付款 → 回调验签通过 →
   `pay_callback` paid + `dispatch.granted=true` → 余额入账,
   `channelTradeNo` 为真实渠道单号(非 `MOCK`/`REAL` 前缀);
4. **幂等复核**: 网关重推通知(微信会重试 15 次)→ 不重复入账;
5. **前端**: 支付宝 H5 跳转返回 / 微信支付完成 → 轮询 paid → 余额刷新;
6. **对账**: 次日 `POST /api/payment/reconciliation/start`(admin)核对渠道账单与平台流水。

### 4.6 灰度路径建议

```
mock(当前) → mock_fallback + 凭证注入
           → 观察渠道执行器成功率与 fallback 留痕
           → 稳定后 PAY60_CHANNEL_MODE=real 全量
```

`mock_fallback` 下 real 执行失败自动回退 mock(支付单留痕 `fallback=true`),
业务不中断, 是渠道执行器上线的标准灰度档。
