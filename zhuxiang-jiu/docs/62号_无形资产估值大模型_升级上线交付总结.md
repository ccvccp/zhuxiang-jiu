## 一、背景与目标

62号 P0-P5 已全线交付(资产登记/估值引擎/场景折算/压测/衰减/
阈值/申诉/公平审计/验证回流/红队), 原用**一代开关**: 各服务内联
`current_mode()` 直读 env(7 处重复定义)——无护栏、无运行时切档、
无控制面、无响应标记。本次升级:

- 决策可控(off 关闭 / shadow 观察 / assist 生产)
- 业务护栏(三指标恶化自动暂停)
- 运行时切档(免容器重建, 人工留痕)
- 响应标记(av62Mode 字段)
- 一代开关零调用点改动平滑迁移(同步桥接)

## 二、三态与读取链

`AV62_MODE`(沿用既有变量名):

| 态 | 行为 |
|---|---|
| off(默认) | 7 决策端点 409; 观测/纠错面不受影响 |
| shadow | 决策放行 + 响应留痕标记 `av62Mode` |
| assist | 决策生效(生产档) |

读取链(优先级): **护栏暂停 > 运行时 override > 环境变量 > 默认 off**。

## 三、端点分类(25 → 29)

| 面 | 数量 | 端点 |
|---|---|---|
| 决策面(门控) | 7 | assets 登记、assess 估值、scenarios/convert、stress、activate、threshold/calibrate、redteam |
| 观测面 | 14 | registry、assets 列表/详情、model/status、assessments 列表/详情、scenarios、thresholds、fairness/report、learn/status、dashboard |
| 豁免面(纠错/回流) | 4 | appeals 提交/列表/详情/裁决、feedback/collect(人工铁律: 申诉与回流不受开关影响) |
| 控制面(新增) | 4 | GET /mode、POST /mode/override、POST /mode/guard、POST /mode/resume |

## 四、同步桥接(本次升级核心创新)

既有 7 个服务的 `require_active_mode()` 为**同步函数**且调用点深入
服务层(登记/估值/折算/压测/激活/阈值/红队/申诉重估)。为零调用点改动:

- 进程级快照 `_G`(override/paused/force) + 同步读取器
  `legacy_current_mode()`(强制 > 暂停 > override > env > off)
- 各服务原函数签名不变, 函数体一行委托集中模式层
- env 实时读取; override/pause 由异步操作刷新并持久化
- `legacy_forced(mode)` 上下文: 申诉重估/裁决专用强制态
  (暂停/override 期间仍可重估——申诉不受开关影响铁律)——
  替换原 env 直改写法(os.environ 临时 mutation)
- 服务层门控与路由层 `@_decision` 装饰器读取**同一集中模式层**,
  两层口径永不漂移

## 五、护栏三指标(62号语义)

| 指标 | 基线 | 代理语义 |
|---|---|---|
| appealOverturnRate 申诉翻案率 | 0.05 | 裁决 overturn 占比——估值误判代理 |
| stressFailRate 压测失效率 | 0.10 | 反事实压测不通过占比——估值稳健代理 |
| fairnessAnomalyRate 公平异常率 | 0.05 | 公平审计超阈占比——公平性代理 |

恶化判定: (cur-base)/base > **3%** 自动暂停(基线 0 时 cur>0 即恶化);
留痕 pausedReason/breachTrail(≤50); 恢复须人工 resume(决策留痕)。
全确定性(阈值比较, LLM 禁入)。

## 七、部署转段 SOP

1. 服务器同步: av62_mode_service.py(新)+ 7 服务桥接 + 路由 + 测试
2. `.env` 写 `AV62_MODE=assist` → `docker compose up -d --build backend`
3. 三层自验: L1 `GET /api/av62/mode` → assist; L2 决策冒烟
   (POST /assets 200+标记); L3 观测(registry/model-status 200)
4. 回滚: `sed -i 's/^AV62_MODE=.*/AV62_MODE=off/' /opt/zhuxiang/.env
   && docker compose up -d backend`(秒级)
