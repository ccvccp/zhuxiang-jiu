> 需求: 引入概率型唤醒评分, 为唤醒置信度 EMA 平滑与误唤醒
> 观测提供连续分值数据基础

## 〇、需求 × 现状矩阵(摸底实证)

| 维度 | 现状(xiaozhu_service 摸底) | 差距 |
|---|---|---|
| 唤醒判定 | `detect_wake` 三段容错**全二值**: ①前缀 WAKE_WORDS 七近似音(小竹/小朱/小珠/小猪/小竹竹/小主/晓竹) ②叠词残余剥离 ③句中唤醒截取 | **无连续分值**——近似音不分级(精确"小竹"与弱近似"小主"同权 1/0) |

## 一、P1 三缺口(边界)

### 缺口 1: 唤醒评分函数(核心增量)

```
detect_wake_v2(text) -> (woken: bool, command: str, score: float)
    (旧 detect_wake 签名不动, 内部可委托 v2 保兼容)

评分设计(确定性规则产连续分, 纯标准库):
    1.00  精确"小竹"前缀
    0.90  强近似音(小竹竹/晓竹——韵母同 u 近 a)
    0.80  同韵近似(小朱/小珠/小猪——韵母同为 u)
    0.70  弱近似(小主——韵 zhu→zhu 同, 声调意象弱)
    句中唤醒: 位置衰减 ×0.75(首 1/3)/×0.65(中后段)
              ——越靠后越可能是闲聊误触
    "小X"未注册音: 韵母比对小映射表(u 韵家族 0.5-0.6
              拦截面, 如"小住/小助"——观察留痕不唤醒)
    0.00  无唤醒意象
WAKE_THRESHOLD(默认 0.75, env XIAOZHU_WAKE_THRESHOLD 可调):
    分值 ≥ 阈值 → 唤醒; 近似音全表命中 ≥0.70 + 旧前缀逻辑
    兜底——on 态与旧行为差异仅"未注册 u 韵音留痕不唤醒"
    (旧表外本就不唤醒, 零行为差异)
```

**纯标准库铁律**: 不引 pypinyin——韵母比对用预置小映射表
(仅"小X"两字模式 × u/a 韵家族 ~15 字), 不做全字拼音。

### 缺口 2: 分值留痕(数据基础——EMA 的前提)

- 主链路会话/事件记录增 `wakeScore` 字段: **woken 与
  not_woken 轮均留痕**(not_woken 轮的近音残分 0.3-0.7 正是
  误唤醒观测的关键样本)
- 留痕通道复用既有会话存储(48号 P0 事件留痕惯例), 不新建表

### 缺口 3: shadow 双轨(灰度铁律)

- `XIAOZHU_WAKE_SCORE_MODE=off`(默认): v2 评分**计算+留痕**
  但判定仍走旧 detect_wake——**零行为差异**, 纯观测积累
- `on`: 判定按 WAKE_THRESHOLD 分值化(与旧行为差异面:
  仅"未注册 u 韵音"从旧表外不变仍不唤醒——即实际零差异,
  on 的意义在于阈值可调能力上线)
- 53号 login53_service 调用点: 保持旧 detect_wake(不接评分,
  零破坏), 留 P2 评估

## 二、P2+(触发条件型, 勿提前)

| 项 | 触发 |
|---|---|
| 唤醒分值 EMA 平滑判定 | wakeScore 留痕积累 ≥7 日(shadow 数据) |
| 52号扩"误唤醒率"维度 | 本批 shadow 数据回看后, 挂 52号 五维扩展 |
| 阈值动态化(误唤醒率反馈) | 52号维度稳定 4 周 |
| 53号接入评分 | 48号 on 稳定后 |

## 三、实施路径(四步)

1. 评分函数 + 韵母小映射表 + 单测(分级/位置衰减/未注册音/
   **旧 test_xiaozhu_p0 detect_wake 用例全绿锁兼容**)
2. wakeScore 留痕(主链路 + not_woken 轮) + WAKE_SCORE_MODE
   off 默认 + 单测
3. on 态阈值判定 + XIAOZHU_WAKE_THRESHOLD env + 单测
   (阈值边界/与旧表等价断言)
4. 回归(48号全家族 p0-p5 + 53号 login 相关)→ 生产部署 →
   验收(shadow 留痕分值分布实证/ off 零差异实证)→ 实录回填

## 四、风险控制

- **零破坏**: detect_wake 签名/语义不动(53号与既有单测锁)
- **灰度**: WAKE_SCORE_MODE=off 默认——上线即 shadow 留痕,
  行为零变更
- **纯标准库**: 韵母小表手工预置, 不引第三方
- **fail-soft**: 评分异常回退旧二值判定
- **反语音霸权铁律**继承: 未唤醒不执行的既有语义不变

## 五、ROI 与触发器

- 数据资产: not_woken 轮近音残分分布 = 误唤醒面的**首个
  量化观测**(此前完全盲区)
- 平滑前提: 本批即"证伪关闭档"候选 1 的触发条件落地——
  分值积累 7 日后 EMA 平滑具备对象
- 48号 ROI 触发器: shadow 分值分布稳定 1 周(误唤醒样本
  量 ≥100 轮)→ 评估 on + 启动 P2 EMA 平滑

## 六、P1 实施实录(2026-10-01 上线)

- **评分函数**: WAKE_SCORE_TABLE 七近似音分级(1.0/0.9/0.8/0.7)
  + 句中位置衰减(前 1/3 ×0.75/中后 ×0.65) + "小X"未注册 u 韵
  家族 12 字小表(0.55 观察留痕不唤醒)——纯标准库, 未引第三方
- **detect_wake_v2**: (woken, command, score) 三元组;
  XIAOZHU_WAKE_SCORE_MODE=off 默认判定走旧轨零差异;
  login53_service 调用点未动(旧 detect_wake 签名锁)
- **留痕**: not_woken/wakeup 两个 early-return 轮 extra 增
  wakeScore(成功解析轮 score 恒高无分布信息量, 口径注明);
  wakeup_free 点击模式 score=1.0
- **实施中两处即修**(单测暴露):
  ① 阈值等价性: 初版默认线 0.75 漏掉弱近似"小主"(0.7)——
  on 态将与旧表不等价; 修正 WAKE_THRESHOLD_DEFAULT=0.7
  (=旧 WAKE_WORDS 命中面完全等价)
  ② fail-soft 结构: wake_score 初版在 try 外(评分崩溃穿透)
  + except 分支 score 未定义——挪入 try + 兜底 0.0
- **单测**: test_xiaozhu_wake_p1 6/6(分级/句中衰减/off 零差异
  12 用例全等断言/on 阈值含 env 调低唤醒 u 韵音与越界钳制/
  旧签名锁/fail-soft); 家族回归 61/61 全绿
- **生产验收**: off 默认实证; 六用例评分正确(1.0/0.8/0.7/
  0.55/0.0/句中 0.52)且 v2 与旧判定零差异全 True
- **上线后状态**: XIAOZHU_WAKE_SCORE_MODE=off——评分计算
  +留痕积累中(误唤醒面首个量化观测启动); ROI 触发器: 分值
  分布稳定 1 周(not_woken 残分样本 ≥100 轮)→ 评估 on +
  启动 P2 EMA 平滑
