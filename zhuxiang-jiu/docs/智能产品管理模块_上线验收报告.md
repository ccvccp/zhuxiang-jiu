## 五、验收中发现并解决的问题(工程记录)

### 5.1 基线测试梳理(检查期发现)

- test_product_routes.py 为 **pytest 套件**(82 测试)——直跑
  静默无输出(无 `__main__` 块), 须 `python -m pytest` 运行;
  首版基线误读(直跑无输出被误判)——独立脚本与 pytest 套件
  须区分运行方式
- test_pdm_p2.py 存量 F841 未用变量(pdm_repo)清理

### 5.2 端点计数口径(测试修正实录)

- openapi paths 按路径计数(3 处 POST/GET、GET/PUT 共享路径),
  30 方法端点 = 27 路径——专项断言改用**方法级计数**(≥30 方法),
  "端点"语义对齐方法而非路径

### 5.3 护栏口径预防(承智图教训)

- 智图工单「pending 草稿」自锁教训前置消化: PDM 商品流程态
  (draft/ai_reviewing/manual_reviewing)为流转在途业务常态,
  终审驳回率分母只含**已决状态**(rejected+on_sale)——
  部署前另检查生产 PDM 表零数据, 双保险防自锁
- 实机实证: guard 聚合 total 1(draft)但驳回率 0 不误暂停

## 六、回滚与运维

- **回滚命令**:
  `sed -i 's/^PDM_MODE=.*/PDM_MODE=off/' /opt/zhuxiang/.env && docker compose up -d backend`
- **运行时切档**(免容器重建):
  `POST /api/pdm/mode/override {"mode":"shadow"}`
- **护栏暂停恢复**: `POST /api/pdm/mode/resume`(人工留痕)
- **巡检开关**: PDM_GUARD_AUTO=off 可关(默认 on——
  护栏是保护机制)
- **巡检间隔**: PDM_GUARD_INTERVAL(默认 3600s, 最小 60s)
- **off 态语义**: PDM 决策 16 写端点 409; **force-delist
  安全阀 + 观测面 9 GET + 基础产品 7 端点零影响**——
  off 态下安全处置与消费端浏览完全无碍
