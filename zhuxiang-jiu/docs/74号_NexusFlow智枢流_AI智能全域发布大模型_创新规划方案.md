## 二、命名与定位

### 2.1 命名释义
- **Nexus（智枢）**：内容与平台之间的智能神经中枢——不只是管道，是语义理解与决策核心
- **Flow（流）**：内容不被"发布"，而是像水一样根据地形（平台规则/用户偏好/账号人设）自动改变形态、流向最该去的地方
- **中文名**：智枢·流——智慧中枢，顺势而流

### 2.2 定位跃迁

| 维度 | 传统自动化发布 | NexusFlow 智能发布 |
|---|---|---|
| 内容处理 | 机械裁剪、强制换行 | 按平台调性重写/扩写/缩写（模板化适配） |
| 封面/标题 | 统一使用源文件 | 按平台人格+数据反馈生成多版本 |
| 合规审核 | 关键词黑名单 | 六红线确定性引擎+safe_harbor 例外+警示语注入 |
| 异常处理 | 报错停止人工介入 | 错误归因分级+自愈重试（指数退避/换适配档） |
| 数据反馈 | 仅记录阅读量 | 关联内容特征归因分析，优化下一次生成 |
| 决策依据 | 静态规则 | 实时信号（72号感知）+人设状态+预算系数 |

### 2.3 本站化铁律调和（与源文档的关键分歧处理）

源文档依赖 LLM 生成（AIGC 核心），本站铁律"LLM 禁入判定链"。调和原则：

1. **合规判定 100% 确定性**：六红线引擎=词表+模式匹配+结构校验，零 LLM（源文档亦要求"发布前强制经过确定性规则引擎二次校验"——本站升格为唯一判定层）
2. **内容适配模板化**：平台人格话术=确定性模板拼接+源内容字段插值（73号 hint 范式），LLM 仅作可选辅助改写（NEXUSFLOW74_LLM_MODE，默认 off）
3. **决策编排确定性**：平台选择矩阵/频次封顶/预算分配=查表公式（71号范式），Multi-Agent 协作降维为"策划→创作→审核→运营"四阶段确定性流水线，每阶段留痕可追溯

## 四、酒类合规中枢（zxjiu.com 垂直定制——确定性引擎）

### 4.1 六红线（规则库种子，rule_type=prohibition）

| 红线 | 禁止模式（词表+正则） | 法规依据 |
|---|---|---|
| R1 诱导饮酒 | 劝酒/拼酒/干杯/一口闷/"不喝不是"/"必须醉" | 广告法 §23 |
| R2 醉酒危险形象 | 醉酒/瘫倒/酒后驾车/代驾缺失的饮酒画面 | 平台社区规范 |
| R3 健康功效 | 养生/护肝/助眠/不上头/根治/壮阳 | 广告法+食品安全法 |
| R4 未成年人 | 校园/学生装/动漫联名未标适龄 | 未成年人保护法 |
| R5 绝对化用语 | 国家级/最高级/最佳/国酒/国宴指定 | 广告法 §9 |
| R6 警示语缺失 | 发布包无"过量饮酒有害健康"显著位置 | 平台酒类规范 |

### 4.2 safe_harbor（例外条款——防误杀）

- 专业品鉴/文化科普 + 显著警示语 → 合规
- 持证商家/预包装/正规渠道 → 电商侧合规
- "低度/纯粮酿造/口感柔和"（口感描述）→ 不属 R3

### 4.3 引擎输出四态

`pass`（合规）/ `review_required`（命中灰度边界→人工复核）/ `block`（红线命中）/ `legal_risk`（高危组合）

每条规则携带 `confidence`（官方文档源 0.9+，社区源 0.6-0.8）与 `test_cases`（正反例——红队复用）。

## 七、模式四档（71号范式平移）

| 档 | 语义 |
|---|---|
| off | 观测面常开（规则库/人格/矩阵/数据汇总），发布面关闭（默认） |
| shadow | 适配包生成留痕不输出（影子期≥7 天，评估签核后转 assist） |
| assist | 适配包输出至人工确认位；B 档人工操作发布；**发布永远显式确认** |
| full | 仅 A 档 API 直连低风险域自主（定时发布/警示语注入）；B 档永远 assist（平台操作显式性铁律） |

**KILL 开关**：NEXUSFLOW74_KILL=1 发布面强制关闭，观测面保留。

## 九、铁律与红线（74号九律）

1. **LLM 禁入判定链**：合规判定/平台选择/频次封顶 100% 确定性公式；LLM 仅可选辅助改写且默认关闭
2. **发布显式性**：B 档平台操作永远人工确认（assist 恒定）；full 仅限 A 档低风险域
3. **合规前置**：任何适配包输出前必过六红线引擎；block 级永不进入发布队列
4. **72号零破坏**：感知子系统物理复用，ATTRACT72_MODE 独立生效
5. **数据诚实**：B 档回执必须登记真实结果，未登记视为未发布
6. **免疫自动/解冻人工**：冻结保护方向自动；解冻须 NEXUSFLOW74_IMMUNITY=1 环境变量双保险
7. **进化不自动生效**：规则/权重变更须 46号审批链人工签核
8. **观测面常开**：规则库/数据汇总/看板不受 MODE 影响
9. **广告法优先**：平台规则与广告法冲突时，从严执行
