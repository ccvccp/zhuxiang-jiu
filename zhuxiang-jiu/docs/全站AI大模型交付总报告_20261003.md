## 五、共享工程资产（当日沉淀）

### 5.1 范式与铁律（全模型一致）

- 三态灰度读取链：override > env > off；shadow=观测冻结（进化+AB计数）
- 建议书永不自动（晋升/切档/处置全人工裁决）
- 决策留痕可审计（意图/参数before-after/操作人/时间）
- 进化参数全 clamp 安全阀 + 防刷分闸（同决策同来源只进化一次）
- 合规层权重永不参与进化；LLM 禁入合规与财务数字链

### 5.2 测试与验证总账

| 资产 | 规模 |
|---|---|
| 智搜回归 + 边界审计 | 91 + 67 |
| 智启元回归 | 49 |
| 智运/智法/小竹等专项 | 既有套件全绿 |
| 生产验证脚本（deploy/） | 当日新增 15 个（zs_*×13 + zy 相关） |

### 5.3 工程教训汇编（十三条）

1. Redis 双模式必须双测（str 键事故）
2. Python re 中文非 `\b` 边界 → lookaround
3. NFKC 全角归一（手机输入法）
4. 进化参数跨段污染 → 测试段间隔离
5. clamp ≠ 防刷量 → 同决策同来源闸
6. 声明式注册表校验器（首跑抓不一致）
7. 跨模块联用先核数据字典（命名/省名口径）
8. 参数口径分类：数值 Hash vs 字符串 Hash 分立
9. 断言语义随设计演进（A/B 下"同输入同输出"→"结果集确定性"）
10. 诚实裁剪（不做空心 Agent）
11. fail-soft 全链（LLM 故障永不阻断主链）
12. PowerShell 管线：heredoc 不支持/嵌套引号剥离/git 静默失败重跑
13. 多层引号转义炸防治：验证脚本本地直连生产（文件化最强）
