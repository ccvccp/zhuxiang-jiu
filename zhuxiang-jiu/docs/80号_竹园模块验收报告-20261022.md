## 一、模块定位与架构

竹园(zhuyuan)是 80 号网站资产智能管理与自进化 Agent, 竹氏三兄弟第三位:
竹盾管**空间影响面**(78 号), 竹医管**时间业务链**(79 号), 竹园管**资产养护**——
从前沿 AI 管理系统规划书裁剪为轻量 Python CLI 工具链(禁常驻 LLM/向量库/
LangGraph, 裁剪决策 10 项见方案)。五检查器职责分离:

| 检查器 | 命令 | 职责 | Benchmark/验收 |
| --- | --- | --- | --- |
| audit 盘点 | `zhuyuan audit` | 资产完整性七项口径(占位符/SEO/断链图/ALT/空正文/资质三件套 → 资产台账+度量) | M0: B2 挖空样本 100% |
| comply 合规 | `zhuyuan comply` | 违禁词 regex 引擎(五组规则) → 合规报告归档 | M1: B1 整改实录回放 100% |
| probe 探针 | `zhuyuan probe --url` | Playwright 三探针(基座/转化/信任, 微信 UA 移动视口) → 探针报告归档 | 真实页面正反例+双页验证 |
| prescribe 处方 | `zhuyuan prescribe [--query]` | 三源缺口归一化 → 竹医 cases 检索复用 → 建议+案例引用(只出不施) | 缺口样本→处方含引用 |
| evolve 自进化 | `zhuyuan evolve` | 审查发现 → 五段式案例草稿(入库走人工确认) | 草稿五段齐+确认门铁证 |

辅助件: stats 度量管道(zhuyuan:stats hash, Redis 不可达降级) +
loop 闭环演示(`python agent-infra/zhuyuan/loop.py` 一条命令跑通
盘点→合规→处方→入库四环)。
