## 六、运营机制

**三态语义**：
- off：观测面常开（radar/history/score/prime/price/feedback/neighbor/carbon/level/whitepaper），决策面 409
- shadow：决策留痕不执行
- assist（当前）：决策面开（groupbuy 发布/响应/关闭 · merchant 申请/复评 · guide 导购）

**护栏体系**：
- `POST /api/xinzhi/mode/guard`：A/B 护栏检查（退款率/客诉率/卸载率 三指标恶化>3% → guard_pause 自动暂停+留痕）
- `POST /api/xinzhi/mode/resume`：人工恢复
- `POST /api/xinzhi/mode/override`：运行时切档（免容器重建，人工留痕；空串清除回落 env）

**回滚**：
```bash
sed -i 's/^XINZHI_MODE=.*/XINZHI_MODE=off/' /opt/zhuxiang/.env
cd /opt/zhuxiang && docker compose up -d backend
```
