## 二、大模型二代转段内容(全站范式)

### 2.1 三态灰度 AGREEMENT_MODE(agreement_mode_service.py 新增)

- **三态**: off(默认)/shadow(条款协议观察期)/assist(条款协议辅助期)
- **读取链**: 护栏暂停 > 运行时 override > env `AGREEMENT_MODE` > 默认 off
- **状态存储**: 整档 JSON 单键 `zhuxiang:agreement:mode_state`
- **同步桥接**(62号范式): 进程快照 `_G` + `legacy_current_mode()`
- **红线**: 条款四态状态机(draft/reviewing/published/inactive)语义保留; 观测面永不关停(合规公示口径); LLM 禁入

### 2.2 护栏三指标(条款协议·法律合规语义, 恶化>3% 自动 guard_pause)

| 指标 | 口径 | 基线 | 恶化代理 |
|---|---|---|---|
| 条款停用率 agreementInactiveRate | inactive / 已决条款(published+inactive) | 0.10 | 已生效条款被停用(合规失效) |
| 协议停用率 protocolInactiveRate | inactive / 已决协议(active+inactive) | 0.10 | 角色协议配置失效 |
| 版本失配率 versionMismatchRate | 旧版同意 / 总同意 | 0.10 | 条款更新后用户未重签(法律风险) |

**口径铁律**(承智图/PDM 教训): 流程态 draft/reviewing 不进条款停用分母; 分母 0 取 0(冷启动不误判)。

### 2.3 三面口径(15 端点)

| 面 | 端点 | 口径 |
|---|---|---|
| 决策面(4 POST) | 条款创建/发布/新版本/角色协议创建 | off 409 + agreementMode 标记 |
| **用户同意权豁免(1)** | **consent** | **永不关停**(签署条款是用户法律行为——大模型关闭不阻碍用户行权) |
| 观测面(6 GET) | 条款列表/详情/同意记录/角色协议/历史/统计 | 永不关停 |
| 控制面(4) | mode / override / guard(缺省实时聚合) / resume | admin 门禁 |

### 2.4 自动巡检(agreement_scheduler.py 新增 + main.py 挂载)

- AGREEMENT_GUARD_AUTO 默认 on, AGREEMENT_GUARD_INTERVAL 默认 3600s(最小 60s)
- 聚合源: agreement_repository list_agreements/list_consents/list_protocols(上限 1000)

### 2.5 鉴权优先(参数化装饰器, 第五次零改动复用)

- @_decision(admin=True 默认): X-Role 非 admin 放行函数体触发 403——403 优先于门控 409

## 三、工程记录(实施中发现并解决)

### 3.1 存量路由缺陷修复(检查期发现——本模块核心工程记录)

- **现象**: `GET /api/agreements/consents`、`GET /api/agreements/role-protocols`(及新增 mode 端点)返回 422 int_parsing
- **根因**: detail 路由 `GET /api/agreements/{agreement_id}`(int 路径参数)先注册——单段字面路径被其吞掉(FastAPI 路径参数验证 422 不再继续匹配)
- **修复**: detail 路由移至**全部单段字面路径(consents/role-protocols/mode 及控制面)之后**注册; 两段路径(stats/overview)不受影响
- **实证**: 修复后 consents/role-protocols/mode 全 200, 数字 id 详情 404 正常; 生产实机复验 200(存量缺陷生产修复)
- **沉淀**: 同前缀下 int 路径参数路由与单段字面路径共存时, 字面路径必须先注册; 存量测试未覆盖的字面路径调用是缺陷藏身处

### 3.2 仓储方法名(测试修正实录)

- 首版巡检造数用 `repo.create_agreement`——实际仓储为 `save_agreement`(全字段含 id)+`next_agreement_id`

## 六、回滚与运维

- **回滚命令**:
  `sed -i 's/^AGREEMENT_MODE=.*/AGREEMENT_MODE=off/' /opt/zhuxiang/.env && docker compose up -d backend`
- **运行时切档**(免容器重建):
  `POST /api/agreements/mode/override {"mode":"shadow"}`
